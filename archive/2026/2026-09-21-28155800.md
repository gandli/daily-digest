无需打开臃肿的 Xcode 窗口，直接在浏览器里以 60fps 运行全功能 iOS 虚拟设备！轻量级工具 baguette 正在成为 iOS 开发者与 AI Agent 研究者的新利器。

传统的 iOS 模拟器受限于图形界面与资源占用，难以做大规模多设备集群和自动化。baguette 则将整个设备模拟与交互环境搬到了 Web 控制台与无头管线中，核心亮点非常全面：

浏览器直连与多设备集群：只需终端执行 brew install baguette，即可在浏览器中同时管理与操作 iPhone、iPad Pro、Apple Watch 等多款设备，轻松搭建 Headless 多设备农场。

高帧率与完整手势支持：提供 60fps 实时推流，支持多指触控、滑动、双指缩放（Pinch）以及电源锁屏、Home 键等物理按键映射。

硬件级画面重定向：支持直接将本地电脑的摄像头（Webcam）实时流输入到模拟器的相机中，让测试扫码、拍照与图像识别变得极其简单。

AI Agent 原生集成：直接输出无障碍树（a11y tree）和实时系统日志（live os_log），AI 智能体可以精准解析页面节点并直接“上手”操作正在运行的 iOS App。

无论是用于移动端 UI 自动化测试、跨设备协同调试，还是构建能够自主操作手机的 Mobile AI Agent，这种免 Xcode 界面的 Web 方案都大幅降低了工程落地的门槛。

项目链接：https://github.com/tddworks/baguette
