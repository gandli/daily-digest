탭 열 개 켜던 리서치, 한 줄로 끝났다

깃허브 트렌딩 1위 찍고 별 5만9천개 넘게 받은 스킬이 있길래 뭐길래 싶어서 바로 깔아봤다. 명령어 한 줄 쳤더니 레딧, 트위터, 유튜브, 해커뉴스, 폴리마켓까지 동시에 뒤지고 오더라. 조사 하나에 이렇게까지 판을 벌이나 싶었는데 써보니 이유가 있었다.

이름은 last30days. 클로드 코드에 쓰는 스킬이라는 건데, 스킬이란 게 앱스토어에서 앱 깔듯 클로드한테 기능 하나 얹어주는 거라고 보면 된다. 이거 깔면 클로드가 /last30days라는 새 명령어를 쓸 수 있게 됨.

예전엔 뭐 하나 조사하려면 레딧 들어가서 검색하고, 트위터 켜서 또 검색하고, 유튜브 영상 자막 뒤지고... 탭 대여섯 개 켜놓고 왔다갔다 하다가 지쳐서 대충 정리하고 말았는데. 이제는 클로드한테 /last30days [주제] 딱 한 줄 치면 저 소스들을 한번에 다 훑고 와서 요약본 하나로 정리해 던져준다.

포인트는 그냥 검색해오는 게 아니라 사람들이 진짜 반응한 걸 점수 매긴다는 거다. 레딧 추천수, 트위터 좋아요, 유튜브 조회수는 물론이고 폴리마켓 배당률까지 긁어온다. 폴리마켓은 실제 돈 걸고 베팅하는 예측시장이라, 저기 나온 확률은 사람들이 입으로 하는 말이 아니라 지갑으로 보여주는 확신이다. README에 구글은 편집자를 모으고 이건 사람을 검색한다는 문장이 있던데, 이게 지금까지 본 도구 설명 중에 제일 와닿는 표현이었다.

설정 복잡할까 봐 걱정했는데, 레딧·해커뉴스·폴리마켓·깃허브는 깔자마자 바로 됨. 트위터·유튜브·틱톡·아카이브 논문 같은 건 설정 마법사 한 번 돌리면 30초 안에 풀린다고 한다. 그리고 클로드 코드 전용은 아니고 코덱스, 커서, 코파일럿, 제미나이 CLI 같은 데서도 쓸 수 있는 범용 스킬이더라. 다만 클로드 코드에서 마켓플레이스로 깔면 업데이트까지 알아서 되니까 그쪽이 제일 편했다.

검색창에 검색어 치는 거랑, 사람들이 실제로 뭘 누르고 뭘 걸었는지 뒤지는 거는 완전히 다른 답이 나온다.

개인적으로는 폴리마켓 배당률을 근거로 끌어온다는 부분이 제일 마음에 들었다. 여론조사나 댓글 반응보다 돈 걸어놓은 사람들 확률이 더 정직하다는 얘기를 어디서 들은 적 있는데, 그걸 자동으로 긁어와서 요약에 섞어준다는 거니까. 이거 하나로 리서치 습관이 좀 게을러질 것 같기도 하다.

혼자 사이드 프로젝트 하면서 트렌드나 반응 조사할 때 탭 열 개씩 켜놓고 헤맨 적 있는 사람, 그럴 때는 뭘로 정리했는지 궁금하다.

十个标签页的调研，一行命令就搞定

GitHub 趋势榜第一，收获超过5.9万个星标的那个技能，看起来挺牛的，就好奇它到底是什么，马上下载试了试。一敲一行命令，它就把 Reddit、Twitter、YouTube、Hacker News、Polymarket 全都同时搜了个遍。原本觉得一个调研要铺开这么大阵仗有点夸张，用过之后才明白有道理。

名字叫 last30days，是给 Claude Code 用的一个技能。所谓技能，就相当于在 App Store 里给 Claude 加装一个功能模块。用上它后，Claude 就能用 /last30days 这个新命令了。

以前查点什么，得打开 Reddit 搜一遍，又开 Twitter 再搜一遍，YouTube 视频字幕翻个遍……开了五六个标签页来回切换，累得要死，最后草草收场。现在呢？在 Claude 里敲一行 /last30days [主题]，它就把那些来源全扫一遍，整理成一份摘要扔给你。

关键点不是简单搜个东西，而是它会给人们的真实反应打分。Reddit 的推荐数、Twitter 的点赞、YouTube 的播放量当然少不了，连 Polymarket 的赔率都抓来了。Polymarket 是真金白银下注的预测市场，那里的概率不是人们嘴上说说的，而是用钱包投票的确定性。README 里有句话说 Google 是搜集编辑，而这个是搜集人，算是我见过的最打动人的工具描述。

本来担心设置会不会很麻烦，结果 Reddit、Hacker News、Polymarket、GitHub 都是装上就能用。Twitter、YouTube、TikTok、arXiv 论文这类需要跑一次设置向导，30秒内就搞定。而且它不局限于 Claude Code，在 Codex、Cursor、Copilot、Gemini CLI 这些地方也能用，是个通用技能。只不过从 Claude Code 的市场安装的话，更新都自动搞定，所以那边最省心。

在搜索框里敲关键词，和去挖人们实际点击了什么、下了什么注，完全是两种答案。

个人觉得最赞的是它会根据 Polymarket 赔率来拉数据。以前听人说过，比起民调或评论反应，那些真下钱的赌徒概率更诚实。这个工具能自动抓来混进摘要里。有了它，我的调研习惯怕是要变懒了。

一个人搞副业项目时，查趋势或反应开了十来个标签页迷路过的人，那时候你是怎么整理的？挺好奇的。
