Imagina poder conectar dos máquinas directamente con un simple token:

Sin cuenta de Tailscale.
Sin VPN.
Sin abrir puertos.
Sin root.
Sin configurar rutas ni DNS.

[Tailcat]

Reutiliza WireGuard + NAT traversal + DERP para crear un túnel cifrado entre dos máquinas.

Y luego puedes hacer cosas como:

→ Pasar datos entre equipos
→ Exponer puertos locales
→ Conectarte por SSH
→ Crear un SOCKS5 proxy
→ Actuar como exit node
→ Transferir archivos desde el navegador
→ Incluso usar tu propio relay DERP

Además, si NAT traversal funciona, Tailcat intenta convertir la conexión en P2P directo; si no, utiliza DERP como fallback.

Todo esto como un proyecto open source en Go.

**🌐 中文翻译**

想象一下能够用一个简单的令牌直接连接两台机器：

无需 Tailscale 账户。
无需 VPN。
无需开放端口。
无需 root 权限。
无需配置路由或 DNS。

[Tailcat]

重用 WireGuard + NAT 穿越 + DERP 来创建两台机器之间的加密隧道。

然后你就可以做像这样的操作：

→ 在设备间传递数据
→ 暴露本地端口
→ 通过 SSH 连接
→ 创建 SOCKS5 代理
→ 充当出口节点
→ 从浏览器传输文件
→ 甚至使用你自己的 DERP 中继

此外，如果 NAT 穿越成功，Tailcat 会尝试将连接转换为直接 P2P；如果不行，则使用 DERP 作为后备。

这一切作为一个用 Go 语言编写的开源项目。
