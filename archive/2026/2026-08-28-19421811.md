一张截图，直接变成可运行的 React / Vue 前端。

开源项目 screenshot-to-code 已经拿到 75.1K Stars。它不是把图片“临摹”成另一张图，而是把截图、Figma 设计稿，甚至网站操作录屏，转换成可继续修改的功能代码。

支持：

• HTML + Tailwind / CSS
• React + Tailwind
• Vue + Tailwind
• Bootstrap
• Ionic + Tailwind

对独立开发者和前端来说，最实用的场景是快速复刻页面、搭原型，再把时间留给交互和业务逻辑。

但本地部署并非零门槛：至少需要 OpenAI、Anthropic 或 Gemini 中的一种 API Key，并同时启动 React/Vite 前端和 FastAPI 后端；视频模式还必须使用 Gemini。
