**🌐 中文翻译**

🔴 研究人员 zeifan 宣布，他在 Windows 的 USB 打印机驱动程序 usbprint.sys 中发现了一个越界读取（OOB Read）漏洞。研究人员将该漏洞报告给了 Microsoft MSRC，但 Microsoft 决定不发布修复补丁。

攻击流程如下：

恶意 USB 设备连接到计算机 -> 将自身伪装为 USB 打印机 -> 延迟（STALL）IEEE-1284 身份请求 -> 发送特制（无 NUL 字符）的 USB 字符串描述符 -> usbprint.sys 处理数据 -> 内核 OOB Read -> Windows BSOD / DoS
