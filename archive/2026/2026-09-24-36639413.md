几十块钱淘来的闲置电视盒子，如何秒变 7×24 小时低功耗 Linux 个人服务器？强烈推荐收藏这个开源神作：amlogic-s9xxx-armbian。

很多朋友家里都有运营商送的魔百盒（如 CM311-1a、E900V22D）或者外贸盒子（如 X96 Max+），如果只是用来看电视难免卡顿吃灰。该项目基于 Debian/Ubuntu 深度优化，专门为这类 ARM 架构盒子注入新生：

🔹 芯片生态覆盖极广

不仅全面支持晶晨 Amlogic（S905 系列、S905X2/X3、S922X、A311D 等），还扩展兼容了瑞芯微 Rockchip（RK3588、RK3568、RK3399）和全志 Allwinner（H618、H6）等数十款主流芯片与板卡。

🔹 内置保姆级开箱运维工具

项目团队内置了一整套极简命令行工具，对新手极其友好：

armbian-ddbr：刷机前一键完整备份原厂 Android 系统，随时可回退，无惧变砖；

armbian-install：U 盘体验满意后，一键写入内部 eMMC，拔掉 U 盘直接独立开机；

armbian-update：轻松在线平滑更新或回退 Linux 内核；

armbian-software：一键安装 Docker、面板环境以及常用服务；

还配有 armbian-swap 扩充虚拟内存、armbian-openvfd 控制机身 LED 面板等实用命令。

🔹 云端与本地构建双支持

仓库不仅支持本地运行 ./rebuild 打包，还提供了完备的 GitHub Actions 工作流，没有高性能 Linux 编译机也能利用云端流水线打包专属固件。

日常待机功耗仅 2～5W，整年电费不过几块钱。挂载移动硬盘做轻量 NAS、部署 Home Assistant 智能家居中枢、跑 Docker 微服务或作为旁路由去广告，性价比直接拉满！
