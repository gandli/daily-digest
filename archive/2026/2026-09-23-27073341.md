Güvenlik araştırmacısı @Markak_, CVE-2026-80521 için container escape PoC demosu paylaştı. 

Açık upstream'de 6 Ağustos'ta düzeltildi; ancak araştırmacıya göre Ubuntu 26.04'ün ilgili kernel'inde henüz backport edilmemiş durumda.

Videoda ise, Ubuntu 26.04 (7.0.0-31-generic) çalışan bir container içinden exploit tetikleniyor. Payload birkaç pc-hijack denemesinden sonra container süreçleri yerine host süreçlerini listeliyor ve id çıktısı uid=0(root) dönüyor. Yani PoC, container izolasyonunu kırıp host'ta root alındığını canlı gösteriyor. Açık, Linux kernel'in AF_UNIX garbage collection mekanizmasındaki bir race condition / use-after-free'den kaynaklanıyor. 

Araştırmacı, CVE'yi dfs-large1 ile keşfettiğini, exploit'i ise GPT-5.6 Sol ile ürettiğini söylüyor.

Wite up: https://depthfirst.com/research/containers-are-no-longer-safe

**🌐 中文翻译**

安全研究人员 @Markak_ 分享了 CVE-2026-80521 的容器逃逸 PoC 演示。

该漏洞已在 upstream 中于 8 月 6 日修复；但据研究人员称，Ubuntu 26.04 的相关内核中尚未进行 backport。

视频中，在运行 Ubuntu 26.04 (7.0.0-31-generic) 的容器内触发了 exploit。Payload 在几次 pc-hijack 尝试后，列出了主机进程而非容器进程，并且 id 输出显示 uid=0(root)。也就是说，PoC 实时展示了打破容器隔离并在主机上获取 root 权限。该漏洞源于 Linux 内核 AF_UNIX 垃圾回收机制中的一个竞争条件 / use-after-free。

研究人员表示，他使用 dfs-large1 发现了 CVE，并使用 GPT-5.6 Sol 生成 exploit。
