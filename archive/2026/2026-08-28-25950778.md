我从以前就一直在关注这个，现在在 GitHub 上也变得非常受欢迎了呢。

一个能把代码库或系统说明直接转换成交互式架构图的工具。

Archify
https://github.com/tt-a1i/archify

可以直接在 Claude Code、Codex、Cursor 这样的 AI 代理中使用。

代理生成类型指定的 JSON 中间表示后，Archify 就会决定性地将其编译成 HTML/SVG，搞定。

支持架构、工作流、序列等多种图表类型，还能比较……支持各种功能，帮了大忙。

布局也由代理来判断，所有输出物都必须通过 schema 验证才能被认可为最终产物。
