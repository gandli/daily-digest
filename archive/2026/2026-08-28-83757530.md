A PoC/exploit has been discovered for vulnerability in Apache Log4j2.

Vendor: Apache
Product: Log4j2
Description: A deserialization flaw in Log4j2's FilteredObjectInputStream allows the deserialization filter to be bypassed using java.rmi.MarshalledObject. Its embedded payload is processed by a separate unfiltered ObjectInputStream, allowing attacker-controlled gadget chains to be deserialized. In applications that expose serialized LogEvent processing and have a compatible gadget library available, the issue can lead to remote code execution without authentication.
