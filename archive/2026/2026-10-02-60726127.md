🏝️ 如果你正打算尝试 TanStack Start 构建全栈应用，推荐看看开源全栈样板：Cove Stack（原名 TanStarter，GitHub 已收获 1.3k+ Star）。

它把目前现代前端与轻量全栈生态中最顺手的一套技术栈做了深度整合，非常适合用作全栈原型开发或轻量级 SaaS 起步模板：

🛠️ 核心技术栈亮点：

应用骨架：React + TanStack Start + TanStack Router + TanStack Query，拥抱类型安全路由与服务端函数。

构建与运行时：由 Vite Plus (vp) 与 Nitro 驱动，兼顾本地极速构建体验与多平台无缝部署（支持 Vercel、Netlify、Node 等）。

组件与样式：Tailwind CSS + shadcn/ui + Base UI，内置深浅色主题切换 Provider 与开箱即用的 UI 规范。

数据库与鉴权：Drizzle ORM + PostgreSQL，搭配开发体验优秀的 Better Auth，并附带了鉴权服务端中间件与 Schema 生成脚本。

现代工程化实践： • 引入 Varlock 通过 .env.schema 实现严格的环境变量类型生成与加载校验。 • 接入 evlog 统一输出标准结构化请求日志。 • 采用 Oxfmt 与 Oxlint 替换传统 ESLint/Prettier，代码检查速度大幅提升。 • 配套 Vitest 与 Playwright 测试骨架。
🚀 快速上手：终端直接运行即可交互式初始化： pnpm create cove
根据 .env.schema 完善配置后，依次执行 vpr env:load、vpr db generate 与 vpr dev 即可快速拉起本地开发服务。项目采用 Unlicense 协议完全开源，无论是个人学习还是商业二开都没有代码版权负担。
