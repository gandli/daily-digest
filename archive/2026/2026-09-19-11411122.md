If you need to run something elevated in a Remote Desktop session, eg AVD, you can't paste directly into the UAC "Run as Administrator" dialogue but you can paste into "Run as different user" dialogue (eg shift right click on pwsh.exe shortcut on desktop) & from there start elevated process via

start pwsh.exe (or powershell.exe) -verb runas

-passthru only used here for demo purposes

fltmc.exe used to prove when elevated

**🌐 中文翻译**

如果您需要在远程桌面会话中以提升权限运行某些内容，例如 AVD，您无法直接将内容粘贴到 UAC 的“以管理员身份运行”对话框中，但您可以将内容粘贴到“以其他用户身份运行”对话框中（例如，在桌面上右键单击 pwsh.exe 快捷方式并按住 Shift 键），然后从中通过以下方式启动提升权限的进程：

start pwsh.exe（或 powershell.exe）-verb runas

-passthru 在此仅用于演示目的

fltmc.exe 用于证明何时处于提升权限状态
