Shizuku Next: a new take on Shizuku for Android.

This fork adds some interesting improvements:

🔹automated Wireless Debugging pairing
🔹automatic service restart with a watchdog
🔹batch management of Shizuku permissions
🔹support for Wireless Debugging, USB, System and Root start methods
🔹a new Material 3 interface
🔹clearer device and service status information

The good part? Shizuku-compatible apps keep working, since the package name and API remain unchanged.

One important detail: Shizuku Next uses its own signing key, so you need to uninstall the original Shizuku or another fork before installing it.
