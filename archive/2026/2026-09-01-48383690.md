**🌐 中文翻译**

在 Windows 上反汇编一个程序仍然意味着你得坐在调试器前几个小时：一个充满汇编代码的窗口，按 F7、F8，然后盯着看哪一行出了怪事。

x64dbg 就是那个工具。逆向工程师、恶意软件分析师或有权限审计软件的人都在用它。

现在有个插件能让 Claude 或 Codex 动手操作。它叫 x64dbg-mcp-server。模型并不“理解”程序。它替你按按钮：设置断点、读取内存、查看寄存器、寻找入口点。

84 个命令。用 Zig 写的。没有 Python 中间层。

不变的是：总得有人决定在哪儿停下来。如果你让模型“找出把戏”，它会瞎设置断点。

还有个严肃的注意事项：这玩意儿用明文 HTTP 通信，能读写活进程的内存。你在 localhost 上启动它，用 token 保护。如果你把它公开到网络上，就等于把那台机器的控制权送给任何人了。

只用于你有权打开的程序。
