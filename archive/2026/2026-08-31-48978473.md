This open-source project makes AI code review free by letting you run your own reviewer on GitHub 🔥

Most AI code review tools charge you for every repository, PR, or review.

This takes a different approach.

Connect your GitHub repo, and it automatically reviews pull requests, understands the repository context, and posts findings directly inside the PR.

You can run the whole thing yourself and bring your own model.

No separate code review SaaS. No per-review bill.

What you get:

> Automatic reviews on new and updated PRs
> Inline comments + review summaries
> Open-source model support
> Per-repository review rules
> Custom skipped paths and triggers
> Model chains and fallbacks
> Self-hosted infrastructure
> Review history and job monitoring

It’s still in beta, but the idea is simple:

Your code. Your models. Your code reviewer.

这个开源项目通过让你在 GitHub 上运行自己的审查工具，使 AI 代码审查变得免费 🔥

大多数 AI 代码审查工具会为每个仓库、PR 或审查向你收费。

这个项目采用了不同的方法。

连接你的 GitHub 仓库，它会自动审查拉取请求，理解仓库上下文，并在 PR 内直接发布发现结果。

你可以自己运行整个系统，并使用自己的模型。

无需单独的代码审查 SaaS 服务。无需按审查计费。

你将获得：

> 对新 PR 和更新 PR 的自动审查
> 行内评论 + 审查摘要
> 开源模型支持
> 按仓库的审查规则
> 自定义跳过路径和触发器
> 模型链和备用方案
> 自托管基础设施
> 审查历史和任务监控

它仍处于 beta 阶段，但理念很简单：

你的代码。你的模型。你的代码审查工具。
