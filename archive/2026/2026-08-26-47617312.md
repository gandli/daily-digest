《Dictata：本地 Whisper 听写 + LLM 清理》

Dictata：本地 Whisper 听写 + LLM 清理

100% 本地的系统级语音听写工具，适用于 Windows，原生 Rust 编写。按一下全局热键，说话，再按一下：文本在本地转录，粘贴进当前活动应用。数据永远不会离开这台机器。转录运行在多后端 Dictata Engine https://github.com/AntoineChatry/DictataEngine 上——默认用 whisper.cpp https://github.com/ggerganov/whisper.cpp，可选 ONNX 后端（Parakeet、SenseVoice、Moonshine、Zipformer）。

当前版本：v0.1.0——见 CHANGELOG.md CHANGELOG.md。

功能特性

• 热键听写（切换或按住说话），自动粘贴进当前活动应用，浮动 dock 带波形（大小、不透明度、位置可配置）。
• 连续模式（流式）：边说边插入文本，在每个检测到的停顿处输出。
• 静音跳过（VAD）：非流式听写可选 whisper.cpp 的语音活动检测——更少的算力，静音处更少的幻觉。首次使用下载一个小（约 2 MB）模型；在配置中开关。
• Vulkan GPU 转录（AMD/Intel/NVIDIA）或 CPU——whisper-rs 带 vulkan feature。
• 多后端引擎：默认 whisper.cpp；可选 ONNX 后端（NVIDIA Parakeet、SenseVoice、Moonshine、Zipformer），每个通过 Cargo feature 在构建时启用。后端根据所选模型的形状自动挑选（ggml .bin 文件 → whisper，ONNX bundle 目录 → 对应后端）。
• 音频来源：麦克风、系统音频（WASAPI 环回）或两者混合（会议模式）。
• 输出模式：原始，或通过本地 OpenAI 兼容 LLM 后处理（清理、邮件、消息、清单……），提示词可自定义。
• 转录文件（音频/视频，历史页面）——ffmpeg 处理的任何格式。
• 自定义词汇和替换，作为初始提示注入。
• 内置 ggml 模型库：下载、删除，以及硬件感知推荐（Vulkan 下检测 GPU/VRAM，否则 CPU/RAM）。
• 推荐的 ONNX 模型：一键验证过的 bundle（Parakeet、SenseVoice、Zipformer、Moonshine），在 Models 页面，紧挨 ggml 目录。
• HuggingFace 搜索：从直接 URL、仓库（owner/name）或关键词搜索安装任意 ggml .bin 模型或 ONNX bundle。
• fr / en / es 界面，深色主题，系统托盘图标，转录历史。

系统要求

• Windows 10/11。本版本不支持 Linux——见 LINUX.md LINUX.md 了解哪些能用、哪些不能、为什么。
• ffmpeg https://ffmpeg.org/ 在 PATH 中（仅"转录文件"需要）。
• 构建 GPU 支持需要：Vulkan SDK https://vulkan.lunarg.com/ 和 Visual Studio Build Tools（含 CMake + Ninja）。

构建

cargo build --release

构建细节：

• MAX_PATH 变通（Windows）：whisper.cpp 的 vulkan-shaders-gen 子项目可能超过 Windows MAX_PATH 限制（260 字符），导致 MSBuild 失败（FTK1011/C1083）。如果发生，创建一个本地（不跟踪的）.cargo/config.toml，把构建指向驱动器根目录的短路径：

    [build]
  target-dir = "C:/wt"   # 任意短路径

  可执行文件和它的 config.json 随后位于 <target-dir>\<profile>\。
• cargo clean 之后，在带 Ninja 生成器的 Visual Studio 环境里重建：

VsDevCmd.bat -arch=amd64 && set CMAKE_GENERATOR=Ninja && set CMAKE_GENERATOR_INSTANCE= && set VULKAN_SDK=<SDK path> && cargo build

纯 CPU 构建（不需要 Vulkan SDK）：

cargo build --release --no-default-features --features whisper

whisper 是转录后端：--no-default-features 会去掉 vulkan（引入它的正是这个），所以必须显式重新启用，否则二进制没有后端、无法转录。

转录后端（可选）

ONNX 后端默认关闭——原装构建只带 whisper.cpp。构建时启用一个（或几个）；每个都通过 ort 静态链接 onnxruntime，所以可执行文件旁边不会多出额外 DLL：

cargo build --release --features parakeet      # NVIDIA Parakeet（GPU 加 parakeet-directml）
cargo build --release --features sensevoice    # SenseVoice CTC
cargo build --release --features moonshine     # Moonshine
cargo build --release --features zipformer     # Zipformer transducer

全部后端一起（GPU whisper + 每个 ONNX 后端）：

cargo build --release --features "vulkan,parakeet-directml,sensevoice,moonshine,zipformer,vad"

与 vulkan（默认）组合，可以在 ONNX 后端之外保留 GPU whisper，例如 --features "vulkan,parakeet-directml"。

打包发布

powershell -ExecutionPolicy Bypass -File scripts\release-windows.ps1 -Variant both

运行测试、构建，写出 dist\dictata-<version>-windows-x86_64[-cpu].zip 及 SHA-256。zip 只含 dictata.exe、README.md、LICENSE 和 CHANGELOG.md：不附带 config.json（应用首次运行时自己写默认值，开发用的 config.json 携带个人数据）。二进制自包含——旁边不需要任何 DLL；Vulkan 构建使用显卡驱动提供的 loader。

可执行文件携带图标和版本元数据，由 http://build.rs 通过 winresource 嵌入。图标本身由一个脚本绘制，而不是作为不透明 blob 检入——改数字就能一次性重新生成所有尺寸：

powershell -ExecutionPolicy Bypass -File scripts\make-icon.ps1

scripts/release-linux.sh 镜像了打包脚本，但从未运行过——见 LINUX.md LINUX.md。

用法

1. 启动可执行文件：应用住在系统托盘。
2. 打开设置（托盘菜单，或启动时设置 DICTATA_OPEN_SETTINGS=1 环境变量）：在 Models 页面选一个模型（内置下载），设置热键、语言和音频来源。
3. 把光标放到想写的位置，按热键（默认 Ctrl+Alt+Space），说话，再按一次。按住 Esc 约半秒取消当前这次——Esc 是全局读取的，普通单按会留给正在输入的应用。

配置从可执行文件旁边的 config.json 读取，或从 DICTATA_HOME 环境变量指向的目录读取。文件必须是 UTF-8 无 BOM。

GPU：gpu 配置字段——"auto"（默认，可用时用 Vulkan）、"cpu"、"vulkan"、"cuda"。

架构

• http://main.rs：编排——状态、热键、dock、转录线程
• http://audio.rs：cpal 采集（麦克风 / 环回 / 混音）、16 kHz 重采样、ffmpeg 解码
• http://transcriber.rs：ASR 引擎之上的门面（后端按模型形状挑选）
• engine/：多后端 ASR 引擎——AsrEngine trait、EngineKind::detect、各后端（whisper、Parakeet、SenseVoice、Moonshine、Zipformer）
• http://streaming.rs：连续模式——按停顿分块、渐进输出
• http://settings.rs：设置窗口（8 页，egui）——表现层
• settings_logic.rs：设置业务逻辑，无 UI 也可测试
• http://dock.rs：浮动 dock（波形、状态）
• http://modes.rs / http://llm.rs：输出模式和本地 LLM 后处理
• http://models.rs：ggml + ONNX 目录、下载/删除（文件和 bundle）、HuggingFace 搜索、路径
• http://i18n.rs：fr/en/es 翻译（tr()）
• http://config.rs / http://history.rs / http://paste.rs / http://hotkey.rs / http://tray.rs / http://hardware.rs / http://platform.rs：配置、历史、粘贴、全局热键、托盘、硬件检测、Windows 集成
