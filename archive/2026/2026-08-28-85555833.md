If you’ve ever sent Hermes to do something on the web and watched it immediately hit a login screen, this is a very useful update.

Hermes can now use a copy of your existing browser profile.

Turn on Use My Real Browser Profile and Hermes copies the active profile from your default Chrome, Edge, Brave, or Chromium browser into its own managed browser snapshot.

That can bring over your cookies, saved logins, and preferences. So when Hermes opens the sites you already use, it can arrive with the same logged-in access you already have.

Your live browser profile stays separate. Hermes drives the copied snapshot, not the profile you’re actively browsing with.

The practical difference:

→ Less stopping to log into websites
→ Less rebuilding browser sessions
→ Hermes can actually work inside the accounts and tools you already use

For a browser agent, this removes one of the most common points of friction.

如果你曾经让赫尔墨斯在网上执行某项任务，却眼睁睁看着它立刻撞上登录页面，那么这是一个非常有用的更新。

赫尔墨斯现在可以使用你现有浏览器配置文件的副本。

开启“使用我的真实浏览器配置文件”选项，赫尔墨斯就会将你默认 Chrome、Edge、Brave 或 Chromium 浏览器的活动配置文件复制到它自己管理的浏览器快照中。

这样就能带上你的 Cookie、保存的登录信息和偏好设置。所以当赫尔墨斯打开你已经使用的网站时，它就能带着你已有的登录访问权限直接进入。

你实时的浏览器配置文件保持独立。赫尔墨斯驱动的是复制的快照，而不是你正在积极浏览的那个配置文件。

实际区别：

→ 减少登录网站的停顿
→ 减少重建浏览器会话
→ 赫尔墨斯实际上能在你已有的账户和工具中工作

对于浏览器代理来说，这消除了最常见的摩擦点之一。
