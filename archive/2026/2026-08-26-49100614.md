Developers is paying Mapbox $5 for every 1,000 map load. One guy is giving the same thing away unlimited.

It's called OpenFreeMap.

Free map hosting built on OpenStreetMap data. No limits on views. No registration. No API key. No cookies.

Here's whats crazy about it:

→ Unlimited map views and request on the public instance
→ Full planet download every week in MBTiles and Btrfs form
→ Built on OpenMapTiles, Planetiler, MapLibre and Wikidata
→ Custom style ready to drop into you're site
→ Deployment tooling that provision clean Ubuntu servers over SSH
→ The entire production stack is open — no open-core holdback

And the engineering is insane. There is no tile server at all. Just nginx serving a Btrfs image containing 300 million hard-linked file on dedicated hardware.

Mapbox charge $5 per 1,000 web map loads after the free tier. Every time your map initialize, that counter tick up.

This one cost nothing. MIT licensed.

One developer is out-engineering a billion dollar company and asking for coffee money.

开发者为 Mapbox 每 1000 次地图加载支付 5 美元。一个家伙却无限量免费提供同样的东西。

基于 OpenStreetMap 数据的免费地图托管。无浏览量限制。无需注册。无需 API 密钥。无 Cookie。

以下是它疯狂的地方：

→ 公共实例上无限地图浏览和请求
→ 每周完整星球数据下载，以 MBTiles 和 Btrfs 格式
→ 基于 OpenMapTiles、Planetiler、MapLibre 和 Wikidata 构建
→ 自定义样式，随时可丢入你的网站
→ 部署工具，通过 SSH 提供干净的 Ubuntu 服务器
→ 整个生产栈开源——无开源核心限制

而且工程技术令人疯狂。根本没有瓦片服务器。只是 nginx 提供一个 Btrfs 镜像，包含 3 亿个硬链接文件，运行在专用硬件上。

Mapbox 在免费额度后，每 1000 次网页地图加载收费 5 美元。每次你的地图初始化，那个计数器就会跳一下。

这个却完全免费。MIT 许可。
