《AI Agents - The Definitive Guide》这本关于 Agent 开发指南的开源书籍，值得一看。

作者把配套代码整个开源了，12 章内容对应 35 个 notebook，按章节分好目录。

从思维链、思维树、ReAct 讲到多 Agent 分工协作，Agent 记忆、评测、成本核算这些生产阶段的主题也各有实操代码。

GitHub：http://github.com/Nicolepcx/ai-agents-the-definitive-guide

每个 notebook 都带 Colab 链接，浏览器点开就能跑，本地什么环境都不用装。

翻目录时留意到，最后一章专门讲给 Agent 做威胁建模，这个主题在入门教程里少见。

正在做 Agent 开发的朋友可以按主题挑着学习，书没买也不影响把代码过一遍。
