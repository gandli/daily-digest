9 GitHub repos for Claude Code that will 10x your next project:

Bookmark this.

1. Superpowers

An agentic skills framework and a full software development methodology in one.

It hands Claude a repeatable way to plan, build, and ship instead of one-off prompts. The skills carry across a project instead of resetting every session.

https://github.com/obra/superpowers

2. Awesome Claude Code

A curated map of the whole ecosystem.

Skills, agents, status lines, hooks, plugins, and tooling, hand-picked in one place. Check here before you build anything custom, because someone already shipped half of what you need.

https://github.com/hesreallyhim/awesome-claude-code

3. GSD (Get Shit Done)

Meta-prompting and spec-driven development in a lightweight package.

You write the spec, it builds the context, and Claude works against a plan instead of vibes. The closest thing to giving your agent a project manager.

https://github.com/gsd-build/get-shit-done

4. Claude Mem

Persistent memory across every session.

It captures what the agent did, compresses it, and feeds the relevant slice back into future runs. The agent stops relearning your codebase every morning. Works with Codex, Gemini, and Copilot too.

https://github.com/thedotmack/claude-mem

5. UI UX Pro Max

Design intelligence bolted onto the agent.

It gives Claude a real sense of layout, hierarchy, and platform conventions, so the output stops looking like a wireframe someone forgot to finish. Worth it if you ship frontends.

https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

6. n8n-MCP

Turns Claude into an automation builder.

Describe the workflow in plain English and it wires up the n8n nodes for you, across Claude Code, Desktop, Cursor, or Windsurf.

https://github.com/czlonkowski/n8n-mcp

7. Obsidian Skills

Teaches the agent to use your vault.

Markdown, Bases, JSON Canvas, and the Obsidian CLI all become native tools. Your second brain stops being read-only storage and starts being live context the agent reasons over.

https://github.com/kepano/obsidian-skills

8. LightRAG

Simple and fast retrieval-augmented generation.

Graph-based retrieval that traverses how entities relate instead of flat vector similarity. Cleaner context in, fewer hallucinations out, and light enough to run without a heavy stack.

https://github.com/hkuds/lightrag

9. Everything Claude Code

A full harness performance optimization system.

Skills, instincts, memory, security, and research-first development in one setup. Less a plugin, more a complete operating layer for how your agent works. Runs on Codex, Opencode, and Cursor too.

https://github.com/affaan-m/everything-claude-code

整个生态系统的精选地图。

每个会话的持久记忆。

将 Claude 变成自动化构建器。
