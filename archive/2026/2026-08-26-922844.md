tunneru is here: a zero-dependency tunneling engine and self-hosted ngrok alternative written in go from scratch.

in simpler words: expose localhost to the public internet instantly for webhook testing (like stripe or github) with zero accounts, a custom 9-byte binary multiplexer, and real-time request inspection.

details on how to use available on the docs section of the website and the github readme :D
