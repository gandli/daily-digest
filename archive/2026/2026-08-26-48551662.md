Your X bookmarks are only useful if you can find them again.

Siftly is a self-hosted X bookmark manager for people who want to organize and revisit saved posts without moving their bookmark data to the cloud.

It helps you turn a pile of saved posts into a searchable, categorized knowledge base by importing bookmarks and running entity extraction, vision analysis, semantic tagging, and categorization.

Key features:

• Local-first storage – bookmark data is stored in a local SQLite file on your machine
• Built-in import – export bookmarks through a bookmarklet or browser-console script, then upload the file
• AI search – search across tweet text, image OCR, visual tags, semantic tags, and categories
• Interactive mindmap – explore bookmarks visually by category and open the original post from a node
• Export formats – download data as CSV, JSON, or a ZIP with a category’s bookmarks and media

It’s open-source (MIT license).

**🌐 中文翻译**

你的 X 书签只有在你能再次找到它们时才有用。

Siftly 是一个自托管的 X 书签管理器，专为那些希望组织和重访保存的帖子，而无需将书签数据移至云端的人设计。

它通过导入书签并运行实体提取、视觉分析、语义标记和分类，帮助你将一堆保存的帖子转化为一个可搜索的、分类的知识库。

主要功能：

• 本地优先存储 – 书签数据存储在你机器上的本地 SQLite 文件中
• 内置导入 – 通过书签小工具或浏览器控制台脚本导出书签，然后上传文件
• AI 搜索 – 搜索推文文本、图像 OCR、视觉标签、语义标签和类别
• 交互式思维导图 – 通过类别视觉化探索书签，并从节点打开原始帖子
• 导出格式 – 以 CSV、JSON 或 ZIP 格式下载数据，包括某个类别的书签和媒体

它是开源的（MIT 许可证）。
