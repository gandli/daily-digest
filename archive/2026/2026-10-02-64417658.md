#开源推荐 gh-aw（GitHub Agentic Workflows） 是 GitHub 开源的 AI 仓库自动化项目，让 AI 代理通过 GitHub Actions 处理 Issue 分类、PR 审查、CI 失败排查、文档维护和仓库报告等任务，为现有 CI/CD 补充理解上下文与推理判断的能力。开发者在 Markdown 正文中描述任务目标，在 YAML 文件头中配置触发条件、权限、工具和 AI 引擎，再通过 gh aw compile 生成标准 Actions 工作流；工作流运行时，由所选 AI 引擎理解指令并调用工具完成任务。目前内置支持 GitHub Copilot、Claude Code、OpenAI Codex、Google Gemini 和 Pi，默认使用 Copilot。为控制自动化操作的影响范围，代理默认在沙盒中运行，并使用只读 GitHub 权限；发表评论、创建 Issue 或 PR 等已配置的写入请求，通常通过 safe-outputs 机制校验，再由具有指定权限的独立任务执行，将 AI 的任务处理与对仓库的实际写入分开管理。
https://github.com/github/gh-aw
