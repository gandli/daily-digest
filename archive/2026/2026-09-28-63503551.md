重装 Windows 最崩溃的部分，微软替你写了个脚本。

重装系统最难受的是，Git、Python、VS Code、WSL……又得一个个装回来。

微软现在做了个开源项目 Windows Developer Config，可以把这套流程一次跑完。给经常重装电脑、换电脑写代码的人，省事不少。

用法很简单：在 Windows 11 打开 PowerShell，先保存手头的工作，再运行标准版：

irm https://aka.ms/devconfig/standard/setup.ps1 | iex

然后会安装 Windows Terminal、PowerShell 7、Git、VS Code、Python、Node.js、PowerToys 等工具，配置终端和部分系统选项，还会装上 WSL 与 Ubuntu。

运行中会请求管理员权限；装 WSL 时电脑会重启一次。重新登录后，按提示再确认一次权限，等它跑完。最后从开始菜单打开 Ubuntu，自己设置 Linux 用户名和密码，就基本齐了。

项目及完整改动清单： https://github.com/microsoft/WindowsDeveloperConfig
