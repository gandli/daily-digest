如果你厌倦了网站看起来像“氛围编码”风格，这里有 15 个你需要的 UI 资源。

1 - http://ui-skills.com - 为人类和编码代理设计的 playbook。可用于审计 UI、修复通用 AI 设计、改进动态效果、无障碍性和抛光。

2 - http://coss.com/ui - 一个 http://Cal.com 的生产就绪设计系统。你拥有的可访问 React 组件。非常适合构建真实产品 UI，而不会出现通常的 SaaS 外观。

3 - http://designsystemchecklist.com - 这是一个实用的设计系统检查清单，能阻止代理创建随机的 UI 风格。

4 - http://reui.io/components -
1,000+ 免费 shadcn 组件，以及高级模式如数据网格、看板、甘特图、过滤器和日历。非常适合复杂产品界面。

5 - http://kinetics.colorion.co - 使用 CSS、React 和 AI 提示的现成弹簧动画。

6 - http://iconcreator.dev - 免费的基于浏览器的自定义图标设计器。

7 - http://vibeprompts.dev - 针对特定 UI 部分的 256 个提示，如仪表板、定价、认证、入门引导和英雄部分。给代理一个具体的布局目标，而不是“让它看起来好看”。

8 - http://animatedbuttons.colorion.co - 99 个仅用 CSS 的按钮交互。只需复制 CSS 或提示。适合保持产品中交互的一致性。

9 - http://component.gallery - 来自 95 个真实设计系统的 2,600+ 示例。

10 - http://designsystems.one -88 个生产设计系统，包含令牌、堆栈和可下载的设计(.)md 文件。

11 - http://utopia.fyi - 生成流畅的排版和间距。

12 - http://open-props.style - 现成的设计令牌，用于颜色、阴影、圆角、间距、缓动等。阻止代理到处发明随机值。

13 - http://interfaces.rauno.me - 让界面感觉完成的微小交互细节检查清单。

14 - http://bg.ibelick.com - Tailwind 和 CSS 的复制粘贴背景。

15 - http://motion-primitives.com - React 的可重用动态组件。
