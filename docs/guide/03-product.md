## /product — 今日 HN 酷产品

本命令用于查看 Hacker News 当日精选酷产品卡片(含封面图与摘要链接)。Bot 直接读取 archive 分支预生成的 JSON,秒回产品卡;若当日尚未生成,则自动触发 GitHub Actions 工作流,并提示预计耗时,完成后由用户主动再发起请求获取结果。

### 步骤 1: 发送命令

在 Bot 对话框中输入命令触发词 **`/hn`**,然后发送。

### 步骤 2: 查看 Bot 首次响应

若 archive 分支已有当日 JSON,Bot 会立即返回一张产品卡(包含标题、摘要、OG 封面图与跳转链接)。若数据尚未生成,Bot 会回复一条进度提示,告诉你内容正在生成中,预计 2-5 分钟完成,完成后会自动推送。

![首次发送 /hn,Bot 回复生成进度提示](assets/03-product-r1.png)

> 当前 e2e 测试记录中,首次与第二次发送均命中「未生成」分支,Bot 两次都返回了进度提示,说明该事务在测试时段始终走 repository_dispatch 触发 Actions 的路径。

### 步骤 3: 等待 Actions 触发完成

收到进度提示后,无需任何额外操作。Bot 在后台已通过 `repository_dispatch` 事件唤起 GitHub Actions 工作流,工作流会抓取 Hacker News 当日热门内容、渲染 OG 图,并把最终 JSON 提交至 archive 分支,作为下次查询的缓存。整个过程通常耗时 2-5 分钟,可通过 GitHub 仓库 Actions 标签页查看运行状态。

### 步骤 4: 重新发送命令获取结果

等待 2-5 分钟后,在同一对话中再次发送 **`/hn`**,Bot 此时会从 archive 分支读取已就绪的 JSON,并立即返回今日酷产品卡(含 OG 图)。

![再次发送 /hn,Bot 回复生成进度提示(等待中)](assets/03-product-r2.png)

> 若第二次仍返回进度提示,说明 Actions 任务尚未跑完,请再等待片刻后重试,直到看到产品卡为止。

### 步骤 5: 阅读与跳转

收到产品卡后,可直接点击卡片中的标题或「查看原文」链接跳转至 Hacker News 原帖,也可以长按 OG 封面图保存本地。Bot 单次只返回一张卡片,若想浏览更多,可等待次日再发送 `/hn`,或通过其他相关命令切换类别。

### 小贴士

- 首次发送 `/hn` 若只看到 ⏳ 进度提示,请务必再发一次命令拉取结果,Bot 不会主动把卡片推到你的对话里。
- Actions 生成依赖 Hacker News 当日上榜情况,周末或节假日热门帖较少时,生成时间可能略长于 5 分钟,属正常现象。
- 若连续多次发送均停留在 ⏳ 提示且超过 10 分钟未拿到卡片,可前往对应 GitHub 仓库检查 Actions 运行日志,排查是否触发失败。
