### 步骤 1：发送 /product 命令

在任意与 Bot 对话的私聊或群组中，输入并发送：

```
/product
```

Bot 在收到指令后会先尝试从 archive 分支读取当日的 JSON 数据。如果你看到下面的提示，说明本地缓存中没有今日产品，需要等待异步生成。

> ⏳ 今日 HN 酷产品生成中(约 2-5 分钟), 完成后自动推送。

此时 Bot 内部已经通过 `repository_dispatch` 事件触发了 GitHub Actions 工作流，工作流会抓取 Hacker News 当日的热门产品帖子并写入 archive 分支。**你不需要做任何额外操作**，只需保持当前对话窗口打开即可。

![首次发送 /product, Bot 提示生成中](assets/03-product-r1.png)

### 步骤 2：等待生成完成（可继续使用 Bot）

生成通常需要 2-5 分钟，期间你可以正常使用 Bot 的其他命令，也可以直接在当前聊天里再次发送 `/product` 来主动拉取结果。

需要说明的是：

- 如果生成尚未完成，重复发送仍会得到步骤 1 中的“生成中”提示。
- 完成后无需你再次发送，Bot 会主动把产品卡推送到当前对话。
- 如果超过 10 分钟仍未收到推送，可稍后再发一次 `/product` 拉取。

### 步骤 3：查看推送的产品卡

当 Actions 完成数据写入后，Bot 会自动把当日的酷产品卡片推送出来，内容包括日期、产品名称、作者、发布时间、简介以及原始讨论链接，消息中还会附带该产品的 Open Graph 预览图，便于一眼判断是否符合兴趣。

例如某次推送的内容如下：

> 🚀 2026-08-29 Linear — 快得离谱的项目管理工具 👤 by karpathy · about 3 hours ago 📝 一款以速度著称的产品规划与 issue 跟踪工具。 💬 "Linear

卡片中通常以引用块形式展示一段社区高赞评论，帮你快速了解产品的亮点与争议。点击消息中的链接即可跳转到 Hacker News 原帖参与讨论。

![重复 /product 后 Bot 推送产品卡](assets/03-product-r2.png)

### 步骤 4：继续浏览或换日重试

阅读完卡片后，你可以：

- 点击文中的链接查看 HN 原帖或产品官网。
- 第二天再次发送 `/product` 获取新一天的产品推荐。
- 在群组中 @ 同事或转发卡片分享给感兴趣的人。

## 小贴士

- 首次发送后看到“生成中”提示属正常现象，不必重复刷新或重启 Bot，耐心等待 Actions 完成即可。
- 若群组中消息较多，建议把 Bot 消息置顶，或在发送 `/product` 前先确认当前日期，避免错过推送。
- archive 分支的历史数据会保留过往每日推荐，想回顾往期产品可在 GitHub 仓库的 archive 分支下查找对应日期的 JSON 文件。
