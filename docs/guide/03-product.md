## /product — 今日 HN 酷产品

通过本指令,Bot 会从 archive 分支读取预先生成的产品卡数据并即时返回,卡片中包含 Open Graph 预览图;若当天尚未抓取到任何条目,Bot 将自动触发 GitHub Actions 抓取任务,你只需稍候即可收到推送,无需反复重试。

### 步骤 1:发送指令

在 Bot 对话窗口中输入 `/hn` 并发送。这是触发现日 Hacker News 酷产品推送的唯一入口,无需附带任何参数。

### 步骤 2:等待首次响应

Bot 在收到指令后立即返回一条提示消息,告知你今日产品卡正在生成中,预计耗时 2 至 5 分钟,完成后会自动推送到当前对话。

![首次发送 /hn 后收到的生成提示](assets/03-product-r1.png)

此时,你只需保持对话窗口打开,无需执行其他操作。

### 步骤 3:等待产品卡推送

Bot 会在 Actions 工作流完成后,将当日的酷产品卡片主动推送给你。卡片以图文形式呈现,包含产品标题、简介、原始链接以及对应的 OG 预览图,直接点击链接即可跳转到 Hacker News 原文。

### 步骤 4:若未收到推送可再次发起

若 5 分钟后仍未收到任何产品卡消息,说明首次触发可能因网络或调度原因未生效,你可以在对话中再次发送 `/hn` 进行重试。

Bot 会再次返回生成提示,表示新一轮抓取任务已重新入队。

![重复发送 /hn 时再次收到的生成提示](assets/03-product-r2.png)

### 步骤 5:接收最终推送

无论你是首次发送还是重复发送,只要 Actions 工作流顺利执行完成,Bot 都会将当日的酷产品卡推送到当前会话。重复发送 `/hn` 不会产生重复的产品卡推送,而是作为兜底机制,确保即便首次触发失败也能最终送达。

### 小贴士

- **保持会话窗口在前台运行**:Bot 的产品卡推送基于当前会话,关闭或退出对话窗口可能导致推送消息无法及时送达。
- **避免短时间内多次重试**:每次发送 `/hn` 都会触发一次 Actions 运行,反复发送只会增加队列等待时间,通常一次重试即可。
- **网络异常时可稍候再试**:若 GitHub Actions 端偶发故障,可在数分钟后再次发送 `/hn`,archive 分支中已有缓存数据时会直接返回,体验更迅速。
