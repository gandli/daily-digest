### /product — 今日 HN 酷产品

通过 `/product` 命令，Bot 会从 Hacker News 当日热门中精选一款产品，并以精美卡片(含 OG 图、标题、作者、发布时间与简介)秒级回推给用户。

---

### 步骤 1：发送命令

在任意与 Bot 的私聊或群聊中，发送：

```
/product
```

Bot 收到请求后，会先尝试从 GitHub archive 分支读取当日的精选产品 JSON。如果命中缓存，Bot 将**秒回**一张产品卡(包含 Open Graph 配图、标题、作者、发布时间和一句话简介)。

### 步骤 2：等待首次反馈

如果当前 archive 分支尚无当日数据，Bot 会立刻回执一条提示消息，告诉用户内容正在生成中：

> ⏳ 今日 HN 酷产品生成中(约 2-5 分钟), 完成后自动推送。

同时，Bot 在后台通过 `repository_dispatch` 事件触发 GitHub Actions 工作流，去抓取 HN 热门、筛选并渲染产品卡写入 archive 分支。你不需要重复发送命令，也无需守在屏幕前——产品生成完成后，Bot 会**主动推送**到当前对话窗口。

![首次发送 /product 后 Bot 返回生成中提示](assets/03-product-r1.png)

### 步骤 3：接收产品卡推送

等待 2-5 分钟后(实际取决于 Actions 队列与 HN 数据抓取耗时)，Bot 会将当日精选产品卡自动推送到对话中。卡片样式示例如下：

> 🚀 2026-08-29 **Linear** — 快得离谱的项目管理工具
> 👤 by karpathy · about 3 hours ago
> 📝 一款以速度著称的产品规划与 issue 跟踪工具。
> 💬 "Linear …"

卡片左侧或顶部会附上从产品官网抓取的 OG 图，标题、发布日期、作者、简介一目了然。

![Bot 自动推送当日 HN 酷产品卡](assets/03-product-r2.png)

### 步骤 4(可选)：重新拉取

若你错过了自动推送，或想再次查看今日产品，再次发送 `/product` 即可。此时 archive 分支已存在数据，Bot 会直接秒回产品卡，而不再走生成流程。

---

### 小贴士

- **耐心等待自动推送**：第一次返回「生成中」提示后，**不要反复发送** `/product`，否则会在 Actions 队列中堆积重复任务，延长生成时间。
- **可订阅每日定时推送**：将 `/product` 加入群聊的定时任务或配合其他命令(如 `/subscribe`)，即可每天固定时间收到今日酷产品。
- **关注 archive 分支**：所有历史产品卡都保存在 GitHub 仓库的 archive 分支中，可直接通过浏览器翻阅往期精选。
