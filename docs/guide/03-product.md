### 步骤 1: 发送指令

在 Telegram 对话窗口中输入以下指令并发送:

```
/product
```

Bot 接收到指令后,会立即判断当日是否已有缓存的产品卡片。如果已有数据,会直接以秒回的形式推送产品卡片;如果没有当日数据,则会触发 GitHub Actions 工作流,先生成数据,生成完成后再向你推送。整体等待时间在数十秒到数分钟之间。

### 步骤 2: 等待首次生成提示

如果当日首次调用,Bot 会先回复一条提示,告诉你卡片正在生成中。提示内容大致如下:

> ⏳ 今日 HN 酷产品生成中(约 2-5 分钟), 完成后自动推送。

此时无需重复发送指令,Bot 会在后台完成生成后,主动将产品卡片推送到当前对话。常见的产品卡字段包括日期、产品名(及其链接)、作者(以 👤 by 标识)、发布时间、简介(📝)、社区评论精选(💬)以及一张 OG 大图。

如果当前阶段就是这一步,效果如下图所示:

### 步骤 3: 收到生成完成的产品卡片

等待数十秒到数分钟,Bot 会在同一个对话中推送一条或多条消息,包含产品卡片正文与配图。卡片示例如下:

> 🚀 2026-08-29 Linear — 快得离谱的项目管理工具
> 👤 by karpathy · about 3 hours ago
> 📝 一款以速度著称的产品规划与 issue 跟踪工具。
> 💬 "Linear …"

生成完成后,你可以在此基础上继续探索:点击产品名跳转阅读详情,查看作者主页了解发布者背景,或顺着精选评论深挖社区反馈。

### 小贴士

- **首次请求请耐心等待**:如果当日还没有数据,Bot 需要先调用 repository_dispatch 触发 Actions 流水线,通常在 2-5 分钟内完成;之后再次使用 `/product` 即可秒回。
- **避免重复发送**:在 Bot 提示"生成中"后,不必再发一次指令,生成完成会主动推送;重复发送可能让当日队列出现冗余任务。
- **跨设备同步查看**:由于卡片支持 OG 图,即使在桌面或移动端切换设备,只要是同一个 Telegram 对话,都能看到完整的产品图文卡片,便于随时回看当日推荐。
