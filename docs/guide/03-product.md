## /product — 今日 HN 酷产品

本章介绍如何使用 `/product` 命令,获取 Hacker News 当日热门产品卡片。该功能通过读取 archive 分支的 JSON 数据秒回产品信息,并在数据缺失时自动触发生成流程。

### 步骤 1: 发送命令

在 Bot 对话窗口中输入 `/product` 并发送,启动今日产品卡片查询。Bot 立即响应并告知生成进度,无需手动干预。

> 用户发送:`/product`
> Bot 回复:⏳ 今日 HN 酷产品生成中(约 2-5 分钟),完成后自动推送。

![]\(assets/03-product-r1.png)

此时 Bot 已经检查了 archive 分支的 JSON 数据,若当日内容尚未生成,会通过 `repository_dispatch` 触发 GitHub Actions 工作流开始生产产品卡片,耐心等待即可。

### 步骤 2: 等待推送

生成流程通常需要 2-5 分钟。期间无需重复发送命令或执行其他操作,Bot 会在卡片就绪后自动推送到当前对话。

### 步骤 3: 接收产品卡片

生成完成后,Bot 会主动推送完整的产品卡片,包含日期、产品名称、作者、发布时间、简介以及 HN 原帖引用。卡片中内嵌 OG 图,直观展示产品 Logo 或界面截图。

> Bot 回复:🚀 2026-08-29 Linear — 快得离谱的项目管理工具 👤 by karpathy · about 3 hours ago 📝 一款以速度著称的产品规划与 issue 跟踪工具。 💬 "Linear

![]\(assets/03-product-r2.png)

卡片示例展示了 2026-08-29 的推荐产品 Linear,由 karpathy 约 3 小时前发布,主打速度优势。

### 步骤 4: 重新查询历史产品

若想再次查看当天的产品卡片,只需再次发送 `/product`。Bot 会直接从 archive 分支读取已有 JSON 快速返回,无需再次触发 Actions,响应几乎是即时的。

## 小贴士

- **首次发送耐心等待**:若当日首次有人触发查询,需要等待 Actions 生成,2-5 分钟内会有结果;后续同一天再查询即为秒回。
- **OG 图展示效果**:卡片中的 OG 图依赖网络加载,在 Bot 客户端开启图片预览时可获得最佳阅读体验。
- **触发时机建议**:HN 每日热门集中在美东时间上午形成,建议北京时间晚上或次日清晨查询,数据更完整。
