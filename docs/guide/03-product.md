## /product — 今日 HN 酷产品

通过 `/product` 指令,Bot 会从 Hacker News 当日热门话题中挑选出最值得关注的产品类项目,生成一张带标题、作者、简介、原文链接和 OG 预览图的产品卡片推送给你。无需任何参数,直接发送指令即可。

### 步骤 1: 发送指令触发查询

在 Bot 对话框中输入:

```
/product
```

Bot 会立即读取 archive 分支上的 JSON 缓存文件。如果你今天还没有生成过,缓存为空,Bot 会先调用 `repository_dispatch` 触发 GitHub Actions 工作流去抓取数据并生成卡片,然后给你回一条生成中提示:

> ⏳ 今日 HN 酷产品生成中(约 2-5 分钟), 完成后自动推送。

此时请耐心等待,无需重复发送指令,Bot 会在卡片就绪后自动推送。

![首次触发后 Bot 返回生成中提示](assets/03-product-r1.png)

### 步骤 2: 等待自动推送

Actions 工作流完成抓取与渲染后(通常 2-5 分钟,网络繁忙时可能更久),Bot 会主动向你发送今日的产品卡片,内容包含:

- 日期与产品名称
- 作者与发布时间
- 简短中文摘要
- Hacker News 原文讨论链接
- 来自原网站的 OG 预览图

无需再做任何操作,卡片会直接出现在对话中。

### 步骤 3: 查看已生成的卡片

如果你在第一次触发后没能及时看到推送,再次发送 `/product` 即可秒级读取已缓存的 JSON 数据,把同一张产品卡片重新发给你,不会再重复触发 Actions 流程,也不会出现新的生成中提示。

![再次发送指令时 Bot 直接返回已生成的产品卡片](assets/03-product-r2.png)

### 步骤 4: 后续每日查看

第二天想看新一天的产品推荐,直接重复步骤 1 即可。当 archive 缓存中没有当天的 JSON 时,Bot 会再次走 "提示生成中 → Actions 抓取 → 自动推送" 的完整流程;缓存命中则直接秒回卡片。

### 小贴士

- **不要在生成中提示后短时间内反复发送指令**:首次触发后等待 Bot 主动推送即可,反复发送只会让 Bot 反复读取空缓存并重复触发 Actions,造成不必要的资源消耗。
- **若推送迟迟未到**:可等待 5-10 分钟后再次发送 `/product`,此时缓存大概率已写入,Bot 会直接把卡片发给你,无需排查 Actions 日志。
- **卡片内容来源于 HN 公开讨论**:摘要由 Bot 自动化生成,如有疑问或想看更多讨论,可点击卡片中的链接跳转到 Hacker News 原文参与讨论。
