### 步骤 1:发送 /hn 命令

在 Telegram 对话框中输入 `/hn` 并发送。Bot 收到命令后,会立即检查 `archive` 分支是否已有今日的产品数据。

如果当日数据尚未生成(这是最常见的情况),Bot 会通过 `repository_dispatch` 事件触发 GitHub Actions 工作流,开始拉取 Hacker News 当日热门产品,并将整理后的 JSON 文件写入 `archive` 分支。整个生成过程通常需要 2 至 5 分钟。

Bot 的即时回复如下:

> ⏳ 今日 Hacker News 酷产品生成中(约 2-5 分钟),完成后自动推送。

此时请耐心等待,无需重复发送命令。

![首次发送 /hn,Bot 提示生成中](assets/03-product-r1.png)

### 步骤 2:等待 Bot 主动推送产品卡

GitHub Actions 完成数据抓取、整理并提交到 `archive` 分支后,Bot 会自动读取该分支的 JSON 文件,并将内容渲染为产品卡片推送给用户,无需任何额外操作。

推送的产品卡片包含以下要素:

- 🚀 标题行:日期、产品名称与一句中文卖点,例如「🚀 2026-08-30 Linear — 快得离谱的项目管理工具」
- 👤 署名行:作者 HN ID、发布时间(相对时间,如 about 3 hours ago)
- 📝 简介行:产品的一句话中文描述
- 💬 引用行:热门评论摘录
- OG 图卡片:Hacker News 原文的预览图(由 Open Graph 元信息自动解析)

完整推送示例如下:

> 🚀 2026-08-30 Linear — 快得离谱的项目管理工具 👤 by karpathy · about 3 hours ago 📝 一款以速度著称的产品规划与 issue 跟踪工具。 💬 "Linear

请直接点击卡片下方的链接即可跳转到 Hacker News 原帖查看完整讨论。

![Bot 自动推送的产品卡片,含 OG 图与产品详情](assets/03-product-r2.png)

### 小贴士

- 如果等待超过 5 分钟仍未收到推送,大概率是 GitHub Actions 排队或失败所致,此时可再发送一次 `/hn`,Bot 会重新触发工作流。
- 当日数据已被其他用户触发并生成后,你发送 `/hn` 会立刻秒回产品卡,无需等待;反之首次发送几乎总会进入「生成中」状态。
- 产品卡中的 OG 图来自原帖页面,若原帖未提供 OG 图,卡片将仅展示文字内容,这是正常现象。
