## /product — 今日 HN 酷产品

通过 `/product` 命令,Bot 会从 Hacker News 每日榜单中精选一款"酷产品"并生成精美产品卡片(含标题、作者、简介、原文摘要与 OG 图)推送给您。卡片数据由 archive 分支预先生成,响应迅速;若当天尚未入库,Bot 还会自动触发抓取任务,完成后再次推送。

### 步骤 1: 发送命令

在任意对话中向 Bot 发送:

```
/product
```

Bot 首先会检查 archive 分支是否已有当天的产品数据。

### 步骤 2: 等待首次响应

- **若已有当日数据**:Bot 会立即(秒级)推送一张完整的产品卡片。
- **若尚无当日数据**:Bot 不会让您干等,而是主动触发 `repository_dispatch` 事件,由后台 GitHub Actions 抓取并生成数据,预计耗时 2–5 分钟。此时您会看到如下提示:

  > ⏳ 今日 HN 酷产品生成中(约 2-5 分钟), 完成后自动推送。

  收到该提示后请耐心等待,无需重复操作,Bot 会在数据就绪后自动把卡片推送到当前对话。

![首次请求时,Bot 提示正在生成](assets/03-product-r1.png)

### 步骤 3: 接收产品卡片

数据准备就绪后,Bot 会自动向您推送一张产品卡,内容包含:

- 🚀 **日期与产品名** — 例如 `2026-08-29 Linear — 快得离谱的项目管理工具`
- 👤 **发布者与时间** — 例如 `by karpathy · about 3 hours ago`
- 📝 **一句话简介** — 例如 `一款以速度著称的产品规划与 issue 跟踪工具。`
- 💬 **原文摘要** — 摘录自 Hacker News 上的热门评论或介绍文字
- 🖼 **OG 图** — 由 archive 分支同步托管,随消息一起展示

如果首次只收到了"生成中"的提示,稍后再发送一次 `/product` 也能立即拉取已经入库的卡片,效果完全相同。

![Bot 推送的产品卡示例](assets/03-product-r2.png)

### 小贴士

- 看到 ⏳ 提示后,直接静候自动推送即可,无需连续刷命令;短时间内重复发送会重复排队,反而延长等待。
- 若 5 分钟后仍未收到卡片,可再发一次 `/product`;此时 archive 分支往往已经写好,会秒级返回。
- 想换一天的产品?把日期作为参数传入(例如 `/product 2026-08-28`)即可查询历史精选(以 Bot 是否支持该参数为准)。
