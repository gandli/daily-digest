# /product — 今日 HN 酷产品

通过 `/product` 命令,Bot 会从 Hacker News 每日热榜中挑选一款酷产品,以精美产品卡(含 OG 图)的形式推送给你。如果当日内容尚未生成,Bot 会自动触发后台构建任务,稍候即可收到推送。

## 使用流程

### 步骤 1: 发送 /product 命令
在 Telegram 对话框中输入 `/product` 并发送。Bot 会先检查 archive 分支的 JSON 数据,如果当日已有产物,会立即返回产品卡;如果还没有,会触发 Actions 生成流程。

### 步骤 2: 等待首次生成结果
若当日 JSON 数据尚未就绪,Bot 会回复一条生成提示:

> ⏳ 今日 Hacker News 酷产品生成中(约 2-5 分钟),完成后自动推送。

此时无需重复发送命令,后台 Actions 任务会通过 `repository_dispatch` 事件触发数据抓取与卡片渲染。

![首次请求时 Bot 回复生成提示](assets/03-product-r1.png)

### 步骤 3: 收到推送的产品卡
等待 2-5 分钟后,Bot 会自动将今日酷产品卡片推送至对话。产品卡包含日期、产品名称、配图、作者、发布时间以及核心亮点摘录。例如:

> 🚀 2026-08-30 Linear — 快得离谱的项目管理工具 👤 by karpathy · about 3 hours ago 📝 一款以速度著称的产品规划与 issue 跟踪工具。 💬 "Linear …"

产品卡随附一张 OG 预览图,直观展示产品界面或 Logo。

![Bot 推送的产品卡内容](assets/03-product-r2.png)

### 步骤 4: 查看或分享
收到卡片后,可直接点击图片查看高清大图,也可长按转发给好友或在群聊中分享。

## 小贴士

- **首次请求稍安勿躁**:当日首次发送 `/product` 时,若数据未生成会触发一次 Actions 构建,大约 2-5 分钟完成,期间请勿反复发送命令,避免重复触发任务。
- **每日仅一条精品**:Bot 每天精选一款产品,适合在早晨通勤时段查看,作为科技产品发现的新方式。
- **JSON 命中即秒回**:如果你在当天的其他时段再次发送 `/product`,由于 archive 分支已有当日 JSON,Bot 会立即返回卡片,无需等待。
