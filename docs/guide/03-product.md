## /product — 今日 HN 酷产品

通过本命令，Bot 会从 Hacker News 每日榜单中精选一款酷产品，并以产品卡的形式推送给用户。卡片包含标题、作者、发布时间、亮点描述以及 Open Graph 预览图。

### 步骤 1: 发送命令

在 Telegram 对话窗口中输入 `/hn` 并发送。注意命令前缀是斜杠 `/`，后接小写字母 `hn`，不要带任何参数。

### 步骤 2: 等待首次响应

Bot 收到指令后，首先会尝试从 GitHub archive 分支读取当日的产品数据 JSON。

- **若有当日数据**：Bot 会立即回复一张完整的产品卡，包含 OG 图，无需等待。
- **若无当日数据**：Bot 会通过 `repository_dispatch` 触发 GitHub Actions 工作流，调用 Hacker News API 抓取并生成内容，然后回复一条排队提示：

> ⏳ 今日 Hacker News 酷产品生成中（约 2-5 分钟），完成后自动推送。

### 步骤 3: 接收自动推送的产品卡

触发 Actions 后，无需再次发送命令。工作流完成数据抓取、筛选和卡片渲染后，Bot 会主动向同一对话推送产品卡。卡片内容包括：

- 🚀 **日期与标题**：例如 `2026-08-30 Linear — 快得离谱的项目管理工具`
- 👤 **作者与发布时间**：例如 `by karkarpathy · about 3 hours ago`
- 📝 **亮点摘要**：对产品的简要中文描述
- 💬 **HN 热门评论摘录**：展示社区热议观点
- 🖼 **OG 预览图**：产品官网的 Open Graph 图片

![生成完成后自动推送的产品卡](assets/03-product-r2.png)

### 步骤 4: 后续每日使用

产品卡会在每天固定时点由 Actions 自动生成并写入 archive 分支。此后任何用户在当天首次发送 `/hn`，Bot 都会从缓存秒回产品卡，无需再次触发工作流。

### 小贴士

- **耐心等待首轮提示**：首次请求若看到排队提示，请勿重复发送命令，重复发送只会反复触发 Actions，浪费额度；等待 2-5 分钟即可收到自动推送。
- **关注对话上下文**：产品卡会推送到你发送命令的同一个对话（包括私聊和群组），请确认当前对话是你希望接收内容的位置。
- **OG 图加载失败属正常现象**：若图片因网络原因加载失败，正文文字部分仍完整可读，可以根据标题和摘要点击原链接前往 Hacker News 查看讨论。
