## /product — 今日 HN 酷产品

本指令用于拉取当天 Hacker News 上的热门产品。Bot 会优先尝试从缓存秒回产品卡片;如果当天还没有数据,则自动触发后台生成任务,稍候再查即可。

### 步骤 1: 发送指令

在 Bot 对话框中输入 `/product`(对话记录中使用的是别名 `/hn`,二者效果相同),然后按回车发送。

Bot 立即返回一条排队提示:

> ⏳ 今日 Hacker News 酷产品生成中(约 2-5 分钟),完成后自动推送。

这表示当天尚未缓存内容,Bot 已经向 GitHub Actions 派发了抓取与生成任务。

![首次发送 /product,Bot 返回生成中提示](assets/03-product-r1.png)

### 步骤 2: 等待生成完成

任务通常需要 2–5 分钟。在此期间你不需要做任何事,Bot 也不会再次主动推送。生成动作由 GitHub Actions 完成,涉及抓取 Hacker News 热门条目、筛选产品类目、撰写中文摘要并渲染 OG 分享卡。

### 步骤 3: 重新查询并领取卡片

等待几分钟后,**再次发送 `/product`(或 `/hn`)**。此时 archive 分支的 JSON 缓存已就绪,Bot 会直接返回完整产品卡,无需再次排队。

卡片通常包含以下字段:

- **🚀 日期与产品名**:例如 `2026-08-30 Linear — 快得离谱的项目管理工具`
- **👤 作者与发布时间**:例如 `by karpathy · about 3 hours ago`
- **📝 一句话简介**:用中文概括产品定位
- **💬 社区热议摘录**:截取 Hacker News 上的代表性评论
- **🖼 OG 分享卡图**:可直接转发到社交平台

![二次发送后,Bot 直接返回完整产品卡](assets/03-product-r2.png)

### 步骤 4: 转发或继续探索

拿到卡片后,你可以:

- 直接点击 OG 图转发到 Telegram 频道、Twitter 或其他社交平台;
- 回复 Bot 表达「再来一张」之类的需求,Bot 会按当天的热度继续推荐;
- 当天若反复查询,均直接命中缓存,响应时间为秒级。

---

### 小贴士

1. **先别急着再发**。首次收到「约 2-5 分钟」提示后,等待 3 分钟再查一次最稳妥;频繁重发只会重复排队,不会加快生成。
2. **缓存时效约一天**。同一日期内多次发送 `/product` 都会秒回同一张卡;想看新内容,等次日再查即可。
3. **OG 图是关键产物**。如果你运营的是科技类频道,直接转发这张带 OG 预览的卡片,比纯文本链接点击率高很多。
