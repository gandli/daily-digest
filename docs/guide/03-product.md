### /product — 今日 HN 酷产品

通过本指令，Bot 会从 Hacker News 当日热门讨论中挑选一条最受关注的产品类话题，整理为一张简洁的产品卡片(含 Open Graph 封面图)推送给你。整个流程基于 archive 分支的 JSON 缓存，秒级响应；当日数据尚未生成时，Bot 会自动触发 GitHub Actions 抓取任务，无需你手动干预。

### 步骤 1: 发送指令

在任意与 Bot 的私聊或群聊中,输入:

```
/product
```

### 步骤 2: 等待生成或接收卡片

Bot 的回复取决于当日缓存状态,会出现以下两种情况:

**情况 A: 首次调用,当日尚未生成**

Bot 立即回复一条排队提示:

> ⏳ 今日 HN 酷产品生成中(约 2-5 分钟), 完成后自动推送。

此时 Bot 已向 GitHub 发送 `repository_dispatch` 事件,触发 Actions 工作流抓取并整理 HN 当日热门产品话题。生成完成后,Bot 会主动将产品卡片推送至当前对话,无需你再次发送指令。

![首次调用,Bot 提示生成中](assets/03-product-r1.png)

**情况 B: 数据已就绪,直接返回卡片**

Bot 立即推送一条产品卡片,格式如下:

> 🚀 2026-08-29 Linear — 快得离谱的项目管理工具
> 👤 by karpathy · about 3 hours ago
> 📝 一款以速度著称的产品规划与 issue 跟踪工具。
> 💬 "Linear ...

卡片中包含产品名称、发布者、HN 原始发布时间、简要描述,以及首条热门评论节选,同时附带一张 OG 封面图,点击即可跳转原文。

![数据已就绪,Bot 返回产品卡片](assets/03-product-r2.png)

### 步骤 3: 查看与跳转

收到卡片后,直接阅读摘要即可快速了解该产品的亮点与社区评价。如需深入阅读:

- 点击 OG 图或卡片中的链接跳转 Hacker News 原帖;
- 在原帖中浏览更多评论、查看产品官网。

### 小贴士

- 首次调用 `/product` 当天可能会遇到排队提示,通常 2-5 分钟内会自动推送;若超过 10 分钟仍未收到,可再次发送 `/product` 重新触发。
- 卡片中的日期为 HN 抓取当日日期,产品本身可能是当天发布,也可能是 HN 当日重新热议的旧产品。
- 如希望浏览往期推荐,可直接重新发送 `/product` 指令,Bot 会从 archive 分支 JSON 中检索最近一次缓存并返回。
