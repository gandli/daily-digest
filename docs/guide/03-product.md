## /product — 今日 HN 酷产品

本指令从 Hacker News 每日榜单中精选一条「酷产品」信息,以精美产品卡(含标题、作者、时间、简介与原文摘要)的形式直接推送给你。底层数据存放在 `archive` 分支的 JSON 文件中,读取延迟极低;若当日 JSON 尚未生成,Bot 会自动触发 GitHub Actions 抓取任务,生成完成后再向你推送。

### 步骤 1: 发送指令

在任意与 Bot 对话的聊天窗口中,输入并发送:

```
/product
```

### 步骤 2: 等待首次回应

Bot 收到指令后会立刻检查 `archive` 分支中当天的 JSON 文件。两种可能结果:

- **有数据**:直接秒回产品卡(含标题、作者、发布时间、OG 图等信息),无需等待;
- **无当日数据**:Bot 会向 GitHub 仓库派发 `repository_dispatch` 事件,触发 Actions 抓取流程,此时你会看到「生成中」的提示。

例如在数据尚未就绪时,Bot 会回复:

> ⏳ 今日 HN 酷产品生成中(约 2-5 分钟), 完成后自动推送。

这表示 Bot 已为你排定任务,生成完成后会自动把卡片推回当前聊天,无需你再次发送指令。

![生成中提示,提示约 2-5 分钟后自动推送](assets/03-product-r1.png)

### 步骤 3: 接收产品卡

当 Actions 任务完成、JSON 写入 `archive` 分支后,Bot 会立刻拉取最新数据并推送产品卡。卡片通常包含以下信息:

- 🚀 **日期与产品名**:例如 `2026-08-30 Linear`;
- 👤 **作者与发布时间**:例如 `by karkarpathy · about 3 hours ago`;
- 📝 **一句话简介**:用中文概括产品亮点;
- 💬 **原文摘要**:抓取自 HN 讨论或官网描述的关键句。

示例推送内容:

> 🚀 2026-08-30 Linear — 快得离谱的项目管理工具 👤 by karpathy · about 3 hours ago 📝 一款以速度著称的产品规划与 issue 跟踪工具。 💬 "Linear …"

![产品卡推送,含标题、作者、简介与摘要](assets/03-product-r2.png)

### 步骤 4: 查看或转发

收到卡片后,你可以:

- 直接点击卡片中的链接跳转到 Hacker News 原帖或产品官网;
- 转发卡片给好友或群组,卡片格式会保持完整;
- 在卡片下方继续与 Bot 对话,询问更多细节(例如「这个产品的定价?」),Bot 会根据上下文作答。

### 小贴士

- 若你多次发送 `/product` 都收到「生成中」提示,请耐心等待 2-5 分钟,Bot 会在数据就绪后**自动推送**,不需要再次发送指令。
- 产品卡中的图片来源于产品官网或 HN 抓取的 OG 图,若图片加载失败,通常是源站防盗链,文字信息依然完整可读。
- 想换个时间点看历史酷产品?可以输入 `/product 2026-08-29` 这样的日期参数(若 Bot 支持),直接拉取指定日期的归档数据。
