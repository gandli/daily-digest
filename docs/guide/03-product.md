### 步骤 1:发送 `/product` 命令

在 Telegram 对话框中输入斜杠命令 `/product` 并发送,即可向 Bot 请求「今日 HN 酷产品」卡片。

### 步骤 2:首次请求 — 触发数据生成

当 Bot 在 archive 分支缓存的 JSON 中未找到当日记录时,会执行以下动作:

- 通过 `repository_dispatch` 事件向仓库触发 GitHub Actions 工作流;
- 工作流运行抓取与渲染脚本,生成产品卡(耗时约 2-5 分钟);
- Bot 立即向用户回送提示消息,告知生成已启动。

![首次请求触发数据生成,Bot 返回排队提示](assets/03-product-r1.png)

Bot 回复示例:

> ⏳ 今日 Hacker News 酷产品生成中(约 2-5 分钟),完成后自动推送。

此时**无需再次发送命令**,只需保持对话窗口开启,等待 Bot 主动推送即可。

### 步骤 3:再次请求 — 读取缓存秒回产品卡

工作流完成后,当日产品数据被写入 archive 分支的 JSON 文件。若用户在生成期间或之后再次发送 `/product`,Bot 会直接从缓存读取并秒回产品卡:

- 卡片包含日期、产品名称、一句话简介、作者与发布时间;
- 摘要正文中保留 Hacker News 原帖的高亮短评;
- 若配置了 OG 图托管,卡片会附带缩略图链接。

![Bot 直接从缓存读取并推送完整产品卡](assets/03-product-r2.png)

Bot 回复示例:

> 🚀 2026-08-30 Linear — 快得离谱的项目管理工具
> 👤 by karpathy · about 3 hours ago
> 📝 一款以速度著称的产品规划与 issue 跟踪工具。
> 💬 "Linear 的键盘驱动体验让 issue 跟踪几乎不打断思路。"

看到这条消息,说明今日推荐已成功送达,可直接点击卡片访问原帖。

### 小贴士

- **首次请求后耐心等待**:工作流一般 2-5 分钟内完成,期间重复发送 `/product` 不会取消生成,反而会持续命中「排队中」分支。
- **离线归档可随时回看**:每日产品卡落地 archive 分支后,即使错过推送,反复发送 `/product` 都会秒回最近一次的产品记录,适合作为常驻书签。
- **关注截图与作者字段**:卡片中的 `👤 by` 行会标注 Hacker News 原帖作者,若对该作者过往推荐感兴趣,可结合 `/digest` 系列命令横向查阅。
