## /product — 今日 HN 酷产品

本命令用于获取当日 Hacker News 上值得关注的酷产品,Bot 会以产品卡片(含标题、简介、链接和 OG 图)的形式秒回呈现。

### 步骤 1: 发送命令

在 Bot 对话窗口中输入:

```
/hn
```

> 注意:文档路径虽为 `/product`,但实际触发命令为 `/hn`,请以此为准发送。

### 步骤 2: 等待首次响应

Bot 收到命令后会立即处理,通常有两种结果:

- **当日数据已存在(秒回)**:直接收到一张或多张产品卡片,包含标题、OG 图与跳转链接。
- **当日数据尚未生成**:Bot 返回生成提示消息,告知用户正在后台生成,完成后会自动推送。

当前演示属于第二种情况。Bot 回复:

> ⏳ 今日 Hacker News 酷产品生成中(约 2-5 分钟),完成后自动推送。

此时 Bot 内部已通过 `repository_dispatch` 事件触发 GitHub Actions 工作流,由 Actions 抓取并整理当日 HN 热门产品数据,随后写入 archive 分支对应的 JSON 文件。

![首次发送 /hn,Bot 返回生成提示](assets/03-product-r1.png)

### 步骤 3: 再次发送命令确认状态

若用户在等待期间再次发送 `/hn`,Bot 会保持幂等,继续提示生成进行中,而不会重复触发任务:

> ⏳ 今日 Hacker News 酷产品生成中(约 2-5 分钟),完成后自动推送。

![再次发送 /hn,Bot 仍返回生成提示](assets/03-product-r2.png)

> 这一行为验证了事务的关键点:当日无数据时,Bot 不会返回空卡片或报错,而是给出明确等待提示。

### 步骤 4: 接收自动推送的产品卡

等待 2–5 分钟后,Bot 会在同一对话中主动推送结果:

- 当 archive 分支的 JSON 文件就绪后,Bot 读取并解析;
- 以单张产品卡或多张卡片的形式发出,每张卡片包含标题、简要描述、原文链接以及 OG 预览图;
- 用户可直接点击链接跳转到 Hacker News 原帖,或基于 OG 图快速预览产品主页。

### 事务与验证小结

- **触发条件**:仅当 archive 分支 JSON 中存在当日数据时秒回产品卡;无数据则触发 `repository_dispatch`,走 Actions 生成链路。
- **幂等性**:多次发送 `/hn` 在生成阶段只会得到相同的等待提示,不会产生重复任务。
- **自动推送**:生成完成后由 Bot 主动推送,无需用户再次操作。

---

### 小贴士

1. **耐心等待推送**:触发生成后无需反复发送命令,只需保持窗口打开,2–5 分钟内即可收到产品卡;重复发送只会看到相同的提示消息。
2. **利用 OG 图快速筛选**:产品卡附带 OG 预览图,可先看图判断是否感兴趣,再点链接深入阅读,提升信息浏览效率。
3. **关注生成时间**:若超过 10 分钟仍未收到推送,可能是 Actions 队列拥堵或接口异常,可在 GitHub 仓库的 Actions 页面查看 `repository_dispatch` 触发的对应工作流运行状态。
