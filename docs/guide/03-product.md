### 步骤 1: 发送指令触发查询

在 Bot 对话窗口中输入以下命令并发送:

```
/hn
```

Bot 收到指令后,会立刻读取 `archive` 分支下的当日产品 JSON 文件。如果数据已存在,则直接渲染产品卡并回复;如果尚未生成,则进入步骤 2 的等待流程。

### 步骤 2: 首次触发后的等待提示

如果你在每日首次发送 `/hn`,当日 JSON 通常尚未就绪。此时 Bot 会检测到无数据,并通过 `repository_dispatch` 事件触发 GitHub Actions 工作流,开始爬取与整理 Hacker News 当日热门产品。

Bot 立即回复一条提示,告知你任务已进入后台:

> ⏳ 今日 Hacker News 酷产品生成中(约 2-5 分钟), 完成后自动推送。

!首次发送命令后的等待提示](assets/03-product-r1.png)

在此期间,你无需重复发送指令,也不必停留在对话窗口——Bot 会在数据准备好后主动推送。

### 步骤 3: 等待 Bot 主动推送

通常 2 至 5 分钟后,Bot 会将生成完成的产品卡直接发送到当前对话。你不需要再次输入 `/hn`,只需留意消息通知即可。如果超过 5 分钟仍未收到,可进入步骤 4 的处理方式。

### 步骤 4: 重新发送指令获取产品卡

当 Bot 完成生成并写入 `archive` 分支的 JSON 后,再次发送 `/hn`。此时 Bot 能够从 JSON 中读到当日数据,直接渲染并回复产品卡:

> 🚀 2026-08-30 Linear — 快得离谱的项目管理工具
> 👤 by karpathy · about 3 hours ago
> 📝 一款以速度著称的产品规划与 issue 跟踪工具。
> 💬 "Linear ...

!成功获取产品卡的展示效果](assets/03-product-r2.png)

产品卡包含标题、作者与发布时间、简介、引用语录,并附带 OG 图(从 HN 链接页面抓取的预览图),整体视觉清爽,适合在 Telegram 中直接浏览与转发。

## 小贴士

- 首次发送 `/hn` 后若收到「生成中」提示,**不必重复触发**——重复发送只会让 Bot 再读一次空数据,徒增延迟;耐心等待 Bot 主动推送即可。
- 若等待超过 5 分钟仍未收到推送,建议先确认 GitHub Actions 是否正常运行(查看仓库的 Actions 标签页),再考虑重新发送 `/hn`。
- 产品卡的 JSON 保存在 `archive` 分支,你可以直接访问该分支查看历史每日推荐,便于回溯。
