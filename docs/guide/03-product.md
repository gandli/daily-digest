## /product — 今日 HN 酷产品

通过 `/product` 命令，Bot 会从 Hacker News 每日热榜中精选一款酷产品，以精美卡片形式（含标题、作者、发布时间、简介以及 OG 图）推送给您。该命令读取 archive 分支下的 JSON 文件实现秒级响应；如果当日数据尚未生成，Bot 会自动触发 GitHub Actions 抓取任务，并在数分钟后重新推送结果。

### 步骤 1: 发起产品请求

在 Bot 对话窗口中输入命令:

```
/product
```

发送后，Bot 会立即根据当前日期检查 archive 分支中是否已有当日的 HN 产品 JSON 数据。

### 步骤 2: 首次请求触发数据生成

当 archive 分支中尚无当日产品数据时（即首次调用时），Bot 会通过 `repository_dispatch` 事件触发 GitHub Actions 工作流，异步抓取并生成当日的 Hacker News 酷产品卡片。此时 Bot 会回复一条提示信息，告知您生成任务已启动:

> ⏳ 今日 Hacker News 酷产品生成中(约 2-5 分钟), 完成后自动推送。

整个提示信息如截图所示:

![首次请求 Bot 返回生成提示](assets/03-product-r1.png)

您无需重复发送命令，只需耐心等待 2 至 5 分钟。

### 步骤 3: 等待自动推送或二次查询

生成完成后，Bot 会自动将产品卡片推送到当前对话。如果等待过程中您希望确认数据是否已就绪，可以再次发送 `/product` 命令。当 archive 分支已存在当日 JSON 时，Bot 会直接读取并秒回完整的产品卡片。

### 步骤 4: 接收产品卡片

二次请求或等待推送后，Bot 会返回当日精选产品，格式如下:

> 🚀 2026-08-30 Linear — 快得离谱的项目管理工具 👤 by karpathy · about 3 hours ago 📝 一款以速度著称的产品规划与 issue 跟踪工具。 💬 "Linear

卡片中包含日期、产品名称、副标题、作者、发布时间、简介以及原文评论摘录，并附带 OG 预览图。完整示例见截图:

![Bot 返回产品卡片](assets/03-product-r2.png)

### 小贴士

- 首次发送 `/product` 后若只看到"生成中"提示，请勿频繁重复发送；Bot 会在数据就绪后自动推送，无需手动干预。
- 如果等待超过 5 分钟仍未收到推送，可再次发送 `/product` 命令进行二次查询，Bot 会重新检查数据状态。
- 每日产品数据由 GitHub Actions 自动维护，您可以在 archive 分支中查阅历史 JSON 记录，回顾往期酷产品。
