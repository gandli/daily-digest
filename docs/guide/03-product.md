## /product — 今日 HN 酷产品

本命令用于获取 Hacker News 当日最受关注的产品类热门讨论,Bot 会以精美的产品卡形式(包含标题、作者、发布时间、简介与原文摘要)直接推送给你。生成依赖后端缓存,首次调用可能需要等待,后续读取缓存即可秒回。

### 步骤 1: 发送命令

在任意与 Bot 对话的聊天窗口中,直接输入:

```
/product
```

并按下发送键。Bot 收到请求后,会先检查 archive 分支上是否已有今日的产品数据缓存。

### 步骤 2: 等待首次生成提示

如果当日暂无缓存(例如你是一天中较早发起请求的用户),Bot 会立即回复一条生成提示,告知你后台正在启动抓取流程,无需你执行任何额外操作,只需耐心等待 2 至 5 分钟:

> ⏳ 今日 HN 酷产品生成中(约 2-5 分钟), 完成后自动推送。

![首次请求触发后台生成提示](assets/03-product-r1.png)

Bot 在背后会自动通过 `repository_dispatch` 触发 GitHub Actions 工作流,拉取 Hacker News 当日数据并筛选出最具话题性的产品,写入 archive 分支的 JSON 文件。

### 步骤 3: 接收生成完成推送

无需你再次发送命令,生成工作流结束后,Bot 会主动向你推送一张完整的产品卡。卡片内容包含日期、标题、作者、发布时间、文章摘要以及原文摘录等信息。例如:

> 🚀 2026-08-29 Linear — 快得离谱的项目管理工具
> 👤 by karpathy · about 3 hours ago
> 📝 一款以速度著称的产品规划与 issue 跟踪工具。
> 💬 "Linear …"

同时,卡片会附带一张 OG(Open Graph)预览图,方便你在聊天窗口内直接预览产品截图,点击卡片即可跳转到 Hacker News 原文讨论。

![生成完成后自动推送产品卡](assets/03-product-r2.png)

### 步骤 4: 后续秒回(可选)

当 archive 分支已存在当日 JSON 缓存后,再次发送 `/product`,Bot 会直接从缓存读取并秒回一张新的产品卡(若当日存在多条优质条目,可能会轮换展示),整个过程无需等待。

### 小贴士

- 耐心等待推送:首次生成通常需要 2-5 分钟,期间无需重复发送命令,Bot 会在完成后主动推送到当前聊天窗口。
- 错过后再试:如果错过了自动推送或想换一个候选产品,可以随时再发一次 `/product` 重新抽取。
- 早间体验最佳:清晨时段缓存为空概率较高,会触发完整生成流程;稍后再调用则通常可秒回卡片。
