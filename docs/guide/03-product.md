## /product — 今日 HN 酷产品

`/product` 命令(也写作 `/hn`)用于获取 Hacker News 当日热度最高的产品类条目。Bot 会从 archive 分支直接读取已生成的 JSON 缓存,瞬时返回一张包含标题、作者、发布时间、简介、原文链接与 OG 封面图的产品卡;若当日数据尚未生成,则自动触发 GitHub Actions 抓取流程,并在生成完毕后主动推送给你。

### 步骤 1: 发送命令

在 Bot 对话框中输入 `/product` 或 `/hn`,按回车发送。

### 步骤 2: 等待首轮响应

Bot 立即回复一行提示,告知当日数据正在生成中:

> ⏳ 今日 HN 酷产品生成中(约 2-5 分钟), 完成后自动推送。

这条消息意味着 archive 分支里还没有今天的 JSON 缓存,Bot 已通过 `repository_dispatch` 事件触发 GitHub Actions 工作流,正在后台抓取 Hacker News 的当日热门产品。

![等待生成提示](assets/03-product-r1.png)

此时你无需任何操作,等待即可。生成通常在 2 到 5 分钟内完成。

### 步骤 3: 主动查询结果(可选)

如果不想等推送,可以在数分钟后再次发送 `/product` 或 `/hn` 主动拉取。Bot 会从 archive 分支读取已落地的 JSON,直接返回产品卡,典型样式如下:

> 🚀 2026-08-30 Linear — 快得离谱的项目管理工具 👤 by karpathy · about 3 hours ago 📝 一款以速度著称的产品规划与 issue 跟踪工具。 💬 "Linear …

卡片中包含日期、产品名、一句话标题、作者、相对发布时间、简介以及 Hacker News 原帖链接,通常还附带一张 OG 封面图,便于直观了解产品。

![产品卡示例](assets/03-product-r2.png)

### 步骤 4: 查看与互动

收到产品卡后,你可以:

- 点击文中链接,跳转阅读 Hacker News 原帖及讨论;
- 在群聊中转发卡片,推荐给同好;
- 继续发送 `/product` 获取下一条或换一个日期的酷产品。

### 小贴士

- **首次调用请稍候**:首次发送命令时大概率会收到"生成中"提示,2-5 分钟后再次发送即可拿到结果;后续同日内的重复请求基本都是秒回。
- **命令别名通用**:`/product` 与 `/hn` 等价,任意一个都能触发同样的产品卡逻辑,习惯哪个就用哪个。
- **主动轮询更及时**:不想等自动推送时,每隔一两分钟重发一次命令,直到拿到卡片为止——这比单纯等待推送更可控。
