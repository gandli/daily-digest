## /product — 今日 HN 酷产品

本命令用于从 Hacker News 每日热门中挑选一款值得关注的酷产品, 生成结构化产品卡并直接推送给你。卡片包含标题、作者、发布时间、一句话简介以及精选评论摘录, 并附带 OG 图, 适合收藏或分享。

### 步骤 1: 发送触发命令

在 Bot 对话中输入 `/hn` 并发送(本 Bot 同时支持 `/product` 作为别名)。Bot 会立刻读取 archive 分支的预生成 JSON 数据。

- **若当日已生成**: 进入步骤 2, 直接返回产品卡。
- **若当日尚未生成**: Bot 立即回复生成提示, 同时通过 `repository_dispatch` 向 GitHub Actions 派发任务, 后台异步生成数据, 你无需重复发送命令。

![首轮触发, Bot 返回生成提示](assets/03-product-r1.png)

### 步骤 2: 等待首轮提示(如适用)

如果你在步骤 1 看到的是生成提示, 请耐心等待。生成耗时约 2-5 分钟, 完成后 Bot 会自动向当前对话推送产品卡, 不需要你再次输入命令。

### 步骤 3: 查看产品卡

下一轮(本例中为第二次发送 `/hn`)时, 由于 archive 分支已存在当日 JSON, Bot 直接返回完整产品卡, 格式如下:

- 🚀 顶部带产品 emoji 与日期, 例如 `🚀 2026-08-30 Linear — 快得离谱的项目管理工具`
- 👤 作者与发布时间, 例如 `👤 by karpathy · about 3 hours ago`
- 📝 一句话简介
- 💬 精选评论摘录(以引号片段呈现)
- 文末附带 OG 图, 适合在支持预览的聊天中直接显示

![第二轮触发, Bot 返回完整产品卡](assets/03-product-r2.png)

### 步骤 4: 收藏或继续浏览

收到卡片后, 你可以:

- 收藏该消息, 方便日后回看;
- 长按卡片查看完整的 OG 预览图;
- 继续发送 `/hn` 查看下一条(如当日 archive 仍有其他条目)或次日新数据。

### 小贴士

- **首次使用可能稍慢**: 若当日首次触发且 archive 无数据, 等待 2-5 分钟即可, 无需重复刷屏。
- **命令别名**: `/hn` 与 `/product` 等价, 习惯哪个就用哪个。
- **离线缓存**: archive 分支每天只生成一次, 重复发送不会重复触发 Actions, 可放心查看。
