### 步骤 1：发送 /product 命令

在 Telegram 对话框中输入 `/product` 并发送。Bot 收到请求后,会先尝试读取 archive 分支上的当日 JSON 数据。

### 步骤 2：等待首次响应——触发生成任务

若当日 archive 分支还没有可用的产品数据,Bot 会立即向 GitHub 发起 `repository_dispatch` 事件,触发 Actions 工作流开始抓取 Hacker News 当日高赞产品。

此时你将看到 Bot 的提示消息:

> ⏳ 今日 HN 酷产品生成中(约 2-5 分钟), 完成后自动推送。

![首次提示,告知用户任务已进入生成队列](assets/03-product-r1.png)

收到这条提示后,**无需再重复发送命令**,保持对话窗口开启即可。Bot 会在生成完成后主动把产品卡推送到当前聊天。

### 步骤 3：接收产品卡——读取 archive 分支 JSON

Actions 抓取并整理完毕后,会把结果写入 archive 分支的 JSON 文件。当用户再次调用 `/product`(或 Bot 主动推送)时,Bot 直接从 archive 分支读取已有数据,秒级返回完整的产品卡片,包含标题、作者、发布时间、简介,以及抓取自原帖的 Open Graph 封面图。

效果示例:

> 👤 by karpathy · about 3 hours ago
> 📝 一款以速度著称的产品规划与 issue 跟踪工具。
> 💬 "Linear ...

![再次调用后,直接秒回完整产品卡](assets/03-product-r2.png)

### 步骤 4：查看与分享

点击卡片中的链接可跳转到 Hacker News 原帖,继续阅读评论或收藏产品。卡片自带的 OG 图会作为消息内嵌缩略图展示,无需额外下载。

### 小贴士

- 首次使用或跨日(UTC 零点)后第一次调用时,几乎都会进入"生成中"流程;同一天内的后续调用会直接秒回,不必担心重复触发抓取。
- 生成通常在 2-5 分钟内完成,若超过 10 分钟仍未收到推送,可在对话中再发一次 `/product` 重新检查;若 archive 已有数据则会立即返回,若无数据则会再次进入等待流程。
- 产品卡内含封面图,若 Telegram 客户端设置了"不自动下载媒体",请在查看前允许下载以确保图片正常显示。
