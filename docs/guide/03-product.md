### 步骤 1：发送触发命令

在 Bot 对话窗口中输入以下命令并发送：

```
/product
```

也可以使用别名 `/hn`，两者效果完全相同。发送后，Bot 会立即返回一条提示，告知你今日的 Hacker News 酷产品正在生成中，请耐心等待约 2 到 5 分钟。

Bot 的回复内容大致如下：

> ⏳ 今日 Hacker News 酷产品生成中（约 2-5 分钟），完成后自动推送。

同时，Bot 会在后台通过 `repository_dispatch` 触发 GitHub Actions 工作流，由该工作流抓取 Hacker News 当日热门产品数据并写入 archive 分支的 JSON 文件。

![首次发送 /hn 后，Bot 返回生成提示](assets/03-product-r1.png)

### 步骤 2：等待生成完成

在 Bot 提示生成中后，你无需重复发送命令，也不需要做任何额外操作。只需保持当前聊天窗口开启，等待 Actions 工作流执行完毕即可。

工作流的执行过程如下：

1. GitHub Actions 被 `repository_dispatch` 事件唤醒并开始运行；
2. 脚本抓取 Hacker News 当日 Top 榜单，筛选出最具讨论度的产品类条目；
3. 抓取完成后，将产品标题、作者、发布时间与摘要写入 archive 分支对应的 JSON 文件；
4. 文件更新后立即被部署端读取并缓存，供 Bot 查询。

整个过程通常在 2 到 5 分钟内完成，若 Hacker News 接口偶发延迟，可能会稍久一些。

### 步骤 3：再次发送命令获取产品卡

等待约 2 到 5 分钟后，再次向 Bot 发送 `/product`（或 `/hn`）。此时 Bot 会从 archive 分支的 JSON 文件中读取当日数据，并立即以产品卡的形式回复你。

产品卡包含以下信息：

- 📅 日期：例如 `2026-08-30`；
- 🚀 产品名称：例如 `Linear — 快得离谱的项目管理工具`；
- 👤 作者与发布时间：例如 `by karpathy · about 3 hours ago`；
- 📝 一句话简介：概括产品的核心亮点；
- 💬 Hacker News 讨论摘要：摘录热门评论或产品卖点原文；
- 🖼 OG 图片：产品官网或相关预览图，随卡片一同展示。

Bot 的回复示例如下：

> 🚀 2026-08-30 Linear — 快得离谱的项目管理工具
> 👤 by karpathy · about 3 hours ago
> 📝 一款以速度著称的产品规划与 issue 跟踪工具。
> 💬 "Linear ……"

![再次发送 /hn 后，Bot 返回完整产品卡](assets/03-product-r2.png)

### 小贴士

1. **首次发送后请勿频繁重试**：触发 Actions 后立即重复发送命令并不会加速生成，反而可能产生多余的 dispatch 事件，建议等待 5 分钟后再尝试。
2. **善用别名 `/hn`**：如果觉得 `/product` 输入较长，等价的 `/hn` 随时可用，两条命令返回的内容完全一致。
3. **每日数据独立缓存**：每次返回的产品卡都来自当日 archive 分支的 JSON 快照，若想回顾历史产品，可关注 archive 分支中按日期命名的文件。
