## /trending — 今日 GitHub Trending

通过 `/trending` 命令,Bot 会为你拉取当天 GitHub Trending 列表,并自动整理成可直接阅读的卡片消息。每条卡片包含仓库名、星标数、作者、一句话简介、话题标签以及跳转链接。

### 步骤 1: 发送命令

在任意与 Bot 的私聊或群组中,输入:

```
/trending
```

### 步骤 2: 等待占位消息

当日的 Trending 还未生成时,Bot 会立刻回复一条占位消息,告诉你任务正在执行:

> ⏳ Trending 生成中(10-30 秒), 完成后自动推送。

看到这条消息时,不需要重复发送命令,后台任务正在跑完整管线(抓取 → 翻译 → 存档 → 发卡)。如果之前已经生成过、当天缓存命中,你会直接看到卡片,跳过占位阶段。

![占位消息与首条卡片](assets/02-trending-r1.png)

### 步骤 3: 阅读推送的卡片

占位消息发出约 10-30 秒后,Bot 会以连续多条消息的形式推送卡片,每条对应一个 Trending 仓库,格式如下:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending #c #editor 🗂 <a href="...">

其中 `1/2`、`2/2` 表示当日共 2 条卡片,数字表示当前条数与总条数,方便你确认是否已经收齐。

### 步骤 4: 复看当日 Trending

当天再次输入 `/trending` 时,Bot 会直接从缓存返回已经整理好的卡片,通常毫秒级响应,不会再发占位消息。

![缓存命中,秒回卡片](assets/02-trending-r2.png)

### 小贴士

- **不要重复刷命令**:看到「⏳ 生成中」后耐心等待 10-30 秒,重复发送不会加快生成,反而会产生多条占位。
- **跨设备一致**:同一份当日 Trending 缓存在所有会话共享,你在私聊看到的卡片,和群组里拉到的是同一份结果。
- **跳转阅读**:卡片中带 🗂 的链接指向 GitHub 仓库页,长按或点击即可在浏览器中打开详情与源码。
