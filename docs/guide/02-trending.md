## /trending — 今日 GitHub Trending

`/trending` 命令用于拉取当天 GitHub Trending 列表,自动完成翻译与归档,整理成卡片直接推送到当前会话。整个流程对缓存做了优化,首次触发会稍慢,之后会瞬间返回。

### 步骤 1: 发送命令

在任意与 Bot 的私聊或群组中,直接输入:

```
/trending
```

然后发送即可,无需附加任何参数。Bot 收到命令后会立刻判断今日数据是否已存在于缓存中,从而决定走「秒回」还是「生成」分支。

### 步骤 2: 等待占位提示(首次或缓存未命中)

如果当前是当日首次请求,缓存尚未命中,Bot 会先回一条占位消息,告诉你任务已启动但需要一点时间:

> ⏳ Trending 生成中(10-30 秒),完成后自动推送。

此时 **不要重复发送** `/trending`,多次请求只会触发多次后台任务,不会加速。等待 10 到 30 秒即可,生成完成后 Bot 会主动把卡片推送到同一个会话。

![首次请求,先回占位提示,随后陆续推送卡片](assets/02-trending-r1.png)

### 步骤 3: 阅读推送的 Trending 卡片

生成完成后,Bot 会按 `1/2`、`2/2` 的顺序,把当天的 Trending 项目逐条推送过来。每张卡片包含以下信息:

- **仓库名与作者**:如 `antirez/kilo 👤 antirez`。
- **Star 数**:例如 `⭐ 3.2k`。
- **一句话中文摘要**:对仓库用途的简要中文介绍。
- **话题标签**:自动生成的话题标签,如 `#trending #c #editor`,方便在群组里聚合检索。
- **归档标识**:末尾的 `🗂` 表示这条已写入 Bot 的历史档案,事后可通过归档命令回查。
- **链接**:点击即可跳转到对应的 GitHub 仓库页面。

例如一轮典型的回复会包含两条:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。 #trending #c #editor 🗂
> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。 #trending 🗂

### 步骤 4: 复用缓存(同日再次请求)

当天再次发送 `/trending` 时,Bot 会发现缓存已经命中,跳过抓取与翻译管线,直接秒级回显同样的卡片,不会再发送「⏳ 生成中」占位。这一行为使得 `/trending` 在群里被频繁复读时既稳定又省资源。

![同日再次请求,直接秒回卡片,无占位提示](assets/02-trending-r2.png)

### 小贴士

- **每天 0 点左右自动刷新**:Bot 在每天凌晨会清空当日 Trending 缓存,因此次日首次 `/trending` 仍会走完整生成流程,耗时约 10-30 秒。
- **不要并发触发**:在占位提示仍在时,不要再次发送 `/trending`,会生成重复任务并互相竞争资源,既不更快也更费时。
- **配合归档命令使用**:卡片末尾的 `🗂` 表示已归档,如果某条你感兴趣,可以紧接着使用 Bot 提供的归档检索命令(如 `/archive` 或 `搜归档`),按话题标签(如 `#c`)或日期快速回看。
