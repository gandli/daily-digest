# /trending — 今日 GitHub Trending

通过本命令,你可以一键获取当天 GitHub Trending 列表。Bot 会自动抓取、翻译中文简介并整理成易读卡片推送给你。

### 步骤 1: 发送指令

在 Telegram 对话框中输入命令 `/trending`(亦可使用短别名 `/gt`),然后发送给 Bot。命令不区分大小写,也无须附带任何参数。

### 步骤 2: 等待首次响应

Bot 会立即回复一条占位消息,告知你正在生成结果:

> ⏳ GitHub Trending 生成中(10-30 秒), 完成后自动推送。

这是因为完整管线包含「抓取 → 翻译 → 存档 → 发卡」多个环节,首次执行需要 10–30 秒。**无需重复发送命令**,等待 Bot 自动推送即可。

![占位消息与首张卡片推送](assets/02-trending-r1.png)

### 步骤 3: 接收第一批卡片

当流水线完成后,Bot 会依次推送若干条编号卡片,每条代表一个 Trending 仓库,包含三部分信息:

- **仓库标识与数据**:仓库全称(如 `antirez/kilo`)、Star 数(如 ⭐ 3.2k)、作者头像与用户名(如 👤 antirez)。
- **中文简介**:由 Bot 自动翻译或生成的一句话介绍,帮助你快速判断是否值得深入了解。
- **标签与链接**:末尾以 `#` 开头的标签(如 `#trending #c #editor`)用于检索,`🗂` 后紧跟可点击的链接,直接跳转到对应 GitHub 仓库页面。

例如,在首次调用中你将看到 `1/2 antirez/kilo …` 与 `2/2 sharkdp/bat …` 两张连续卡片。

### 步骤 4: 复用以秒回卡片

当天再次发送 `/trending` 时,Bot 会直接读取已缓存的结果,**不再回显「生成中」占位**,而是立即推送与上一次相同(或最新已抓取)的卡片列表,响应时间通常在 1 秒以内。

![复调用秒回卡片列表](assets/02-trending-r2.png)

### 步骤 5: 浏览与跳转

依次查看推送的卡片即可。如需进一步了解某个仓库,直接点击卡片末尾的 GitHub 链接在浏览器中打开即可。所有卡片同时支持 Telegram 端内的「消息搜索」,通过标签(如 `#python`)检索历史记录。

## 小贴士

- **避免重复触发**:首次收到「⏳ 生成中」后耐心等待,不要短时间内连发多次 `/trending`,以免产生重复的后台任务。
- **理解卡片格式**:编号 `n/N` 表示当天共有 N 个 Trending,当前为第 n 个;Star 数 `k` 代表千、`M` 代表百万。
- **定时刷新**:Bot 通常会在每日固定时间(建议查阅 `/help`)自动重建缓存,无需手动反复调用即可获得当天最新榜单。
