# /trending — 今日 GitHub Trending

`/trending` 命令用于拉取当天 GitHub Trending 热门仓库，并通过 Bot 推送一张精选卡片。首次调用会先返回占位提示，再由后台完成抓取与翻译后正式发卡；同一自然日内重复调用则会直接命中缓存，秒级返回，无需等待。

### 步骤 1：发送命令

在 Telegram 对话窗口中输入 `/trending` 并发送，触发当天的 Trending 拉取流程。命令无需附加任何参数，Bot 会以“今天”为默认时间范围自动处理。

### 步骤 2：等待占位提示（首次调用）

首次发送后，Bot 会立刻回复一条提示消息，告知卡片正在生成中：

> ⏳ Trending 生成中（10-30 秒），完成后自动推送。

此时无需任何额外操作，Bot 会在后台依次执行抓取、翻译、存档、发卡四项任务，整个过程通常在 10 到 30 秒内完成。

![首次调用，Bot 返回占位提示并随后推送完整卡片](assets/02-trending-r1.png)

### 步骤 3：接收完整卡片

后台任务完成后，Bot 会在同一聊天中按 `1/2`、`2/2` 的形式分条推送今日 Trending 卡片。每条卡片包含：

- 仓库路径（例如 `antirez/kilo`）
- Star 数与作者名（例如 ⭐ 3.2k 👤 antirez）
- 中文简介
- 主题标签（如 `#trending #c #editor`）
- 跳转链接（HTML 锚点形式，点击即可直达 GitHub）

当 1/2 与 2/2 两条消息都收到后，当天的 Trending 拉取即完成。

### 步骤 4：直接命中缓存（当日再次调用）

在同一自然日内再次发送 `/trending` 时，Bot 会跳过抓取与翻译管线，直接从缓存中读取当日结果，秒级返回完整的 1/2、2/2 卡片，不再出现“生成中”的占位提示。

![当日再次调用，Bot 直接秒回完整卡片](assets/02-trending-r2.png)

## 小贴士

- **每天只需首次等待**：当日首次调用会触发 10-30 秒的生成过程，若只需浏览内容，可在生成完成后再来查看，避免反复发送造成重复排队。
- **跨日会重新拉取**：Bot 以“自然日”为缓存单位，第二天再次调用 `/trending` 时会重新生成一次新的卡片，确保内容始终是当天的 Trending 榜单。
- **关注标签筛选主题**：卡片末尾的 `#c` 等主题标签可帮助你快速判断仓库所属领域，结合跳转链接可直接在 GitHub 上进一步阅读源码或 Star。
