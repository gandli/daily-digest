## /trending — 今日 GitHub Trending

通过 `/trending`(对话中以别名 `/gt` 调用)指令,即可获取当日 GitHub Trending 仓库摘要。Bot 会优先返回缓存内容;若当日尚未生成,则先发送占位提示,后台完成抓取、翻译、存档后再自动推送卡片。

### 步骤 1: 发送指令

在 Telegram 对话中输入并发送 `/trending`(或快捷别名 `/gt`)。

### 步骤 2: 等待首次响应(缓存未命中场景)

若当日尚未生成,Bot 立即回复一条占位提示,告知生成任务已启动:

> ⏳ GitHub Trending 生成中(10-30 秒), 完成后自动推送。

此占位仅出现一次,无需重复发送指令。完整管线(抓取 → 翻译 → 存档 → 发卡)在后台运行,通常 10-30 秒内完成。

![首次调用,占位提示与首张卡片依次出现](assets/02-trending-r1.png)

### 步骤 3: 接收生成的 Trending 卡片

后台任务完成后,Bot 自动推送今日 Trending 列表(本对话样例为 2/2 条)。每张卡片包含:

- 序号与仓库全称,如 `1/2 antirez/kilo`
- ⭐ 星标数与 👤 作者,例如 `⭐ 3.2k 👤 antirez`
- 中文摘要与话题标签(例如 `#trending #c #editor`)
- 🗂 后的仓库链接,可直接点击访问

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending #c #editor 🗂 <a href="..."

### 步骤 4: 二次调用(缓存命中场景)

同一天内再次发送 `/trending` 或 `/gt`,Bot 直接秒回完整的 Trending 卡片,不再出现占位提示,也无须重新跑管线。

![二次调用,直接返回卡片,无占位提示](assets/02-trending-r2.png)

### 步骤 5: 浏览与跳转

逐条阅读卡片摘要,点击 🗂 后面的链接即可在浏览器中打开对应的 GitHub 仓库。

## 小贴士

- 占位提示出现后请耐心等待,不要重复发送 `/trending`,否则会重复排队同一任务。
- 摘要内容为机器翻译润色,建议结合链接到原仓库查看 README,获取最准确的描述。
- 若想查看其它日期的 Trending,请使用 `/trending YYYY-MM-DD` 格式(以 Bot 支持为准),默认指令仅返回当日数据。
