## /trending — 今日 GitHub Trending

`/trending` 用于拉取当天 GitHub Trending 榜单,以单条消息卡片形式逐条推送热门仓库简介。当日首次请求触发后台管线,后续请求通常直接命中缓存。

### 步骤 1: 发送命令

在 Bot 对话中输入并发送:

```
/trending
```

Bot 会先回一条占位消息,提示你等待:

> ⏳ Trending 生成中(10-30 秒), 完成后自动推送。

此时 Bot 已在后台启动完整管线(抓取 → 翻译 → 存档 → 发卡),你无需任何额外操作,只需原地等候。

### 步骤 2: 等待首张卡片推送

10-30 秒后,Bot 会主动把榜单分成多条消息按顺序发出,无需你再发送任何命令。典型的第 1 条内容形如:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez
> 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。
> #trending #c #editor 🗂 <a href="https://.../antirez/kilo">链接</a>

### 步骤 3: 接收后续卡片

第 1 条发出后,Bot 会立即继续推送剩余条目,例如:

> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp
> 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。
> #trending 🗂 <a href="https://.../sharkdp/bat">链接</a>

看到 `2/2` 即表示当日榜单推送完毕。

### 步骤 4: 再次请求,体验缓存加速

几分钟后再次发送 `/trending`,由于缓存已命中,Bot 不会再发送"⏳ 生成中"占位,而是直接逐条重发当日卡片,几乎秒回。

### 小贴士

- **别重复点**:占位消息出现后,无需再次发送 `/trending`,重复发送只会重启同一管线,反而可能拉长等待时间。
- **错峰再问**:如果想确认 Bot 是否还在线,在第一次请求完成后再发一次即可;命中缓存的秒回是验证 Bot 状态最直观的方式。
- **榜单当天有效**:每日 Trending 会在自然日切换时刷新;若想看昨日榜单,可在管线不支持回溯时改为浏览 GitHub 官网。
