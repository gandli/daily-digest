## /trending — 今日 GitHub Trending

`/trending` 用于拉取当天的 GitHub Trending 仓库, 并由 Bot 自动翻译简介、生成卡片推送给你。Bot 会优先读取缓存, 命中则直接秒回; 未命中时则先发占位提示, 等待 10-30 秒后再推送完整结果。

### 步骤 1: 发送指令

在 Bot 对话窗口中输入:

```
/trending
```

发送即可, 无需附加任何参数。

### 步骤 2: 等待占位提示(首次或缓存未命中)

当今日尚未生成过 Trending 卡片时, Bot 会先回复一条占位消息, 提示生成任务已启动:

> ⏳ Trending 生成中(10-30 秒), 完成后自动推送。

此时你无需重复发送指令, 只需保持对话窗口打开, 等候 Bot 自动推送即可。

![首次调用占位提示](assets/02-trending-r1.png)

### 步骤 3: 接收完整卡片

等待约 10-30 秒后, Bot 会以编号列表形式连续推送 2 条(或更多)仓库卡片, 每条卡片包含:

- 序号与仓库名, 例如 `1/2 antirez/kilo`
- ⭐ Star 数与 👤 作者
- 中文翻译后的简介
- 标签, 例如 `#trending #c #editor`
- 🗂 跳转链接, 可直接点击查看原仓库

示例卡片:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending #c #editor 🗂 <a href="…">…</a>
>
> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending 🗂 <a href="…">…</a>

点击卡片末尾的 🗂 链接, 即可跳转到 GitHub 查看项目详情。

### 步骤 4: 二次调用(命中缓存)

当日再次发送 `/trending` 时, Bot 会直接复用已生成的卡片, 不再发占位提示, 而是立即连续推送完整列表, 体验接近“秒回”。如需刷新当日内容, 等待每日缓存自然失效即可, 不必反复触发。

![缓存命中秒回卡片](assets/02-trending-r2.png)

### 小贴士

- 占位提示出现后请耐心等待 10-30 秒, 重复发送 `/trending` 不会加快生成, 反而会重新排队。
- 每张卡片末尾的 🗂 链接指向 GitHub 原仓库, 标签(如 `#python` / `#rust`)可用于粗略判断技术栈方向。
- 卡片内容由翻译管线自动生成, 简介侧重总体定位, 详细架构与使用方式建议结合仓库 README 阅读。
