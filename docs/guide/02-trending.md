### 步骤 1：发送 /gt 指令

在 Telegram 对话框中输入斜杠命令 **/gt** 并发送。这是 Bot 提供的 GitHub Trending 快捷入口，等价于「/trending」。发送后无需其他操作，等待 Bot 响应即可。

### 步骤 2：等待「生成中」占位提示

首次触发或缓存未命中时，Bot 会立即回复一条占位消息：

> ⏳ Trending 生成中(10-30 秒), 完成后自动推送。

这表示 Bot 正在后台执行完整管线：抓取 GitHub 当日 Trending 榜单 → 翻译仓库描述为中文 → 归档到内部存储 → 组装并推送卡片。整个过程通常在 10 到 30 秒内完成，你不需要重复发送命令。

![首次 /trending 的占位提示与推送结果](assets/02-trending-r1.png)

### 步骤 3：接收并阅读 Trending 卡片

管线完成后，Bot 会以编号消息的形式连续推送当日榜单。卡片包含三类关键信息：

- **仓库路径**（如 `antirez/kilo`、`sharkdp/bat`）；
- **星标数与作者**（例如 ⭐ 3.2k 👤 antirez）；
- **一句话中文简介**（如「这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。」）；
- **话题标签**（如 `#trending #c #editor`）和 **🗂 跳转链接**，点击即可直达 GitHub 仓库页面。

逐条浏览即可快速了解今日热门项目。

### 步骤 4：再次查询时直接命中缓存

在同一自然日内再次发送 **/gt**，Bot 会直接复用已生成的卡片，**不再回显「⏳ 生成中」占位**，而是立即按原顺序推送完整结果，响应速度接近「秒回」。验证缓存命中行为的截图如下：

![重复 /trending 时直接返回缓存结果](assets/02-trending-r2.png)

如果你看到「⏳ 生成中」再次出现，说明缓存已过期或被刷新（例如跨天、运维重建索引），属于正常现象，等待新一轮推送即可。

---

## 小贴士

1. **不要重复点击发送**：生成占位后，Bot 会在后台自动推送结果，短时间内连发多次 /gt 只会产生冗余任务，可能拉长等待时间。
2. **跨天请重新触发**：Bot 的缓存以「当日」为单位，每天首次调用会重新拉取真实榜单；如发现列表与预期不符，可多等几分钟再试一次。
3. **关注话题标签**：简介末尾的 `#c`、`#editor` 等标签是仓库的语言或领域关键词，便于你在多条卡片中快速识别自己感兴趣的方向。
