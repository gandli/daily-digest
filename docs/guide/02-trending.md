## /trending — 今日 GitHub Trending

通过本指令可获取当天 GitHub Trending 热门仓库列表。Bot 会智能判断是否已有当日缓存:命中缓存时立即返回完整卡片;未命中时先发送占位提示,后台异步生成后自动推送。

### 步骤 1: 发送触发指令

在聊天窗口中输入:

```
/gt
```

或输入完整指令:

```
/trending
```

两条指令等价,均会触发今日 Trending 拉取流程。

### 步骤 2: 等待占位回执(首次触发)

若 Bot 当前无今日缓存,会立即回复一条提示消息,告知用户后台正在生成,无需等待:

> ⏳ GitHub Trending 生成中(10-30 秒),完成后自动推送。

随后保持聊天窗口打开,Bot 会在 10 到 30 秒内主动推送完整结果。

![首次触发时的占位回执与后台生成结果](assets/02-trending-r1.png)

### 步骤 3: 查看推送的 Trending 卡片

Bot 会按热度顺序逐条推送仓库卡片,每条卡片包含:

- 序号与总量(如 `1/2`、`2/2`),便于了解列表长度;
- 仓库路径(如 `antirez/kilo`、`sharkdp/bat`);
- 星标数(如 ⭐ 3.2k、⭐ 50.0k);
- 作者名(如 👤 antirez);
- 一句话中文简介与话题标签(如 `#trending #c #editor`);
- 🗂 跳转链接,可点击直达 GitHub 仓库页面。

卡片以分条消息形式推送,翻阅聊天记录即可逐一查看。

### 步骤 4: 再次查询(命中缓存)

在同一自然日内再次发送 `/gt` 或 `/trending`,Bot 将直接从缓存返回完整卡片列表,不再发送「⏳ 生成中」提示,实现秒级响应。

![再次查询时秒回完整卡片列表](assets/02-trending-r2.png)

### 步骤 5: 跨日自动失效

缓存仅在当天有效。跨天后首次发送指令,Bot 会重新执行步骤 2 与步骤 3 的完整流程,再次抓取并生成当日最新 Trending。

## 小贴士

- **高频查询无需等待**:同一日内重复使用 `/gt` 会走缓存路径,响应速度远快于首次触发,适合随时查阅。
- **主动推送无需保持操作**:首次触发后的 10-30 秒内,Bot 会自动把结果推回当前聊天,期间可正常使用其他功能,不必盯着对话框。
- **点击 🗂 直达仓库**:每张卡片末尾的折叠链接即为对应 GitHub 仓库地址,可直接打开查看源码、Star 或 Fork。
