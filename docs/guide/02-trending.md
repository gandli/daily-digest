## /trending — 今日 GitHub Trending

使用此命令可一键获取当天 GitHub Trending 热门仓库,Bot 会以紧凑的卡片格式推送仓库简介、Star 数、维护者及标签,方便快速浏览技术风向。

### 步骤 1:发送命令

在 Telegram 对话框中输入 `/trending`(本例中使用等价的快捷别名 `/gt`)并发送,即可触发今日 GitHub Trending 拉取。

### 步骤 2:等待占位提示(仅缓存未命中时)

Bot 会立即回执一条状态消息,告知正在生成中。这条占位消息仅在当日缓存未命中、需要后台跑完整管线(抓取 → 翻译 → 存档 → 发卡)时出现;若缓存已命中,会直接进入步骤 3 的卡片推送,看不到此提示。

> ⏳ GitHub Trending 生成中(10-30 秒),完成后自动推送。

### 步骤 3:接收第一条仓库卡片

后台任务完成后,Bot 会自动连续推送若干条编号仓库卡片,无需用户再做任何操作。卡片采用「序号/总数 仓库名 ⭐ Star 数 👤 维护者」开头,后接中文简介、主题标签(以 `#` 开头)以及 `🗂` 直达链接。例如本轮第 1 条:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。 #trending #c #editor 🗂 <a href="...">...</a>

首次请求时,步骤 2 的占位提示与步骤 3 的卡片推送会在同一对话中先后出现,如下图所示。

![首次请求时先看到占位提示,随后收到第一条仓库卡片](assets/02-trending-r1.png)

### 步骤 4:接收后续仓库卡片并继续浏览

Bot 会按编号顺序依次推送剩余的仓库卡片,直到「序号/总数」中的分母为止。例如本轮第 2 条:

> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。 #trending 🗂 <a href="...">...</a>

当日的全部卡片推送完毕即可结束本次浏览。

### 步骤 5:当日再次请求走缓存

在同一自然日内再次发送 `/trending`(或 `/gt`)时,Bot 会直接命中缓存,跳过「⏳ 生成中」占位,秒回完整卡片列表,体验与步骤 3、步骤 4 完全一致,只是不会再出现步骤 2。

![同日再次请求直接返回完整卡片,无占位提示](assets/02-trending-r2.png)

### 小贴士

- 首次触发后请耐心等待 10-30 秒,期间不要重复发送命令,后台管线跑完后 Bot 会自动推送卡片,重复请求只会重新走占位流程。
- `/gt` 与 `/trending` 是同一条命令的两种写法,可任选使用,功能与返回内容完全一致。
- 卡片中的 `🗂` 链接指向对应仓库的 GitHub 页面,长按或点击即可直接跳转查看源码与详情。
