## /trending — 今日 GitHub Trending

通过一条命令即可拉取当天 GitHub Trending 热门仓库。Bot 会先在后台跑「抓取 → 翻译 → 存档 → 发卡」完整管线，再以编号卡片的形式推送给你。

### 步骤 1:发送命令

在 Telegram 对话框中输入以下命令并发送:

```
/trending
```

### 步骤 2:等待占位回复

Bot 检测到当天还没有缓存,会立刻回一条占位消息,提示你管线正在跑:

> ⏳ Trending 生成中(10-30 秒), 完成后自动推送。

此时你无需任何操作,也不必重复发送命令。

### 步骤 3:接收编号卡片

约 10–30 秒后,Bot 会把当日 Trending 仓库以 `1/2`、`2/2` 这样的多张编号卡片自动推送到当前对话。每张卡片包含:仓库名、Star 数、作者、简介翻译、相关话题标签(#trending 等)以及🗂 链接按钮。点开按钮即可跳转到对应 GitHub 仓库页面。

![首次执行 /trending,先收到占位消息,再陆续收到编号卡片](assets/02-trending-r1.png)

### 步骤 4:再次查询(命中缓存)

当天再次发送 `/trending`,由于缓存已命中,Bot 会跳过占位消息,直接按相同格式(仍是 `1/2`、`2/2` 编号卡片)秒级推送当天的内容,无需等待。

![缓存命中时,直接秒回编号卡片,不再有占位消息](assets/02-trending-r2.png)

### 小贴士

- 每天的 Trending 内容在首次请求后即被缓存;同一自然日内多次发送 `/trending` 都是秒回,适合随时回看。
- 看到「⏳ 生成中」后请耐心等待,**不要重复发送命令**,重复请求不会加快生成,反而可能让 Bot 排队处理。
- 编号卡片中的🗂 按钮是直达原仓库的入口;长按卡片还能转存或转发给好友,方便分享当天热门项目。
