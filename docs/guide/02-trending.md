## /trending — 今日 GitHub Trending

通过本指令可一键拉取当天 GitHub Trending 热门仓库摘要。Bot 会在首次请求时启动完整流水线(抓取 → 翻译 → 存档 → 发卡),后续请求则会命中缓存,秒级返回。

### 步骤 1: 发送指令

在 Bot 对话中输入并发送:

```
/trending
```

### 步骤 2: 等待占位提示(冷启动场景)

若当天缓存尚未生成,Bot 会立即回执一条占位消息,告知流水线正在运行:

> ⏳ Trending 生成中(10-30 秒), 完成后自动推送。

此时无需重复发送指令,等待卡片自动推送即可。等待时长通常在 10-30 秒之间,取决于网络与翻译服务负载。

![冷启动:占位提示 + 后续两张卡片依次推送](assets/02-trending-r1.png)

### 步骤 3: 接收 Trending 卡片

流水线完成后,Bot 会以编号形式依次推送仓库卡片,格式如下:

- **序号 / 总数**:形如 `1/2`,`2/2`,标识当天的仓库排名
- **仓库名**:`owner/repo` 形式,例如 `antirez/kilo`
- **⭐ Star 数**:展示当前累计 Star 数量
- **👤 作者**:仓库所有者用户名
- **简介**:对仓库功能与亮点的一句话中文摘要
- **标签**:以 `#` 开头的关键词,例如 `#trending`、`#c`、`#editor`
- **🗂 存档**:附带 archive 链接,可查阅或回看历史

首次拉取的完整对话如上图所示:先看到「生成中」提示,再依次收到 `1/2 antirez/kilo` 与 `2/2 sharkdp/bat` 两条卡片。

### 步骤 4: 再次发送指令(缓存命中)

当天再次输入 `/trending`,Bot 不再触发流水线,而是直接从缓存返回相同卡片,响应几乎是即时的。

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez ...
> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp ...

![热路径:缓存命中,直接秒回两张卡片](assets/02-trending-r2.png)

对比两张截图可见:第二轮没有「生成中」占位,Bot 在毫秒级同时或连续返回了完整卡片列表。

### 小贴士

- **耐心等待占位消息**:看到「⏳ 生成中」后请勿重复发送 `/trending`,重复请求可能使流水线重复排队,反而延长等待时间。
- **当天缓存有效**:每日 Trending 列表在自然日内会缓存复用,一天内多次查询均走快速通道;跨天后再次请求会重新触发完整流水线。
- **关注 archive 链接**:卡片底部的 🗂 存档链接可用于回溯历史 Trending,也方便收藏感兴趣的仓库。
