### 步骤 1: 发送命令

在 Telegram 任意与 Bot 的私聊或群聊中,输入命令 `/gt` 并发送。这是拉取当日 GitHub Trending 项目的入口命令,大小写不敏感,也可写作 `/trending` 触发同一管线。

### 步骤 2: 等待占位提示

首次发送或当日缓存尚未生成时,Bot 不会立刻返回完整卡片,而是回复一条轻量占位消息,提示你稍候:

> ⏳ Trending 生成中(10-30 秒), 完成后自动推送。

这表示后台已拉起完整管线,正在依次执行抓取 Trending 列表、翻译描述、写入存档三步。占位消息的目的是让 Bot 响应时间落在交互可接受范围内,避免命令超时。

![首次发送后 Bot 推送占位提示与两张项目卡片](assets/02-trending-r1.png)

### 步骤 3: 接收项目卡片

约 10-30 秒后,Bot 会在同一聊天中自动推送分批卡片,每张卡片按 `编号/总数 仓库名 ⭐ 星标 👤 作者 简介 #标签` 的格式组织:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending #c #editor 🗂 `<a href="…">`
>
> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending 🗂 `<a href="https:…">`

每张卡片底部带有一个 🗂 折叠链接,点击即可跳转到对应 GitHub 仓库详情页;尾部的 `#trending` 及主题标签(如 `#c`、`#editor`)便于二次聚合检索。

### 步骤 4: 重复命令命中缓存

当日再次发送 `/gt` 时,管线直接命中当日缓存,不会再走抓取与翻译流程,而是秒级回显相同的卡片序列,内容与首次保持一致:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez … #trending #c #editor 🗂
>
> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp … #trending 🗂

![重复发送后 Bot 直接返回缓存卡片](assets/02-trending-r2.png)

这意味着你可以在群内反复 `@Bot /gt` 供多人查看,不会对上游 GitHub 造成重复请求。

### 小贴士

- **首推慢、回推快**: 每天每个聊天首次触发需等待 10-30 秒,之后当日内所有调用均为缓存命中,适合在技术群早间播报时使用。
- **以链接为准**: 卡片中的中文简介用于快速筛选,涉及版本、兼容性等关键信息请以 🗂 折叠链接指向的 GitHub 仓库 README 为准。
- **跨天自动刷新**: 缓存按自然日生效,跨天后再次发送 `/gt` 会重新触发抓取与翻译管线,看到新的占位提示即代表已切换到新一天的数据。
