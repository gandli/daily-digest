### /trending — 今日 GitHub Trending

通过一条命令即可拉取当天 GitHub Trending 仓库的精选卡片。命中缓存时 Bot 会瞬间返回结果;未命中时 Bot 先回一条占位消息,随后在后台完成抓取、翻译、存档与发卡全流程,并自动推送最终结果。

### 步骤 1: 发送命令

在 Telegram 对话窗口中输入以下命令并发送:

`/gt`

Bot 会根据当前是否有可用缓存,返回不同的反馈。

### 步骤 2a: 未命中缓存 — 等待生成

如果当天尚未生成过 Trending 卡片,Bot 会先回复一条占位消息:

> ⏳ GitHub Trending 生成中(10-30 秒), 完成后自动推送。

随后在后台依次执行抓取 → 翻译 → 存档 → 发卡流程,无需你做任何额外操作。生成完成后,Bot 会把卡片直接推到当前对话,通常在 10 到 30 秒内送达。

![未命中缓存时 Bot 先回占位、再推送完整卡片](assets/02-trending-r1.png)

### 步骤 2b: 命中缓存 — 秒回卡片

如果当日 Trending 已生成过,Bot 会立即连发完整卡片,无需等待。卡片内容包含仓库名、星标数、作者、一句话简介、相关标签以及跳转链接。例如:

![命中缓存时 Bot 直接连发完整卡片](assets/02-trending-r2.png)

### 步骤 3: 阅读并点击链接

逐条浏览仓库标题、星标、作者与简介,根据标签(#c、#editor 等)判断是否感兴趣。点开卡片底部的链接即可跳转到 GitHub 仓库页查看源码、README 与使用示例。卡片以 `n/n` 形式编号,共两张,可在同一消息流中读完。

### 小贴士

- 首次触发或超过当日缓存周期时,务必留意那条「⏳ 生成中」占位消息,生成期间请勿重复发送 `/gt`,否则会重复排队并可能覆盖推送。
- 一次 `/gt` 通常包含 2 张当日精选仓库卡片,适合在早间或午间定时查看,以把握每日热点。
- 若长时间(超过 30 秒)未收到后续推送,可能是后台管线异常,可稍后重试 `/gt`,或检查 Bot 是否仍在当前对话中处于可用状态。
