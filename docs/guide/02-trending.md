## /trending — 今日 GitHub Trending

使用 `/trending`(常用别名 `/gt`)可一键拉取当天 GitHub Trending 仓库。Bot 会自动为你抓取榜单、翻译简介,并以卡片形式推送到对话中。下面以两次连续调用为例,演示完整流程。

### 步骤 1: 发送指令

在任意与 Bot 的对话中,输入命令:

```
/trending
```

(或使用其别名 `/gt`)

### 步骤 2: 等待首条占位回复

Bot 会先判断当天榜单是否已有缓存。

- **未命中缓存**:Bot 立即返回一条占位消息,告知你正在生成中:

  > ⏳ GitHub Trending 生成中(10-30 秒),完成后自动推送。

  这条消息表示后台正在执行完整管线:抓取 GitHub Trending → 翻译仓库简介 → 归档结果 → 推送卡片。无需你做任何事,等待即可。

![首次调用触发生成中提示](assets/02-trending-r1.png)

### 步骤 3: 接收首条结果卡片

后台管线完成后,Bot 会按榜单顺序依次推送卡片,每条仓库一张。每张卡片包含:

- 序号与总数(例如 `1/2`);
- `用户名/仓库名`;
- 今日 Star 数(例如 `⭐ 3.2k`);
- 作者名(例如 `👤 antirez`);
- 翻译后的中文简介;
- 话题标签(例如 `#trending #c #editor`);
- 仓库链接(以 HTML 锚标签形式给出)。

### 步骤 4: 接收剩余卡片,完成推送

Bot 会继续推送剩余仓库卡片,直至榜单全部发送完毕。例如本例中第二条:

> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。 #trending 🗂 <a ...

此时,完整的当天 GitHub Trending 推送结束。

### 步骤 5: 再次调用,验证缓存生效

当你在同一天内再次发送 `/trending` 时,Bot 会直接命中当天已生成的缓存,跳过占位回复,立刻按相同顺序逐条推送卡片,体验上属于"秒回"。

![再次调用直接命中缓存,秒回卡片](assets/02-trending-r2.png)

### 小贴士

1. **首条"⏳ 生成中"是占位符,请勿重复发送命令**。后台管线正在运行,重复触发只会让任务队列变长,反而延迟你自己的卡片到达。
2. **一天内多次调用会复用同一份缓存**。若想看新内容,可在次日零时之后再调用,Bot 会自动重新抓取并生成新榜单。
3. **卡片中的链接使用 HTML 锚标签格式**(`<a href="...">`)。在支持富文本渲染的 Telegram 客户端中可直接点击跳转 GitHub 仓库页面。
