## /trending — 今日 GitHub Trending

通过 `/trending` 命令,你可以随时获取当天 GitHub Trending 仓库榜单。Bot 会按"抓取 → 翻译 → 存档 → 发卡"的完整流水线处理,首次请求需等待,后续即可秒回。

### 步骤 1: 发送命令

在任意 Bot 对话中,输入以下命令并发送:

```
/trending
```

Bot 收到请求后,会立即回执一条占位消息,提示后台正在生成。

### 步骤 2: 等待占位回执

Bot 首先返回:

> ⏳ Trending 生成中(10-30 秒), 完成后自动推送。

![首次请求占位消息](assets/02-trending-r1.png)

这张占位卡表示 Bot 已经把任务排入后台流水线。如果当天 Trending 尚未缓存,完整流程(抓取 → 翻译 → 存档 → 发卡)需要 10-30 秒,期间无需任何额外操作,等待即可。

### 步骤 3: 接收完整榜单

后台任务完成后,Bot 会自动在同一对话中推送当天的 Trending 卡片,每条仓库一张,按热度顺序编号:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending #c #editor 🗂 <a href="…">
>
> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending 🗂 <a href="…">

![首轮生成的完整榜单](assets/02-trending-r1.png)

每张卡片包含仓库名、Star 数、作者、中文简介、话题标签以及原始链接,可以直接点开查看。

### 步骤 4: 再次请求触发缓存秒回

当天再次发送 `/trending` 时,Bot 命中缓存,跳过占位与生成阶段,直接推送完整榜单:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending #c #editor 🗂 <a href="…">
>
> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending 🗂 <a href="…">

![缓存命中直接返回榜单](assets/02-trending-r2.png)

可以看到,第二轮请求**没有**出现"⏳ 生成中"占位,这就是缓存命中后的秒回行为。

### 小贴士

- **首次请求请耐心等待**: 看到"⏳ 生成中"提示后,不要重复发送命令,重复请求会被重新排队,反而延长等待时间。
- **跨日缓存会失效**: 每天凌晨(UTC) Trending 榜单刷新后,首次请求需要重新走完整流水线,之后再次请求即可秒回。
- **点链接直接跳转**: 每张卡片末尾的 `<a href="…">` 链接指向对应 GitHub 仓库首页,可直接点开查看 README 和源码。
