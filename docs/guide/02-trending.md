### 步骤 1：发送 /trending 命令

在 Telegram 对话窗口中输入框内键入 `/trending`,然后点击发送(或按回车键)。这是触发今日 GitHub 热门仓库查询的唯一指令,无需任何额外参数。

### 步骤 2：等待占位提示

Bot 接收到指令后,会立即回复一条占位消息:

> ⏳ Trending 生成中(10-30 秒),完成后自动推送。

此时 Bot 正在后台执行完整的处理流水线:从 GitHub 拉取当天的 Trending 列表、翻译仓库描述、归档数据、最后生成可读卡片。该提示让用户明确知道请求已被受理,无需重复发送命令。

![首轮触发后立即收到占位提示,随后推送两条仓库卡片](assets/02-trending-r1.png)

### 步骤 3：接收仓库卡片

大约 10 到 30 秒后,Bot 会按热度顺序连续推送 2 条仓库卡片。每张卡片采用统一格式,包含以下信息:

- **序号与仓库全称**:如 `1/2 antirez/kilo`,冒号前的分母表示当日总卡片数。
- **星标数**:以 `⭐` 加数字呈现,例如 `⭐ 3.2k` 或 `⭐ 50.0k`,直观反映社区关注度。
- **作者昵称**:以 `👤` 前缀标注仓库所有者,如 `antirez`、`sharkdp`。
- **中文简介**:对仓库功能与特点的简明翻译说明。
- **话题标签**:以 `#` 开头的关键词,例如 `#trending`、`#c`、`#editor`,方便快速判断技术领域。
- **链接标记**:卡片末尾的 `🗂` 图标后跟可点击的仓库链接。

### 步骤 4：再次查询(命中缓存)

在同一天内再次发送 `/trending`,Bot 会跳过抓取与翻译流程,直接读取已归档的当日数据,几乎瞬时返回与首轮内容一致的卡片,不再出现「生成中」占位。

![重复请求直接命中缓存,秒级返回卡片](assets/02-trending-r2.png)

### 小贴士

- **避免重复触发**:看到「⏳ 生成中」提示后请耐心等待,不要在 30 秒内连续发送 `/trending`,以免在流水线中生成多份重复任务。
- **关注标签快速筛选**:若只对特定语言或领域感兴趣,可优先查看每张卡片的话题标签(如 `#python`、`#llm`),再决定是否点击链接深入了解。
- **跨时区说明**:Bot 所拉取的是 UTC 当日的 Trending 快照,通常在每个自然日的凌晨完成更新;如需最新数据,请等待日切后再行查询。
