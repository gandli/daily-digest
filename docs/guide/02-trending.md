### 步骤 1：发送指令

在 Telegram 对话框中输入 `/trending` 并发送。这是当日 GitHub Trending 仓库的快捷查询命令，Bot 会在收到后立即响应。

### 步骤 2：等待占位提示

若当前没有可用缓存，Bot 会先回一条提示消息告知你生成进度，例如：

> ⏳ Trending 生成中(10-30 秒), 完成后自动推送。

这条消息表示 Bot 已开始执行完整管线（抓取 → 翻译 → 存档 → 发卡），请耐心等待 10–30 秒，无需重复发送指令。首次或缓存过期场景下通常会看到该提示。

![首次调用返回占位提示与首条卡片](assets/02-trending-r1.png)

### 步骤 3：查看推送卡片

管线完成后，Bot 会按顺序将当日 Trending 仓库以多条消息形式推送到同一对话中，每条消息对应一个仓库卡片，格式示例：

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending #c #editor 🗂 <a ...>

卡片包含：序号（如 `1/2`）、仓库名（`owner/repo`）、星标数、作者、简介中文翻译、热门标签、归档图标以及跳转链接。截图示例中可见 `antirez/kilo` 与 `sharkdp/bat` 两张卡片依次到达。

### 步骤 4：二次查询（缓存命中）

当你再次发送 `/trending` 时，若当日缓存仍然有效，Bot 会跳过完整管线，直接秒回卡片，不再返回“⏳ 生成中”占位消息。

![二次调用直接秒回卡片，无占位提示](assets/02-trending-r2.png)

对比两轮截图可以清晰看出：首次调用多了占位提示，二次调用则直接推送结果，这就是缓存命中带来的体验差异。

### 小贴士

- 看到 “⏳ 生成中” 时请勿重复点击 `/trending`，否则会触发新的生成任务、延长等待时间。
- 卡片中的 `#trending #c #editor` 等标签便于你按主题筛选关注方向，点击消息下方的链接即可跳转到对应 GitHub 仓库。
- 每日 Trending 数据在当天内会被缓存复用，建议在同一自然日内重复查询以获得最快响应；跨天后再次调用则会重新走完整管线。
