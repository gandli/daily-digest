## /trending — 今日 GitHub Trending

通过 `/trending` 命令(简写 `/gt`)获取当天 GitHub Trending 仓库列表。Bot 会先尝试返回缓存卡片;若缓存未命中,会先回一个「生成中」的占位消息,然后在 10-30 秒内自动推送完整卡片,无需再次发送命令。

### 步骤 1: 发送命令

在 Telegram 对话框中输入以下任一命令并发送:

- `/trending`
- `/gt`

Bot 会根据缓存状态给出两种不同的反馈。

### 步骤 2a: 缓存未命中 — 收到「生成中」占位

当 Bot 尚未拉取过当天的 Trending 时,会立即回复一条占位消息:

> ⏳ GitHub Trending 生成中(10-30 秒),完成后自动推送。

此时无需任何操作,等待即可。下图展示了发送命令后立刻收到的占位消息:

![占位消息与首批卡片推送](assets/02-trending-r1.png)

### 步骤 2b: 后台管线完成 — 收到完整卡片

约 10-30 秒后,Bot 会自动向同一对话推送当天的 Trending 列表,通常分多条消息,格式形如:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。 #trending #c #editor 🗂 <a href="...">…</a>
>
> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp … #trending 🗂 <a href="...">…</a>

每条卡片包含仓库名、Star 数、作者、中文简介、话题标签与跳转链接。序号 `n/N` 表示当天共 N 张卡片,这是第 n 条。

### 步骤 2c: 缓存命中 — 秒回卡片

当天第二次(或之后)发送命令时,Bot 已存在当日缓存,会**直接**返回完整卡片,不再出现「⏳ 生成中」的占位消息:

![命中缓存直接返回卡片](assets/02-trending-r2.png)

### 步骤 3: 查看与跳转

卡片中的链接均为 GitHub 仓库地址,点击即可在浏览器中打开仓库主页;`#trending` 与 `#c` 等标签便于搜索同类历史记录。

---

### 小贴士

1. **收到「⏳ 生成中」后不要重复发命令**:后台管线一次只能跑一份,重复触发只会增加占位消息,真正有用的卡片还是按原计划自动推送。
2. **跨日会重新生成**:Bot 按自然日刷新缓存,第二天首次发送会再次经历「占位 → 推送」流程;同日多次发送均走缓存,速度极快。
3. **简写 `/gt` 适合日常刷榜**:长命令 `/trending` 与短命令 `/gt` 行为完全一致,可任意选用,建议在常用群聊中绑定快捷输入。
