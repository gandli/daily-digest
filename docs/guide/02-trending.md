### 步骤 1：发送指令

在 Telegram 对话窗口中输入指令 `/gt` 并发送。这是触发「今日 GitHub Trending」功能的唯一命令，无需附带任何参数。

### 步骤 2：等待占位提示

Bot 收到请求后会立即检查缓存。若当日 Trending 尚未生成完毕，Bot 会先回一条占位消息：

> ⏳ GitHub Trending 生成中(10-30 秒), 完成后自动推送。

这条提示告知用户后台正在跑完整管线（抓取 → 翻译 → 存档 → 发卡），请耐心等待。

### 步骤 3：接收第一张卡片

等待 10-30 秒后，Bot 会自动把结果推送到当前聊天。第一张卡片格式如下：

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending #c #editor 🗂 \<a href="https:...

卡片包含仓库名（owner/repo）、星标数、作者、一句话中文简介、话题标签与跳转链接。其中 `1/2` 表示这是当日 Trending 第 1 条，共 2 条。

![首轮生成：占位提示 + 2 张卡片依次推送](assets/02-trending-r1.png)

### 步骤 4：接收第二张卡片

紧接着第一条，Bot 推送第 2 条：

> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending 🗂 \<a href="https:...

至此当日 Trending 全部推送完成。

### 步骤 5：缓存命中场景

若当天已经生成过一次，再次发送 `/gt` 时 Bot 会直接秒回卡片，不再出现「⏳ 生成中」占位提示。

![缓存命中：直接秒回 2 张卡片，无占位消息](assets/02-trending-r2.png)

## 小贴士

1. **不要重复刷屏**：首次发送后等待 10-30 秒即可，Bot 会主动把结果推过来；重复发送同一指令只会消耗你的请求次数。
2. **链接需在 Telegram 客户端渲染**：HTML `<a>` 标签只有在支持富文本渲染的客户端才会显示为可点击链接，未渲染时是一段原始 HTML 文本。
3. **跨日刷新**：次日再次发送 `/gt` 时，缓存失效，会重新走一遍生成流程并再次出现占位提示。
