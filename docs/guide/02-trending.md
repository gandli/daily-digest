## /trending — 今日 GitHub Trending

`/trending`(命令别名 `/gt`)用于拉取当日 GitHub Trending 列表,Bot 会自动整理仓库简介、附上话题标签,并提供存档链接。系统对结果做缓存处理,短时间内重复调用可实现秒级返回。

### 步骤 1: 发送指令

在任意与 Bot 私聊或群聊的对话窗口中输入:

```
/gt
```

或使用完整命令:

```
/trending
```

Bot 收到指令后开始处理本次请求。

### 步骤 2: 等待首次占位响应(缓存未命中场景)

如果当天 Trending 内容尚未在缓存中,Bot 会先返回一条占位消息,告诉用户后台任务已启动:

> ⏳ Trending 生成中(10-30 秒), 完成后自动推送。

此时无需任何操作,等待 Bot 主动推送结果卡片即可,整个生成过程通常在 10 至 30 秒内完成。

### 步骤 3: 接收完整 Trending 卡片

后台管线依次完成抓取、翻译、存档后,Bot 会以编号形式逐条推送当天的 Trending 仓库卡片,每条包含序号、仓库名、星标数、作者、简介、话题标签以及存档链接,例如:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending #c #editor 🗂 存档链接
> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending 🗂 存档链接

卡片会按当日热度顺序依次发送,用户可直接点击 🗂 后的链接查看或收藏。

![首次调用 /gt,先看到占位消息,随后收到完整 Trending 卡片](assets/02-trending-r1.png)

### 步骤 4: 重复调用,体验缓存加速

当日再次发送 `/gt` 时,由于缓存已命中,Bot 会跳过占位消息,直接以编号形式秒级返回完整 Trending 卡片:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending #c #editor 🗂 存档链接
> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending 🗂 存档链接

整个过程不再出现「生成中」提示,响应几乎是即时的。

![再次调用 /gt,跳过占位直接返回卡片,体现缓存效果](assets/02-trending-r2.png)

### 小贴士

- 首次调用看到「⏳ 生成中」时不要重复发送指令,后台管线会在 10–30 秒内自动推送结果,反复触发只会重新排队。
- 卡片末尾的 🗂 链接是 Bot 自动生成的存档页面,建议收藏以便日后回看,而不必每次都重新生成。
- `/gt` 是 `/trending` 的快捷别名,在群聊中频繁使用时,短别名输入更方便,也更不容易输错。
