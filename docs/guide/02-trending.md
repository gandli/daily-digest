## /trending — 今日 GitHub Trending

通过 `/trending`(对话中也写作 `/gt`)指令，一键获取当天 GitHub Trending 仓库列表。Bot 会自动抓取仓库信息、翻译描述并整理成卡片发送给你。卡片包含仓库名、星标数、作者、简介翻译以及话题标签,并附带存档链接便于回看。

### 步骤 1:发送指令

在 Telegram 对话窗口中输入 `/trending` 或其等价简写 `/gt`,然后发送。这是触发整个流水线的唯一动作,无需额外参数。

### 步骤 2:等待占位提示(首次或缓存未命中)

如果今日 Trending 尚未生成,Bot 会立即回复一条占位消息:

> ⏳ GitHub Trending 生成中(10-30 秒), 完成后自动推送。

这条消息表示后台已开始跑完整管线(抓取 → 翻译 → 存档 → 发卡),你只需等待即可,不需要重复发送指令。等待期间可继续做其他事,Bot 会在完成后主动推送结果卡片。

![首次调用触发占位提示并随后收到卡片](assets/02-trending-r1.png)

### 步骤 3:接收结果卡片

管线完成后,Bot 会按 `n/N 仓库名 ⭐ 星标数 👤 作者 简介翻译 #标签` 的格式连续推送若干条卡片。每条卡片对应一个仓库,通常包含仓库简介的中文翻译、话题标签(如 `#trending #c #editor`)以及一个 🔗 存档链接(点击可在归档页面查看完整内容)。卡片按顺序编号,`1/N` 表示这是当天 Trending 列表的第 1 条。

### 步骤 4:缓存命中时再次调用(秒回)

当天内再次发送 `/trending` 时,Bot 直接从缓存读取并按相同格式秒回卡片,不再发送占位提示。整个流程几乎瞬时完成,适合反复查看或分享给他人。

![再次调用直接秒回缓存卡片](assets/02-trending-r2.png)

### 步骤 5:阅读与回看

卡片送达后,点击仓库名或下方的存档链接即可跳转到 GitHub 或归档页面查看完整信息。如果当天 Trending 仓库较多,卡片可能分多条发送,按编号顺序阅读即可。

### 小贴士

- 耐心等待占位消息:首次触发后请勿重复发送 `/gt`,重复请求只会让 Bot 排队更多任务,不会加速生成。
- 善用缓存秒回:在同一会话内反复调用会直接读取缓存,适合先发送指令、稍后回看。
- 关注存档链接:卡片中的存档链接保留了完整翻译和标签,即使原始仓库热度退去也能随时回顾。
