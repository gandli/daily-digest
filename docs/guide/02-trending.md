## /trending — 今日 GitHub Trending

`/trending` 命令(也可用简写 `/gt`)用于拉取当天 GitHub Trending 仓库,Bot 会以卡片形式逐条推送。为了兼顾响应速度与内容质量,Bot 采用了缓存 + 后台管线机制。

### 步骤 1: 发送命令

在 Telegram 对话中输入 `/gt` 或 `/trending` 并发送。

- Bot 收到后,首先查询当天缓存。
- 若当天数据已生成并缓存命中,直接进入步骤 3 的卡片推送流程,秒级返回。
- 若缓存未命中,Bot 立即回复一条占位消息,提示用户稍候。

### 步骤 2: 等待「生成中」占位(缓存未命中时)

若 Bot 首次或当日首次执行,会立即返回如下提示:

> ⏳ GitHub Trending 生成中(10-30 秒), 完成后自动推送。

此时无需重复发送命令。Bot 在后台依次执行抓取 → 翻译 → 存档 → 发卡四步管线,完成后会作为新消息自动推送到当前对话。

实际效果可参考首次触发的占位消息与后续卡片推送:

![首次触发占位消息与卡片推送](assets/02-trending-r1.png)

### 步骤 3: 查看逐条推送卡片

管线完成后,Bot 会按 Trending 顺序逐条发送卡片,每条内容包含:

- 序号(例如 `1/2`、`2/2`),用于提示当日总条数;
- `仓库名`(如 `antirez/kilo`);
- `⭐ Star 数`(如 `⭐ 3.2k`);
- `👤 作者`(如 `👤 antirez`);
- 一句话中文简介与主题 `#标签`;
- `🗂` 后跟原仓库链接,可直接点击跳转。

示例输出:

> `1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending #c #editor 🗂 <仓库链接>`
>
> `2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending 🗂 <仓库链接>`

### 步骤 4: 当日重复调用命中缓存

同一天内再次发送 `/gt`,由于缓存已存在,Bot 会跳过生成占位,直接以卡片形式逐条重发当日结果,响应通常在 1 秒内完成,可随时用作快速回顾:

![当日重复调用直接返回卡片](assets/02-trending-r2.png)

### 小贴士

- 不要在看到「⏳ 生成中」后重复发送命令,后台管线完成后会主动推送,重复触发只会消耗次数。
- 跨日后缓存会自动失效,首次调用会在次日再次触发生成占位;若 30 秒内仍未收到卡片,可再发一次 `/gt` 触发重试。
- 卡片中 `🗂` 后为 GitHub 原始链接,可直接点击跳转查看仓库详情、Star 与贡献者。
