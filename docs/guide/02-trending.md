# /trending — 今日 GitHub Trending

通过 `/trending` 命令(本例使用其简写 `/gt`)即可一键查看当天 GitHub Trending 仓库,无需打开浏览器,适合每天早晨快速了解开源社区动向。Bot 会自动抓取榜单、翻译描述并以精美卡片形式推送给你。

### 步骤 1: 发送 /trending 命令

在 Telegram 对话框中输入 `/trending` 或其简写 `/gt` 并发送。Bot 会立刻判断今天的 Trending 卡片是否已缓存。

### 步骤 2: 等待「占位提示」

若今日缓存尚未生成,Bot 会先回一条占位消息:

> ⏳ GitHub Trending 生成中(10-30 秒), 完成后自动推送。

这条提示意味着 Bot 正在后台跑完整流水线:抓取 GitHub 榜单 → 翻译仓库描述 → 归档结果 → 生成卡片。10–30 秒内,真正的 Trending 卡片会自动推送到当前聊天。

![首次请求时收到占位提示与完整卡片](assets/02-trending-r1.png)

### 步骤 3: 阅读自动推送的 Trending 卡片

后台任务完成后,Bot 会连续推送多条消息,每条对应一个上榜仓库。卡片格式如下:

> **1/2** antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。 `#trending` `#c` `#editor` 🗂 [查看详情](链接)

从图中可以看到,首条卡片是 `antirez/kilo`(作者 antirez 的 C 语言文本编辑器),第二条是 `sharkdp/bat`(高人气命令行工具)。每张卡片都包含仓库名、星标数、作者、翻译后的简介、话题标签与直达链接。

### 步骤 4: 再次请求,体验缓存秒回

稍等片刻后再次发送 `/gt`,由于今日 Trending 已缓存完毕,Bot **不再发送占位提示**,直接连续推送完整卡片,实现「秒回」体验。

![第二次请求直接秒回卡片,无占位消息](assets/02-trending-r2.png)

对比两张截图可以发现:第一次有「⏳ 生成中」提示与卡片并存;第二次则干净利落,只有两张卡片,几乎零延迟。

### 小贴士

- **简写更方便**:在任意 Telegram 聊天框直接输入 `/gt` 即可触发,与 `/trending` 完全等价,适合日常快速查看。
- **占位消息无需重复触发**:看到「⏳ 生成中」后耐心等待即可,后台完成后会主动推送,无需再次发送命令。
- **每天自动刷新**:Bot 通常按天更新缓存,次日首次请求时会再次看到占位提示,之后当日内均为秒回。
