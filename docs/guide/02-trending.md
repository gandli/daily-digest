# /trending — 今日 GitHub Trending

通过 `/trending` 命令，Bot 会为你拉取当天 GitHub Trending 列表，自动翻译仓库描述并整理成卡片推送。Bot 对结果做了缓存,重复请求可直接秒回。

### 步骤 1: 发送命令

在任意私聊或群组中输入:

```
/trending
```

Bot 收到请求后,会根据当前缓存状态有两种回复:

- **缓存命中**: 直接秒回当天的 Trending 卡片。
- **缓存未命中**: Bot 会先回一条占位消息「⏳ Trending 生成中(10-30 秒), 完成后自动推送。」,然后在后台跑完整管线(抓取 → 翻译 → 存档 → 发卡),完成后将卡片推到当前对话。

### 步骤 2: 查看占位消息

如果是当天第一次请求,你会先看到一条生成提示,告知你 Bot 正在后台跑管线、预计 10-30 秒完成,完成后会自动推送,无需你再次发送命令。

![占位消息与首批卡片](assets/02-trending-r1.png)

### 步骤 3: 阅读 Trending 卡片

管线完成后,Bot 会将仓库列表以编号消息形式推送,每条卡片包含:

- 序号与总数(例如 `1/2` 表示当天共 2 个仓库,当前是第 1 个)
- `仓库名`,形如 `antirez/kilo`
- `⭐ 星标数`,例如 `⭐ 3.2k`
- `👤 作者`,例如 `antirez`
- 中文翻译/简介
- 话题标签,例如 `#trending #c #editor`
- 🗂 图标,后面跟仓库链接,可直接点击访问

### 步骤 4: 再次请求(命中缓存)

当天内再次发送 `/trending`,Bot 会直接命中缓存,跳过占位消息,立即以相同格式把当天卡片重新推送一遍,适合分享或重看。

![命中缓存后直接返回当天卡片](assets/02-trending-r2.png)

## 小贴士

- **不要重复点击**: 生成中时耐心等待 10-30 秒,Bot 完成后会主动推送,不需要你再次发送 `/trending`。
- **跨天失效**: 缓存按当天(自然日)维度维护,跨天后会重新走一次完整管线,以保证看到的是「今日」Trending。
- **链接需点击**: 卡片里的 `<a href=...>` 是 Telegram 支持的预览链接,直接点击消息即可跳转到对应仓库页面。
