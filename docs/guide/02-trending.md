## /trending — 今日 GitHub Trending

命令 `/trending`(可简写为 `/gt`)用于拉取当天 GitHub Trending 仓库,并以分页卡片的形式自动推送到当前会话。

### 步骤 1: 发送命令

在 Bot 对话中输入以下任一形式:

- `/trending`
- `/gt`

Bot 会立刻进入"接收 → 处理 → 推送"的状态机。

### 步骤 2: 等待占位消息

如果当天缓存尚未生成,Bot 会先回一条占位提示,告知后台正在跑完整管线(抓取 → 翻译 → 存档 → 发卡):

> ⏳ GitHub Trending 生成中(10-30 秒),完成后自动推送。

此时不需要再次发送命令,只需等待即可。

### 步骤 3: 接收第一页卡片

后台跑完后,Bot 会依次推送分页卡片,每条消息为一页,格式形如:

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。#trending #c #editor 🗂 <a href="https://github.com/antirez/kilo">…</a>

页码 `1/N` 表示这是第几页 / 总页数,`N` 通常为 2。卡片包含仓库名、Star 数、作者、一句话中文简介、话题标签与跳转链接。

### 步骤 4: 接收剩余分页

Bot 会继续推送后续页面,直到最后一页:

> 2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。#trending 🗂 <a href="https://github.com/sharkdp/bat">…</a>

至此当天 Trending 拉取完成。完整流程参见下图。

![首轮触发占位并依次收到 1/2 与 2/2 卡片](assets/02-trending-r1.png)

### 步骤 5: 缓存命中场景(二次调用)

当天内再次发送 `/gt`,由于缓存已存在,Bot 不再回占位消息,而是直接秒回完整卡片列表,先 1/2、再 2/2,顺序与内容与首次一致:

![二次调用直接秒回 1/2 与 2/2 卡片](assets/02-trending-r2.png)

### 小贴士

- 看到"⏳ 生成中"提示后请耐心等待 10-30 秒,直接重复发送 `/gt` 不会加速生成,反而会重新进入等待队列。
- 当天首次调用耗时较长属于正常现象,后续调用会走缓存秒回,适合在群里反复刷取。
- 每条卡片右下角的 🔗 链接可直接跳转到对应 GitHub 仓库,无需手动复制;标签(如 `#c`、`#editor`)可作为话题筛选的参考。
