### 步骤 1: 发送指令

在 Telegram 对话框中输入 `/gt`(也可使用等价命令 `/trending`),然后按下发送键。Bot 接收到指令后会立即判断当日 GitHub Trending 缓存是否命中。

### 步骤 2: 收到「生成中」占位提示(首次或缓存未命中)

如果当日尚未生成过 Trending 卡片,Bot 会先回复一条占位消息,告知用户完整管线(抓取→翻译→存档→发卡)正在后台运行,预计耗时 10-30 秒,完成后会自动推送卡片,无需重复发送指令。

> ⏳ GitHub Trending 生成中(10-30 秒),完成后自动推送。

此时用户无需任何操作,只需在对话中等待推送。

### 步骤 3: 接收 Trending 卡片(首次或缓存未命中)

后台管线完成后,Bot 会以两条编号消息的形式依次推送当日的热门仓库卡片。每张卡片包含排名、仓库路径、星标数、作者、简介、话题标签以及跳转链接。推送效果如下图所示:

![首次触发 Trending:占位提示加两条自动推送的仓库卡片](assets/02-trending-r1.png)

### 步骤 4: 二次发送 `/gt`(缓存命中)

当天再次发送 `/gt` 时,缓存已命中,Bot 不再返回「生成中」占位,而是直接秒回两张仓库卡片,内容与首次推送一致。用户可以借此快速查阅,而不必重复触发后台任务。

![二次触发 Trending:直接秒回缓存中的两张仓库卡片](assets/02-trending-r2.png)

### 步骤 5: 阅读与跳转

用户可直接在 Telegram 内点击卡片底部的链接跳转至对应的 GitHub 仓库页面,了解项目详情、Star 历史与源码;也可借助话题标签(如 `#c`、`#editor`)快速识别仓库所属的技术领域。

## 小贴士

- 占位消息仅在当日首次触发或缓存失效时出现,若反复发送 `/gt`,通常会直接秒回卡片,适合在群聊中频繁查阅。
- 推送以编号消息(1/N、2/N)形式发出,请按顺序阅读;若其中某条未及时看到,可向上滚动聊天记录找回。
- 若等待超过 30 秒仍未收到卡片,可能是后台任务异常,可稍后再发一次 `/gt` 触发重试,或联系 Bot 管理员排查。
