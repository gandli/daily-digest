# /search 关键词 — 搜索历史存档

通过 `/search` 命令,你可以快速检索历史归档中的项目条目。Bot 会在内存索引中按关键词过滤,再按相关度排序,把结果以卡片形式回传,并附带翻页按钮,方便你逐条浏览。

### 步骤 1: 了解基本用法

如果你不熟悉命令格式,直接发送 `/search` 即可。Bot 会回复一条用法说明,告诉你正确的参数形式。

`/search`

Bot 回复:

> 用法: /search 关键词 例: /search rust cli

![/search 用法提示](assets/05-search-r1.png)

### 步骤 2: 输入关键词执行搜索

按照提示,以 `/search` 加上一个或多个关键词的形式发送。Bot 会在内部按以下流程处理:

- 对历史归档建立内存索引
- 用关键词过滤并按相关度排序
- 将当前 query 暂存到 KV,供翻页回调读取

例如,发送 `/search bat` 搜索与 `bat` 相关的项目。

`/search bat`

Bot 回复一张结果卡片,格式大致为:

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

其中 `⭐` 标记表示该条目的相关度评分,标题部分来自项目原始名称与简介。

![/search bat 命中结果](assets/05-search-r2.png)

### 步骤 3: 处理翻页与无结果情况

结果卡片下方通常带有翻页按钮,回调类型为 `sch:page`,Bot 会读取之前存入 KV 的 query,继续在内存索引中分页取出后续结果:

- 当结果超过一页时,点击「下一页」按钮,Bot 会返回第 2/N 页;
- 当已经到达最后一页时,按钮会变为「已是最后一页」或隐藏;
- 如果关键词没有任何匹配,Bot 会回复类似「未找到与「xxx」相关的条目」的提示,你可以尝试更换更短或更通用的关键词再次搜索。

### 小贴士

- **关键词尽量精简**: 多个关键词之间用空格分隔,例如 `/search rust cli`,Bot 会把它们视为「同时包含」的过滤条件,关键词越精准,命中率越高。
- **善用单个关键字**: 当你不确定完整名称时,先用单个短词(如 `bat`、`rust`)试探,再根据首条结果决定是否细化。
- **翻页状态由 KV 维护**: 翻页按钮的可用性依赖当前会话的 query 缓存,如果你切换到其他对话或重启 Bot,翻页状态会重置,需要重新发起搜索。
