## /search 关键词 — 搜索历史存档

通过 `/search` 命令,你可以随时在历史存档中按关键词检索。Bot 会将命中的条目整理成结果卡片,并支持翻页查看。

### 步骤 1: 发送搜索命令

在聊天窗口输入 `/search` 并发送。如果只输入命令而未携带关键词,Bot 会先返回用法提示,引导你补全参数。

Bot 回复如下:

> 用法: /search 关键词 例: /search rust cli

这一步相当于命令的"帮助卡片",告诉 Bot 你想发起一次检索,但还没给出具体查找内容。

![仅输入 /search 时 Bot 返回用法提示](assets/05-search-r1.png)

### 步骤 2: 附带关键词再次发送

按照提示,在命令后追加一个或多个关键词,例如输入 `/search bat` 并发送。Bot 会在内存索引中过滤匹配项,并按相关度对结果进行排序,然后以结果卡片的形式回传。

Bot 回复如下:

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

你会看到三个关键信息:命中关键词(`bat`)、命中条目数与当前页码(`1 条命中,第 1/1 页`)、以及排序最靠前的一条结果(带 ⭐ 标记和仓库简介)。当命中数量较多时,Bot 会附带翻页按钮(以 `sch:page` 开头),你点击后 Bot 会从 KV 中读取上一次的 query,自动翻到下一页。

![附带关键词 bat 后的结果卡片](assets/05-search-r2.png)

### 步骤 3: 翻页或重新检索(可选)

如果结果超过一页,直接点击消息下方的翻页按钮(如 `第 2/3 页`)即可切换;如果想换一个关键词,只需再次发送新的 `/search 新关键词`,旧的翻页上下文会被新 query 覆盖。

### 小贴士

- 多个关键词之间用空格分隔,例如 `/search rust cli`,Bot 会按全部词共同过滤并计算相关度。
- 翻页按钮的回调数据由 Bot 内部管理,你只需点击即可,无需关心 query 是如何暂存的。
- 关键词越具体,结果越精准;若命中数为 0,可以换一个更宽泛的词或缩短关键词再试。
