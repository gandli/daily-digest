### 步骤 1：发送 `/search` 指令

用户在 Telegram 对话框中输入 `/search`,直接发送给 Bot。此时仅发送命令本身,不附带任何关键词。

Bot 会回复一段使用提示,内容为:

> 用法: /search 关键词 例: /search rust cli

此回复告知用户需要附带至少一个关键词才能进行搜索,引导下一步操作。

![首次调用 /search 的使用提示](assets/05-search-r1.png)

### 步骤 2：附带关键词执行搜索

用户在 `/search` 后加上一个空格以及具体的关键词,例如 `/search bat`,然后发送。

Bot 会执行以下后台流程:基于内存索引对全部历史存档进行关键词过滤,然后按相关度对命中项排序,最终以结果卡片的形式呈现。卡片中会展示命中总数与当前页码,例如:

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

消息开头的 🔍 表示这是一次搜索结果,星号 ⭐ 标注了项目名称与简介,末尾的「第 X/Y 页」告知用户当前所在分页。

![关键词 bat 的搜索结果卡片](assets/05-search-r2.png)

### 步骤 3：浏览结果并翻页

当命中条目超过单页可显示的数量时,Bot 会附带翻页按钮,每个按钮对应一个 `sch:page` 回调,翻页所需的原始查询关键词(query)已保存在 KV 存储中,用户无需重复输入即可切换页码。点击对应页码按钮,Bot 会返回该页的结果卡片。

如果只有一页(如本例中的「bat」),则不显示翻页按钮,直接呈现所有命中项。

### 小贴士

- 关键词支持多个词组合,例如 `/search rust cli`,Bot 会按相关度综合排序,无需额外加引号。
- 翻页状态由 Bot 端 KV 保存,即使用户关闭对话一段时间后再次点击翻页按钮,仍能定位到正确的查询上下文。
- 若搜索无命中,Bot 会返回零结果提示,可尝试缩短关键词或更换相近词再次搜索。
