## /search 关键词 — 搜索历史存档

通过 `/search` 命令，可以在 Bot 的历史存档中快速检索你感兴趣的仓库。本节按真实对话流程演示从首次触发到命中结果的全过程。

### 步骤 1: 输入 `/search`(不带关键词)

当你不确定命令格式时,先单独发送 `/search`,Bot 会返回用法提示,告诉你需要附带关键词。

> 用法: /search 关键词 例: /search rust cli

![单独输入 /search 时,Bot 返回用法提示](assets/05-search-r1.png)

### 步骤 2: 输入 `/search bat`(附带关键词)

掌握了格式后,在命令后直接跟上关键词,例如 `/search bat`。Bot 会执行以下动作:

1. 在内存索引中过滤匹配 `bat` 的存档条目;
2. 按相关度对命中结果排序;
3. 回复一张结果卡片,包含命中数、当前页码以及翻页按钮(用于 callback 翻页与查询状态恢复)。

实际回复如下:

> 🔍 「bat」1 条命中(第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

![搜索 bat 后,Bot 返回 1 条命中并展示仓库名与简介](assets/05-search-r2.png)

### 步骤 3: 解读结果卡片

结果卡片的关键字段含义:

- **🔍 「关键词」N 条命中**:本次检索在内存索引中命中的条目数量;
- **第 X/Y 页**:当前所在页与总页数;
- **⭐ 仓库名 + 简介**:按相关度排序后的展示项。

如果命中数量大于单页容量,Bot 会附带翻页按钮;按钮基于 `sch:page` callback,翻页时查询字符串会被存入 KV,确保后续页面切换仍能恢复原始检索意图。

### 小贴士

1. **关键词越具体,命中率越高**:`bat`、`rust cli` 这类短词往往更聚焦,而单个字母或常见缩写可能命中过多结果。
2. **首次使用先用 `/search` 查看用法**:如步骤 1 所示,不带关键词触发可获得官方示例,避免误输入其他命令。
3. **翻页状态由 Bot 自动保存**:点击翻页按钮时无需重复输入关键词,Bot 会从 KV 恢复查询上下文。
