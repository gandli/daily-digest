## /search 关键词 — 搜索历史存档

当你记得标题里大概有什么关键词、但记不清是哪个仓库时,可以用 `/search` 在历史存档中快速定位。本节按真实使用流程,逐步演示如何发出搜索指令并解读返回的命中卡片。

### 步骤 1: 了解命令格式

如果只发送 `/search` 而不附带任何关键词,Bot 会把它当作空查询处理,并提示正确用法。在聊天窗口中输入:

```
/search
```

Bot 会回复一行使用说明,告诉你需要在其后追加关键词才能发起实际检索。如下:

> 用法: /search 关键词 例: /search rust cli

这一步相当于「调出说明书」,让你确认参数格式无误,避免因为忘记加关键词而得到空结果。

![/search 无参数时返回用法提示](assets/05-search-r1.png)

### 步骤 2: 附带关键词发起检索

确认格式后,在同一条消息里追加想要查找的关键词,例如 `bat`,然后发送:

```
/search bat
```

Bot 会在收到指令后立即执行检索流程:从内存索引中过滤包含 `bat` 的存档条目,按相关度排序后,整理成一张「结果卡片」回传。

### 步骤 3: 阅读结果卡片

Bot 会回复一条结构化消息,大致形如:

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

这条卡片包含三块关键信息:

- **关键词回显**:`「bat」` 表示本次检索使用的关键词,方便你确认指令没被截断或改写。
- **命中概览**:`1 条命中 (第 1/1 页)` 同时给出命中总数和当前页码,让你立刻知道还要不要翻页。
- **条目正文**:`⭐ sharkdp/bat …` 即为命中的存档条目,仓库名在前,描述在后。

当命中数大于单页容量时,Bot 会在卡片下方附上「上一页 / 下一页」按钮,点击后会以 `sch:page` 回调触发翻页,翻页所需的查询上下文会自动写入 KV 存储,无需你重复输入关键词。

![/search bat 返回单条命中卡片](assets/05-search-r2.png)

### 步骤 4: 处理无结果或参数异常

如果 Bot 找不到任何匹配项,卡片会显示 `0 条命中`,此时可以:

- 检查关键词是否有拼写错误;
- 换一个更宽泛的词,例如只搜 `rust` 而不是 `rust cli`;
- 用 `/help` 回顾当前可用的搜索字段。

---

### 小贴士

- 关键词支持空格分隔的多词组合,如 `/search rust cli`,Bot 会按整体相关度排序,而不是要求完全匹配。
- 翻页按钮依赖 KV 存储保存查询上下文,若 Bot 重启后再次点击旧按钮可能会失效,此时直接重新发送一次 `/search 关键词` 即可恢复。
- 结果中的 `⭐` 标记表示该条目在历史存档中具有较高权重,排序通常会优先靠前,可以作为挑选候选时的快速参考。
