## /search 关键词 — 搜索历史存档

本节介绍如何使用 `/search` 命令在 Bot 历史存档中按关键词检索条目。Bot 会在内存中维护索引,按相关度对命中结果排序,并通过卡片形式逐页展示。

### 步骤 1:了解基本用法

直接发送 `/search`(不带任何关键词),Bot 会回复一行简短说明,提示你必须附带查询词。

Bot 会回复:

> 用法: /search 关键词 例: /search rust cli

这条提示来自会话第一轮,告诉你命令的最小参数形式。

![未带关键词时 Bot 返回用法提示](assets/05-search-r1.png)

### 步骤 2:发送带关键词的检索请求

按照提示,重新发送命令并附上你想查找的关键词,例如 `/search bat`。Bot 会立刻在内存索引中过滤匹配项,按相关度排序,然后将第一页结果以卡片形式返回。

Bot 会回复:

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

注意卡片开头会标明:引号内是查询关键词、「N 条命中」是当前匹配总数、「第 X/Y 页」是翻页信息,后面是按相关度排好序的条目。

![输入关键词后 Bot 返回的结果卡片](assets/05-search-r2.png)

### 步骤 3:翻页查看更多结果(若有)

当命中条数超过单页容量,Bot 会在卡片下方附带翻页按钮,按钮的 `sch:page` 回调中已经携带了当前查询关键词,无需你再次输入。直接点击「下一页」或「上一页」,Bot 会返回同一关键词对应的下一页结果。查询字符串会被暂存到 KV 中,保证翻页状态一致。

### 步骤 4:调整关键词或重新检索

如果你对当前结果不满意,可以再发送一次新的 `/search 新关键词`,Bot 会重新走一遍「索引过滤 → 相关度排序 → 翻页按钮」流程,覆盖上一次的查询状态。

### 小贴士

- **关键词尽量精确**:多词组合(如 `rust cli`)能显著缩小命中范围,单字(如 `bat`)容易命中名称相近的条目,排序时会用 ⭐ 标注最佳匹配。
- **留意「第 X/Y 页」**:Y 大于 1 时记得用翻页按钮浏览全部结果,而不是重复发送命令——翻页按钮已自动带上原查询。
- **未带关键词是安全的**:`/search` 单独发送不会清空历史,只会显示一行用法提示,你可以放心试探。
