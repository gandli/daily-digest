## /search 关键词 — 搜索历史存档

`/search` 命令用于在 Bot 内存索引中按关键词查找你过去收藏或交互过的存档条目。Bot 会先在内存索引中过滤匹配项,再按相关度排序,并以结果卡片 + 翻页按钮的形式返回。

### 步骤 1: 了解命令格式

当你不带任何参数直接输入 `/search` 时,Bot 会返回该命令的用法说明,提示你必须附带关键词。

> 用户: `/search`
> Bot: 用法: /search 关键词 例: /search rust cli

![不带参数时 Bot 提示用法](assets/05-search-r1.png)

如果你看到这条提示,说明你已经把命令名打对了,接下来只需要在后面加上要搜索的关键词即可。

### 步骤 2: 输入关键词发起搜索

在命令名后用空格分隔多个关键词,例如 `/search rust cli`。Bot 会立即在内存索引中执行过滤与相关度排序,然后回复一张结果卡片。

> 用户: `/search bat`
> Bot: 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

![命中 1 条结果,显示分页 1/1](assets/05-search-r2.png)

回复内容包含三部分信息:左侧 🔍 图标后的命中关键词、括号内的「N 条命中 (第 X/Y 页)」分页指示,以及卡片正文中按相关度排列的条目(本例为带星标的 sharkdp/bat)。

### 步骤 3: 处理无结果或翻页

如果你搜索的关键词在索引中没有任何匹配,Bot 会返回零命中提示,此时可以尝试换成更宽泛的词或检查拼写。

当结果超过一页时,Bot 会附带 `sch:page` 翻页按钮。点击按钮即可翻到下一页,无需重新输入命令;当前查询(query)会临时存放在 KV 中,Bot 据此读取并渲染对应页的结果。

### 小贴士

- 关键词支持空格分隔的多个词,例如 `/search rust cli`,Bot 会按相关度综合排序,星标条目通常代表本地评分较高的存档。
- 翻页使用内联按钮,query 存在 KV 中,翻页过程中无需重输命令;若会话过期或 Bot 重启,可能需要重新发起一次 `/search`。
- 搜索作用于内存索引,索引未覆盖的新条目不会被检索到;如需扩展覆盖范围,请先通过对应收录命令把目标存档加入 Bot。
