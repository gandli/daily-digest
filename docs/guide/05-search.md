### 步骤 1: 发送搜索命令

在 Telegram 对话窗口中,直接向 Bot 发送斜杠命令 `/search`,后跟你想查找的关键词。关键词可以由一个或多个词组成,词与词之间用空格分隔,例如 `rust cli`。

Bot 在收到纯命令 `/search`(没有任何关键词)时,会回复一段用法说明,提醒你正确的命令格式:

> 用法: /search 关键词 例: /search rust cli

这一步的作用是确认你掌握了命令格式,避免因为漏写关键词而出现空查询。

![Bot 提示 /search 用法说明](assets/05-search-r1.png)

### 步骤 2: 附带关键词再次发送

看到用法提示后,在 `/search` 后面补上你要查找的关键词,例如 `/search bat`,然后再次发送给 Bot。

Bot 收到后会执行以下动作:

1. 在内存索引中按关键词进行过滤;
2. 依据相关度对命中结果进行排序;
3. 统计命中总数,计算当前页码(每页固定条目数);
4. 整理成结果卡片,并附带翻页按钮(若需要)一起回传。

本次你应当收到类似下面的回复:

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

其中,`「bat」` 后面是当前关键词;`1 条命中` 告诉你本次搜索共匹配到多少条历史存档;`(第 1/1 页)` 表示当前在第 1 页,共 1 页;冒号后面是按相关度排序后的首条结果,前面的 ⭐ 是命中关键词的标记。

![Bot 返回 bat 搜索结果](assets/05-search-r2.png)

### 步骤 3: 翻页与细化关键词(可选)

如果结果超过一页,Bot 会在卡片下方附带翻页按钮(以 `sch:page` 开头),当前的查询字符串已经保存在 Bot 的临时存储中,你只需点击「下一页」或「上一页」按钮即可切换,无需重新输入命令。

当你希望更精确地缩小范围时,可以改用更具体的关键词组合再次发送 `/search`,例如 `/search rust async`,Bot 会重新执行索引过滤并返回新一轮结果。

### 小贴士

- 关键词区分大小写,搜索前请确认拼写一致,例如 `bat` 与 `BAT` 命中结果可能不同。
- 想查看更多命中,优先尝试增加一个相关词(如 `bat github`),而不是缩短为单字母,后者容易匹配到大量无关存档。
- 翻页按钮依赖 Bot 的临时存储,会话重启或长时间无活动后可能失效,届时重新发送一次 `/search 关键词` 即可。
