## /search 关键词 — 搜索历史存档

本节介绍如何使用 `/search` 命令在历史存档中检索条目。Bot 会基于内存索引进行关键词过滤并按相关度排序，返回带翻页按钮的结果卡片。

### 步骤 1: 调用命令并查看用法提示

在聊天窗口直接输入 `/search`(不带任何关键词)，Bot 会提示你正确的调用格式。

- 用户操作: 输入 `/search`
- Bot 回复: `用法: /search 关键词  例: /search rust cli`

这一步相当于命令的"自检",帮助你了解参数格式。

![不带关键词时 Bot 返回用法提示](assets/05-search-r1.png)

### 步骤 2: 带上关键词发起检索

按照提示在 `/search` 后输入一个或多个关键词(空格分隔),Bot 会先在内存索引中过滤,再按相关度排序,然后以卡片形式返回命中结果。

- 用户操作: 输入 `/search bat`
- Bot 回复示例: `🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆`

卡片开头以 `🔍` 图标标识,中间是命中条数和分页信息(当前是 `第 1/1 页`,表示只有一页结果),冒号后列出仓库条目,前面用 `⭐` 标记其相关度评分。

![单关键词检索返回结果卡片](assets/05-search-r2.png)

### 步骤 3: 通过按钮翻页查看更多结果

当命中条目超过一页时,Bot 会在卡片下方附带翻页按钮。点击 "下一页" 或 "上一页" 按钮,Bot 会触发 `sch:page` 回调,并把当前查询字符串存入 KV,再返回下一页卡片。

- 用户操作: 点击翻页按钮
- Bot 行为: 根据 `sch:page` 回调定位到下一页结果,卡片内容刷新为新的条目列表,分页标记同步更新为 `第 N/总页数 页`

如果某一页已无更多条目,按钮会变为不可点击状态,避免无效请求。

### 步骤 4: 调整关键词细化结果

如果首轮检索命中太多或没有命中,可以更换或增加关键词重新发起。关键词支持空格分隔的多个词,Bot 会按多词组合过滤并重排相关度。

- 用户操作: 再次输入 `/search 新关键词` 或 `/search 词A 词B`
- Bot 回复: 重新返回新的结果卡片,翻页状态重置为 `第 1/总页数 页`

### 小贴士

- **空查询只触发用法提示**: 仅输入 `/search` 不会发起检索,而是返回格式说明,适合初次接触时验证命令是否生效。
- **多关键词用空格分隔**: 例如 `/search rust cli` 会同时匹配包含 `rust` 和 `cli` 的存档条目,缩小结果范围。
- **结果基于内存索引**: 检索依赖 Bot 启动时加载的内存索引,刚发布的新条目可能需要 Bot 重启后才能被搜到;若始终搜不到目标条目,可尝试更换或拆分关键词。
