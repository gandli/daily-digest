### /search 关键词 — 搜索历史存档

通过 `/search` 命令可以快速在 Bot 的历史存档中查找过去的对话或项目片段。下面按真实使用顺序，逐步说明如何输入关键词、查看命中结果，以及通过按钮翻页浏览更多记录。

### 步骤 1：了解基本用法

直接向 Bot 发送 `/search`，不带任何关键词。此时 Bot 不会执行搜索，而是回复一段简短的用法说明，提示你需要附带关键词才能生效：

> 用法: /search 关键词 例: /search rust cli

这一步的作用是确认命令名称无误、避免空查询带来的歧义。

### 步骤 2：带关键词发起搜索

按照用法示例，输入 `/search` 后再跟一个或多个关键词。例如发送 `/search bat`，Bot 会在内存索引中过滤匹配项，并按相关度排序，最终返回一张结果卡片。

![根据关键词 bat 搜索到的命中结果](assets/05-search-r2.png)

卡片顶部会显示查询关键词、本次命中总数以及当前页码，例如：

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

其中 `⭐` 前缀表示该条目的相关度评分较高，仓库名称 `sharkdp/bat` 与简短描述一同呈现，方便快速判断是否是你要找的存档。

### 步骤 3：通过翻页按钮浏览后续结果

当一次搜索的命中数超过单页容量时，Bot 会在卡片下方附带翻页按钮，按钮的 callback 类型为 `sch:page`。点击「下一页」后，Bot 会从 KV 中读取原始 query 与当前页码，渲染下一页结果卡片，整页替换消息内容，无须重新输入关键词。

如果只有 1 页（如本例中 `bat` 的结果），则不会出现翻页按钮，页面直接停留在唯一一页。

### 步骤 4：结束或重新搜索

浏览完毕后，你可以直接关闭消息，或者发送新的 `/search 关键词` 重新发起一次查询。每次新的 `/search` 都会刷新 KV 中保存的 query，覆盖上一次的搜索上下文，因此翻页按钮不会带到下一次搜索中。

### 小贴士

- 关键词尽量精准且具有区分度，例如使用 `rust cli` 而非单独 `rust`，可以显著缩小命中范围，提高相关度排序的准确性。
- 如果搜索结果为空，Bot 通常不会返回任何卡片，可尝试更换关键词或缩短为单一词汇再试。
- 翻页过程中若出现延迟，可再次点击「下一页」按钮——KV 中保存了原始 query，重新渲染时会自动复用，无需手动补全命令。
