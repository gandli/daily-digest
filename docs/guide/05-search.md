## /search 关键词 — 搜索历史存档

当你只想快速翻找过去转发过的某条存档,而不是浏览最新列表时,使用 `/search` 命令。它会在内存索引中按关键词过滤,并按相关度排序返回结果卡片。

### 步骤 1: 单独调用命令查看用法

直接向 Bot 发送 `/search`(不带任何关键词),Bot 会回应一行用法提示,告诉你参数格式和示例:

> 用法: /search 关键词 例: /search rust cli

这一步相当于内置的"帮助卡",当你忘记怎么传参时随时可用。

![直接调用 /search 时 Bot 返回用法提示](assets/05-search-r1.png)

### 步骤 2: 发送带关键词的搜索指令

按用法提示的格式,把你关心的关键词追加到命令后面,例如 `/search bat`。Bot 会立刻在内存索引中过滤,并按相关度从高到低排序,然后以结果卡片的形式回复:

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

卡片内容解读:

- 「bat」是回显你刚才搜的关键词,方便确认命令解析无误;
- `1 条命中 (第 1/1 页)` 告诉你共匹配多少条、当前是第几页 / 共几页;
- `⭐ sharkdp/bat` 是相关度最高的一条命中,前面带星标表示排序首位;
- 冒号后面的简短描述就是该条存档当时的标题摘要。

![带关键词搜索时 Bot 返回结果卡片](assets/05-search-r2.png)

### 步骤 3(可选): 当结果超过一页时翻页

如果命中数量较多,Bot 在发出卡片的同时会附带翻页按钮(回调数据为 `sch:page`,查询关键词已存入 KV)。你只需点击按钮即可在页码之间来回切换,无需重新输入命令,搜索词也不会丢。

### 步骤 4(可选): 精炼或放宽关键词

如果命中为 0 条或不是你想找的内容,可以直接换关键词再发一次 `/search xxx`。索引是实时基于内存构建的,不需要等待刷新,新一次搜索会用最新词重新过滤和排序。

---

### 小贴士

1. **关键词尽量拆分到具体词**:同一个查询里堆太多泛词容易稀释相关度;像 `/search bat` 比 `/search 一个 bat 命令工具` 更容易命中星标条目。
2. **记不清名字时试别名**:存档里出现过的项目名、工具名、关键术语都可以直接搜,索引对中英文和下划线 / 连字符都按字面匹配。
3. **翻页靠按钮、不靠重输**:看到分页提示就点按钮,搜索词已自动暂存在 KV 里,反复重发反而会重置结果排序。
