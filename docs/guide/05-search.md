## /search 关键词 — 搜索历史存档

使用 `/search` 命令可以在 Bot 的历史存档中快速查找感兴趣的项目。Bot 会在内存索引中按关键词过滤,再依据相关度排序,最后以结果卡片的形式返回,并附带翻页按钮,方便逐页浏览。

### 步骤 1: 调用搜索命令

在聊天窗口中输入 `/search`,注意此时**只输入命令本身,不要附带关键词**。Bot 会回复一行使用提示,告诉你可以输入什么格式的查询:

> 用法: /search 关键词 例: /search rust cli

如果直接看到这行提示,说明命令已正确触发,可以继续下一步。

![只输入 /search 时 Bot 返回的用法提示](assets/05-search-r1.png)

### 步骤 2: 带上关键词发起搜索

按照提示的格式,在命令后面添加要查找的关键词,例如 `bat`,完整输入为 `/search bat`。关键词之间用空格分隔,Bot 会同时匹配多个词项。

### 步骤 3: 查看返回的结果卡片

Bot 处理后会返回一张结果卡片,内容大致如下:

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

其中:

- 🔍 后是回显的关键词;
- “X 条命中” 表示当前查询命中的存档数量;
- “第 X/Y 页” 表明当前位于第几页、共几页;
- ⭐ 后的项目名及其描述就是搜索结果。

![以 /search bat 搜索后 Bot 返回的命中结果](assets/05-search-r2.png)

### 步骤 4: 翻页浏览更多结果

当命中数量超过单页容量时,卡片下方会出现翻页按钮。点击 **下一页** / **上一页** 按钮,Bot 会以 `sch:page` 类型的 callback 回调继续返回下一页结果。原始的查询字符串会暂存在 KV 中,保证翻页时上下文不会丢失。

### 步骤 5: 结束或重新搜索

浏览完所有结果后,你可以直接开始一次新的对话,或者再次使用 `/search 关键词` 发起新的查询,无需手动清理上次的状态。

## 小贴士

- 关键词越具体,结果越精准;多词查询(例如 `/search rust cli`)会同时匹配两个词,适合限定方向。
- 由于结果来自内存索引,重启 Bot 或长期无活动后索引可能重建,极端情况下短时间内重复搜索可能与历史排序略有差异,属正常现象。
- 翻页时如果网络抖动导致按钮无响应,重新发送同一条 `/search` 命令即可重新拿到第一页及翻页按钮。
