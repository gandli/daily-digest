## /search 关键词 — 搜索历史存档

本节介绍如何通过 `/search` 命令在 Bot 内快速检索过往的存档条目。Bot 会在内存中按关键词过滤索引，并按相关度排序后以分页卡片的方式呈现结果，每次翻页时回调数据会被暂存到 KV，便于在多次交互之间保持查询上下文。

### 步骤 1: 了解命令格式

当你只输入 `/search` 而不带任何参数时，Bot 会返回用法提示，引导你补充关键词。

输入示例：

```
/search
```

Bot 会回复：

```
用法: /search 关键词 例: /search rust cli
```

此时屏幕上只会出现一行说明文字，提示你需要提供一个或多个搜索词。这一步的目的是避免空查询进入检索管线，造成无意义的全表扫描。

![未带关键词时的用法提示](assets/05-search-r1.png)

### 步骤 2: 带上关键词发起搜索

在命令后追加需要查找的关键词，关键词之间用空格分隔即可，Bot 会将其视作「全部需要匹配」的组合条件。

输入示例：

```
/search bat
```

Bot 会在索引中完成过滤与相关度排序，然后以结果卡片的形式回复，并在卡片标题中注明当前关键词、命中条数与所在分页。回复示例：

```
🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆
```

`⭐` 前缀表示该条目曾获得收藏标记，相关度更高，因此被排在最前面。如果后续存档数量增加，Bot 会自动按 `第 n/总页数 页` 的方式展示分页信息，并在卡片下方附带翻页按钮，按钮的 `sch:page` 回调会把当前 query 写入 KV，以便下一次回调时仍能定位到同一组结果。

![命中 1 条结果的搜索卡片](assets/05-search-r2.png)

### 步骤 3: 通过翻页按钮继续浏览

当命中数量超过单页容量时，直接点击 Bot 消息下方的「下一页」或「上一页」按钮即可，无需重新输入命令。Bot 会读取上一步暂存在 KV 中的 query，重新执行过滤与排序，并把结果切到目标页。多次翻页过程中，关键词始终保持一致，确保你不会因为重新输入而丢失上下文。

### 小贴士

- 关键词支持空格分隔的多词组合，例如 `/search rust cli`，Bot 会按「同时包含 rust 与 cli」的策略过滤结果，适合用于缩小范围。
- 收藏过的条目会以 `⭐` 标记并优先排序，如果你在找某个「应该存在」却搜不到的结果，可以尝试缩短关键词或去掉修饰词。
- 分页状态保存在 KV 中，如果在翻页过程中 Bot 因超时清理了会话缓存，重新执行一次 `/search 关键词` 即可恢复，不影响历史存档本身。
