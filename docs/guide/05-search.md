# /search 关键词 — 搜索历史存档

`/search` 命令用于在 Bot 的历史存档中检索特定主题的条目。Bot 会基于内存索引进行关键词过滤，并按相关度排序后以卡片形式返回结果，附带翻页按钮供翻阅。

### 步骤 1: 调用命令不带参数

直接在聊天窗口输入 `/search` 并发送。

Bot 会检测到缺少搜索词，返回用法提示：

> 用法: /search 关键词 例: /search rust cli

![搜索用法提示](assets/05-search-r1.png)

此时说明命令已被正确接收，但还需要补充关键词才能开始检索。

### 步骤 2: 输入完整搜索指令

按照 Bot 给出的示例格式，输入 `/search` 后空格再接关键词，例如输入 `/search bat` 并发送。

Bot 收到请求后，会执行以下流程：

1. 在内存索引中过滤包含「bat」的条目；
2. 按相关度对命中结果排序；
3. 将查询参数与当前页码写入 KV 存储（供翻页 callback 使用）；
4. 以结果卡片形式返回，并在卡片下方附带翻页按钮（callback 为 `sch:page`，携带已保存的 query）。

例如本次实际对话中，Bot 返回：

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

![搜索结果卡片](assets/05-search-r2.png)

卡片标题中的星星图标 ⭐ 表示该条目被标记为精选，结果末尾的「第 1/1 页」表示当前是唯一一页，无需翻页。

### 步骤 3: 查看结果或翻页

如果命中结果超过一页，卡片底部会出现翻页按钮（如「下一页」）。直接点击按钮即可触发 `sch:page` callback，Bot 会从 KV 中读取已保存的 query 并渲染对应页码，无需重新输入搜索词。

若仅有 1 页命中，则不会出现翻页按钮，可直接查看当前结果卡片中的项目描述与链接。

### 小贴士

- 关键词支持空格分隔的多词组合，例如 `/search rust cli` 会同时匹配包含「rust」与「cli」的存档条目，相关度评分会综合考虑两个词的命中权重。
- 翻页按钮依赖 KV 中保存的 query 上下文，若 Bot 因超时清理了会话数据导致按钮失效，重新发送一次 `/search 关键词` 即可恢复翻页功能。
- 搜索结果中的 ⭐ 图标是精选标记，代表该条目在存档中具备较高参考价值，查找时可优先关注带星项目。
