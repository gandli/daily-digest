## /search 关键词 — 搜索历史存档

借助 `/search` 命令,你可以随时在 Bot 的历史存档中按关键词检索之前收藏过的 GitHub 仓库。整个过程无需离开聊天窗口,结果以卡片形式直接呈现,并支持翻页浏览。

### 步骤 1: 了解命令格式

当你直接发送 `/search` 而不带任何参数时,Bot 会提示正确的用法,引导你补全关键词。

- 用户操作:发送 `/search`(不带关键词)
- Bot 回复:用法说明,例如 `用法: /search 关键词 例: /search rust cli`

这一步的作用是防止你误发空查询,同时给你一个可参考的格式样例。

![Bot 提示 /search 用法](assets/05-search-r1.png)

### 步骤 2: 发送带关键词的搜索请求

按照 Bot 提示的格式,在命令后追加一个或多个关键词。关键词之间用空格分隔,Bot 会基于内存索引进行过滤,并按相关度排序。

- 用户操作:发送 `/search bat`
- Bot 回复:一条结果卡片,标题类似 `🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆`

卡片中通常包含三部分信息:命中的关键词、当前页码与总页数、以及按相关度排好的仓库列表(带星标图标与简短描述)。如果命中数超过单页容量,Bot 会同时附上翻页按钮,底层通过 `sch:page` 回调实现翻页,当前查询状态会暂存在 KV 中,保证翻页过程中关键词不丢失。

![Bot 返回 bat 关键词的搜索结果](assets/05-search-r2.png)

### 步骤 3: 查看结果或继续翻页

收到结果卡片后,你可以直接点击列表中的仓库链接查看详情,也可以点击翻页按钮浏览后续结果。每次翻页都会保留同一组关键词,无需重复输入。

- 用户操作:点击结果链接查看详情,或点击翻页按钮
- Bot 回复:详情内容,或下一页结果卡片(页码随之更新)

### 小贴士

1. **多关键词组合更精准**:用空格分隔多个关键词,例如 `/search rust cli`,可以同时匹配仓库名、描述与标签,过滤掉无关项。
2. **关键词越短越要靠后翻页**:像 `bat` 这类短词命中可能较多,留意结果末尾的页码信息,必要时连续点击翻页按钮直至末尾。
3. **无结果时换个粒度**:如果返回 0 条命中,可尝试改用更宽泛的关键词,或拆分成单次单关键词搜索逐步缩小范围。
