## /search 关键词 — 搜索历史存档

通过 `/search` 命令可以在已收录的历史存档中按关键词快速检索 Bot。系统在收到指令后，会先在内存索引中进行关键词过滤，再按相关度排序，最后以结果卡片的形式返回匹配项，并附带翻页按钮以便逐页浏览。

### 步骤 1: 调用搜索命令

在聊天窗口中输入 `/search` 并发送。Bot 会立即回复一行简明用法提示，告诉你完整的命令格式与一个示例。

Bot 回复内容如下:

> 用法: /search 关键词 例: /search rust cli

此时屏幕上只会看到这段提示，并没有实际搜索结果。

![无关键词时 Bot 返回用法提示](assets/05-search-r1.png)

### 步骤 2: 补充关键词发起检索

根据步骤 1 中 Bot 给出的格式，紧跟 `/search` 之后输入你想要查找的关键词(支持空格分隔的多个词)，例如 `/search bat`，然后再次发送。

### 步骤 3: 接收结果卡片

Bot 在后台完成「内存索引过滤 + 相关度排序」后，会返回一张搜索结果卡片。卡片包含三块要素:

- **标题行**: 以 🔍 图标开头，显示关键词、命中条数以及当前所在页码，格式形如 `「bat」1 条命中 (第 1/1 页)`；
- **结果条目**: 紧随其后，每条以 ⭐ 标识仓库/项目名称，后接对该条目的简介，例如 `⭐ sharkdp/bat 带语法高亮的 cat 命令克隆`；
- **翻页按钮**: 卡片底部附带翻页控件，其 callback 为 `sch:page`，查询上下文会暂存于 KV 中，按钮在不同分页会话之间保持一致状态。

![输入 bat 后 Bot 返回的搜索结果卡片](assets/05-search-r2.png)

### 步骤 4: 浏览更多结果(可选)

当命中条目超过当前页可显示的数量时，直接点击卡片下方的翻页按钮即可切换到下一页。Bot 会根据 KV 中保存的 `query` 重新渲染下一页结果，无需重新输入命令。翻到末页后，按钮状态会随之更新以反映已无更多内容。

### 小贴士

- **关键词尽量具体**: 单字或宽泛词汇(如 `cli`、`rust`)可能命中较多结果，导致翻页;加入限定词(如 `rust async`、`bat github`)通常能更快定位目标。
- **空格表示多词匹配**: `/search rust cli` 表示同时包含 `rust` 与 `cli` 的条目，相关度排序会自动把两个词都强相关的项目排在前面。
- **翻页基于同一查询**: 翻页按钮依赖 KV 中存储的查询字符串，短期内重新发起 `/search` 不会清除之前的翻页上下文，但如果会话状态被清理，则需要重新输入完整关键词。
