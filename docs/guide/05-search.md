### 步骤 1: 输入 /search 单独查看用法

在聊天窗口中输入 `/search`（不附加任何关键词），发送给 Bot。

Bot 会回复一段简短的使用说明，提示你必须在命令后面加上至少一个关键词才能进行搜索，例如：

> 用法: /search 关键词
> 例: /search rust cli

这一步骤的作用是帮助你了解命令的完整格式，避免因缺少关键词而搜索失败。

![搜索命令的用法提示](assets/05-search-r1.png)

### 步骤 2: 输入 /search 加关键词执行搜索

按照 Bot 给出的格式，输入 `/search` 后接一个或多个关键词，例如 `/search bat`，然后发送。

Bot 会在内存索引中执行过滤，并按相关度排序后返回结果卡片，大致结构如下：

- 顶部是一行摘要，包含放大镜图标、关键词、被尖引号包裹的关键词、命中条数以及当前页码，例如 `🔍 「bat」1 条命中 (第 1/1 页)`；
- 摘要下方是结果列表项，使用 ⭐ 标识仓库/条目，并用粗体显示标题，紧接其后是简短的描述，例如 `⭐ sharkdp/bat 带语法高亮的 cat 命令克隆`。

如果关键词命中数较多，结果卡片底部会附带翻页按钮，按钮的 callback 数据遵循 `sch:page` 格式，并将当前 query 存入 KV，便于在翻页动作中复用，无需你重新输入关键词。

![带关键词的搜索结果卡片](assets/05-search-r2.png)

### 步骤 3: 阅读结果并按需翻页

查看 Bot 返回的结果卡片，根据标题和描述判断哪些条目符合你的需求：

- 如果结果只有一页（页码显示 `第 1/1 页`），说明当前关键词已经收敛到全部命中，直接阅读即可，无需操作翻页按钮；
- 如果结果显示 `第 1/N 页`（N > 1），说明命中数超过单页容量，可以点击卡片底部的「下一页」按钮，Bot 会按照 `sch:page` callback 从 KV 中读取此前保存的 query，自动加载下一页结果，保持相同的关键词和排序。

翻页过程中无需重新输入 `/search 关键词`，Bot 会替你记住上下文。

## 小贴士

1. **关键词尽量精确**：使用具体、独特的词汇（如 `bat` 而非 `cat`）可以显著提高命中率并减少噪音；多词查询请用空格分隔，例如 `/search rust cli`，Bot 会按全部词项做交集过滤。
2. **先发 `/search` 探格式**：如果忘记完整语法，可以先单独发送 `/search`，Bot 会立刻返回用法示例，避免无效搜索。
3. **关注摘要行**：结果卡片第一行同时显示「关键词、命中数、页码」，可以快速判断是否需要翻页或调整关键词；如果命中数为 0，说明当前内存索引中没有匹配项，建议换个同义词或更宽泛的词再试一次。
