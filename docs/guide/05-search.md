### 步骤 1: 查看用法提示

直接向 Bot 发送 `/search`(不带任何关键词)。Bot 会回显用法说明,告知该命令需要附带关键词参数,并给出格式示例,例如 `/search rust cli`。

![不带关键词时,Bot 返回用法提示](assets/05-search-r1.png)

### 步骤 2: 发送完整搜索命令

按照提示的格式,输入「斜杠 search 加一个或多个关键词」,关键词之间用空格分隔。例如输入 `/search bat`,Bot 会立即在内存索引中按关键词过滤条目,并按相关度排序。

### 步骤 3: 阅读结果卡片

Bot 会返回一张结果卡片,显示本次命中的总条数、当前页码与总页数,并在卡片正文中列出仓库名称与一句话简介。卡片示例如下:

🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

卡片中的 ⭐ 图标、星标仓库名与简介文字,均来自历史存档的元数据。

![输入 /search bat 后,Bot 返回结果卡片](assets/05-search-r2.png)

### 步骤 4: 翻页浏览更多结果

若结果不止一页,卡片下方会出现翻页按钮(如「下一页」)。直接点击按钮,Bot 会以 callback 形式(回调标识 `sch:page`)接收翻页请求,并从 KV 中读取先前缓存的原始 query,无需重新输入关键词即可切换页码,继续浏览后续条目。

### 步骤 5: 发起新搜索

完成当前查询后,只需再发送一条新的 `/search 关键词` 命令,即可开始下一轮检索。每次新命令都会覆盖上一次的查询上下文。

### 小贴士

- 关键词数量越多、越具体,过滤越精确。例如 `/search rust cli` 比单独搜索 `rust` 更易命中目标条目。
- 翻页按钮依赖 callback 机制,仅在 Bot 客户端支持内联按钮时可见;若你的客户端只能显示纯文本,可重新发送带页码偏移的 `/search 关键词` 组合以变通实现翻页。
- 搜索结果来源于内存索引,索引在 Bot 进程内维护,重启后需等待重新构建,因此刚启动时短暂搜索可能返回空结果,稍候再试即可。
