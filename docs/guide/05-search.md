## /search 关键词 — 搜索历史存档

本节演示如何通过 `/search` 命令在历史存档中检索项目,并查看结果卡片与翻页交互。

### 步骤 1: 单独发送 /search 查看用法提示

当你只输入 `/search` 而不带任何关键词时,Bot 会识别为缺少参数,并立即返回命令的调用方式:

> 用法: /search 关键词 例: /search rust cli

这一步相当于一次"自检",帮助你在忘记语法时随时确认正确格式。

![用法提示](assets/05-search-r1.png)

### 步骤 2: 附加关键词执行检索

按照 Bot 给出的示例格式,在 `/search` 后追加一个或多个关键词,例如 `/search bat`,Bot 会执行以下动作:

1. 在内存索引中按关键词过滤历史存档;
2. 按相关度对命中项排序;
3. 取当前页(默认第 1 页)的结果,渲染为结果卡片;
4. 在卡片底部附加翻页按钮,callback 数据形如 `sch:page:2:bat`,其中页码与查询字符串会一并写入 KV,以便后续翻页时还原上下文。

本轮 Bot 的回复为:

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

可以看到,标题前缀 `⭐` 表示高相关度命中,括号中的 `第 1/1 页` 同时给出当前页码与总页数,便于一眼判断是否需要翻页。

![结果卡片](assets/05-search-r2.png)

### 步骤 3(可选): 通过翻页按钮浏览更多结果

当命中数超过单页容量,或当前处于中间页时,Bot 会在结果卡片下方显示 `上一页 / 下一页` 按钮。点击后,Bot 会根据 callback 中的页码从 KV 取出原始查询字符串,重新执行过滤与排序,并用新的页面替换原消息。整个过程中你无需重新输入关键词,会话状态由 Bot 自动维护。

### 小贴士

- 关键词支持空格分隔的多个词,例如 `/search rust cli`,Bot 会按多词联合匹配,缩小范围、提升精确度。
- 当返回结果只有 1 条时,翻页按钮不会出现,可直接根据标题中的 `⭐` 数与描述判断是否为你要找的存档。
- 若命中数为 0,Bot 会返回空结果提示,此时可尝试缩短关键词或改用更通用的术语再次检索。
