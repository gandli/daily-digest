## /search 关键词 — 搜索历史存档

`/search` 命令用于在 Bot 的历史存档中按关键词检索过往分享的内容,底层先在内存索引中过滤,再按相关度排序输出结果卡片,翻页通过 callback 按钮实现。

### 步骤 1: 发送 `/search` 查看用法

直接在聊天窗口输入 `/search` 并发送。

Bot 会返回一行简短的用法提示,告诉你命令需要附带关键词,例如:

> 用法: /search 关键词 例: /search rust cli

如果你只发了命令而没有带关键词,Bot 就只会回复这一行说明,不会进入检索流程。正确做法是在命令后直接写一个或多个关键词,用空格分隔。

![未带关键词时 Bot 返回用法提示](assets/05-search-r1.png)

### 步骤 2: 带上关键词发送完整命令

在 `/search` 后追加要查找的关键词并发送,例如输入 `/search bat`。命令由三部分组成:

- 命令名: `/search`,固定不变;
- 空格分隔符: 至少一个空格;
- 关键词: 一个或多个词,Bot 会用它们在索引中匹配存档条目。

Bot 接收到后会立即在内存索引中按关键词过滤,并按相关度对命中结果排序。

### 步骤 3: 阅读 Bot 返回的结果卡片

Bot 会用一段带 Emoji 的消息回复,格式大致为:

> 🔍 「关键词」N 条命中 (第 X/Y 页): ⭐ 仓库名 — 一句话描述

例如,搜索 `bat` 时 Bot 回复:

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

这条回复里包含三层信息:命中关键词(用「」包裹)、命中条数与分页(第 X/Y 页)、以及一条用 ⭐ 引出的结果卡片(仓库名 + 简述)。即使只有一条命中,Bot 也会显示「第 1/1 页」,保持格式一致,便于后续翻页逻辑复用。

![搜索 bat 命中 1 条结果](assets/05-search-r2.png)

### 步骤 4: 翻页查看更多结果(当命中数大于 1 页时)

当命中条数超过单页容量时,结果卡片下方会出现翻页按钮。直接点击按钮即可切换页码,无需重新输入命令。

按钮背后是 `sch:page` callback 协议,Bot 会把当前 query 暂存在 KV 中,保证翻页时关键词不会丢失,返回的依然是同一组命中,只是显示不同切片。

### 小贴士

- 关键词尽量用空格分隔多个词,Bot 会按全部词同时匹配,缩小结果范围,比单个长词更精准。
- 如果只发了 `/search` 而没带关键词,Bot 不会报错,只会再次打印用法,这时补上关键词重新发送即可。
- 翻页按钮的 query 依赖 KV 存储,如果长时间(超过会话有效期)未操作,可能需要重新执行一次 `/search 关键词` 来刷新上下文。
