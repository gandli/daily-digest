## /search 关键词 — 搜索历史存档

通过 `/search` 命令,你可以快速在 Bot 历史存档中检索包含指定关键词的内容。Bot 会从内存索引中过滤出相关条目,按相关度排序后以卡片形式返回,每页展示若干结果,并附带翻页按钮方便继续浏览。

### 步骤 1: 尝试单独使用命令

在聊天窗口直接输入 `/search` 并发送,不带任何关键词。Bot 会判定为缺少参数,并回复一行使用说明,提示你补上关键词。

![仅输入 /search 时,Bot 返回用法示例](assets/05-search-r1.png)

### 步骤 2: 补上关键词发起检索

按照 Bot 给出的格式,输入完整的命令 `/search bat`,其中 `bat` 是你想要查找的关键词。Bot 接收到命令后,会先在内存索引中进行关键词过滤,再按相关度排序,然后取出当前页的条目。

### 步骤 3: 查看结果卡片

Bot 会以一条消息回复检索结果,内容包括:开头一个搜索图标与"关键词"组合、命中条数与页码提示(如"1 条命中 (第 1/1 页)"),以及若干条按相关度排序的结果条目,每条前面带 ⭐ 标记的项目标题与简介,例如"sharkdp/bat — 带语法高亮的 cat 命令克隆"。

![输入 /search bat 后,Bot 返回 1 条命中结果](assets/05-search-r2.png)

### 步骤 4: 使用翻页按钮浏览更多

如果命中条数超过一页,Bot 会在结果卡片下方附带翻页按钮(对应 `sch:page` 回调)。点击"下一页"或"上一页"按钮即可翻看其他结果;当前查询条件会被存入 KV 中,翻页时无需重新输入命令。

### 步骤 5: 重新发起检索

若想搜索其他关键词,直接发送新的 `/search 关键词` 命令即可,无需先结束当前会话。每次新命令都会重新走一遍"索引过滤 + 相关度排序 + 卡片返回"的流程。

### 小贴士

- 关键词支持空格分隔的多个词,例如 `/search rust cli` 会同时匹配包含 `rust` 与 `cli` 的存档条目,检索覆盖面更广。
- 搜索是实时在内存索引上完成的,响应通常很快;但请注意索引反映的是 Bot 已收录的存档范围,新增内容需要经过收录流程后才能被搜到。
- 如果命中结果很多,记得使用结果卡片下方的翻页按钮,查询条件会自动保留,不必重复输入关键词。
