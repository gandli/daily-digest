### 步骤 1：了解基本用法

在任意聊天窗口中向 Bot 发送纯命令 `/search`（不带任何关键词）。Bot 会回复一行使用提示，告诉您正确的命令格式是 `/search 关键词`，并附带示例 `/search rust cli`。此时还没有执行任何搜索，仅是查询语法说明。

![用法提示](assets/05-search-r1.png)

### 步骤 2：发起搜索请求

在确认格式后，输入您想查找的关键词。例如发送 `/search bat`。Bot 会读取您消息中的关键词，在内存索引中执行过滤，并按相关度排序。

### 步骤 3：查看搜索结果

Bot 立即返回一张结果卡片，包含以下要素：

- 标题前缀的 🔍 图标，方便在消息流中快速识别；
- 用书名号包裹的关键词「bat」原文回显，便于确认搜索词无误；
- 命中条数与分页信息，例如「1 条命中 (第 1/1 页)」；
- 项目条目，本例为「⭐ sharkdp/bat — 带语法高亮的 cat 命令克隆」，其中 ⭐ 表示该仓库在排序中获得最高权重。

![搜索结果卡片](assets/05-search-r2.png)

### 步骤 4：翻页或继续浏览

若结果不止一页，Bot 会在卡片下方附带翻页按钮。点击任一按钮即可切换页码，Bot 会在内部通过 `sch:page` 回调携带查询字符串，并将原始 `query` 临时存入 KV 中以保证翻页上下文不丢失。整个过程无需您重新输入 `/search` 命令。

### 小贴士

- 关键词支持空格分隔的多个词，例如 `/search rust cli` 会同时匹配包含「rust」和「cli」的存档，相关度由两个词共同决定。
- 当命中数为 0 时，Bot 同样会返回结果卡片，可尝试更短或更通用的关键词重新搜索。
- 翻页时若网络延迟，请耐心等待；KV 中缓存的查询字符串在短时间内有效，无需重复输入命令。
