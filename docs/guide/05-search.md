### 步骤 1：调用命令查看用法

在 Telegram 对话窗口中直接输入 `/search` 并发送，Bot 会返回一行简短说明，提示该命令必须搭配关键词使用。例如机器人会回复：

> 用法: /search 关键词 例: /search rust cli

此时页面没有任何结果卡片，仅起到提示作用。确认格式无误后，再进入下一步操作。

![查看 /search 命令用法](assets/05-search-r1.png)

### 步骤 2：输入「关键词」获取搜索结果

按照提示的格式，在 `/search` 后紧跟一个或多个关键词，多个关键词之间用空格分隔即可视为组合检索条件。示例：发送 `/search bat`。Bot 接收到请求后，会先在内存索引中过滤，再按相关度排序，最终以结果卡片形式回传。本例中机器人回复内容为：

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

回复信息包含三部分：左侧漏斗图标表示本次检索，括号内标注命中数量与当前页码（`第 1/1 页`），随后是仓库条目，包含 GitHub 所有者/仓库名（`sharkdp/bat`）以及一句话简介。

![搜索 bat 的命中结果](assets/05-search-r2.png)

### 步骤 3：翻页浏览更多结果

当命中条目超过一页容量时，结果卡片下方会出现翻页按钮（如「下一页」）。点击后，Bot 会以 `sch:page` 类型的回调查询回调自身，并把当前 `query` 存入 KV 存储以便恢复上下文，无需用户重新输入关键词。重复点击即可逐页浏览，直到末页为止。

### 步骤 4：处理无结果或异常情况

若关键词拼写有误、索引中确实无匹配项，Bot 会返回零命中提示（例如「🔍 「xxx」0 条命中」）。此时可尝试更换更宽泛的关键词，或返回 `/search` 提示重新组织检索语句。

## 小贴士

- **关键词尽量精简**：先用单一关键词缩小范围，再视结果加入修饰词；空格分隔的多个关键词按同时命中处理，适合精确筛选。
- **留意命中数量与页码**：`(第 X/Y 页)` 直接反映结果规模，若 X 与 Y 差距较大，说明可继续翻页查看。
- **翻页由回调驱动**：点击翻页按钮时无需重新输入关键词，Bot 会通过 KV 中暂存的 `query` 自动恢复检索上下文，因此中途请勿清空会话状态。
