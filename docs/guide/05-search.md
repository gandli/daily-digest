## /search 关键词 — 搜索历史存档

`/search` 用于在历史存档中按关键词检索 GitHub 仓库推荐记录。命令接受一个或多个关键词,内部通过内存索引进行匹配并按相关度排序,命中结果以卡片形式分页展示。

### 步骤 1: 发送搜索命令

在 Bot 对话框中输入 `/search` 并发送,不带任何参数。Bot 会返回一行用法提示,告诉你正确的命令格式与示例。

Bot 回复:
> 用法: /search 关键词 例: /search rust cli

此时没有任何匹配结果,仅作为参数说明。

### 步骤 2: 附带关键词发起检索

根据提示,在 `/search` 后追加一个或多个关键词(用空格分隔),例如 `/search bat`,然后发送。Bot 会按相关度排序后返回首个结果,并附上翻页信息。

Bot 回复:
> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

![关键词 bat 命中 1 条结果](assets/05-search-r2.png)

### 步骤 3: 浏览与翻页

结果卡片下方会附带翻页按钮,点击任一按钮即可跳转到对应页。Bot 内部以 callback(形如 `sch:page`)回调处理翻页,当前查询关键词会被存入 KV,确保翻页时仍能基于同一关键词继续检索。命中文本与原 `/search` 命令一致,只是翻页信息(如 `第 1/2 页`)会随页码变化。

> 截图示意见 `assets/05-search-r2.png`,结果位于首屏消息中。

### 步骤 4: 调整关键词再次搜索

如果当前结果不是想要的,直接发送新的 `/search 关键词` 命令(例如 `/search rust cli`)即可发起新一次检索,无需先清除上一条结果。新的查询会覆盖 KV 中的旧关键词。

### 小贴士

- **空格分隔多关键词**: 多个关键词之间用半角空格分隔,例如 `/search rust cli`,命中条件由内存索引决定,通常匹配仓库名或描述中的相关字段。
- **命中数为 0 时**: Bot 仅返回用法提示,不会显示空结果卡片,可直接换一个更宽泛的关键词重试。
- **翻页状态由 Bot 托管**: 翻页时不需要重新输入关键词,基于上次 `/search` 的查询继续;但发送新 `/search` 会重置翻页上下文,翻页按钮作用于最新一次查询。
