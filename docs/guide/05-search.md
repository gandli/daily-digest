# /search 关键词 — 搜索历史存档

通过 `/search` 命令,可以在 Bot 的历史存档中快速定位感兴趣的条目。命令接受一个或多个关键词,Bot 会在内存索引中过滤并按相关度排序,然后以结果卡片的形式返回。卡片底部带有翻页按钮,便于逐页浏览。

### 步骤 1: 了解命令格式

如果你只输入 `/search` 而不带任何关键词,Bot 会返回用法提示,告诉你正确的格式以及一个示例。此时屏幕上不会显示搜索结果,只显示一行帮助文字。

![]()

> 用法: /search 关键词
> 例: /search rust cli

### 步骤 2: 输入关键词发起搜索

在 `/search` 后面加上你想要查找的关键词,关键词之间用空格分隔。例如,如果你想查找与 `bat` 相关的存档,可以输入:

```
/search bat
```

发送后,Bot 会立即在内存索引中检索匹配项,并按相关度排序。`assets/05-search-r2.png` 中的结果对应这一步。

![]()

Bot 会回复一条结果卡片,内容大致如下:

> 🔍 「bat」1 条命中 (第 1/1 页)
> ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

### 步骤 3: 翻页浏览更多结果(可选)

当命中数超过一页时,结果卡片下方会出现翻页按钮,形如 `sch:page:2` 之类的回调标识。点击按钮即可翻到下一页,无需再次输入命令。Bot 会把当前的 query 暂存在 KV 中,以便翻页时保持搜索上下文一致。

如果命中数只有一页(例如步骤 2 中搜索 `bat` 只返回 1 条),则不会显示翻页按钮。

### 步骤 4: 退出或重新搜索

搜索没有持续状态,任何时候你都可以:

- 输入新的 `/search 关键词` 发起一次全新的检索;
- 发送其他命令(如 `/list`、`/tag`)切换到别的功能。

无需显式退出,也不会占用额外的会话资源。

## 小贴士

- **关键词越具体,结果越精准**。多词组合(如 `rust cli`)会同时匹配多个维度,比单个宽泛词更容易命中目标条目。
- **关注结果前的 ⭐ 标记**。相关度较高的条目会被优先列出并加星,通常代表更值得一看。
- **翻页状态由 Bot 临时保存**。如果长时间未操作,KV 中的 query 可能过期,届时点击翻页按钮可能需要重新输入命令。
