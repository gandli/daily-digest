# /search 关键词 — 搜索历史存档

本节介绍如何用 `/search` 命令在 Bot 的历史存档中检索条目。Bot 会在内存索引中按关键词过滤，再按相关度排序后以卡片形式返回结果,支持翻页浏览。

### 步骤 1: 了解命令格式

如果你直接发送 `/search` 而不带任何关键词,Bot 会返回用法提示,告诉你命令的书写方式。

**用户操作**:发送 `/search`(不带关键词)。

**Bot 回复**:用法: /search 关键词 例: /search rust cli

![直接调用 /search 时,Bot 返回用法提示](assets/05-search-r1.png)

### 步骤 2: 输入完整关键词

按照提示的格式,在命令后加上你想要查找的关键词。关键词可以是一个词,也可以是多个词组合,词与词之间用空格分隔。

**用户操作**:发送 `/search bat`。

Bot 接收到命令后,会执行以下流程:

1. 在内存索引中过滤包含 `bat` 的历史条目;
2. 按相关度对命中结果排序;
3. 取当前页的条目组装成结果卡片;
4. 翻页所需的原始 query 写入 KV,供翻页按钮回调使用。

### 步骤 3: 查看结果卡片

**Bot 回复**:🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

结果卡片中包含三部分信息:

- **命中数与分页**:括号内显示「第 X/Y 页」,告知当前在第几页、共几页;
- **相关度标记**:条目前的 ⭐ 标识该项与关键词的相关度评分;
- **条目描述**:条目的标题与简介,帮助你判断是否符合需求。

![搜索 bat 后,Bot 返回唯一一条命中结果](assets/05-search-r2.png)

### 步骤 4: 翻页查看更多结果(可选)

如果命中数超过一页,结果卡片下方会附带翻页按钮。点击按钮会触发 `sch:page` 回调,Bot 根据之前写入 KV 的原始 query,加载上一页或下一页的内容,你无需重新输入关键词。

## 小贴士

- **关键词越具体,结果越精准**:用空格分隔多个关键词(如 `rust cli`)可以缩小范围,避免命中过多无关条目。
- **留意分页提示**:括号中的「第 X/Y 页」能让你快速判断是否需要翻页,以及对当前结果集的规模有大致概念。
- **翻页状态由 Bot 暂存**:由于 query 已写入 KV,翻页时直接点按钮即可,不必重新发送 `/search` 命令,节省输入成本。
