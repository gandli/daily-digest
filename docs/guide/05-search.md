### /search 关键词 — 搜索历史存档

通过 `/search` 命令可以在 Bot 的历史存档中快速检索感兴趣的项目。系统会在内存索引中进行关键词过滤，并按相关度排序后以卡片形式返回结果。

### 步骤 1：了解命令用法

在 Bot 对话框中直接输入 `/search`，不要附加任何关键词。

Bot 会回复一行用法说明，引导你补充搜索词：

> 用法: /search 关键词 例: /search rust cli

这条提示告诉你必须至少提供一个关键词，否则不会触发检索。

### 步骤 2：发送检索请求

在 `/search` 后面空一格，再输入你想要查找的关键词。例如，想查找 `bat` 这个命令行工具，输入：

```
/search bat
```

完整请求由命令名、关键词两段组成，多个关键词之间用空格分隔（如 `/search rust cli`），便于 Bot 同时匹配多个维度。

### 步骤 3：查看结果卡片

Bot 会基于内存索引过滤，并按相关度排序，把命中的项目整理为一张结果卡片。本例中仅有一个相关项目，因此只有一页：

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

卡片包含三部分信息：搜索关键词（用书名号包裹）、命中数量与当前页码（`第 1/1 页`）、以及按相关度排列的仓库条目，条目前用 ⭐ 表示热度或权重。

### 步骤 4：翻页浏览（如有需要）

当命中结果超过一页时，Bot 会附带翻页按钮，点击按钮即可加载下一页，无需重新输入命令。每次翻页会触发 `sch:page` 回调，Bot 把当前的查询条件暂存在 KV 中，保持浏览上下文连贯。

### 步骤 5：调整关键词重新搜索

如果首轮结果不够理想，可以更换关键词再次发起 `/search`。每次新请求都会触发一次完整的过滤与排序流程，旧结果不会被保留。

### 小贴士

- **多关键词更精准**：使用 `/search rust cli` 这类组合可以同时匹配标签与描述，过滤噪声项目，比单关键词命中率更高。
- **关注 ⭐ 标记**：结果列表中带 ⭐ 的项目通常是相关度更高或更受欢迎的存档，可优先查看。
- **翻页无需重输**：当结果超过一页时，直接点击翻页按钮即可，查询状态由 Bot 自动保存，省去重复输入关键词的步骤。
