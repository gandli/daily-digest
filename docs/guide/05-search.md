## /search 关键词 — 搜索历史存档

当你只记得某个工具的名字、关键词或片段,却想不起完整的存档条目时,使用 `/search` 命令可以在历史存档中快速定位。本章按真实对话逐步演示从查看用法到获得结果的全过程。

### 步骤 1: 发送 `/search` 查看用法

如果你不确定 `/search` 后面应该接什么,先单独发送 `/search`。Bot 会返回一行用法说明,告诉你命令格式和示例关键词。

预期 Bot 回复:

> 用法: /search 关键词 例: /search rust cli

![查看 /search 用法说明](assets/05-search-r1.png)

### 步骤 2: 发送 `/search 关键词` 执行搜索

确认格式后,把你想要查找的关键词紧跟在命令后面,例如 `/search bat`。Bot 会以内存索引过滤历史存档,再按相关度排序,将命中的条目渲染为结果卡片并附上翻页信息。

预期 Bot 回复:

> 🔍 「bat」1 条命中 (第 1/1 页): ⭐ sharkdp/bat 带语法高亮的 cat 命令克隆

![搜索结果卡片展示](assets/05-search-r2.png)

### 步骤 3: 翻页或发起新搜索(可选)

当命中超过一页时,结果卡片下方会出现翻页按钮,点击后 Bot 会以 `sch:page` 回调触发下一次查询,并把当前 query 暂存到 KV 中以便连续翻页。如果你想换一个关键词,直接再发送一条新的 `/search 新关键词` 即可,无需先取消上一次搜索。

### 小贴士

- 关键词越具体,排序越靠前:多词组合(如 `rust cli`)比单词更容易命中目标条目,`⭐` 标记会出现在最相关的卡片上。
- 翻页状态由 Bot 在 KV 中临时保存,会话内连续点击翻页按钮不会丢失上下文;但如果长时间没有活动,建议重新发起一次 `/search` 以拿到最新结果。
- 仅发送 `/search` 不带任何关键词只会得到用法提示,真正的检索一定要在命令后至少留一个关键词。
