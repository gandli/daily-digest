## 任意网页链接 → markdown 存档

这一节介绍如何将普通网页链接快速转为 markdown,并完成 GitHub 存档与 Telegraph 发布,最终以一张摘要卡片呈现全部产物链接。

### 步骤 1:发送目标网页链接

将需要存档的 URL 直接发送给 Bot,无需任何前缀或命令。

- 用户动作:复制并粘贴 `https://example.com/blog/demo-post`。
- Bot 行为:Bot 立即抓取网页正文,提取标题与摘要,生成 markdown 文本,同时写入 GitHub 仓库并发布到 Telegraph。

### 步骤 2:查看返回的存档卡片

Bot 处理完成后,会回复一张包含四类信息的卡片:

1. **标题**:例如 "小而美命令行工具 📝"。
2. **摘要**:一段中文摘要,概括页面核心要点。
3. **标签**:`#archive` `#开发工具` `#命令行`,便于后续检索。
4. **📁 三链按钮**:分别指向 web.archive.org 快照、GitHub 存档与 Telegraph 页,点击即可跳转。

### 步骤 3:确认存档与分发

如果三链按钮均可正常打开,且摘要与原文一致,即可视为本次网页存档事务完成。后续若需再次访问,直接在 GitHub 仓库或 Telegraph 页面检索标题即可。

## 小贴士

- **优先粘贴可公开访问的链接**:需要登录或反爬严格的页面可能抓取失败,建议提前在浏览器中确认页面可正常打开,再交给 Bot 处理。
- **利用标签检索历史存档**:Bot 自动添加的 `#archive` 是统一前缀,搭配具体主题标签(如 `#开发工具`)可在 GitHub 仓库中快速筛选。
- **三链互为备份**:GitHub 存档便于版本管理,web.archive.org 快照抗链接失效,Telegraph 页阅读体验最佳,建议在重要内容上三者都留存。
