### 步骤 1: 发送普通网页链接

将任意可公开访问的 URL 直接发送给 Bot,无需附带额外指令或命令前缀。Bot 会识别这是一个普通网页链接,而非命令、文本笔记或其他类型的内容。

### 步骤 2: 等待 Bot 抓取与处理

Bot 在收到链接后,会依次执行以下处理动作:抓取网页正文内容、将其转换为 markdown 格式、生成简明摘要、提取标签,并同时推送到 GitHub 存档仓库和 Telegraph 页面。整个过程通常耗时数秒,期间无需用户介入。

### 步骤 3: 查看 Bot 返回的存档卡片

处理完成后,Bot 会回送一张包含三段信息的存档卡片,格式固定如下:

- **标题行**:抓取到的网页标题,以 emoji 表情开头(如 📝)。
- **摘要段**:一两句话的中文摘要,概括网页的核心内容要点。
- **标签行**:使用 `#标签名` 格式列出关键主题词。
- **链接区**:以 📁 标记的存档链接集合,包含 GitHub 存档地址、Wayback Machine 历史快照链接和 Telegraph 镜像页。

### 步骤 4: 验证存档完整性

如果需要确认存档已成功保存,可点击卡片中的 📁 链接,逐一验证三个目标:

- GitHub 存档仓库中存在对应的 markdown 文件。
- Wayback Machine 已收录该网页的历史快照。
- Telegraph 页面可正常打开并显示与原网页一致的内容。

若其中任一链接无法打开,建议重新发送一次链接触发处理。

### 小贴士

- **私密页面不支持**:Bot 仅能抓取公开可访问的网页,登录墙、付费墙或反爬机制保护的内容可能会抓取失败或仅返回部分内容。
- **发送链接即触发**:无需使用 `/archive` 之类的命令,直接粘贴 URL 即可,Bot 会根据内容类型自动判定处理方式。
- **摘要仅供参考**:Bot 生成的摘要由模型自动提取,用于快速回顾内容定位,正式引用时请以原文为准。
