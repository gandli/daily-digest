### 步骤 1:粘贴任意普通网页链接

在聊天窗口中直接粘贴一个普通网页的 URL,无需添加额外说明或命令。Bot 会自动识别链接类型,进入网页转 Markdown 存档流程。

### 步骤 2:等待 Bot 抓取并转换

Bot 接收到 URL 后,会在后台完成以下处理:

1. 抓取目标网页正文内容;
2. 将 HTML 转换为结构清晰的 Markdown 文本;
3. 同时生成标题摘要与关键词标签;
4. 把 Markdown 推送到 GitHub 仓库作为永久存档,并同步生成一个 Telegraph 可读页面。

这一过程通常只需几秒钟,期间无需用户介入。

### 步骤 3:查看 Bot 返回的存档卡片

处理完成后,Bot 会以一张整合卡片回复,内容包含:

- **标题**:自动提炼的网页主标题(本例为"小而美命令行工具 📝");
- **摘要**:一段中文摘要,概括网页核心要点(本例为"这是一段用于手册演示的中文摘要, 说明该内容的核心要点。");
- **标签**:从正文提取的话题标签(本例为 `#archive #开发工具 #命令行`);
- **📁 三链入口**:分别指向 Web Archive 永久快照、GitHub 仓库中的 Markdown 文件,以及 Telegraph 美化阅读页,任选其一即可打开。

### 步骤 4:按需打开对应链接

用户可根据场景选择入口:

- 想看**原始网页的归档快照**,点击 Web Archive 链接,即使原站失效也能访问;
- 想查看**结构化 Markdown 源文件**,打开 GitHub 链接,可直接复制、引用、二次编辑;
- 想获得**最佳阅读排版**,进入 Telegraph 链接,适合长文沉浸式阅读。

## 小贴士

- 该功能专用于**普通可公开访问的网页**,对于需要登录、付费墙或反爬保护的页面,Bot 可能抓取失败或只得到空摘要,建议先确认链接可匿名打开;
- Bot 会同时写一份到 GitHub,若你希望归档到**指定仓库或指定路径**,可在粘贴链接前附带形如 `repo:user/revo path:notes/` 的前缀,Bot 会优先读取;
- 标签由正文自动抽取,若想强制覆盖,可在链接后空格追加 `#自定义标签`,Bot 会把它合并进最终卡片。
