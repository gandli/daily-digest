## 任意网页链接 → markdown 存档

当你希望将一篇普通网页(博客文章、文档页面、新闻报道等)完整保存到 GitHub 仓库,并同时获得一个可直接分享的 Telegraph 阅读页时,可以使用本功能。Bot 会自动抓取正文、生成摘要、上传存档,最终以一张包含标题、摘要与三条链接的卡片回复给你。

### 步骤 1: 发送目标网页链接

在 Bot 对话窗口中,粘贴一条普通 URL,无需附加任何文字说明。Bot 会识别这是一个网页抓取请求,而非普通聊天消息。

### 步骤 2: 等待 Bot 抓取与处理

Bot 会执行以下后台动作:

1. 请求目标 URL,获取 HTML 原文;
2. 提取标题、正文与关键元信息;
3. 将正文转换为 markdown 格式;
4. 准备 GitHub 存档路径(通常位于 `archive/` 或按时间归档的子目录);
5. 生成 Telegraph 镜像页。

整个过程通常在数秒内完成,期间你只需等待,不必重复发送。

### 步骤 3: 查看返回的存档卡片

处理完成后,Bot 会回复一条消息,结构如下:

- **首行**:页面标题(示例:「小而美命令行工具」);
- **次行**:一句中文摘要,概括该页的核心要点;
- **关键词行**:若干 `#` 标签,便于后续按主题检索;
- **末行**:以 📁 开头的链接组,包含三条链接——GitHub 原始存档、Wayback Machine 历史快照、Telegra.ph 在线阅读页。

### 步骤 4: 打开链接进行核对

点击 📁 链接组中的任意一条:

- **GitHub 链接**:查看格式化后的 markdown 源文件,可作为原始存档;
- **Wayback Machine 链接**:查看该页在公共快照中的历史版本,用于版本回溯;
- **Telegraph 链接**:获得一个清爽、适配手机浏览的在线阅读页,适合直接转发给他人。

如发现摘要与正文不符或抓取缺失,可回到步骤 1 重发,Bot 会以最新请求覆盖之前的存档。

### 小贴士

- **仅支持公开 URL**:Bot 抓取时遵循目标站点的 `robots.txt`,登录墙、付费墙或 robots 禁抓的页面可能返回空内容,此时建议改用「粘贴 markdown 文本 → 存档」流程。
- **同一 URL 重复发送是安全的**:Bot 会按提交顺序保留多份快照,适合作为同一篇文章在不同时间点的存档备份。
- **标签由 Bot 自动生成**:若关键词与预期不符,可在自定义命令章节学习如何追加或覆盖标签,实现更精细的归档分类。
