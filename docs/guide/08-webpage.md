## 任意网页链接 → markdown 存档

把一个普通网页 URL 丢给 Bot，它会自动抓取正文、转成 markdown、推送到 GitHub 仓库和 Telegraph，并回执一张带标题、摘要、标签与三链入口的存档卡片，方便后续检索与分享。

### 步骤 1：粘贴网页链接

在任意聊天窗口中，把要存档的网页 URL 直接发送给 Bot，无需额外命令或前缀。

### 步骤 2：等待 Bot 抓取与转换

Bot 收到 URL 后会执行一串后台动作：抓取页面正文、提取核心信息、生成中文摘要与标签、把内容写入 GitHub 仓库，并同步创建一份 Telegraph 镜像页。处理时间通常在数秒到十几秒之间，取决于页面大小与网络状况。

### 步骤 3：查看回执卡片

处理完成后，Bot 会回执一张存档卡片，包含三部分信息：

- **标题与摘要**：基于正文自动生成的中文概述，例如 *小而美命令行工具 📝 这是一段用于手册演示的中文摘要，说明该内容的核心要点。*
- **标签行**：从内容中提炼的话题标签，例如 `#archive #开发工具 #命令行`，便于日后按主题筛选。
- **三链入口**：以 📁 开头的链接组，分别指向 GitHub 存档、原始网页与 Internet Archive 快照（例如 `https://web.archive.org/web/...`），三条链接互为冗余，即使原站失效也能回溯。

### 小贴士

- **只粘贴 URL 即可**：不需要 `/archive` 这类触发命令，Bot 会自动识别以 `http://` 或 `https://` 开头的纯链接消息。
- **三链冗余很关键**：原站可能下线或被删，但 GitHub 仓库、Internet Archive 快照通常长期可访问，建议收藏时优先复制 📁 中的 GitHub 链接。
- **可观测的失败信号**：若 Bot 长时间无回复（超过约 30 秒），大概率是抓取被目标站点拦截，可尝试换用该页面的存档版 URL（如 `web.archive.org` 上的快照）重新发送。
