# 任意网页链接 → markdown 存档

本章节介绍如何将普通网页 URL 快速转换为 markdown 格式, 并自动归档到 GitHub 与 Telegraph, 同时生成包含摘要与三条外链的分享卡片。

### 步骤 1: 复制目标网页链接

在浏览器中打开你想存档的网页, 然后从地址栏复制完整 URL(以 `http://` 或 `https://` 开头)。本例中的目标链接为:

`https://example.com/blog/demo-post`

### 步骤 2: 发送给 Bot

将复制的链接直接粘贴到与 Bot 的对话窗口并发送, 无需附带任何额外说明文字。Bot 会自动识别这是一个普通网页, 而非图片或其他类型的内容。

### 步骤 3: 等待 Bot 处理并生成存档卡片

Bot 在后台会依次完成以下动作: 抓取网页正文 → 转换为 markdown 格式 → 推送到 GitHub 仓库 → 创建 Telegraph 镜像页 → 提取标题与摘要 → 组装最终卡片。

### 步骤 4: 查看 Bot 返回的存档卡片

Bot 最终会返回一张格式化的存档卡片, 包含以下四部分内容:

1. **标题**: 从网页正文中提取的核心标题, 例如「小而美命令行工具」。
2. **摘要**: 一段简短的中文概述, 概括文章主要要点。
3. **标签**: 自动生成的话题标签(如 `#archive` `#开发工具` `#命令行`), 便于后续检索。
4. **📁 三链归档区**: 提供三条外链, 分别指向 GitHub 存档、原始网页以及 Web Archive 历史快照。

完整的卡片效果如下所示:

### 步骤 5: 点击归档链接进行验证

点击 📁 区域中的任意一条链接即可验证存档是否成功:

- **GitHub 链接**: 查看 markdown 格式的纯净文本存档。
- **Telegraph 链接**: 查看排版精美的可读页面。
- **Web Archive 链接**: 查看该网页的历史快照, 防止原链接失效后无法访问。

若三条链接均能正常打开, 即表示存档事务圆满完成。

---

### 小贴士

- **确保链接可公开访问**: Bot 仅能抓取无需登录、无地区限制的公开网页; 部分站点会返回 403 或反爬页面, 此时存档内容可能为空。
- **批量处理**: 如需一次存档多个网页, 可以分多次发送, 每条链接都会独立生成一张卡片, 便于在聊天记录中分别管理。
- **标签可追溯**: Bot 自动提取的标签基于关键词频率, 同一主题的多次存档会自然形成统一的标签体系, 后续可通过搜索标签快速找到历史记录。
