### 步骤 1: 发送网页链接

在 Bot 对话窗口中,直接粘贴一个普通网页的 URL,无需附加任何额外说明文字。例如发送 `https://example.com/blog/demo-post`。Bot 接收后会立即启动抓取与转换流程。

### 步骤 2: 等待 Bot 处理

Bot 会按以下顺序完成处理:

1. 抓取目标网页的正文内容;
2. 将 HTML 转换为标准 Markdown 格式;
3. 提取或生成标题(本例为 "小而美命令行工具");
4. 生成一段中文摘要描述核心要点;
5. 提炼话题标签(本例为 `#archive #开发工具 #命令行`);
6. 同时创建 GitHub 仓库存档与 Telegraph 镜像页面。

整个过程通常在数秒内完成,无需用户额外操作。

### 步骤 3: 查看返回卡片

处理完毕后,Bot 会发送一条包含完整信息的存档卡片。卡片内容包括:

- **标题**:原文标题(可点击原链接);
- **摘要**:中文要点概述;
- **话题标签**:以 `#` 前缀标记的关键词;
- **📁 三链图标**:点击展开后可访问 GitHub 存档、Telegra.ph 镜像页、Wayback Machine 历史快照三个归档位置。

### 步骤 4: 访问任一归档版本

根据需要点击对应链接:

- 需要版本管理、可被搜索引擎检索 → 选 **GitHub 存档**;
- 需要纯净阅读体验、加载迅速 → 选 **Telegraph 镜像页**;
- 需要追溯该 URL 在不同时间点的网页状态 → 选 **Wayback Machine 快照**。

三个归档互为冗余备份,即使原网页失效也能持续访问。

## 小贴士

1. **支持任意公开网页**:不仅限于文章页,产品页、文档页、博客归档均可一键转存,只要不被目标网站反爬限制阻挡。
2. **摘要可作速览**:若时间紧张,直接阅读 Bot 生成的中文摘要即可掌握核心信息,无需打开任一归档链接。
3. **标签便于检索**:所有通过此功能存档的页面都会打上话题标签,后续可利用 Bot 的标签搜索能力快速找回同一主题的历史存档。
