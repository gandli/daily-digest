### 步骤 1: 发送网页链接

在任意聊天中向 Bot 发送一条普通网页链接, 无需附加任何命令或参数。例如直接发送:

```
https://example.com/blog/demo-post
```

Bot 会立即开始后台处理, 抓取页面正文并转换为 Markdown 格式。

### 步骤 2: 接收存档卡片

几秒后, Bot 会回复一张存档卡片, 包含三部分内容:

- **标题行**: 已提取的网页标题, 如「小而美命令行工具」;
- **摘要正文**: 一段概括页面核心内容的中文摘要, 由 Bot 自动生成;
- **话题标签**: 以 `#` 开头的关键词, 例如 `#archive #开发工具 #命令行`;
- **📁 链接组**: 三个外部链接入口——GitHub 存档、Telegraph 镜像、Wayback Machine 快照, 点击即可访问。

对话记录示例:

> 小而美命令行工具 📝 这是一段用于手册演示的中文摘要, 说明该内容的核心要点。 #archive #开发工具 #命令行 📁 <a href="https://web.archive.org/web/

![Bot 回复的网页存档卡片, 含标题、摘要、标签和三个 📁 链接](assets/08-webpage-r1.png)

### 步骤 3: 访问与检索存档

点击卡片底部 📁 区域的任一链接即可:

- **GitHub 链接**: 在仓库中查看永久保存的 Markdown 原文, 适合检索与版本管理;
- **Telegraph 链接**: 浏览去除原站样式、纯文本优化的可读页面;
- **Wayback 链接**: 查阅原网页的历史快照, 当原站失效时尤为有用。

如需二次检索, 可向 Bot 发送 `#标签关键词` 或直接搜索存档库中的标题字段。

### 小贴士

- 链接必须是标准 `http://` 或 `https://` 开头, Bot 不支持 `javascript:`、本地 `file://` 或已失效的重定向链。
- 抓取时间通常在 5 秒以内, 但面对加载缓慢或反爬严格的站点, Bot 会返回降级提示, 此时可换用 Telegraph 链接阅读。
- 生成的摘要长度受原文体量影响, 短博客可能仅 1–2 句, 长文则可能包含多段要点。
