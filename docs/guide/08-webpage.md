### 步骤 1：发送网页链接

将任意普通网页的 URL 直接发送给 Bot，无需附加任何命令或参数。Bot 会自动识别这是一个网页链接（而非文本、命令或图片），并启动归档流程。

### 步骤 2：等待 Bot 处理并回复卡片

Bot 会执行以下后台操作：抓取网页正文、将内容转换为 Markdown 格式、上传至 GitHub 仓库存档、生成 Telegraph 镜像页，最后整合为一条消息卡片回复给你。处理时间视网页大小而定，通常在数秒到数十秒之间。

### 步骤 3：查看返回的归档卡片

Bot 回复的卡片包含三类信息：

- **标题与摘要**：自动提取的页面标题（例如"小而美命令行工具 📝"）和一段中文摘要，概括页面核心内容；
- **标签**：自动从内容中提炼的关键词（例如 `#archive` `#开发工具` `#命令行`），便于后续检索；
- **📁 三链接按钮**：分别指向 Internet Archive 快照、GitHub 存档和 Telegraph 镜像页，点击即可在对应平台查阅完整内容。

### 步骤 4：使用归档内容

点击卡片中的 📁 按钮，在适合的场景下打开对应版本：

- 需要长期引用或查看原始页面结构时，使用 Internet Archive 链接；
- 需要 Markdown 源码以便二次编辑或嵌入文档时，使用 GitHub 存档链接；
- 需要快速阅读、且对排版有较好要求时，使用 Telegraph 镜像页。

## 小贴士

- **仅支持公开 URL**：Bot 只能抓取无需登录即可访问的网页；遇到登录墙、付费墙或反爬虫机制时，抓取会失败或返回不完整内容。
- **避免一次发送多条链接**：当前流程是单链接处理，连续发送多个 URL 会按顺序排队执行，后续链接的响应会有较长延迟，建议逐条发送。
- **摘要与标签基于正文自动生成**：若原网页正文较短（如纯首页、纯导航页），摘要可能较为简略，标签也可能为空；正文越丰富，生成的摘要与标签质量越高。
