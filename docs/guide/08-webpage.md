## 任意网页链接 → markdown 存档

当你看到一篇值得收藏的长文、博客或文档页面时,只需把链接发给 Bot,它会自动抓取正文、生成摘要,并把原文永久备份到 GitHub 仓库与 Web Archive,最后回传一张包含标题、摘要、标签与三个存档入口的卡片。

### 步骤 1:复制并粘贴目标 URL

在 Telegram 中找到希望存档的网页链接,直接长按复制,然后粘贴到与 Bot 的私聊窗口中发送即可。无需任何命令前缀,Bot 会自动识别纯文本 URL 并触发抓取流程。

### 步骤 2:等待 Bot 抓取与解析

Bot 收到链接后,会向目标网站发起请求,提取正文内容(过滤广告、导航栏等噪音),并自动生成中文摘要与若干相关标签。普通博客页面通常在数秒内完成,内容较多的文档可能需要稍长一些时间。

### 步骤 3:接收存档卡片

抓取完成后,Bot 会返回一张消息卡片,包含以下信息:

- **标题**:原文的页面标题
- **摘要**:由 Bot 自动生成的中文要点概述
- **标签**:以 `#` 开头的关键词,便于日后检索
- **📁 三链**:分别指向 GitHub 仓库中的 markdown 备份、Telegra.ph 镜像页面,以及 Web Archive 永久快照

例如,当输入 `https://example.com/blog/demo-post` 时,Bot 会回复:

> **小而美命令行工具** 📝 这是一段用于手册演示的中文摘要,说明该内容的核心要点。 `#archive` `#开发工具` `#命令行` 📁

### 步骤 4:点击对应链接查阅或分享

卡片中的三个链接各司其职:

- **GitHub 链接**:打开即可看到纯 markdown 格式的原文备份,适合二次编辑、版本管理与全文搜索。
- **Telegra.ph 链接**:一个轻量级的在线阅读页面,无需登录即可分享给他人阅读,排版清爽。
- **Web Archive 链接**:指向互联网档案馆的快照,即使原网站宕稿或删文,也能从快照中找回原文。

### 小贴士

- **链接尽量使用规范形式**:避免带有大量追踪参数(例如 `?utm_source=...`)的链接,这类参数可能干扰 Bot 的正文识别,导致摘要不够准确。
- **私密或登录后才能访问的页面无法存档**:Bot 只会抓取公开可访问的网页,需要登录或付费墙后的内容将获取失败。
- **如需修改摘要或标签**:Bot 生成的内容可直接使用,若希望调整,可手动在 GitHub 仓库中编辑对应 markdown 文件,改动会与原文快照互不冲突。
