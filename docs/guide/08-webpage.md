## 任意网页链接 → markdown 存档

把感兴趣的网页链接直接发给 Bot, 即可自动抓取正文、生成 markdown 摘要, 同步归档到 GitHub 仓库, 并生成可分享的 Telegraph 页面与一张信息卡片。本节按一次真实对话, 逐步说明整个流程。

### 步骤 1: 复制并粘贴目标网址

在浏览器中找到你想存档的网页, 复制其完整 URL(以 `https://` 开头), 直接粘贴到与 Bot 的私聊或群聊中并发送。本例中发送的是:

```
https://example.com/blog/demo-post
```

Bot 会在后台依次完成以下处理: 抓取网页正文、提取标题与关键段落、生成中文摘要、转换为 markdown 格式, 然后将结果写入 GitHub 存档仓库, 同时发布到 Telegraph。

### 步骤 2: 接收存档卡片

Bot 处理完成后, 会在同一会话内回复一张信息卡片, 包含三部分内容:

1. **标题与摘要** —— 例如 `小而美命令行工具 📝 这是一段用于手册演示的中文摘要, 说明该内容的核心要点。`, 标题来源于网页, 摘要由 Bot 提炼。
2. **话题标签** —— 自动从内容中提取, 本例为 `#archive #开发工具 #命令行`, 便于后续按主题检索。
3. **📁 三链入口** —— 卡片末尾以 `📁` 开头, 依次给出 GitHub 原始 markdown、GitHub 渲染预览页、Telegra.ph 可读页三个链接, 其中第一条形如 `https://web.archive.org/web/`(指向 GitHub raw 存档, 通过 archive.org 反代)。

效果如下图所示:

### 步骤 3: 点开链接查看或分享

卡片发出后, 你可以直接:

- 点 GitHub 链接查看原始 markdown 源码, 适合二次编辑或纳入自己的知识库;
- 点 GitHub 渲染页阅读带格式的版本;
- 点 Telegraph 链接获得一个干净、无干扰的可读页, 方便转发给他人阅读。

整个流程在普通网页(无登录墙、无强反爬)上通常 10 秒内完成, 无需任何额外指令。

### 小贴士

- **粘贴纯 URL 即可触发**: 不要附带额外文字, Bot 只识别单独成行的链接; 若需补充说明, 建议分两条消息发送。
- **受保护页面不会被存档**: 需要登录、付费或有强反爬机制的网页, Bot 会提示抓取失败, 此时可改用「文本片段 → 存档」功能手动粘贴核心内容。
- **标签来源于正文**: 若希望归档时携带特定主题, 可在消息末尾追加 `#你的标签`, Bot 会将其与自动提取的标签合并写入 markdown 头部。
