## 任意网页链接 → markdown 存档

本节介绍如何将任意网页链接快速转成 markdown 文本,并自动归档到 GitHub、生成 Telegraph 外链页面,最后以一张包含标题、摘要和三链的卡片呈现。

### 步骤 1: 复制并粘贴目标 URL

将需要存档的网页链接从浏览器地址栏复制下来,直接粘贴并发送给 Bot,无需添加任何额外指令或前缀。

### 步骤 2: 查看 Bot 生成的存档卡片

Bot 接收到链接后,会依次完成抓取、解析、转写 markdown 三个动作,并将结果同步至 GitHub 存档与 Telegraph 页面。最终,Bot 会以一张信息卡形式回复,内容包含:

- **标题**:源自抓取到的网页标题,例如「小而美命令行工具 📝」;
- **摘要**:由 Bot 提炼的中文核心要点;
- **话题标签**:自动从内容中提取的关键词,例如 `#archive #开发工具 #命令行`;
- **📁 三链**:分别指向 GitHub 存档、Telegraph 外链页以及原始网页(以 `📁` 图标为统一前缀的链接组)。

### 步骤 3: 在 GitHub 仓库中检索存档

点击卡片中的 GitHub 链接,即可跳转到对应仓库中的 markdown 文件。文件命名通常采用页面 slug 或日期形式,便于在 commits 历史中按时间线回溯。

### 步骤 4: 分享 Telegraph 外链

若需要将内容分享到不支持 markdown 渲染的平台(如部分社交媒体),可直接使用 Telegraph 链接。该页面由 Bot 自动生成,展示效果与卡片内容保持一致。

### 小贴士

1. **链接越干净,抓取越稳定**:粘贴 URL 前,建议先去掉 `utm_*`、追踪参数等多余 query string,有助于 Bot 更准确地识别页面主体内容。
2. **付费墙与登录页不可用**:Bot 仅能抓取公开可访问的网页,遇到需登录或被反爬保护的页面时,转写结果可能不完整。
3. **同一链接仅会重复触发一次**:若在短时间内重复发送相同 URL,Bot 会返回既有的存档卡片,避免在 GitHub 仓库中产生重复 commit。
