### 步骤 1: 发送网页链接

在 Telegram 对话窗口中,将你想要存档的网页链接直接发送给 Bot。链接可以是任意普通 URL,无需携带额外参数或指令。

### 步骤 2: Bot 自动抓取并转换

Bot 收到链接后,会自动访问该网页、抓取正文内容,并将其转换为标准 Markdown 格式。这一过程在后台完成,通常只需数秒。

### 步骤 3: 查看存档卡片

转换完成后,Bot 会回复一张存档卡片,包含四个关键部分:

- **标题**:从网页正文中自动提炼的主标题;
- **摘要**:一段中文摘要,概括文章核心要点;
- **标签**:以 `#` 开头的关键词,例如 `#archive`、`#开发工具`、`#命令行`,方便后续检索;
- **📁 三链区**:同时提供 GitHub 源码存档、Markdown 原文链接以及 Telegraph 页面链接,确保内容多渠道留存。

### 步骤 4: 验证与访问存档

点击卡片底部 📁 区域的任意链接,即可跳转到对应平台查看完整内容。GitHub 链接适合代码片段和结构化文档的查阅,Telegraph 链接则提供更优的阅读排版,二者互为补充。

## 小贴士

1. **链接越干净越好**:发送前可去掉 URL 中多余的追踪参数(如 `?utm_source=...`),有助于 Bot 更准确地识别正文内容,避免摘要被推广信息干扰。
2. **配合标签检索**:Bot 自动生成的 `#标签` 基于正文关键词,如果想自定义分类,可以在发送链接后追加一句简短指令,Bot 会将其纳入标签体系。
3. **失败重试策略**:若 Bot 长时间未回复或返回抓取失败提示,通常是目标站点设置了反爬机制。此时可尝试复制正文粘贴给 Bot,使用「纯文本 → markdown」流程完成存档。
