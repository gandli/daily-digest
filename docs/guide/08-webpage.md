## 任意网页链接 → markdown 存档

本节介绍如何将任意普通网页链接快速转存为 markdown 格式,并自动完成 GitHub 存档与 Telegraph 发布,最终以一张包含标题、摘要与三链的卡片回传。

### 步骤 1: 复制目标网页链接

在浏览器中找到想要存档的文章或博文,复制其完整 URL。该 URL 应为标准的 `http://` 或 `https://` 开头形式,目前 Bot 主要面向普通网页(非视频、登录受限页等)。

### 步骤 2: 发送给 Bot

将链接作为一条普通消息发送给 Bot,无需附加任何命令或说明。Bot 收到后会立即开始处理:抓取网页正文、清洗无关元素、转换为结构化 markdown,并并行提交 GitHub 存档与 Telegraph 发布。

### 步骤 3: 查看返回的存档卡片

处理完成后,Bot 会回传一条包含完整归档信息的卡片消息,内容依次为:

- **标题**:从网页正文中自动提炼的主标题,例如 `小而美命令行工具`;
- **摘要**:一段中文摘要,概括页面核心要点,方便快速判断是否为自己需要的内容;
- **标签**:依据内容自动生成的 hashtag,例如 `#archive` `#开发工具` `#命令行`;
- **📁 三链**:在 `📁` 之后,Bot 会依次附上 archive.org 快照链接、GitHub 仓库存档链接以及 Telegraph 阅读页链接,三链合在一起即可永久回访该内容。

### 步骤 4: 二次访问

点击卡片中 `📁` 后任一链接即可打开对应存档:archive.org 适合作为公开快照引用,GitHub 仓库适合长期维护与检索,Telegra.ph 适合在线阅读与分享。三者互为冗余,任意一个失效都不会影响其余两个的可用性。

## 小贴士

- **链接以裸 URL 形式发送即可**,无需在消息中附加标题或备注,避免干扰 Bot 对正文的自动提取。
- **若想自定义标签**,可以在链接后另起一行用 `#自定义标签` 的形式补充,Bot 会与自动标签合并后一起展示。
- **遇到需要登录或 JS 渲染过重的页面**(如部分社交平台),抓取摘要可能不完整,建议优先选择阅读型博客或文档站,效果最佳。
