### 步骤 1: 发送网页链接

在 Telegram 对话窗口中,直接将需要存档的网页 URL 粘贴或输入并发送给 Bot。本例中发送的链接为 `https://example.com/blog/demo-post`。Bot 接收到链接后,会自动触发网页抓取与归档流程,无需用户输入额外指令。

### 步骤 2: 查看 Bot 返回的归档卡片

Bot 完成处理后,会在对话中返回一张格式化的卡片消息,包含以下要素:

- **标题**:文章的核心标题(本例为"小而美命令行工具 📝")。
- **摘要**:由 Bot 自动生成的中文内容摘要,概括页面核心要点(本例为"这是一段用于手册演示的中文摘要, 说明该内容的核心要点。")。
- **话题标签**:根据内容自动提炼的关键词(本例为 `#archive #开发工具 #命令行`),便于分类检索。
- **三链入口**:以 📁 图标开头的链接区,依次提供 GitHub 存档、原始网页、Wayback Machine 快照三个访问入口。

卡片整体呈现如下效果:

![Bot 返回的归档卡片,含标题、摘要、话题标签和三链入口](assets/08-webpage-r1.png)

### 步骤 3: 访问三链入口

点击 📁 后提供的链接,即可分别进入:

1. **GitHub 存档**:查看该网页转 markdown 后的完整文本存档,可作为长期备份与版本管理。
2. **原始网页**:跳转至 Telegraph 页面或源 URL,复核抓取结果的完整性。
3. **Wayback Machine**:通过互联网档案库查阅历史快照,验证内容的时效性与原始状态。

---

## 小贴士

- **链接需为公网可访问的普通 URL**;部分需要登录或存在反爬机制的网站可能无法完整抓取,建议优先选择公开内容页。
- **摘要与标签由 Bot 自动生成**,若需修正可在卡片返回后直接回复补充说明,Bot 会据此更新归档元数据。
- **三链中的 GitHub 存档为 markdown 格式**,适合后续检索与二次编辑;建议将常用话题的归档按 hashtag 归类整理。
