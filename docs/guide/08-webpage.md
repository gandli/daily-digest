### 任意网页链接 → markdown 存档

本节演示如何把一个普通网页链接,经 Bot 转换成 markdown 文本,保存到 GitHub 仓库,同时生成 Telegraph 镜像页,并以一张汇总卡片呈现标题、摘要与三条存档链接。

### 步骤 1: 复制目标网页链接

在浏览器中打开希望存档的网页,从地址栏复制完整 URL。Bot 会以 URL 开头作为输入,因此无需额外说明标题或摘要,完全由 Bot 自动提取。

### 步骤 2: 发送给 Bot

将复制的链接直接粘贴到与 Bot 的对话窗口并发送。例如粘贴 `https://example.com/blog/demo-post` 后回车。

### 步骤 3: 等待 Bot 处理

Bot 会依次执行三件事:抓取网页正文、将正文转为 markdown、上传到 GitHub 仓库并同步生成 Telegraph 页面。处理耗时视网页大小而定,通常在数秒内完成。

### 步骤 4: 接收存档卡片

处理完成后,Bot 会返回一张包含全部关键信息的卡片,内容如下:

> 小而美命令行工具 📝 这是一段用于手册演示的中文摘要,说明该内容的核心要点。 #archive #开发工具 #命令行 📁 [Web Archive 链接]

卡片由四部分组成:

- **标题**:从网页 `<title>` 或首个标题元素提取。
- **摘要正文**:由正文段落压缩而成的中文一句话概要。
- **话题标签**:自动从正文与原标签中抽取,便于检索。
- **三链区块**:依次为 GitHub 原文、GitHub raw 源、Telegra.ph 镜像、Web Archive 快照,均位于 `📁` 之后,点击即可打开。

### 步骤 5: 点击链接验证

依次打开 GitHub 链接确认 markdown 已提交,打开 Telegra.ph 链接确认浏览器友好的镜像页可读。如需追溯网页历史版本,可使用 Web Archive 链接,即便原站宕机也能访问历史快照。

### 小贴士

- **支持范围**:任意公开可访问的 HTTP(S) 网页均可,包括博客、文档站、新闻稿;需要登录的页面因抓取不到正文,会回退为仅保留 URL 与元信息。
- **重复提交**:若同一 URL 已存档,Bot 会跳过 GitHub 写入,直接返回已有三链,避免仓库内出现重复条目。
- **隐私提醒**:抓取过程会读取网页正文,建议不要用此流程存档包含个人敏感信息的内网页面。
