### 步骤 1: 粘贴需要存档的网页链接

在 Telegram 对话中找到 Bot, 直接将普通网页的 URL 粘贴到输入框并发送即可。例如发送 `https://example.com/blog/demo-post`, Bot 会立即开始抓取与解析, 无需附加任何命令或前缀。

### 步骤 2: 接收 Bot 返回的存档卡片

稍等片刻, Bot 会将网页内容整理后, 回复一张富文本卡片, 包含三部分信息:

- **标题**: 文章原始标题, 例如 "小而美命令行工具 📝"。
- **摘要**: Bot 自动生成的中文摘要, 用一句话概括正文要点。
- **标签**: 以 `#` 开头的关键词, 便于检索, 例如 `#archive #开发工具 #命令行`。

### 步骤 3: 点击卡片底部的 📁 链接合集

卡片末尾会附带一个 📁 收纳图标, 下面展开三组链接, 分别指向不同位置:

- **GitHub 存档**: Markdown 源文件已提交至仓库, 便于版本管理与二次编辑。
- **Telegraph 页**: 即时渲染的阅读版页面, 适合直接转发分享。
- **原始链接**: 保留来源 URL, 方便溯源核对。

### 步骤 4: 按需使用三种产物

拿到卡片后, 你可以根据场景选择合适的产物: 想长期归并资料时复制 GitHub 链接, 想让朋友快速浏览时发送 Telegraph 链接, 需要核对原文时点开原始链接。

## 小贴士

- 仅支持粘贴**纯 URL**, 不要附带其他文字, 以免 Bot 误判输入。
- 若网页需要登录或存在反爬机制, Bot 可能抓取失败, 此时可手动复制正文发送给 Bot 使用纯文本存档功能。
- 摘要与标签由 Bot 自动生成, 如不满意可在同一会话中追加指令要求重写。
