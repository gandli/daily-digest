### 步骤 1: 粘贴网页链接

用户将任意普通网页的 URL 直接发送给 Bot,无需附加任何命令或说明,只需粘贴链接本身即可。Bot 会自动识别这是一个网页存档请求,而不是文本翻译、笔记或其他类型的指令。

### 步骤 2: Bot 自动转写并生成摘要

Bot 接收到 URL 后,会立即抓取页面内容并转换为 Markdown 格式,同时提炼出标题与摘要。从对话记录可以看到,Bot 返回的卡片包含以下要素:

- **标题**:小而美命令行工具
- **正文摘要**:这是一段用于手册演示的中文摘要,说明该内容的核心要点。
- **标签**:#archive #开发工具 #命令行

整段处理过程在用户视角是"一键完成"的,无需等待确认或追加操作。

### 步骤 3: 获取三链存档卡片

转换完成后,Bot 会一次性推送最终卡片,其中包含 📁 三个存档链接,分别指向:

- **GitHub 存档**:内容以 Markdown 文件形式存入指定仓库,方便版本管理与检索。
- **Telegraph 页**:即时渲染的在线阅读页面,无需登录即可打开。
- **Web Archive 快照**:第三方时间快照,提供独立于 Bot 的持久备份。

用户无需选择存哪里,Bot 默认全部写入。卡片中三个链接以 `📁` 图标引导,一眼可辨。

### 步骤 4: 验证与回溯

拿到卡片后,用户可以点击任一链接验证内容是否完整、摘要是否准确。若发现偏差,可在原消息下直接回复修正意见,Bot 会重新触发抓取与归档流程,生成一份新的卡片覆盖旧记录。

## 小贴士

1. **链接越干净越好**:粘贴前尽量去掉 `utm_source`、`ref=` 等跟踪参数,这样 Bot 抓取到的标题与摘要更接近原文主旨,存档版本也更易于复用。
2. **需要自定义标签时**:在 URL 后附带 `#标签1 #标签2`,Bot 会用你提供的标签覆盖自动生成的标签,方便后续按主题检索。
3. **私密页面需配合登录态**:Bot 仅能抓取公开可访问的网页,若目标站点需要登录,先将内容导出为可访问的公开链接再发送给 Bot,否则存档将失败或内容残缺。
