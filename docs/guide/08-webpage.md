## 任意网页链接 → markdown 存档

将普通网址一键转换为结构化的 markdown 存档,并同时生成 GitHub 永久快照、Telegraph 阅读页以及一张可直接转发的卡片。

### 步骤 1:粘贴网页链接

在任意对话中,直接向 Bot 发送一个普通网页的 URL(无需加任何指令或前缀)。

例如发送:`https://example.com/blog/demo-post`

Bot 会自动识别链接、抓取正文内容,并跳转到下一步的转换与存档流程。

### 步骤 2:查看归档卡片

Bot 完成解析后,会返回一张结构化的卡片消息,包含以下内容:

- **标题**:来自网页的正文标题,例如「小而美命令行工具 📝」
- **摘要**:由 Bot 自动生成的一段中文摘要,概括页面核心要点
- **标签**:从正文中抽取的话题标签,以 `#` 形式分行排列,例如 `#archive #开发工具 #命令行`
- **三链入口**:底部以 `📁` 为前缀,附带 GitHub 存档链接、Web Archive 快照链接以及 Telegraph 阅读页链接,便于随时回访

### 步骤 3:访问存档与快照

根据卡片底部的三组链接,可按需选择入口:

- 点击 **GitHub 链接** 可查看已提交的 markdown 原始文件,适合二次编辑或版本管理
- 点击 **Web Archive 链接** 可访问互联网档案馆对该页面的历史快照,即使原站失效也能查阅
- 点击 **Telegraph 链接** 可在 Telegraph 上获得排版清爽的在线阅读版本,适合分享给他人

### 小贴士

- 抓取效果取决于目标站点是否对爬虫开放,部分需要登录或开启反爬保护的页面可能无法完整提取正文,建议优先粘贴公开可访问的博客或文档链接
- 摘要与标签由 Bot 基于正文自动生成,若发现抓取了无关导航或评论内容,可在链接后追加 `?section=main` 之类的提示词,引导 Bot 聚焦正文区域
- 卡片可一键转发到群组或频道,接收方无需额外配置即可点击 `📁` 后的三个链接,非常适合作为团队知识沉淀的标准动作
