### 步骤 1:发送网页链接

在 Telegram 对话窗口中,直接向 Bot 粘贴一个普通网页的完整 URL。例如发送 `https://example.com/blog/demo-post`。Bot 会自动识别这是一个普通网页链接,而不是命令或图片,因此无需添加任何额外指令。粘贴完毕后按发送键即可。

### 步骤 2:等待 Bot 处理与抓取

Bot 接收到 URL 后会自动启动抓取流程。它会访问目标网页,提取页面的标题、正文内容,并据此生成一段简短的中文摘要。抓取和转换的过程通常在数秒内完成,期间 Bot 会显示一个加载指示。整个流程对用户而言是无感的,你只需等待结果。

### 步骤 3:查看 Bot 返回的存档卡片

抓取完成后,Bot 会回复一张格式化的存档卡片,包含以下要素:

- **标题**:从原网页自动提取的文章标题,如"小而美命令行工具 📝"。
- **摘要**:由 Bot 根据正文生成的简短中文摘要,说明内容的核心要点。
- **标签**:根据内容主题自动生成的话题标签,如 `#archive` `#开发工具` `#命令行`,方便后续检索。
- **📁 三链按钮**:末尾的 📁 图标后附带三条跳转链接,分别指向 GitHub 存档仓库、Telegra.ph 镜像页面,以及 archive.org 历史快照,确保内容即使原站失效也可访问。

![Bot 返回的网页存档卡片,包含标题、摘要、标签和三条归档链接](assets/08-webpage-r1.png)

### 步骤 4:点击 📁 链接访问存档

点卡 Bot 回复中 📁 后面的链接,即可在新窗口打开对应的存档位置。GitHub 链接可查看完整的 markdown 源文件,Telegra.ph 提供即开即读的渲染页面,archive.org 链接则可以对比不同时间点的页面快照,验证内容是否被篡改。

## 小贴士

- **仅支持 http/https 公网链接**:Bot 暂无法处理需要登录、验证码或付费墙拦截的网页,粘贴前请确认链接为公开可访问的状态。
- **摘要依赖正文可读性**:如果目标网页以图片或 JavaScript 动态渲染为主,生成的摘要可能不够准确,此时建议直接打开 GitHub 存档查看完整 markdown 源文件。
- **标签可辅助检索**:Bot 自动生成的标签基于内容主题,如需在 GitHub 仓库中按主题筛选文章,可利用这些标签作为关键词搜索。
