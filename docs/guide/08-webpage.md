## 任意网页链接 → markdown 存档

把任意公开网页 URL 发送给 Bot,Bot 会自动抓取正文、生成中文摘要,并把内容以 markdown 格式同步存档到 GitHub 仓库与 Telegraph,最后回传一张信息卡片,方便后续检索与分享。整个过程无需手动复制正文,也无需额外配置。

### 步骤 1:发送网页链接

在 Telegram 对话窗口中,直接粘贴一个普通 URL(支持 `http://` 与 `https://`)。Bot 会自动识别这是一个网页存档请求,无需附加任何命令或前缀。

> 用户输入: `https://example.com/blog/demo-post`

### 步骤 2:查看回执卡片

Bot 抓取并解析完成后,会在同一对话内回传一条消息,包含以下要素:

- **标题**:从网页 `<title>` 提取的核心主题,例如 `小而美命令行工具`
- **摘要**:由 Bot 提炼的一段中文说明,概述网页核心要点
- **话题标签**:自动从内容中抽取的关键词,例如 `#archive` `#开发工具` `#命令行`
- **📁 存档链接**:指向 GitHub 仓库与 Telegraph 镜像页的链接(对话中以 `<a href="https://web.archive.org/web/` 开头,可直接点击访问)

![Bot 返回的存档卡片,包含标题、中文摘要、话题标签与存档链接](assets/08-webpage-r1.png)

### 步骤 3:点击链接查看完整内容

卡片中的存档链接指向两份独立副本:

- **GitHub 存档**:以 markdown 文件形式保存在仓库 `archive/` 目录,可全文搜索、可版本管理
- **Telegraph 镜像**:提供即时渲染的阅读页,无需登录即可打开

任选其一即可阅读完整正文,两份内容保持一致。

---

### 小贴士

- **链接必须是公开可访问的 URL**。需要登录、付费墙或地区限制的页面,Bot 无法抓取正文,卡片会回传失败提示。
- **想要更精准的归档**,可以先在网页中用 `#` 选择关键段落,再发送链接,Bot 会将选区一并纳入 markdown 存档。
- **担心重复归档同一篇文章**?Bot 会基于 URL 哈希自动去重,重复发送相同链接不会生成第二份档案,只会重新推送一次卡片。
