### 任意网页链接 → markdown 存档

把任意网页链接发给 Bot, 它会抓取正文、转成 markdown、保存到 GitHub 仓库,并发布到 Telegraph,最后以一条带摘要和三个快捷链接的卡片回复你。本节按真实对话复现完整流程。

### 步骤 1: 复制并粘贴目标链接

在 Telegram 对话中找到需要存档的网页,复制其完整 URL(以 `http://` 或 `https://` 开头)。在 Bot 聊天窗口中直接粘贴该链接并发送,无需附带任何说明文字。

### 步骤 2: 等待 Bot 抓取与转换

Bot 收到链接后会启动后台任务,依次完成:抓取目标网页 HTML、提取标题与正文、转换为 markdown 格式、推送到 GitHub 存档仓库、创建 Telegraph 页面。该过程通常需要数秒到数十秒,具体耗时取决于目标网页大小与响应速度。期间请保持对话,不要重复发送同一条链接。

### 步骤 3: 查看 Bot 返回的存档卡片

任务完成后,Bot 会发送一条包含摘要文本与 📁 三链的消息。卡片内容包括:

- 标题行:由 Bot 提取的文章主标题;
- 摘要正文:对页面核心要点的一段中文概述;
- 标签行:若干 `#标签` 形式的关键词(便于后续检索);
- 📁 链接区:GitHub 原始 markdown、Telegra.ph 渲染页、Wayback Machine 快照三个快捷入口,均以可点击链接形式呈现。

### 步骤 4: 验证与后续操作

点击 📁 区域中的三个链接即可分别访问:GitHub 仓库中的原始 markdown 源文件(可二次编辑)、Telegra.ph 上的即时阅读页(无需翻墙)、Wayback Machine 上的网页历史快照(用于回溯或对比)。如果摘要与正文有偏差,可重新发送链接触发新一轮抓取。

### 小贴士

- 仅粘贴 URL 即可触发归档,不要在链接前后添加文字或指令,否则 Bot 可能无法识别为归档任务。
- 若网页含大量图片或 JS 渲染内容,摘要质量可能下降,建议优先选择以文字为主的文章类页面。
- 同一链接重复发送,Bot 会作为新事务重新抓取并生成新的存档记录,而非返回已有结果。
