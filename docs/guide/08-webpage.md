## 任意网页链接 → Markdown 存档

本节介绍如何将任意普通网页链接一键转换为 Markdown 格式,并自动归档到 GitHub 仓库与 Telegraph 页面,最终以一张信息卡片的形式回传给用户。整个流程无需额外命令,只需粘贴 URL 即可触发。

### 步骤 1: 复制目标网页链接

在浏览器中打开希望存档的网页,从地址栏复制完整的 URL(以 `http://` 或 `https://` 开头的标准链接)。本例中复制的链接为:

```
https://example.com/blog/demo-post
```

### 步骤 2: 将链接发送给 Bot

回到 Telegram,直接将链接粘贴到与 Bot 的对话框中并发送。Bot 会自动识别这是一个普通网页链接,而非需要解析命令或特定格式的输入,因此无需添加任何前缀或修饰。

### 步骤 3: 等待 Bot 抓取并转换

Bot 在收到链接后会执行以下后台动作:

1. 使用抓取服务读取目标网页的正文内容;
2. 将正文转换为结构化的 Markdown 文本,保留标题、段落、列表等基本元素;
3. 调用 GitHub API 将 Markdown 文件写入存档仓库(默认仓库为 `archive`);
4. 调用 Telegraph API 基于 Markdown 内容生成可在线阅读的页面;
5. 调用 Wayback Machine 归档原始网页,生成长期备份链接;
6. 提取页面标题与正文,生成一段中文摘要,并附带话题标签。

整个过程通常在数秒内完成,无需用户干预。

### 步骤 4: 查看 Bot 回传的信息卡片

处理完成后,Bot 会回传一张包含四要素的存档卡片:

- **标题**:从原网页提取的文章标题,本例为"小而美命令行工具";
- **摘要**:由 Bot 生成的中文内容概述,说明文章的核心要点;
- **话题标签**:基于内容自动生成,例如 `#archive #开发工具 #命令行`;
- **三链图标 📁**:依次提供 GitHub Markdown 源文件、Telegra.ph 阅读页、Wayback Machine 归档页的跳转链接。

### 步骤 5: 点击链接进行访问或校对

用户可按需点击卡片中的不同链接:

- 想查看原始排版与在线阅读体验,点击 Telegraph 链接;
- 想下载或二次编辑 Markdown 源文件,点击 GitHub 链接;
- 想确认原始网页已被长期备份,点击 Wayback Machine 链接。

如果发现摘要与实际内容偏差较大,可以删除该存档或在 Bot 中反馈,以便后续优化提取策略。

### 小贴士

1. **优先使用规范的 canonical 链接**:部分网站存在跟踪参数(如 `?utm_source=xxx`),建议先去掉冗余参数再发送给 Bot,可避免重复归档同一篇文章。
2. **私密或需登录的页面无法完整抓取**:Bot 使用匿名抓取服务,对于需要登录或设置防爬墙的页面,只能获取到公开部分或公开预览内容。
3. **批量粘贴请逐条发送**:Bot 当前对每条消息独立处理,一次性粘贴多条链接只会把整段文本当作单个 URL 处理,建议逐条发送以获得多张独立存档卡片。
