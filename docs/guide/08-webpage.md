## 任意网页链接 → markdown 存档

本节介绍如何将一个普通网页链接快速转化为可长期检索的 markdown 存档。Bot 会自动抓取正文、生成摘要,并同时推送至 GitHub 仓库与 Telegraph,最终以一张包含标题、摘要和三条归档链接的卡片回传给用户。

### 步骤 1: 发送网页链接

在 Telegram 对话窗口中,将任意可公开访问的网址直接粘贴并发送。无需添加额外命令、标签或说明文字,Bot 会自动识别 URL 格式并进入「网页归档」处理流程。

### 步骤 2: 等待 Bot 抓取与解析

Bot 在收到链接后会访问目标页面,提取正文内容并转换为 markdown 文本,随后生成一段中文摘要与若干标签,用于后续检索和分类。处理耗时取决于目标网站的响应速度,通常在数秒内完成。

### 步骤 3: 查看归档结果卡片

处理完成后,Bot 会返回一张格式统一的存档卡片,包含以下要素:

- **标题**:根据抓取到的正文自动提炼;
- **摘要**:一段中文概述,说明页面核心要点;
- **标签**:以 `#` 开头的关键词,便于按主题检索;
- **📁 归档链接**:GitHub 仓库中的 markdown 文件、Telegraph 镜像页以及 Web Archive 快照,三条链接并存,确保内容可长期访问。

### 步骤 4: 检索与回看

归档完成后,可通过以下任一方式回看内容:

1. 点击卡片中的 GitHub 链接,在仓库中查看结构化的 markdown 源文件;
2. 点击 Telegraph 链接,在浏览器中阅读排版后的版本,适合移动端快速浏览;
3. 使用 Bot 提供的检索命令,以标签(如 `#开发工具`)或关键词搜索过往归档。

### 小贴士

- **链接有效性**:目标页面需为公网可访问状态,登录墙或反爬机制较严格的网站可能导致抓取失败或摘要不完整;
- **批量处理**:每次仅建议发送一条链接,以便 Bot 准确归类;若需批量归档,可分多条消息依次发送;
- **标签复用**:Bot 自动生成的标签(如 `#命令行`、`#开发工具`)可作为后续检索的入口,建议在命名仓库目录时保持标签体系一致,便于跨条目串联。
