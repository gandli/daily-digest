### 任意网页链接 → markdown 存档

把任意普通网页链接发给 Bot,Bot 会自动抓取正文、转换为 markdown 格式,并同步归档到 GitHub 与 Telegraph,最后回执一张信息卡片,包含标题、摘要、标签与三条快捷链接。整个过程无需额外配置,适合日常收藏技术博文、教程、新闻等长内容。

### 步骤 1: 复制并粘贴 URL

在 Telegram 对话中找到目标网页,复制其完整地址(以 `https://` 开头)。发送给 Bot 一条仅含 URL 的消息,例如:

`https://example.com/blog/demo-post`

Bot 会立即开始后台抓取与处理,无需等待,你可以继续做其他事。

### 步骤 2: 接收存档卡片

稍候片刻,Bot 会推送一张回执卡片,典型内容如下:

> **小而美命令行工具** 📝
> 这是一段用于手册演示的中文摘要,说明该内容的核心要点。
> #archive #开发工具 #命令行
> 📁 <a href="https://web.archive.org/web/

卡片分为三部分:

- **标题与摘要**:Bot 自动从网页中提炼的标题,以及一句话中文摘要,方便快速判断内容是否符合预期;
- **标签区**:三个井号标签,反映文章主题,可用于检索;
- **📁 三链区**:依次指向 GitHub 仓库中的 markdown 源文件、Telegra.ph 公开阅读页,以及 Web Archive 永久快照,任选其一打开即可。

### 步骤 3: 查阅与转发

点击卡片中的任意链接即可查看完整存档。若希望分享给他人,直接转发 Bot 的卡片消息即可,无需重新生成。

### 小贴士

- **支持范围**:任意公网可访问的 HTTP(S) 链接均可,包括个人博客、知乎专栏、Medium 帖子等;需登录或付费墙后的内容可能抓取失败。
- **失败重试**:若长时间未收到卡片,先确认链接在浏览器中可正常打开;部分站点对自动化访问有限制,可尝试复制正文文本作为备用方案。
- **命名规范**:GitHub 存档默认按域名归类文件夹,链接中包含日期或 slug 有助于后续检索;如需自定义目录,请在发送链接前先用文本指令指定。
