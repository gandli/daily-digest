### 任意网页链接 → markdown 存档

将任意普通网页链接发送给 Bot,即可一键完成抓取、转写、存档与分享。下面按真实操作顺序逐步演示。

### 步骤 1: 发送网页链接

在 Telegram 对话框中,把要存档的网页 URL 直接发送给 Bot,无需添加任何说明文字。

Bot 接收到链接后会启动抓取与转换流程:

- 抓取目标页面的标题、正文与关键元信息;
- 将正文转为结构化的 Markdown 文本;
- 同时生成 GitHub 仓库存档链接与 Telegraph 阅读页链接;
- 提炼一段中文摘要,用于卡片预览。

### 步骤 2: 查看存档卡片

Bot 回复一张内容卡片,自上而下依次展示:

- **标题**:来自目标网页的原始标题(如"小而美命令行工具 📝");
- **摘要**:Bot 自动生成的中文要点概述,便于快速判断内容价值;
- **标签**:根据正文关键词自动补全的 3 个左右话题标签(例如 `#archive` `#开发工具` `#命令行`);
- **📁 三链合集**:一行 3 个跳转按钮 —— GitHub markdown 存档、原文链接、Telegra.ph 阅读页。

![Bot 返回的标题、摘要、标签与三链卡片](assets/08-webpage-r1.png)

### 步骤 3: 进入后续动作

拿到卡片后,可以根据需要选择:

- 点击 📁 中的 GitHub 链接,在仓库内查看或二次编辑 markdown 原文;
- 点击 Telegraph 链接,以清爽排版分享给他人或嵌入到笔记系统;
- 直接转发卡片消息,让好友也看到摘要与全部入口。

## 小贴士

- Bot 会自动忽略 URL 两端多余的空格与换行,粘贴即发即可,不必手动 trim。
- 若页面正文过长,摘要会保留核心要点而非全文,详细阅读请通过 Telegraph 或 GitHub 链接继续查看。
- 标签由 Bot 根据正文自动生成,如需人工修订或增补,可在 markdown 存档文件中直接修改并提交。
