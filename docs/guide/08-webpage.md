## 任意网页链接 → markdown 存档

通过本功能,你可以将任意普通网页链接一键转换为 Markdown 格式,并自动归档到 GitHub 仓库,同时生成 Telegraph 镜像页与网页时光机快照,最终以一张信息卡片的形式回传给你。整个流程无需手动复制正文,粘贴链接即可完成。

### 步骤 1: 粘贴普通网页链接

在 Bot 对话中直接发送一个普通 HTTP(S) URL,无需附带任何指令或关键词。Bot 会自动识别链接类型并启动网页解析流程。

例如发送:`https://example.com/blog/demo-post`

### 步骤 2: 等待 Bot 抓取与转换

Bot 接收到链接后,会在后台依次完成以下处理:

1. 抓取目标网页正文内容;
2. 将正文转换为 Markdown 格式;
3. 将 Markdown 文件推送至 GitHub 存档仓库;
4. 创建对应的 Telegraph 镜像页;
5. 调用网页时光机(archive.org)生成快照链接。

该过程通常需要数秒至十几秒,期间无需手动干预。

### 步骤 3: 接收 Bot 回传的信息卡片

处理完成后,Bot 会回传一张信息卡片,包含三个部分:

- **标题与摘要**:展示网页的核心内容摘要,例如「小而美命令行工具 📝 这是一段用于手册演示的中文摘要,说明该内容的核心要点」;
- **标签**:根据正文自动提炼的话题标签,如 `#archive` `#开发工具` `#命令行`;
- **📁 三链按钮**:分别指向 GitHub 存档、网页时光机快照(链接形如 `https://web.archive.org/web/...`)、Telegraph 镜像页,点击即可跳转查看。

### 小贴士

- **链接类型限制**:本功能适用于普通网页内容抓取;部分需要登录、存在反爬机制或纯前端渲染的页面可能无法获取完整正文,建议优先粘贴可公开访问的文章型链接。
- **三链用途各异**:GitHub 链接适合长期归档与版本管理,Telegraph 链接阅读体验更佳,网页时光机快照则可作为原始页面的第三方备份,三者互补使用。
- **批量处理**:如需归档多个链接,可依次粘贴发送,Bot 会按接收顺序逐一处理并分别回传独立卡片。
