## 任意网页链接 → markdown 存档

只需将网页链接发送给 Bot,即可自动抓取正文、转换为 markdown 格式,并同步归档到 GitHub 与 Telegraph,最后返回一张包含标题、摘要与三链入口的存档卡片。整个过程无需安装额外软件,纯靠聊天窗口即可完成。

### 步骤 1:复制并粘贴网页链接

在任意浏览器中打开希望存档的网页,复制其完整 URL。回到与 Bot 的对话窗口,将链接以纯文本形式粘贴并发送。注意:

- 仅支持 `http://` 与 `https://` 开头的公网链接;
- 链接应单独成行,避免夹杂其他无关文字,以免干扰正文识别;
- 带有付费墙或登录限制的页面可能抓取失败,建议使用公开可访问的版本。

发送后,Bot 会在后台开始解析页面内容。

### 步骤 2:查看存档卡片

解析完成后,Bot 会返回一条结构化消息,包含三部分信息:

- **标题与摘要**:自动提炼的页面标题(例如"小而美命令行工具"),以及一段简明的中文摘要,概括文章核心要点;
- **话题标签**:依据正文内容自动生成的若干 `#` 标签(如 `#archive`、`#开发工具`、`#命令行`),便于后续检索;
- **📁 三链入口**:点击 📁 即可分别跳转到 Web Archive 时光机快照、GitHub 仓库中的 markdown 文件,以及 Telegraph 镜像页,任选其一查阅即可。

![Bot 返回的存档卡片,包含标题、摘要、标签与 📁 三链](assets/08-webpage-r1.png)

### 步骤 3:在三链中按需查阅

卡片发出后,你可以:

- 在 GitHub 链接中查看或下载原始 markdown 源文件,适合二次编辑、引用到其他项目;
- 在 Telegraph 链接中获得排版整洁、即点即读的在线阅读体验,移动端体验尤佳;
- 在 Web Archive 链接中回溯该页面的历史快照,即使原网站宕机也能找到存档。

三份副本互为冗余,任意一份失效都不影响其他两份的访问。

### 小贴士

- 若 Bot 长时间无响应,可尝试重新发送链接一次,系统会跳过已成功的归档阶段,直接进入重试流程;
- 对于含大量代码块的技术文章,GitHub 链接中的 markdown 版本会保留原始代码格式,推荐使用;
- 若希望自定义标签或修改摘要,可先在 GitHub 链接中编辑对应文件,提交后 Telegraph 与 Web Archive 会保留原始版本以供对照。
