### 步骤 1: 打开与 Bot 的对话

在 Telegram 中找到 daily-digest Bot,点击进入对话窗口。如果是首次使用,需要先点击「Start」按钮,触发 Bot 激活。

### 步骤 2: 发送 /start 命令

在输入框中输入 `/start` 并发送。这是最常用的入门命令,适用于两种场景:一是新用户首次接触 Bot,二是老用户随时调出帮助菜单。

### 步骤 3: 接收 HELP 菜单

Bot 会立即回复一段中文帮助文本,内容包含三部分:可用命令列表、支持的链接类型说明、推送时间信息。回复格式如下:

> 📊 daily-digest 使用
> 
> 命令
> - `/trending` — 今日 GitHub Trending
> - `/product` — 今日 HN 酷产品
> - `/search 关键词` — 搜索历史存档
> - `/archive` — 历史存档(分页+三链)
> 
> 链接
> - GitHub 仓库链接 → 单仓查询存档

![start 命令返回的 HELP 菜单](assets/01-start-r1.png)

从菜单中可以快速了解 Bot 的四大核心命令:查看 GitHub 今日热门趋势、浏览 Hacker News 酷产品、按关键词搜索历史推送内容、翻阅分页历史存档。此外,Bot 也支持直接识别 GitHub 仓库链接,粘贴链接即可查询该仓库的过往存档。

### 步骤 4: 尝试任意文本

如果发送的不是上述命令(例如随意发个「hello」),且当前不在任何分支流程中,Bot 同样会返回这份 HELP 菜单。这是一种兜底机制,确保用户在任何时候都能找回帮助信息。

### 步骤 5: 选择命令继续使用

根据 HELP 菜单的提示,直接发送需要的命令即可开始使用。例如发送 `/trending` 查看今日 GitHub 趋势,或粘贴一个 GitHub 仓库链接查询其历史存档。

---

### 小贴士

- **随时调用帮助**:忘了命令格式时,直接发送 `/start` 或任意文字,Bot 都会重新展示 HELP 菜单,无需记忆。
- **命令与链接二选一**:除了使用命令,也可以直接粘贴 GitHub 仓库链接,Bot 会自动识别并返回该仓库的存档信息,操作更快捷。
- **首次推送时间**:Bot 按设定时间主动推送 Trending 与 Product 内容,若想提前查看,使用 `/trending` 和 `/product` 命令即可立即获取当日内容。
