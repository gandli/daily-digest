## 快速开始

本节将带你完成与 daily-digest Bot 的首次交互,帮助你快速了解 Bot 能做什么以及如何获取每日推送内容。

### 步骤 1: 发送 /start 命令

打开 Telegram,找到 daily-digest Bot,点击对话框下方的「开始」按钮,或在输入框中手动输入 `/start` 并发送。

Bot 收到你的 `/start` 命令后,会立即回复一份欢迎与帮助菜单,内容包含:

- 标题提示「📊 daily-digest 使用」
- 可用命令列表:
  - `/gt` — 查询今日 GitHub Trending
  - `/hn` — 查询今日 Hacker News 酷产品
  - `/ph` — 查询今日 Product Hunt 热门产品
  - `/search 关键词` — 查询历史存档
  - `/archive` — 浏览历史存档(分页+三链)

### 步骤 2: 查看帮助菜单截图

下面是真实对话中 Bot 回复的截图,供你对照确认:

![daily-digest Bot 在收到 /start 后返回的帮助菜单](assets/01-start-r1.png)

通过这份菜单,你可以一目了然地看到 Bot 当前支持的全部命令。后续所有功能都围绕这些命令展开。

### 步骤 3: 选择下一步操作

阅读完帮助菜单后,你可以根据自己的需求选择下一步:

- 如果想浏览当天热门内容,可发送 `/gt`、`/hn` 或 `/ph`;
- 如果想查找往期文章,可使用 `/search 关键词` 或 `/archive` 浏览历史存档。

例如,发送 `/hn` 会触发 Bot 查询今日 Hacker News 上的酷产品并返回结果;发送 `/search AI` 则会按关键词在历史存档中检索相关内容。

---

### 小贴士

1. 不必记忆完整命令列表:任何时候再次发送 `/start`,Bot 都会重新把帮助菜单发给你,相当于随身的命令速查表。
2. 当你不确定该输入什么时,直接发送 `/start` 是最稳妥的入口,它不会修改任何状态,也不会消耗你的查询额度。
3. 关注 Bot 推送时间窗口:每日 GitHub Trending、Hacker News、Product Hunt 的推送会在固定时间发出,建议将 Bot 消息保持开启,避免错过当日精选。
