### 快速开始

欢迎使用 daily-digest Bot!只需几步,你就能获取每日 GitHub Trending、HN 酷产品、关键词搜索与历史存档。下方以全新用户身份走完首次交互流程。

### 步骤 1:发送 `/start` 启动 Bot

在 Telegram 对话框中输入 `/start` 并发送,这是与 Bot 建立会话的入口命令,也是你随时调出帮助菜单的快捷方式。

### 步骤 2:接收 Bot 返回的 HELP 菜单

Bot 收到你的消息后会立即回复一份完整的帮助说明,内容包含三部分:

- **命令列表**:展示 Bot 支持的全部交互命令,包括 `/trending`(今日 GitHub Trending)、`/product`(今日 HN 酷产品)、`/search 关键词`(搜索历史存档)、`/archive`(历史存档,带分页与三链)。
- **支持的链接类型**:Bot 明确说明可解析 GitHub 仓库链接,将其用于单仓存档查询;X 平台(原 Twitter)链接暂不在支持范围内。
- **推送时间**:Bot 会在每天固定时刻自动推送当日 digest,无需你手动触发,适合放在频道或群组中长期订阅。

![首次 /start 后 Bot 返回的 HELP 菜单,包含命令列表、链接类型与推送说明](assets/01-start-r1.png)

### 步骤 3:根据提示选择下一步操作

读完帮助菜单后,你可以从以下任一方向继续:

- 想看今日热门:发送 `/trending` 或 `/product`。
- 想翻历史记录:发送 `/archive` 浏览分页列表,或直接发送 `/search 关键词` 精准定位。
- 想查询某仓库的存档:直接粘贴 GitHub 仓库链接,Bot 会回应该仓库的归档摘要。

### 步骤 4:再次迷失时随时呼出帮助

任何时候发送 `/start`,或发送任意不在上述分支中的文本,Bot 都会回到这份 HELP 菜单,因此你可以放心尝试,不会"卡死"在某个流程里。

### 小贴士

- **帮助是兜底命令**:除 `/trending`、`/product`、`/search`、`/archive` 与 GitHub 链接之外的任何消息,Bot 都会以 HELP 菜单回应,新手阶段可大胆试错。
- **关键词搜索格式固定**:`/search` 与关键词之间需保留空格,例如 `/search LLM`,否则 Bot 不会识别为搜索指令。
- **X 链接暂不支持**:菜单中只列出 GitHub 仓库链接作为可解析类型,粘贴 X/推文链接不会触发归档查询。
