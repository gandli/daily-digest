## 快速开始

本节帮助你在首次接触 daily-digest Bot 时快速跑通整个使用流程，从打开 Bot 到看到帮助菜单，全程只需一条命令。

### 步骤 1:打开 Bot 并发送 `/start`

在 Telegram 中搜索并打开 daily-digest Bot 对话框，在输入框中键入 `/start` 并发送。这是 Bot 识别新用户并进入主流程的入口指令，无论你是首次添加 Bot，还是想重新查看功能列表，都可以发送这条。

发送成功后，Bot 会立即返回欢迎消息和完整的使用说明。消息内容包含命令清单、可查询的链接类型以及推送时间等关键信息。

![Bot 返回的命令列表与功能说明](assets/01-start-r1.png)

### 步骤 2:阅读 Bot 返回的 HELP 菜单

回到消息列表查看 Bot 的回复，你会看到一段结构清晰的帮助文本，主要分为三部分：

1. **命令列表**：包含 `/gt`（查询今日 GitHub Trending）、`/hn`（查询今日 Hacker News 酷产品）、`/ph`（查询今日 Product Hunt 热门产品）、`/search 关键词`（查询历史存档）、`/archive`（浏览历史存档，分页展示三链）。
2. **支持的链接类型**：明确告知 Bot 能从哪些来源抓取每日热门内容。
3. **推送时间**：告知每日内容会在什么时间自动送达。

请完整阅读一遍，确认自己关心的功能入口都在列表中，再决定下一步操作。

### 步骤 3:选择你感兴趣的功能继续使用

完成前两步后，你已经掌握了 Bot 的全部能力概览。后续可以根据需要：

- 想看今天的趋势，发送 `/gt`、`/hn` 或 `/ph`；
- 想检索往期内容，使用 `/search 关键词`；
- 想翻页浏览历史存档，发送 `/archive`。

如果发送了不在命令列表里的文本，Bot 同样会把这份 HELP 菜单再发一遍，避免你遗漏功能。

## 小贴士

- `/start` 是随时可用的“安全牌”：忘记命令或 Bot 表现异常时，重发一次即可重新获得完整帮助菜单，无需翻历史消息。
- 命令与关键词之间用空格分隔，例如 `/search AI` 而不是 `/search,AI`，否则 Bot 会把逗号也当作搜索词的一部分。
- 三个每日查询命令（`/gt`、`/hn`、`/ph`）默认返回当天内容，若当天还未推送，可先用 `/archive` 查看最近一期作为参考。
