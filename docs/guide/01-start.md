## 快速开始

只需三步,就能与 daily-digest Bot 完成首次交互,了解全部可用命令。

### 步骤 1: 找到 Bot 并打开对话

在 Telegram 中搜索并打开 daily-digest Bot 的聊天窗口,无需任何前置设置,新用户可直接进入。

### 步骤 2: 发送 `/start` 触发欢迎菜单

在输入框中键入斜杠命令 `/start` 并发送。这是首次使用 Bot 的标准入口,用于拉取帮助信息。

Bot 接收到 `/start` 后,会立即回复一段使用说明,内容涵盖四类核心命令以及链接支持范围,完整效果如下图所示:

![Bot 回复 HELP 菜单,列出 /trending、/product、/search、/archive 四个命令及 GitHub 仓库链接支持](assets/01-start-r1.png)

回复内容包含以下要点:

- **命令列表**:四个一级命令,分别用于查看当日 GitHub Trending、查看当日 Hacker News 酷产品、按关键词搜索历史存档、分页浏览历史存档(三链汇总)。
- **链接类型**:支持 GitHub 仓库链接,粘贴单条仓库链接即可查询对应存档,链接前缀示例为 `X/`(代表任意仓库拥有者)。
- **推送时间**:每日定时汇总推送,具体发送时刻以 Bot 配置为准。

### 步骤 3: 阅读菜单并选择下一步操作

阅读 Bot 返回的帮助文本后,即可根据需求选择:

- 想看今日热门:发送 `/trending` 或 `/product`;
- 想查某仓库历史:直接粘贴 GitHub 仓库链接;
- 想按关键词回溯:发送 `/search 关键词`;
- 想翻阅全部存档:发送 `/archive`。

如果某次发送了 Bot 不识别的文本(且不在任何命令分支中),Bot 会再次回退到这份 HELP 菜单,作为通用的引导回复。

### 小贴士

- 发送 `/start` 是随时查阅命令清单的快捷方式,忘记用法时无需翻找聊天记录,直接重发即可。
- 链接查询时只需粘贴形如 `https://github.com/owner/repo` 的完整仓库地址,Bot 会自动识别并返回该仓库的历史存档。
- 命令与参数之间使用空格分隔,例如 `/search rust`,关键词无需加引号。
