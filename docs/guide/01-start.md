### 步骤 1: 向 Bot 发送 `/start`

在 Telegram 聊天窗口中找到 daily-digest Bot,点击输入框,键入斜杠加 start,即输入 `/start`,然后点击发送。这是首次使用 Bot 时的标准入门指令,也是随时调出帮助菜单的快捷方式。

### 步骤 2: 查看 Bot 回复的 HELP 菜单

Bot 收到 `/start` 后,会立即回复一份简洁的使用说明菜单,内容包含五个核心命令的列表,具体如下:

- `/gt`:今日 GitHub Trending(兼容 `/trending`)
- `/hn`:今日 HN 酷产品(兼容 `/product`)
- `/ph`:Product Hunt 每日热门
- `/search 关键词`:搜索历史存档
- `/archive`:历史存档(分页浏览)

依据对话记录,菜单正文以「📊 daily-digest 使用」开头,逐行列出每条命令,最后还会补充说明 Bot 支持的链接类型以及每日推送时间等附加信息。完整回复示例如下图所示:

![Bot 回复的 HELP 菜单,列出 /gt、/hn、/ph、/search、/archive 五个命令](assets/01-start-r1.png)

> 备注:除 `/start` 外,当用户发送任意非命令文本(例如「你好」「在吗」)且该消息不匹配任何具体业务分支时,Bot 同样会回退并返回上述 HELP 菜单,可作为二次唤起帮助的备用方式。

### 步骤 3: 确认菜单内容后开始使用

阅读完命令列表后,你就可以根据需要选择下一步操作了:

- 想了解开发者社区热点,发送 `/gt` 或 `/trending`;
- 想浏览 Hacker News 上值得把玩的产品,发送 `/hn` 或 `/product`;
- 想查看 Product Hunt 当日榜单,发送 `/ph`;
- 想检索往期内容,发送 `/search 关键词`;
- 想浏览按日期归档的历史记录,发送 `/archive`。

任意一条命令执行后,后续交互将进入对应的业务分支,本章节不再展开。

## 小贴士

1. 收藏 `/start`:把它当作万能钥匙,无论何时记不清命令,随时发送即可重新调出 HELP 菜单,无需记忆复杂指令。
2. 善用别名:`/gt` 与 `/trending`、`/hn` 与 `/product` 效果完全一致,任选顺手的写法即可。
3. 留意推送时间:菜单末尾会注明 Bot 每日定时推送的时间点,如有需要可结合时区换算,避免错过当日资讯。
