# 快速开始

本章面向首次使用 daily-digest Bot 的用户,演示从添加到首次获得帮助菜单的完整流程。

### 步骤 1: 添加 Bot 并进入对话

在 Telegram 中找到 daily-digest Bot 并发起会话。新用户首次进入时无需任何前置配置,Bot 会立即处于待命状态,等待接收第一条消息。

### 步骤 2: 发送 `/start` 命令

在输入框中键入 `/start` 并发送。这是 Bot 的内置入口命令,既触发欢迎语,也会让 Bot 输出一份完整的使用说明,帮助你了解后续可用功能。

### 步骤 3: 查看 Bot 返回的 HELP 菜单

Bot 会立即回复一段结构化的帮助文本,内容涵盖三类信息:可用命令列表、支持的链接类型,以及每日推送时间。回复示例如下:

📊 daily-digest 使用 命令 /gt — 查询今日 GitHub Trending /hn — 查询今日 Hacker News 酷产品 /ph — 查询今日 Product Hunt 热门产品 /search 关键词 — 查询历史存档 /archive — 浏览历史存档(分页+三链)

![首次 /start 返回的 HELP 菜单](assets/01-start-r1.png)

从回复中可以看到,当前会话已经进入主分支外的默认处理流程,Bot 通过 HELP 菜单告知用户:**命令类**功能包含 `/gt`、`/hn`、`/ph`、`/search`、`/archive`;**链接类**功能支持三类来源的存档;**推送时间**则为每日定时汇总。

### 步骤 4: 根据需要继续操作

阅读完 HELP 菜单后,你可以直接使用上方任意命令进行查询,也可以先关闭对话,等待每日定时推送。下一次任意时刻回到 Bot,只需发送 `/start` 或任意文本,即可重新调出这份帮助菜单。

---

## 小贴士

- **忘记命令时随时发 `/start`**:HELP 菜单是权威的当前功能清单,任何时候不清楚 Bot 支持什么,发送 `/start` 或任意文字即可重看。
- **命令与链接是两套入口**:命令用于主动查询今日热点或翻历史存档,而 Bot 主动推送的每日汇总则基于支持的三类链接来源,二者互补使用体验更佳。
- **首次使用建议先试 `/gt`**:GitHub Trending 数据稳定、响应快,适合作为验证 Bot 是否正常工作的第一个动作,确认无误后再探索 `/hn`、`/ph` 与历史存档功能。
