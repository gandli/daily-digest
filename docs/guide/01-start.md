### 步骤 1: 添加 Bot 并发送 /start

在 Telegram 中找到本 Bot(代号 **daily-digest**),点击「开始」或直接向对话窗口输入 `/start`,即可触发首次握手。

发送后,Bot 会立即返回一份 HELP 菜单,内容包含所有可用命令、支持的链接类型以及每日推送的时间安排。这是新用户了解 Bot 能力的最快入口,无需任何配置,也不要求登录或授权。

![Bot 返回的 HELP 菜单,展示命令列表与支持能力](assets/01-start-r1.png)

### 步骤 2: 阅读并理解菜单内容

HELP 菜单按以下顺序呈现,建议从上到下阅读:

1. **命令列表** — 列出 `/gt`、`/hn`、`/ph`、`/search`、`/archive` 等核心指令,每个命令后面附带中文用途说明,例如 `/gt` 表示「查询今日 GitHub Trending」。
2. **支持的链接类型** — 明确告诉用户 Bot 可以解析和抓取的内容来源,目前覆盖 GitHub、Hacker News、Product Hunt 三大平台。
3. **推送时间** — 提示每日资讯的自动推送时段,方便用户判断何时会收到摘要消息。

### 步骤 3: 选择下一步操作

看完菜单后,你可以根据当天的兴趣直接执行命令:

- 想看技术热点 → 发送 `/gt`;
- 想读 Hacker News 酷产品 → 发送 `/hn`;
- 想浏览 Product Hunt 今日榜 → 发送 `/ph`;
- 想查历史内容 → 发送 `/search 关键词` 或 `/archive` 分页浏览。

也可以再次发送 `/start` 重新调出这份 HELP 菜单,作为速查表随时回看。

## 小贴士

- **把 HELP 菜单当作速查表**:任何时候忘记命令格式,直接重发 `/start` 即可,无需翻阅说明文档。
- **发送非命令文本也会触发 HELP**:若输入一段不在分支中的普通文字,Bot 会回退到同一份菜单,作为兜底引导。
- **菜单中已标注推送时间**:请留意你所在时区与 Bot 推送时间之间的差异,避免错过每日摘要。
