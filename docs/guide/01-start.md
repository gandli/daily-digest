### 快速开始

本节帮助你在首次使用时,用最短路径熟悉 Bot 的核心入口与命令体系。只需一次 `/start`,即可拿到每日推送的全部命令清单与支持的链接类型说明。

### 步骤 1:发起首次对话

在 Telegram 中找到 Bot,点击 **Start** 或在输入框中发送 `/start`。这是新用户接入 Bot 的标准入口,适用于首次关注与后续任意时刻想要重新查看帮助菜单的场景。

发送后,Bot 立即回复一段结构化的 **HELP 菜单**,内容分为三部分:命令列表、支持的链接类型、推送时间说明。你无需记忆命令,这条菜单就是后续所有操作的速查表。

![首次 /start 后 Bot 返回的 HELP 菜单](assets/01-start-r1.png)

### 步骤 2:阅读 HELP 菜单中的关键命令

HELP 菜单中,优先关注以下三条高频命令:

- **/gt** — 查询当日 GitHub Trending,获取开源社区热门项目榜单。
- **/hn** — 查询当日 Hacker News 的酷产品板块,聚焦技术圈讨论热点。
- **/ph** — 查询当日 Product Hunt 热门产品,追踪新产品发布动态。

这三条命令覆盖了 Bot 的三大数据源,适合作为每日例行检索的起点。

### 步骤 3:按需使用存档与检索命令

HELP 菜单的另外两条命令用于回溯历史内容,适合错过了推送时间或想补看某天摘要的场景:

- **/search 关键词** — 按关键词在历史存档中检索匹配记录,例如 `/search AI agent`。
- **/archive** — 浏览历史存档,支持分页查看,并可同时查看 GitHub、Hacker News、Product Hunt 三类来源的内容。

使用时将命令与关键词用空格分隔,Bot 会回传匹配结果或分页列表,按照提示继续操作即可。

### 步骤 4:了解推送时间与链接类型

HELP 菜单末尾会标注每日推送的发送时间,以及 Bot 当前支持解析的链接类型(如 GitHub 仓库、Hacker News 讨论帖、Product Hunt 产品页等)。建议记录推送时间,在内容更新后第一时间查看;若你在对话中直接粘贴支持的链接,Bot 也会按对应来源进行识别与存档。

### 小贴士

- **随时调出帮助**:除首次 `/start` 外,任意时刻发送 `/start` 或任意不在分支中的文本,Bot 都会再次返回 HELP 菜单,适合作为命令速查工具。
- **命令可组合**:先发送 `/archive` 浏览分页列表,定位到感兴趣日期后再用 `/search 关键词` 精确检索,效率更高。
- **关注推送时间**:HELP 菜单中标注的推送时间即为当日内容更新时间,错过可通过 `/archive` 或 `/search` 补看。
