### 步骤 1: 在 Telegram 中打开 Bot 对话

在 Telegram 客户端的搜索栏中找到 daily-digest Bot,点击进入对话窗口。首次添加 Bot 时,Telegram 会在聊天顶部显示"开始"按钮,你也可以直接在输入框中输入任意文字向 Bot 发起首次互动。

### 步骤 2: 发送 `/start` 命令

在消息输入框中键入斜杠加 start,即 `/start`,然后点击发送。这是最常用的入门命令,适用于新用户首次接触 Bot,以及在任何时候想重新查看帮助菜单的场景。

![用户发送 /start 后 Bot 返回完整帮助](assets/01-start-r1.png)

### 步骤 3: 查看 Bot 返回的 HELP 菜单

Bot 收到 `/start` 后,会立即回复一段格式化的帮助信息,内容分为三部分:

- **命令列表**:介绍可用命令,包括 `/gt`(今日 GitHub Trending)、`/hn`(今日 HN 酷产品)、`/ph`(Product Hunt 每日热门)、`/search 关键词`(搜索历史存档)、`/archive`(历史存档,支持分页与三链)。
- **支持的链接类型**:说明 Bot 能识别的链接格式,目前包含 GitHub 仓库链。
- **推送时间**:Bot 不会在帮助菜单中单独罗列推送时间,定时推送依据后台调度,你可以继续通过命令手动拉取。

### 步骤 4: 继续探索或结束

阅读完帮助菜单后,你可以选择立即尝试某个命令(例如发送 `/gt` 查看今日 GitHub 趋势),也可以关闭对话稍后再来。Bot 不会因为你暂时不发言而清除会话,任何时候再次发送 `/start` 都能调出这份帮助。

## 小贴士

- **忘记命令时随时发 `/start`**:它是最安全的"重置"动作,既不会触发数据变更,也不会产生噪音消息,适合作为书签命令随时调出菜单。
- **发送任意非命令文本也能调出帮助**:在不处于任何命令分支时,直接发送一段普通文字,Bot 同样会返回这份 HELP 菜单,作为兜底入口。
- **先看帮助再发链接**:在粘贴 GitHub 仓库链接前,确认地址格式符合 Bot 支持的类型,可以避免被当作无效输入忽略。
