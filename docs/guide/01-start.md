### 步骤 1：添加 Bot 并发起首次对话

在 Telegram 中找到本 Bot 并发起对话。点击对话框下方的"开始"按钮，或在输入框中键入 `/start` 并发送。

### 步骤 2：查看 Bot 返回的 HELP 菜单

Bot 收到你的消息后，会立刻回复一份 HELP 菜单作为引导。菜单内容包含三部分：

- **可用命令**：包括 `/gt`（查询今日 GitHub Trending）、`/hn`（查询今日 Hacker News 酷产品）、`/ph`（查询今日 Product Hunt 热门产品）、`/search 关键词`（查询历史存档）以及 `/archive`（浏览历史存档，支持分页与三链）。
- **支持的链接类型**：菜单末尾会列出当前可识别的来源类型，与上述命令一一对应。
- **推送时间**：菜单中会注明每日定时推送的时刻，便于你安排查看。

如下所示，HELP 菜单以清晰的列表形式呈现，方便快速浏览：

![HELP 菜单示例](assets/01-start-r1.png)

### 步骤 3：选择下一步操作

阅读完菜单后，你可以：

- 直接点击 `/gt`、`/hn`、`/ph` 中的任意一个，查询当天的热门内容；
- 使用 `/search 关键词` 检索历史存档，例如 `/search AI`；
- 使用 `/archive` 进入分页浏览模式；
- 或继续发送 `/start` 再次调出 HELP 菜单。

### 步骤 4：在任意时刻重新调出帮助

如果在使用过程中忘记了命令，不必退出对话，只需再次发送 `/start`，或发送任意不在分支内的非命令文本，Bot 都会重新返回 HELP 菜单作为兜底引导。

## 小贴士

- 发送 `/start` 或任意非命令文本都可以重看 HELP 菜单，是最稳妥的"迷路"恢复方式。
- 关键词检索前无需加井号，例如直接发送 `/search AI` 即可，不要写成 `/search #AI`。
- `/archive` 默认按时间倒序分页，连续发送 `/archive` 可逐页向后翻阅历史三链内容。
