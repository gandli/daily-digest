### 步骤 1：打开与 Bot 的对话

在 Telegram 中搜索并打开 daily-digest Bot 的聊天窗口。Bot 处于静默待命状态,不会主动发送任何内容,只有当你发送消息后才会回复。

### 步骤 2：发送 `/start` 命令

在输入框中键入 `/start` 并发送。这是 Bot 的入门命令,用于初始化会话并展示主菜单。

### 步骤 3：查看 Bot 返回的 HELP 菜单

Bot 会立即回复一段包含完整功能列表的菜单消息,内容涵盖命令清单与基本信息。你将看到以下回复:

> 📊 daily-digest 使用
> /gt — 查询今日 GitHub Trending
> /hn — 查询今日 Hacker News 酷产品
> /ph — 查询今日 Product Hunt 热门产品
> /search 关键词 — 查询历史存档
> /archive — 浏览历史存档(分页+三链)

!Bot 回复 HELP 菜单,列出全部可用命令](assets/01-start-r1.png)

该菜单一次性告知用户 Bot 支持的全部命令以及对应的资讯来源类型(GitHub Trending、Hacker News、Product Hunt)。发送 `/start` 是确认 Bot 可用、了解命令体系的推荐入口动作。

### 步骤 4：根据菜单选择下一步操作

阅读完菜单后,你可以根据兴趣选择任意命令开始使用:

- 发送 `/gt` 查看当日 GitHub Trending 热门项目;
- 发送 `/hn` 浏览 Hacker News 上的精选酷产品;
- 发送 `/ph` 获取 Product Hunt 当日热门榜单;
- 发送 `/search 关键词` 检索历史存档中包含特定关键词的内容;
- 发送 `/archive` 进入历史存档的分页浏览模式,一次性查看三类来源的历史汇总。

> **注意**:除上述 `/start` 外,任何不在命令分支中的普通文本消息也会让 Bot 回退并重新展示 HELP 菜单,因此在不确定时可直接发送任意文字作为"重看菜单"的快捷方式。

### 小贴士

- **首次使用建议先发送 `/start`**:这是最低成本的"健康检查",既能验证 Bot 是否在线,也能一次性拿到完整命令表,避免后续重复尝试。
- **命令支持简写与组合**:`/gt`、`/hn`、`/ph` 为单字母简写,输入更高效;`/search` 必须附带关键词,否则可能无法触发正确分支。
- **历史浏览优先用 `/archive`**:如果你想集中查看过往多日的三链汇总,推荐使用 `/archive` 进入分页模式,而不是反复调用单日命令。
