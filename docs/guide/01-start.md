### 快速开始

本节引导新用户从零开始与 Bot 互动,只需一步即可查看全部可用命令。

### 步骤 1: 向 Bot 发送 /start 命令

在 Telegram 中打开与 Bot 的对话窗口,在输入框中键入以下命令:

`/start`

然后点击发送按钮或按回车键即可。

### 步骤 2: 接收 Bot 回复的 HELP 菜单

Bot 接收到 `/start` 命令后,会立即回复一份完整的 HELP 菜单,内容包含:

1. **命令列表** —— 介绍 Bot 支持的全部交互命令,包括 `/trending`(今日 GitHub Trending)、`/product`(今日 HN 酷产品)、`/ph`(Product Hunt 每日热门)、`/search 关键词`(搜索历史存档)、`/archive`(历史存档,支持分页与三链)。
2. **支持的链接类型** —— 说明 Bot 可以解析和归档的链接格式。
3. **推送时间** —— 告知用户每日自动推送的时间安排。

用户发送任意不在其他分支中的非命令文本(例如随手输入的问候语)时,Bot 也会回退到这一 HELP 菜单,确保新用户不会迷失方向。

### 小贴士

1. **随时回看命令** —— 不必担心忘记命令,直接发送任意文字或 `/start`,Bot 都会重新发送 HELP 菜单。
2. **先读菜单再操作** —— 建议首次使用时先通读 HELP 菜单中的命令说明,了解每条命令的参数要求(例如 `/search` 需要附带关键词),可避免无效交互。
3. **留意推送时间** —— 菜单中标注的推送时间决定了每日自动送达的内容时点,如有变更可在 HELP 菜单中即时确认。
