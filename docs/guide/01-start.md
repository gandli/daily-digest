### 快速开始

本节面向第一次使用 Bot 的新用户,带你走完从添加到上手的完整流程,只需一分钟即可看到推送内容。

### 步骤 1: 添加 Bot 并发送 /start

在 Telegram 中找到 daily-digest Bot,点击 **Start** 或在聊天框输入 `/start` 并发送。这是与 Bot 交互的第一步,Bot 会立即识别你为新用户。

![发送 /start 后 Bot 返回帮助菜单](assets/01-start-r1.png)

### 步骤 2: 阅读 Bot 返回的 HELP 菜单

Bot 在收到你的 `/start` 后,会立刻回复一段结构化的使用说明,包含三部分内容:

- **命令列表**:依次介绍 `/trending`(今日 GitHub Trending)、`/product`(今日 HN 酷产品)、`/search 关键词`(搜索历史存档)、`/archive`(历史存档,支持分页与三链)。
- **支持的链接类型**:目前已支持 **GitHub 仓库链接**,发送任意 GitHub 仓库地址即可触发单仓查询存档。
- **推送时间**:Bot 会在每日固定时间自动推送当日精选内容,无需手动操作。

### 步骤 3: 选择你的下一步动作

阅读完 HELP 菜单后,你可以根据需要选择:

- 想看今天的热门趋势?发送 `/trending` 或 `/product`。
- 想找过去某条内容?直接输入 `/search 关键词`,例如 `/search RAG`。
- 想浏览全部历史?发送 `/archive`,Bot 会以分页形式返回,每条带三类链接。
- 手上正好有 GitHub 仓库链接?直接把链接粘贴发送,Bot 会查询该仓库的历史存档。

### 小贴士

- **忘记命令时怎么办**:随便发一句非命令的文本(比如 `hi` 或 `你好`),Bot 会再次显示 HELP 菜单,等同于随时可用的帮助页。
- **多入口触发**:`/start` 和任意非命令文本都会唤起同一份 HELP 菜单,无需记忆启动方式。
- **链接类型会扩展**:目前仅支持 GitHub 仓库链接的单仓查询,后续将支持更多链接类型,菜单会自动更新。
