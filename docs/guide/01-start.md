## 快速开始

本节帮助你完成 Bot 的首次交互,了解如何调出帮助菜单,以及后续可以使用的命令和链接类型。

### 步骤 1:向 Bot 发送 /start

在 Telegram 中打开与 Bot 的对话窗口,在输入框中键入 `/start` 并发送。这是新用户接入 Bot 后推荐执行的第一步,用于建立会话上下文并拉取使用说明。

Bot 收到指令后,会立即在聊天窗口中返回一段帮助文本,内容包含 Bot 名称 `daily-digest`、可用命令清单,以及支持的链接类型与推送时间。典型回复示例如下:

> 📊 daily-digest 使用 命令
> /gt — 查询今日 GitHub Trending
> /hn — 查询今日 Hacker News 酷产品
> /ph — 查询今日 Product Hunt 热门产品
> /search 关键词 — 查询历史存档
> /archive — 浏览历史存档(分页+三链)

Bot 实际返回的消息与上图保持一致,你可以直接对照查看排版与命令顺序:

![Bot 收到 /start 后返回帮助菜单](assets/01-start-r1.png)

### 步骤 2:阅读帮助菜单

仔细阅读 Bot 返回的命令列表,留意以下几点:

- 每条命令以斜杠 `/` 开头,功能在中文注释中给出,无需额外参数即可执行查询类命令(如 `/gt`、`/hn`、`/ph`)。
- `/search` 与 `/archive` 用于回溯历史内容,前者按关键词检索,后者以分页形式浏览三类来源的历史存档。
- 菜单末尾的提示区域会说明 Bot 支持的链接类型以及每日推送时间,据此判断何时会收到自动汇总。

### 步骤 3:选择后续动作

根据帮助菜单中的命令,你可以直接复制粘贴其中任意一条到输入框并发送,Bot 即返回对应来源的当日热门内容。例如:

- 想看技术趋势,发送 `/gt`;
- 想读产品资讯,发送 `/ph`;
- 想按主题回看历史,发送 `/search 关键词`;
- 想分页翻阅过往存档,发送 `/archive`。

### 步骤 4:再次查看帮助

如果你在会话中临时忘记了命令,可以随时再次发送 `/start`,Bot 会重复返回相同的帮助菜单,不会产生副作用。任意时刻发送 `/start` 都能重新唤起该说明。

### 小贴士

- `/start` 是最安全的"重置"入口:不确定当前可用命令时,先发一次 `/start` 再继续操作,既能确认 Bot 在线,也能拿到最新命令清单。
- 检索类命令(`/gt`、`/hn`、`/ph`)无需附带参数;只有 `/search` 需要在命令后空一格再写关键词,否则会按空关键词处理。
- 历史类功能(`/search`、`/archive`)在内容较多的频道中可能产生分页消息,留意 Bot 连续发送的多条回复,翻页通常需要发送对应的页码或继续指令,具体以 Bot 当时提示为准。
