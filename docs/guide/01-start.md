### 快速开始

本节帮助你在第一次接触 daily-digest Bot 时,迅速了解如何通过命令触发核心功能,并查看 Bot 所支持的内容链接格式。

---

### 步骤 1: 向 Bot 发送 `/start`

在 Telegram 中打开与 daily-digest 的私聊窗口,在输入框中输入斜杠命令 `/start`,然后点击发送。这是与 Bot 建立对话的入口命令,无需任何参数。

Bot 在收到该命令后,会立即返回一段使用说明(同时也是 HELP 菜单),内容包含三部分:

1. **命令列表**: `/trending`(今日 GitHub Trending)、`/product`(今日 HN 酷产品)、`/search 关键词`(搜索历史存档)、`/archive`(历史存档,支持分页与三链接展示)。
2. **支持的链接类型说明**: 告知用户 Bot 可以识别并解析 GitHub 仓库链接,用于单仓查询存档。
3. **推送时间提示**: 标明 Bot 自动推送每日摘要的时间点。

### 步骤 2: 触发 HELP 菜单的另一种方式

如果你不小心错过了 `/start` 的输出,或希望随时重新查看命令列表,可以直接向 Bot 发送**任意非命令文本**(例如随手打一个"hi"或一个表情)。在不匹配其他任何业务分支的前提下,Bot 同样会以 HELP 菜单作为兜底响应,输出内容与 `/start` 完全一致。

这一机制确保你无论在哪个对话阶段,只要发送的内容不构成有效指令,都能回到这份使用说明,不会陷入"无响应"的困惑。

---

### 步骤 3: 选择下一步操作

收到 HELP 菜单后,你可以根据需要选择:

- 想看今天的科技热点 → 发送 `/trending` 或 `/product`。
- 想查找过去推送过的某条信息 → 发送 `/search 关键词`。
- 想浏览全部历史存档 → 发送 `/archive`。
- 想针对某个 GitHub 仓库单独查询历史 → 直接粘贴一条 GitHub 仓库链接。

任意时刻,你都可以再次发送 `/start` 或随意输入文本,重新调出 HELP 菜单作为参考。

---

## 小贴士

- **把 `/start` 设为常用命令**: 在与 Bot 的私聊中长按输入框,可以把 `/start` 固定到命令栏,方便随时调用。
- **GitHub 链接无需额外参数**: 直接粘贴 `https://github.com/owner/repo` 形式的标准仓库链接即可,无需在前后附加任何命令。
- **遇到无响应时先回到 HELP**: 如果某次输入后 Bot 没有按预期回复,直接发送任意文本,即可触发兜底 HELP 菜单,帮助你确认当前支持的指令格式。
