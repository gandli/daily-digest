# 快速开始

本章面向第一次使用 daily-digest Bot 的新用户，帮助你在最短时间内完成首次交互、了解 Bot 能做什么，并顺利进入后续功能模块。

### 步骤 1：在 Telegram 中搜索并打开 Bot 对话

在 Telegram 搜索栏输入 Bot 的用户名，进入与 Bot 的私聊窗口。首次打开时，聊天界面为空，等待你发出第一条消息。

### 步骤 2：发送 `/start` 启动 Bot

在输入框中输入 `/start` 并发送。Bot 会立即回复一段欢迎与帮助信息，其中包含完整的命令清单以及 Bot 当前支持的数据来源与推送时间说明。这段回复是 Bot 的“自我介绍”，也是后续所有操作的入口参考。

![Bot 回复 /start 后的帮助菜单](assets/01-start-r1.png)

回复内容主要分为三部分：

1. **命令列表**：包括 `/gt`（查询今日 GitHub Trending）、`/hn`（查询今日 Hacker News 酷产品）、`/ph`（查询今日 Product Hunt 热门产品）、`/search 关键词`（查询历史存档）、`/archive`（浏览历史存档，支持分页与三链聚合）。
2. **支持的链接类型**：Bot 会说明它能识别和处理的来源链接范围，便于你直接粘贴链接进行检索。
3. **推送时间**：告知每日自动汇总的推送时间，方便你按时查看。

### 步骤 3：确认 Bot 可用，任意粘贴一条文本试一试

如果你不想立刻执行命令，也可以直接发送任意一段非命令文本。Bot 会再次返回与 `/start` 相同的 HELP 菜单。这一行为适用于“新用户加 Bot 后处于未分支状态”的兜底逻辑，确保你在任何状态下都能拿到帮助信息。

### 步骤 4：根据菜单选择下一步操作

阅读完帮助菜单后，你可以：

- 直接点击命令按钮（例如 `/gt`）获取当日 GitHub Trending；
- 使用 `/search 关键词` 检索历史存档中的相关条目；
- 使用 `/archive` 浏览按日期组织的全部历史内容。

如果不确定该用哪一个命令，随时再次发送 `/start` 或任意文本，HELP 菜单都会再次出现。

## 小贴士

1. **随时调用帮助**：无论处于哪个对话分支，只要发送 `/start` 或任意文本，就能重新拉出 HELP 菜单，不必担心操作失误后“迷路”。
2. **先看命令再行动**：首次使用时建议完整阅读一次菜单中的命令说明，明确每个命令的用途与适用场景，再开始具体查询。
3. **注意推送时间**：若希望被动接收每日汇总，请留意菜单中给出的推送时间，并确保 Bot 未被静音，以保证通知能及时送达。
