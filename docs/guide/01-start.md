## 快速开始

本节帮助你在首次添加 Bot 后, 用最少的操作完成"加 Bot → 看帮助"全流程, 立刻了解 Bot 能做什么。

### 步骤 1: 在 Telegram 中找到 Bot 并发起对话

在 Telegram 搜索栏输入 Bot 用户名, 打开对话窗口。Bot 不会主动推送消息, 一切交互都由你发起。

### 步骤 2: 发送 `/start` 触发帮助菜单

在输入框中键入 `/start` 并发送。这是 Bot 唯一识别的"入门指令", 无论你是首次使用还是中途想再看一次帮助, 都可以重新发送。

Bot 接收到 `/start` 后, 会立即返回一份完整的 HELP 菜单, 内容包含三类信息:

1. **命令列表** — 列出当前可用的全部命令及其用途说明:
   - `/gt` — 查询今日 GitHub Trending
   - `/hn` — 查询今日 Hacker News 酷产品
   - `/ph` — 查询今日 Product Hunt 热门产品
   - `/search 关键词` — 查询历史存档
   - `/archive` — 浏览历史存档(分页 + 三链)
2. **支持的链接类型** — 明确告知 Bot 能解析的内容来源范围。
3. **推送时间** — 告知每日自动推送发生的时刻, 方便你按时查收。

### 步骤 3: 阅读 HELP 并选择下一步动作

收到 HELP 菜单后, 你可以直接:

- **立刻体验**: 点击或手动输入某个命令, 例如 `/gt`, 立刻查看今日 GitHub Trending。
- **稍后再看**: 不做任何操作, 等每日定时推送自动送达。
- **重新查看**: 再次发送 `/start` 或任意非命令文本(如"你好"), Bot 会再次返回同一份 HELP 菜单, 便于随时回顾可用指令。

至此, "新用户加 Bot → 看帮助"流程结束。

### 小贴士

- `/start` 是"无副作用"的入门指令, 可以随时重发, 不会影响历史记录或触发额外推送。
- 除 `/start` 外, 发送任意不在命令分支中的普通文本(如"hi"), Bot 也会回 HELP 菜单, 作为兜底引导。
- 第一次不知道该用哪个命令时, 推荐从 `/gt` 开始: 它返回的 GitHub Trending 列表项最少、最易读, 适合先熟悉 Bot 的输出格式。
