## 快速开始

本节引导新用户完成首次交互,只需一条命令即可了解 Bot 全部能力。

### 步骤 1: 向 Bot 发送 /start

在 Telegram 对话窗口中找到并打开 Bot,直接在输入框中输入 `/start`,然后点击发送。

### 步骤 2: 接收 Bot 返回的 HELP 菜单

Bot 收到 `/start` 后会立即回复一段使用说明(也称 HELP 菜单),内容包含三部分:

- **命令列表**:`/trending` 拉取今日 GitHub Trending;`/product` 拉取今日 HN 酷产品;`/search 关键词` 搜索历史存档;`/archive` 查看历史存档(分页+三链)。
- **支持的链接类型**:GitHub 仓库链接会被识别,用于触发单仓查询存档。
- **推送时间**:每日自动推送由 Bot 后台任务负责,无需用户手动触发。

用户发送 `/start` 与 Bot 回 HELP 菜单的实际效果如下:

![用户发送 /start 后 Bot 返回 HELP 菜单](assets/01-start-r1.png)

> 说明:除了 `/start` 之外,用户发送任意非命令文本且不命中任何功能分支时,Bot 同样会回退到该 HELP 菜单,作为兜底提示。

### 步骤 3: 选择后续操作

阅读完 HELP 菜单后,可按需选择以下任一动作:

- 想看今日热门趋势,直接点击 `/trending` 或手动输入。
- 想看今日产品推荐,使用 `/product`。
- 想检索某关键词的历史记录,使用 `/search 关键词`(例如 `/search AI Agent`)。
- 想浏览全部历史存档,使用 `/archive`。
- 想查询某个具体 GitHub 仓库的存档,把仓库链接粘贴到对话框中即可。

### 小贴士

- 把 Bot 置顶或收藏对话,推送到达时不会错过每日摘要。
- 不确定当前该用什么命令时,再发一次 `/start` 即可随时唤出 HELP 菜单。
- `/archive` 输出较长时支持分页;三链分别对应不同历史快照来源,按需点开即可。
