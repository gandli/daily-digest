### 快速开始

本节帮助你在首次添加 Bot 后,立即了解它能做什么,并学会如何调出帮助菜单。

### 步骤 1: 添加 Bot 并发送 /start

打开 Telegram,搜索并添加 daily-digest Bot。添加成功后,在与 Bot 的对话框中输入 `/start` 并发送。Bot 会立刻回复一段欢迎与帮助信息,内容包含命令列表、支持的链接类型,以及每日推送时间。

![Bot 收到 /start 后返回 HELP 菜单](assets/01-start-r1.png)

### 步骤 2: 查看 Bot 返回的 HELP 菜单

留意 Bot 回复的菜单结构,你会看到三部分内容:

- 命令列表:告诉你 Bot 支持哪些指令,例如 `/gt`、`/hn`、`/ph`、`/search`、`/archive`。
- 支持的链接类型:说明 Bot 能够解析和查询的内容来源。
- 推送时间:告诉你每日汇总会在何时自动送达。

这条菜单是你后续操作的入口地图,建议先通读一遍再开始使用。

### 步骤 3: 直接发送任意文字也能调出帮助

如果你已经和 Bot 聊过、但忘记有哪些命令,只要在与 Bot 的对话中发送任意一条非命令文本(例如一句普通问候),Bot 在没有命中任何分支的情况下,同样会返回与 `/start` 相同的 HELP 菜单。这相当于一个“万能回退”,让你随时回到帮助页。

### 步骤 4: 尝试第一条命令

熟悉菜单后,你可以挑一条命令试试,例如发送 `/gt` 让 Bot 返回当日的 GitHub Trending 列表。成功收到结果后,说明 Bot 已配置完毕,可以进入日常使用。

### 小贴士

- 把 HELP 菜单当作速查表:每次忘了命令,直接发 `/start` 或任意文字即可重新调出,不必翻阅历史消息。
- 命令必须以斜杠 `/` 开头才会被识别为指令;普通聊天文字只会触发帮助菜单,不会执行查询。
- 建议收藏本节中的菜单截图,离线时也能快速对照命令名与用途。
