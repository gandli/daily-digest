### 步骤 1：在 Telegram 中打开 Bot 对话

在 Telegram 搜索并进入 daily-digest Bot 的聊天窗口。首次添加时，Bot 不会自动推送任何内容，需要你主动发起一次交互。

### 步骤 2：发送 `/start` 触发帮助菜单

在输入框中输入命令 `/start`，然后点击发送。Bot 会立刻回复一段 HELP 菜单，内容包含三类信息：

1. **命令列表**：说明 `/trending`、`/product`、`/search`、`/archive` 四个命令分别用于拉取今日 GitHub Trending、今日 HN 酷产品、按关键词搜索历史存档、查看分页历史存档（每页带三条链接）。
2. **支持的链接类型**：明确告知 GitHub 仓库链接会被识别为单仓查询请求，回复中将包含该仓库的存档链接（即示例中的 `X/` 前缀）。
3. **推送时间**：提示每日推送的发送时段，方便你掌握信息流节奏。

发送后的实际效果可参考下图：

![发送 /start 后 Bot 返回的 HELP 菜单](assets/01-start-r1.png)

菜单中每条命令都对应一个具体场景：想了解社区热点用 `/trending`，想找灵感产品用 `/product`，想追溯往期内容用 `/search` 或 `/archive`。读完菜单后，你可以直接选择最贴近当前需求的命令继续操作，无需再次发送 `/start`。

### 步骤 3：阅读并选择下一步命令

仔细浏览 Bot 返回的命令清单与说明，确认自己的需求落在哪一类。如果只是想快速浏览今日热点，就发送 `/trending`；如果手头有一个感兴趣的 GitHub 仓库想看历史推送，直接把仓库链接粘贴到聊天框即可，Bot 会自动将其识别为单仓查询请求并返回对应存档。

> 说明：当你在 Bot 对话中发送任意非命令文本（例如一句话、一个链接），且当前不在任何命令的分支处理流程中时，Bot 都会再次回退并发送这份 HELP 菜单，确保你随时能找到入口。

## 小贴士

- 把 `/start` 当作"目录页"：任何时候对命令拿不准，重新发送一次即可拿到完整说明，不会产生副作用。
- 发送 GitHub 仓库链接时无需附带任何文字，粘贴链接后回车即可触发单仓存档查询；X/ 前缀是 Bot 自带的标识，便于和普通搜索结果区分。
- 若想查看历史推送的更多页，记得使用 `/archive` 自带的分页能力，而不是反复发送 `/start`，效率会高很多。
