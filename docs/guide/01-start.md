### 快速开始

第一次使用 Bot 时,无需复杂配置,几个简单的步骤就能看到每日推送的科技热点摘要。

### 步骤 1:向 Bot 发送 `/start` 指令

在 Telegram 对话窗口中找到并打开你已添加的 Bot(例如本例中的 `daily-digest`),在输入框中键入 `/start` 并发送。这是 Bot 识别新用户的入口指令,任何会话中发送 `/start`,都会触发相同的行为。

![用户发送 /start 后的 Bot 回复](assets/01-start-r1.png)

### 步骤 2:查看 Bot 返回的 HELP 菜单

发送后,Bot 会立即在聊天窗口中返回一段帮助信息。这段消息包含了你需要了解的全部核心功能入口,大致分为三部分:

- **命令列表**:`/gt` 用于查询当日 GitHub Trending 热门项目;`/hn` 用于查询当日 Hacker News 酷产品;`/ph` 用于查询当日 Product Hunt 热门产品;`/search 关键词` 用于在历史存档中搜索;`/archive` 用于查看历史存档,支持分页浏览,并提供上述三类链接的归档。
- **支持的链接类型**:Bot 推送的内容覆盖 GitHub、Hacker News 与 Product Hunt 三个来源。
- **推送时间**:Bot 会按照固定时间点主动推送每日摘要,具体时间见消息尾部说明。

请完整阅读这条消息,以便后续按需调用对应命令。

### 步骤 3:选择你想查看的命令开始使用

根据 HELP 菜单中列出的命令,你可以直接发送任意一条命令体验。例如:

- 想看今天的开源热点,发送 `/gt`;
- 想看科技与创客圈讨论,发送 `/hn`;
- 想看新发布的酷产品,发送 `/ph`;
- 想查找某关键词的历史记录,发送 `/search 关键词`;
- 想浏览往期推送合集,发送 `/archive`。

此外,如果你在任意时刻发送了一条非命令的普通文本(例如直接打字而未加斜杠),且该输入不匹配任何现有分支,Bot 同样会以 HELP 菜单作为兜底回复,确保你始终能找到入口。

### 小贴士

- 首次使用建议先完整阅读 `/start` 返回的菜单,把常用命令收藏到输入框快捷栏,后续一键发送更高效。
- 如果不确定该用哪条命令,直接发送任意文字即可触发 HELP 菜单,作为万能的“导航按钮”。
- 想回顾往期内容时,优先使用 `/archive` 浏览归档,再用 `/search 关键词` 精准定位,两条命令配合使用效率最高。
