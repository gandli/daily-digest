## 快速开始

欢迎使用 daily-digest!只需一次对话,你就能掌握当日 GitHub、Hacker News、Product Hunt 三大平台的热榜,并随时调取过往归档。本节将带你完成第一次使用,了解 Bot 的命令体系与响应内容。

### 步骤 1:向 Bot 发送 `/start`

在 Telegram 聊天窗口中,点击输入框,键入斜杠加 start(即 `/start`),然后点击发送。这是最常见的首次唤醒方式,适用于刚把 Bot 添加进对话或希望随时查看功能清单的场景。

### 步骤 2:接收 HELP 菜单

Bot 收到 `/start` 后会立即返回一段格式化的帮助菜单,内容包含可用命令、支持的链接类型以及推送时间等核心信息,帮助你决定下一步使用哪条命令。

![首屏命令列表](assets/01-start-r1.png)

菜单内容示例如下:

> 📊 **daily-digest 使用**
> - `/gt` 查询今日 GitHub Trending
> - `/hn` 查询今日 Hacker News 酷产品
> - `/ph` 查询今日 Product Hunt 热门产品
> - `/search 关键词` 查询历史存档
> - `/archive` 浏览历史存档(分页 + 三链)

### 步骤 3:根据需要继续操作

阅读完菜单后,你可以在同一会话中继续输入命令:

- 想看代码圈热点 → 发送 `/gt`
- 想看科技/创业资讯 → 发送 `/hn`
- 想看新产品发布 → 发送 `/ph`
- 想查找过往内容 → 发送 `/search 关键词` 或 `/archive`

每次 Bot 都会以列表或卡片形式返回当日或归档结果。

### 步骤 4:再次查看帮助

若中途忘记命令,可随时再次发送 `/start`,Bot 会重复返回上述 HELP 菜单;此外,发送任意非命令文本(例如"你好")且该输入未命中任何已有分支时,Bot 同样会回退并展示 HELP 菜单,作为兜底引导。

## 小贴士

1. **首句就用 `/start`**:这是与 Bot 建立对话的最稳妥方式,几乎所有后续操作都依赖这一入口。
2. **`/search` 与 `/archive` 的区别**:`/search` 适合明确知道关键词的场景,`/archive` 则按时间分页浏览,先翻页再搜索效率更高。
3. **乱码输入也是入口**:不小心发了普通文字也别担心,Bot 会贴心地重新弹出 HELP 菜单,不会让会话陷入沉默。
