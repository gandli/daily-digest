### 步骤 1: 发送 /start 命令

在 Telegram 聊天窗口中,点击输入框,输入斜杠加 `start`,即 `/start`,然后按发送键。这是与 daily-digest Bot 互动的起点,也是新用户最常用的入门命令。

### 步骤 2: 接收 Bot 的欢迎与帮助菜单

Bot 收到 `/start` 后,会立即回复一条带📊表情的开场消息,内容涵盖四类核心命令、两类链接识别说明,以及每日推送时间安排。完整消息如下:

> 📊 daily-digest 使用
> 命令
> /trending — 今日 GitHub Trending
> /product — 今日 HN 酷产品
> /search 关键词 — 搜索历史存档
> /archive — 历史存档(分页+三链)
> 链接
> GitHub 仓库链接 → 单仓查询存档
> X/

这条消息相当于 Bot 的总目录,告诉用户后续可以怎么使用。下图展示了这一轮的真实交互效果:

![用户发送 /start 后 Bot 返回帮助菜单](assets/01-start-r1.png)

### 步骤 3: 选择后续操作

拿到帮助菜单后,用户可以按需选择:

- 想看当天热点,发送 `/trending` 或 `/product`。
- 想查找某条历史记录,发送 `/search 关键词`。
- 想浏览全部历史存档,发送 `/archive`。
- 直接粘贴一条 GitHub 仓库链接,Bot 会自动识别并查询该仓库的归档信息。

### 步骤 4: 任意非命令文本的等价入口

如果用户没有发 `/start`,而是直接输入一段普通文字(例如"你好"),在 Bot 没有任何当前分支的状态下,也会收到与上一步完全一致的 HELP 菜单。也就是说,忘记命令时,随手发一条消息也能唤出帮助。

## 小贴士

- 菜单中末尾的 `X/` 表示 Bot 还会识别 X(原 Twitter)平台的链接格式,可作为后续拓展入口留意。
- 帮助菜单由 `/start` 或任意非命令文本触发,无需记忆多个唤醒方式。
- 每日推送时间会随消息一起展示,留意顶部说明即可订阅当日自动投递。
