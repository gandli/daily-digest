# 快速开始

本章面向第一次使用 daily-digest Bot 的新用户,带你在几分钟内完成首次交互、查看可用命令与推送时间,并理解 Bot 会以怎样的方式回复你。

### 步骤 1: 添加 Bot 并发送 /start

在 Telegram 中搜索并打开 daily-digest Bot,点击 **Start** 或直接在对话框中输入命令 `/start` 并发送。Bot 收到该命令后,会立即向你返回一份入门菜单,内容包含所有可用的命令列表、Bot 支持的链接类型,以及每日推送的时间说明。

发送后你将看到如下回复:

> 📊 daily-digest 使用 命令
> /gt — 查询今日 GitHub Trending
> /hn — 查询今日 Hacker News 酷产品
> /ph — 查询今日 Product Hunt 热门产品
> /search 关键词 — 查询历史存档
> /archive — 浏览历史存档(分页+三链)

效果如下图所示。

![Bot 回复的 HELP 菜单,列出可用命令](assets/01-start-r1.png)

### 步骤 2: 阅读并理解命令菜单

菜单中每一行都遵循「`/命令` — 功能说明」的格式。请重点关注以下几个命令的含义:

- `/gt`、`/hn`、`/ph`:分别抓取并展示当天的 GitHub Trending、Hacker News 酷产品、Product Hunt 热门产品,适合快速浏览今日科技与产品动态。
- `/search 关键词`:在历史存档中按关键词检索,适合回溯某条曾经推送过的内容。
- `/archive`:分页浏览历史存档,同时涵盖上述三类来源,适合系统性地翻阅过往内容。

这一步不需要发送任何消息,只需在脑中或笔记中记录下你最常用的命令即可。

### 步骤 3: 选择一个命令开始你的第一次查询

根据你在步骤 2 中记录的偏好,选择一条命令发送。例如输入 `/gt` 并回车,Bot 便会立即返回当日 GitHub Trending 的结果列表。若你对当前结果不满意,可以继续尝试 `/hn` 或 `/ph`,或在结果中寻找继续探索的线索。

至此,你已经完成了 daily-digest Bot 的首次完整交互,后续可随时重复执行步骤 3 来获取每日内容。

### 小贴士

- 任何时候想要再次查看这份命令菜单,只需重新发送 `/start`,Bot 会原样返回 HELP 菜单,适合加入收藏夹随时查阅。
- 如果你不确定接下来该输入什么,直接发送任意非命令文本(例如「你好」),在没有任何分支匹配的情况下,Bot 同样会以 HELP 菜单作为兜底回复,帮助你回到正轨。
- `/search 关键词` 与 `/archive` 适合在早晨推送错过或想深入翻阅时使用:前者按关键词精准定位,后者按时间分页浏览,两者搭配可以高效地回顾历史内容。
