## 快速开始

本节引导新用户完成首次与 daily-digest Bot 的交互,了解可用命令与支持的内容类型,顺利完成"冷启动"。

### 步骤 1: 添加 Bot 并发送 `/start`

在 Telegram 中找到 daily-digest Bot,点击 **Start** 或在输入框键入 `/start` 并发送。这是所有用户与 Bot 建立会话的第一步,无论是否首次使用均可触发,Bot 会用它来确认你的聊天上下文已就绪。

![用户发送 /start,Bot 返回命令列表与链接类型说明](assets/01-start-r1.png)

### 步骤 2: 阅读 Bot 返回的 HELP 菜单

发送 `/start` 后,Bot 会立即回复一段使用说明,内容包含三部分信息:

- **可用命令清单**:四个核心命令的格式与用途
  - `/trending` — 今日 GitHub Trending
  - `/product` — 今日 HN 酷产品
  - `/search <关键词>` — 搜索历史存档
  - `/archive` — 历史存档(分页 + 三链)
- **支持的链接类型**:目前已开放 GitHub 仓库链接,发送后 Bot 会查询该仓库的存档记录,其他类型的链接(`X/` 开头的示意)暂未启用
- **推送时间**:Bot 会按照设定的每日节奏主动向你推送汇总内容,无需手动反复拉取

请完整阅读这段回复,后续所有交互都基于这些命令展开。如果你只记住了其中一条,优先记住 `/trending` —— 它是最常用的入口。

### 步骤 3: 选择下一步动作

收到 HELP 菜单后,你有两个常见选择:

- **立即体验**:直接发送 `/trending` 或 `/product`,查看当天的热门内容,感受 Bot 的输出格式与排版风格
- **按需查询**:粘贴一个 GitHub 仓库链接,Bot 会返回该仓库在历史存档中的命中记录;或先发送 `/archive` 浏览分页存档,再用 `/search 关键词` 精确检索

任意时刻想再次查看这份菜单,重新发送 `/start` 即可,不会产生副作用。

### 小贴士

- 发送 `/start` 不只是打招呼,也是重置上下文的快捷方式:遇到 Bot 行为异常或想确认当前可用命令时,先发一次 `/start` 往往比翻历史消息更高效
- 目前链接识别仅支持 GitHub 仓库 URL(格式如 `https://github.com/owner/repo`),其他链接(普通网页、X/推文链接等)会被忽略并回退到 HELP 菜单,粘贴前请确认地址栏
- 四个命令均无需额外参数,只有 `/search` 必须在命令后空格再跟关键词,例如 `/search llm`,漏掉关键词时 Bot 会回退到 HELP 菜单提醒你补充
