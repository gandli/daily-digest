### 快速开始

欢迎使用 daily-digest Bot。本节面向首次接触本 Bot 的用户,演示从添加 Bot 到获取帮助的最短路径。只需两步即可上手。

### 步骤 1:向 Bot 发送 /start

在 Telegram 中打开 Bot 对话窗口,直接在输入框中键入命令 `/start` 并发送。这是一条标准的启动命令,新用户和老用户均会触发相同的入门响应。

Bot 接收到 `/start` 后,会立即回复一条包含完整命令列表的 **HELP 菜单** 消息,告知 Bot 的全部可用能力:

> 📊 daily-digest 使用 命令
> /gt — 查询今日 GitHub Trending
> /hn — 查询今日 Hacker News 酷产品
> /ph — 查询今日 Product Hunt 热门产品
> /search 关键词 — 查询历史存档
> /archive — 浏览历史存档(分页+三链)

![用户发送 /start 后 Bot 返回的 HELP 菜单](assets/01-start-r1.png)

### 步骤 2:识别 HELP 菜单内容

阅读 Bot 的回复时,请关注以下三类信息:

1. **命令列表**:5 条核心命令(`/gt`、`/hn`、`/ph`、`/search`、`/archive`),分别对应 Trending、热榜产品和历史存档的查询入口。
2. **支持的链接类型**:菜单中明确列出 GitHub Trending、Hacker News、Product Hunt 三类数据源,作为 Bot 的核心抓取范围。
3. **推送时间**:本消息未单列推送时间字段。推送相关的定时行为请留意后续章节中的「每日推送」说明。

至此,你已确认 Bot 可用、掌握了全部入口命令,可以进入下一节《每日推送与查询》体验具体功能。

### 小贴士

- `/start` 是兜底入口:即使你已使用过 Bot,任何时候发送 `/start` 或在无匹配分支时发送任意文本,Bot 都会回退到 HELP 菜单,可作为重置参考。
- 命令支持快捷输入:进入帮助菜单后,直接点击消息中的命令名(如 `/gt`)即可快速发起查询,无需手动键入。
- 推荐把 Bot 对话置顶或开启通知,这样每日定时推送的 Trending 与热榜汇总不会遗漏。
