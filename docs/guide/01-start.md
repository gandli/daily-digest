### 步骤 1: 添加 Bot 并打开对话

在 Telegram 中搜索并添加 daily-digest Bot,进入与 Bot 的私聊窗口。新用户首次与 Bot 交互时,无需任何前置配置,直接进入下一步即可。

### 步骤 2: 发送 /start 命令

在输入框中键入 `/start` 并发送。这是 Bot 推荐的起始命令,用于唤起主菜单与帮助信息。

### 步骤 3: 查看 Bot 返回的帮助菜单

Bot 接收到 `/start` 后,会立即回复一段帮助文本,内容包含三部分:

- **命令列表**: `/gt`(查询今日 GitHub Trending)、`/hn`(查询今日 Hacker News 酷产品)、`/ph`(查询今日 Product Hunt 热门产品)、`/search 关键词`(查询历史存档)、`/archive`(浏览历史存档,支持分页与三链切换)。
- **支持的链接类型**: 与 GitHub、Hacker News、Product Hunt 三大来源对应。
- **推送时间**: Bot 会在每日固定时刻自动推送当日榜单。

### 步骤 4: 选择后续操作

阅读完菜单后,你可以根据需要:

- 直接点击菜单中的某个命令(如 `/gt`)查看当日榜单;
- 发送 `/search 关键词` 检索历史存档;
- 发送 `/archive` 进入分页浏览模式;
- 或者继续发送 `/start` 再次唤起帮助。

## 小贴士

- **忘记命令时,再次发送 `/start`**: Bot 会原样回复完整命令列表,适合随时查阅。
- **发送任意文本也会触发帮助**: 除明确命令外,在非分支状态下发送任意文字,Bot 同样会回退到 HELP 菜单,作为兜底入口。
- **菜单即索引**: 命令列表与支持的链接类型一一对应,选择命令前可先确认来源是否在你的关注范围内,避免误触发检索。
