# 快速开始

本章面向首次使用本 Bot 的用户,只需几个简单的交互即可完成首次接触并了解 Bot 的全部能力。

### 步骤 1:添加 Bot 并发起首次对话

在 Telegram 中找到本 Bot 并将其添加为联系人,然后在聊天窗口中输入斜杠命令 `/start` 并发送。这是 Bot 的初始化入口命令,几乎所有 Telegram Bot 都会通过这条命令向用户致以欢迎并展示自身能力。

发送后,Bot 会立即返回一段中文欢迎与功能说明,内容包含命令列表、链接类型以及推送时间三部分信息,具体见下方步骤 2。

### 步骤 2:查看 Bot 返回的 HELP 菜单

Bot 在收到 `/start` 后会回复一条结构化的菜单消息,内容如下:

> 📊 daily-digest 使用
> 命令
> /gt — 查询今日 GitHub Trending
> /hn — 查询今日 Hacker News 酷产品
> /ph — 查询今日 Product Hunt 热门产品
> /search 关键词 — 查询历史存档
> /archive — 浏览历史存档(分页+三链)

这条回复实际上就是 HELP 菜单,它告诉用户三件事:

- **命令清单**:Bot 支持的全部交互指令,涵盖三大榜单的当日查询以及历史存档检索;
- **支持的链接类型**:从 `三链` 一词可知,每日存档包含 GitHub Trending、Hacker News、Product Hunt 三类来源链接;
- **推送时间**:以 `每日` 为单位汇总,意味着 Bot 会在每天固定时间主动推送当日三链内容。

### 步骤 3:尝试发送任意非命令文本

如果用户不发送 `/start`,而是直接输入一段普通文本(例如 `你好` 或任意不在命令列表中的内容),且当前不处于任何命令分支中,Bot 同样会回复上述 HELP 菜单。这是一条兜底机制,目的是让所有首次接触或暂时迷失的用户都能看到完整的使用说明。

### 步骤 4:根据菜单选择下一步操作

阅读完 HELP 菜单后,用户可以按需选择下一步:

- 想看今天的榜单,直接发送对应的命令,如 `/gt`、`/hn` 或 `/ph`;
- 想查找过往某天的内容,使用 `/search 关键词` 进行关键词检索;
- 想浏览全部历史存档,使用 `/archive` 进入分页浏览模式。

至此,快速开始的引导流程结束,用户已具备使用 Bot 的全部基础知识。

## 小贴士

- 把 `/start` 收藏为常用命令,无论何时忘记如何使用,只要发送这条命令就能重新调出完整菜单。
- 当你不确定当前处于哪个命令的交互状态时,发送一句与命令无关的普通文本即可让 Bot 重新显示 HELP 菜单,避免操作卡住。
- 三大榜单的当日结果只需发送对应的短命令即可获取,无需额外参数,适合日常快速浏览。
