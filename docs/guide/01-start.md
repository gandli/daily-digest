### 快速开始

下面以一次真实对话为例,带你走完 Bot 的最基本使用流程。整个过程只需发送一条消息。

### 步骤 1:发起对话

将 daily-digest Bot 添加为联系人,或在已有聊天窗口中直接发送任意消息。作为第一次接触,最直接的方式就是输入命令 `/start`。

### 步骤 2:查看 Bot 自动回复的 HELP 菜单

Bot 接收到 `/start` 后,会判定当前不在任何分支流程中,因此返回一份完整的 HELP 菜单,作为新用户的使用引导。该菜单分为三个信息块:

- **命令列表**:列出 Bot 当前支持的 4 条核心命令,分别是 `/trending`(今日 GitHub Trending)、`/product`(今日 HN 酷产品)、`/search 关键词`(搜索历史存档)、`/archive`(历史存档,支持分页与三链)。
- **链接类型说明**:告诉用户 Bot 能识别并处理的链接,例如 GitHub 仓库链接会自动触发单仓存档查询,X/(原 Twitter)链接等也可被识别。
- **推送时间**:说明每日自动推送的发生时刻,方便用户预知何时会收到摘要。

### 步骤 3:选择后续动作

拿到 HELP 菜单后,你可以根据需要选择:

- 想看 **今日 GitHub 热门**,发送 `/trending`;
- 想看 **今日 HN 酷产品**,发送 `/product`;
- 想 **按关键词回看历史**,发送 `/search 关键词`;
- 想 **翻阅历史存档**,发送 `/archive`;
- 直接 **粘贴一个 GitHub 仓库链接**,Bot 会自动转为该仓库的存档查询。

任意时刻想再次查看这份菜单,只要再发一次 `/start` 即可。

### 小贴士

- 第一次使用不必拘泥于 `/start`,发送任意非命令文本(例如“你好”)同样会触发 HELP 菜单,适合不熟悉命令的用户先探探路。
- 拿到菜单后,建议把 `/archive` 和 GitHub 仓库直链查询这两个能力记下来——它们是回溯历史最快的方式,比关键词搜索更精准。
- 如果长时间没有收到每日推送,先检查本地时间与 Bot 说明的推送时间是否一致,再尝试发一条 `/start` 确认 Bot 仍在线。
