### 快速开始

欢迎使用 daily-digest 机器人!本节将引导你完成第一次交互,熟悉机器人的主要命令与支持的内容类型。只需发送一条 `/start`,即可随时调出帮助菜单。

### 步骤 1:发送 `/start` 启动机器人

在 Telegram 对话窗口中输入斜杠加 `start`,即文本 `/start`,然后发送。这是新用户加 Bot 后的标准入口命令,机器人会立即返回完整的帮助(HELP)菜单。

机器人会回复一段简洁的指引,内容包含:

- 📊 **daily-digest 使用 命令**
  - `/trending` — 今日 GitHub Trending
  - `/product` — 今日 HN 酷产品
  - `/search 关键词` — 搜索历史存档
  - `/archive` — 历史存档(分页 + 三链)
- **链接**
  - GitHub 仓库链接 → 单仓查询存档
  - X/...

机器人将可用的命令列表、支持识别的链接类型(目前包括 GitHub 仓库链接)以及与推送时间相关的信息一并展示,方便你快速判断后续该用哪条命令。

### 步骤 2:查看帮助菜单并选择下一步

阅读 Bot 返回的消息,根据你的需求选择命令:

- 想看今日 GitHub 热门项目 → 发送 `/trending`
- 想看今日 Hacker News 上的酷产品 → 发送 `/product`
- 想在历史存档中检索关键词 → 发送 `/search 你的关键词`
- 想浏览历史存档分页列表 → 发送 `/archive`
- 想查询某个 GitHub 仓库的存档 → 直接粘贴该仓库的链接

> 小贴士:除了上述命令,机器人同样支持识别 GitHub 仓库链接。粘贴一条 GitHub 仓库 URL(例如 `https://github.com/owner/repo`)发送出去,机器人会将其识别为「单仓查询存档」指令,无需额外输入命令。

### 步骤 3:随时再次调出帮助菜单

如果你在使用过程中忘记了命令格式,只需再次发送 `/start` 或任意非命令文本(例如一句问候语),机器人都会回到 HELP 菜单,重新展示命令列表、支持的链接类型以及推送时间说明。这一设计让你在任何分支之外都能快速回到入口,不必担心迷路了。

### 小贴士

1. **入口命令可重复使用**:`/start` 不是一次性命令,每次发送都会重置到 HELP 菜单,适合作为「忘记命令时的万能钥匙」。
2. **任意文本也能唤起帮助**:在不属于任何分支的状态下,直接发送一句话(非 `/` 开头)同样会触发 HELP 菜单回复,适合不想打命令时使用。
3. **链接与命令可混用**:看到感兴趣的 GitHub 仓库时,直接粘贴链接即可触发单仓存档查询,不必先发送 `/start` 或其他命令。
