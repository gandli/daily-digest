### 快速开始

本节面向第一次使用 daily-digest 的新用户，只需几分钟即可掌握与 Bot 对话的基本方式。整个使用流程围绕"发送指令 — 接收结构化菜单"展开，无需注册或额外配置。

### 步骤 1：发起首次对话

在 Telegram 中找到 daily-digest Bot，点击「开始」按钮或在聊天输入框中键入 `/start` 并发送。这条命令同时也是新用户的"入门指令"，无论你是首次添加 Bot 还是重新进入会话，发送它都会得到一致的结果。

Bot 接收到 `/start` 后，会立即返回一份完整的帮助菜单，列出全部可用命令、当前支持的数据来源链接类型，以及内容推送的时间安排。

### 步骤 2：查看帮助菜单

发送指令后，Bot 会回复如下内容：

> 📊 daily-digest 使用
>
> 命令
> /gt — 查询今日 GitHub Trending
> /hn — 查询今日 Hacker News 酷产品
> /ph — 查询今日 Product Hunt 热门产品
> /search 关键词 — 查询历史存档
> /archive — 浏览历史存档（分页+三链）

这份菜单就是后续所有交互的"导航图"，建议你先通读一遍，再根据当日需求选择对应命令。

![daily-digest 首次发送 /start 后返回的完整帮助菜单](assets/01-start-r1.png)

### 步骤 3：根据菜单发起查询

阅读完帮助菜单后，你就可以按照其中的命令格式发起实际查询。例如，输入 `/gt` 可获取当日 GitHub Trending 列表；输入 `/hn` 抓取 Hacker News 上的热门讨论；若希望追踪某个关键词在历史中的收录情况，可使用 `/search 关键词`。每条命令都会触发一次对应的数据抓取任务，并将结果以消息列表的形式逐条返回。

如果暂时不确定要查什么，再次发送 `/start` 即可随时调出帮助菜单作为参考。

### 小贴士

- 首次使用若错过菜单内容，可随时再次发送 `/start` 重新唤起，Bot 不会重复打扰。
- 当你发送的不是上述任何命令（例如普通文字消息）且当前不在其他分支流程中时，Bot 同样会将帮助菜单作为默认回复，确保你不会陷入"无响应"状态。
- 建议先固定使用 `/gt`、`/hn`、`/ph` 三条命令熟悉每日推送节奏，再尝试 `/search` 与 `/archive` 检索历史内容，体验更顺畅。
