## 快速开始

本章将带你从零开始,完成与 Bot 的首次交互。无论你使用的是 Telegram 桌面端还是手机端,以下步骤都完全一致。

### 步骤 1:添加 Bot 并发送 `/start`

在 Telegram 中找到 daily-digest Bot,点击「Start」或「开始」按钮,即可启动对话。你也可以在聊天框中手动输入 `/start` 并发送,这是所有 Telegram Bot 的标准入口命令。

### 步骤 2:查看 Bot 自动回复的 HELP 菜单

当你发送 `/start` 后,Bot 会立即回复一段使用说明。这段说明包含了所有可用的命令及其用途,帮助你快速了解 Bot 能做什么。

![\/start 触发的 HELP 菜单](assets/01-start-r1.png)

根据 Bot 的回复,你可以看到以下命令:

- **`/gt`** —— 查询今日 GitHub Trending,获取开发者社区最热门的开源项目
- **`/hn`** —— 查询今日 Hacker News 酷产品,了解技术圈讨论的热门话题
- **`/ph`** —— 查询今日 Product Hunt 热门产品,发现新鲜上线的小工具和应用
- **`/search 关键词`** —— 按关键词查询历史存档,例如 `/search AI` 可以找出所有与 AI 相关的过往推送
- **`/archive`** —— 浏览历史存档,支持分页查看,且每条记录都包含 GitHub、Hacker News、Product Hunt 三个来源的链接

### 步骤 3:尝试触发 HELP 菜单的另一种方式

除了 `/start` 命令,Bot 还支持另一种方式唤起同样的帮助菜单:直接发送任意非命令的文本(例如「你好」「hello」等不以上述斜杠指令开头的消息),当该文本不匹配任何已有分支时,Bot 会自动回退并发送同样的 HELP 菜单。这是一种容错设计,确保你随时都能获得帮助。

### 小贴士

1. **首次使用建议从单条命令入手**:不必一次性尝试所有命令。可以先发送 `/gt`,看看今天的 GitHub Trending 列表,熟悉 Bot 的回复格式后,再逐步探索其他功能。
2. **善用 `/search` 检索历史**:如果你某天错过了一条感兴趣的内容,只要记得其中的关键词,就能用 `/search` 把它找回来,不必担心信息流失。
3. **随时输入 `/start` 重看菜单**:HELP 菜单的内容是固定的,你可以随时通过 `/start` 或发送任意非命令文本重新唤起,不必向上翻找历史消息。
