### 步骤 1:粘贴 GitHub 仓库链接

在聊天窗口中,粘贴一个完整的 GitHub 仓库地址,形如 `https://github.com/owner/repo`。Bot 会自动识别链接格式,无需额外命令或前缀。

### 步骤 2:Bot 抓取元数据并生成描述卡

链接提交后,Bot 会立即访问 GitHub 抓取仓库元数据(包括仓库名、星标数、作者等),同时通过 deepwiki / zread 等来源获取仓库的自然语言描述。

- **首次查询**:Bot 完整执行抓取 + 描述生成 + 存档 + 卡片渲染全流程。
- **已查过**:Bot 直接从归档中读取,返回带描述的归档卡,响应更快。

### 步骤 3:接收归档卡片

Bot 回复一张结构化卡片,包含仓库名、星标数、语言标签、作者,以及一段由 deepwiki / zread 生成的中文简介,末尾附带分类标签(如 `#trending #c #editor`)。卡片以 🗂 开头,正文包含可点击的跳转链接。

参考回复样例:

> 🗂 antirez/kilo ⭐ 3.2k · #C 👤 antirez 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。#trending #c #editor <a href="..."

### 小贴士

- **链接必须完整**:仅粘贴 `owner/repo` 短格式不会被识别,请始终带上 `https://github.com/` 前缀。
- **重复查询自动加速**:同一仓库第二次粘贴时,Bot 会跳过抓取流程直接返回归档卡,适合频繁回顾的热门项目。
- **描述由 deepwiki / zread 生成**:若发现简介与实际用途有偏差,可在后续交互中让 Bot 重新抓取或补充上下文。
