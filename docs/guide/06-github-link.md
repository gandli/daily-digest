## 单仓查询

通过粘贴 GitHub 仓库链接,快速获取仓库的元数据、描述信息与归档卡片。

### 步骤 1: 复制仓库链接

在浏览器或 GitHub 客户端中找到目标仓库,复制其完整 URL。链接格式为 `https://github.com/owner/repo`,例如 `https://github.com/antirez/kilo`。

### 步骤 2: 发送链接给 Bot

将复制的链接粘贴到与 Bot 的聊天窗口中并发送。Bot 会自动识别该链接属于 GitHub 仓库地址,并进入查询流程。

### 步骤 3: 接收归档卡片

Bot 处理完成后,会返回一张格式化的归档卡片,内容包含:

- 仓库名称(如 `antirez/kilo`)
- Star 数(如 ⭐ 3.2k)
- 话题标签(如 #C)
- 仓库所有者(如 👤 antirez)
- 仓库描述与特色说明(如“这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言”)
- 话题标签(自动提取,如 #trending #c #editor)
- 归档操作链接(🗂)

### 步骤 4: 查看卡片详情

点击卡片中的归档链接,可进一步查看该仓库的完整存档内容、历史归档记录或相关检索入口。

### 步骤 5: 重复查询(已查过状态)

如果该仓库之前已经查询过,再次发送相同链接时,Bot 会直接返回带描述的归档卡 ♻️,而不会重复执行抓取流程,从而节省响应时间。

## 小贴士

- 链接必须为标准 GitHub 仓库 URL 格式(`https://github.com/owner/repo`),短链或非仓库页面(如 Issue、PR)可能无法正确识别。
- 首次查询时会触发完整抓取流程(获取元数据 + 抓取描述 + 存档 + 生成卡片),响应时间略长,后续重复查询会更快返回。
- 卡片中的话题标签由 Bot 自动从仓库元数据中提取,可帮助你快速了解仓库所属的技术领域。
