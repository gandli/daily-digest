## GitHub 仓库链接 → 单仓查询

当你想了解一个 GitHub 仓库的简介、标签和归档信息时,只需把仓库地址直接发给 Bot,即可一键完成首次抓取或快速调取已有档案。

### 步骤 1:复制仓库链接

在浏览器打开 GitHub 目标仓库页面,复制其 URL。链接需为标准格式 `https://github.com/owner/repo`,例如 `https://github.com/antirez/kilo`。

### 步骤 2:粘贴链接并发送

将复制的链接作为消息内容直接发送给 Bot,无需附加任何说明文字。

### 步骤 3:首次访问时的抓取流程

如果该仓库是 Bot **第一次** 收到,Bot 会按以下顺序自动处理:

1. 调用 GitHub 接口抓取仓库元数据,包括名称、星标数、主要语言、作者、描述等;
2. 调用 deepwiki 与 zread 等知识源,聚合生成一段中文描述;
3. 将仓库信息写入归档库,生成专属的存档卡片;
4. 把整理后的卡片消息回复给你,卡片内含仓库名、星标、语言标签、作者、描述、话题标签以及归档入口。

### 步骤 4:重复访问时的快速返回

如果 Bot 之前已经处理过该仓库,会自动跳过抓取与描述生成步骤,直接从归档库调取已存在的卡片并回复。整个过程几乎是瞬时的,无需重新分析。

### 步骤 5:查看 Bot 回复的归档卡片

以 `https://github.com/antirez/kilo` 为例,Bot 首次收到该链接后会回复类似如下的归档卡片:

> antirez/kilo ⭐ 3.2k · #C 👤 antirez 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。 #trending #c #editor 🗂 <a href="...">查看完整归档</a>

卡片中各字段含义如下:

- **仓库名**:`owner/repo` 形式的完整标识;
- **⭐ 数字**:GitHub 上的 star 数;
- **#语言**:仓库的主要编程语言(用于着色与筛选);
- **👤 作者**:仓库所有者;
- **描述段**:由 deepwiki、zread 等源聚合生成的中文简介;
- **#标签**:自动提取的话题标签,便于后续按主题检索;
- **🗂 入口**:点击可查看该仓库的完整归档信息。

### 步骤 6:后续如何复用

归档卡片回复后,Bot 内部已记录该仓库。下次再粘贴同一链接,Bot 会直接返回步骤 4 中的快速路径结果,描述与标签保持一致,你可以放心地在群聊或私聊中反复查询。

## 小贴士

- **链接越标准越好**:务必使用 `https://github.com/owner/repo` 形式的完整 URL,避免带 `?` 查询参数或 `tree/main` 等子路径,否则 Bot 可能无法正确解析仓库。
- **善用归档入口**:卡片底部的 🗂 链接会跳转到该仓库的完整归档页,可看到首次抓取时间、描述来源、抓取历史等详细信息,适合做长期追踪。
- **二次查询即缓存**:同一仓库在 Bot 内只会触发一次抓取,之后都会走缓存路径。如果仓库本身有重大更新(如描述变更),可通过归档入口查看最近一次的抓取时间,确认信息时效。
