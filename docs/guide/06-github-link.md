## 粘贴 GitHub 仓库链接 → 单仓查询

通过直接发送仓库 URL,Bot 会智能判断该仓库是否已被收录:首次查询会实时抓取元数据与描述信息并存档;再次查询同一仓库则会直接调取已有归档,快速返回带描述的卡片。

### 步骤 1: 复制仓库链接

在浏览器或 GitHub 客户端中找到目标仓库的完整 URL,形如 `https://github.com/owner/repo`。点击地址栏右侧的复制按钮,或手动选中链接后按 `Ctrl+C` / `Cmd+C`。

### 步骤 2: 粘贴链接并发送

回到与 Bot 的聊天窗口,粘贴 URL 并直接发送,无需添加任何额外文字或指令。

### 步骤 3: 查看首次查询响应(以 antirez/kilo 为例)

首次查询时,Bot 会依次执行以下动作:

1. 抓取仓库基础元数据(名称、Star 数、主要语言、作者);
2. 调用 deepwiki/zread 等数据源生成仓库描述;
3. 将元数据与描述一同存档;
4. 输出带描述的归档卡片。

### 步骤 4: 查看重复查询响应

当再次粘贴同一仓库链接时,Bot 会跳过抓取与描述生成步骤,直接以 ♻️ 标识从归档中取出已有数据,秒级返回相同的归档卡片,既节省时间也避免重复抓取。

### 小贴士

- 粘贴时无需附带额外说明文字,Bot 仅凭链接即可识别仓库范围,多余的文字反而可能干扰解析。
- 卡片中显示的 Star 数、描述内容均来自首次查询时的存档快照,后续 GitHub 上的实时变化不会自动同步,如需最新数据可等待 Bot 的归档刷新机制或重新发起请求。
- 若想对比同一作者的多个仓库,可连续粘贴不同链接,每条链接都会独立走"首次/重复"判断逻辑,互不影响。
