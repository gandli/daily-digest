### 步骤 1: 复制仓库链接

在浏览器中打开 GitHub,定位到你想要了解的仓库,复制其浏览器地址栏中的完整 URL。链接必须以 `https://github.com/` 开头,且格式为 `https://github.com/owner/repo`,例如 `https://github.com/antirez/kilo`。

### 步骤 2: 发送给 Bot

将复制的链接粘贴到与 Bot 的对话窗口中,直接发送,无需附加任何说明文字。Bot 会自动识别这是一个 GitHub 仓库链接。

![用户发送仓库链接,Bot 回复归档卡片](assets/06-github-link-r1.png)

### 步骤 3: 查看首次查询的归档卡

如果是该仓库的首次查询,Bot 会执行抓取流程:获取仓库的元数据(如 star 数、语言、作者等),再调用 deepwiki 与 zread 拉取仓库描述,随后进行存档,最后生成一张带描述的归档卡片发送给你。卡片中包含仓库名称、星标数、语言标签、作者头像与昵称、一段精炼的仓库说明、相关话题标签(如 `#trending`、`#c`、`#editor`),以及一个指向存档详情的链接。点击链接即可查看完整归档内容。

### 步骤 4: 查看重复查询的归档卡

如果该仓库之前已经查询过,Bot 会跳过抓取与描述生成步骤,直接从存档中读取已有数据,快速返回同一张带描述的归档卡。这样既节省时间,也保证信息一致性。

## 小贴士

- 发送链接时无需额外输入命令,粘贴即触发,适合在浏览 GitHub 时随时转给 Bot 留档。
- 归档卡中的描述由 deepwiki 与 zread 共同生成,如果觉得说明不够详细,可以点击卡片中的存档链接查看更完整的元数据。
- 星标数、作者等元数据以首次抓取时为准;仓库后续更新不会自动同步,如有需要可删除旧存档后重新发送链接触发一次新查询。
