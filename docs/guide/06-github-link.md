## 单仓查询

将 GitHub 仓库链接直接发送给 Bot,即可快速获取该仓库的元数据、主题标签与一句话描述,适用于发现新项目或归档感兴趣的仓库。

### 步骤 1:复制仓库链接

在浏览器中打开目标 GitHub 仓库页面,从地址栏复制完整链接,形如 `https://github.com/owner/repo`。注意必须是仓库主页链接,而不是单个文件或 Issue 页面。

### 步骤 2:粘贴到 Bot 对话

将链接粘贴到与 Bot 的聊天窗口中直接发送,无需附加任何文字说明,Bot 会自动识别 GitHub 链接格式。

### 步骤 3:查看 Bot 返回的归档卡

Bot 会立即返回一张带描述的归档卡片,内容包含仓库名称、Star 数、主要语言、作者、主题标签以及一段简要说明。

例如发送 `https://github.com/antirez/kilo` 后,Bot 回复:

> antirez/kilo ⭐ 3.2k · #C 👤 antirez 这个仓库实现了经典的文本编辑器,代码精炼,适合学习 C 语言。 #trending #c #editor 🗂

![首次查询返回的归档卡片,包含仓库元数据与描述](assets/06-github-link-r1.png)

### 步骤 4:复用历史记录

如果该仓库之前已经查询过,Bot 会直接调取已存档的描述卡片,不再重复抓取数据,响应速度更快,适合回顾之前收藏过的项目。

## 小贴士

- 链接必须是 `github.com/owner/repo` 形式,粘贴组织主页(如 `github.com/antirez`)不会被识别为单仓查询。
- Bot 会自动从 deepwiki 和 zread 抓取仓库描述,首次查询会稍等片刻,后续重复查询将秒级返回归档卡。
- 主题标签(如 `#c`、`#editor`)基于仓库的 Topics 字段生成,可在 GitHub 端编辑后重新查询以更新归档内容。
