## X/Twitter 链接 → 帖子存档

本节介绍如何把一条 X（推特）帖链接交给 Bot，让它自动拉取原文、生成中文翻译、发布到 Telegraph，并通过卡片形式回传。整个过程无需手动操作。

### 步骤 1：复制 X 帖链接

在 X 应用或网页中打开目标帖子，点击「分享」按钮，选择「复制链接」。链接形如 `https://x.com/<用户名>/status/<帖子ID>`。

### 步骤 2：粘贴链接发送给 Bot

将链接作为一条独立消息发送给 Bot。Bot 会立即识别链接归属并启动抓取流程。

> 用户：https://x.com/Smartpigai/status/2093191865193677285

### 步骤 3：等待 Bot 拉取与翻译

Bot 通过 FxEmbed v2 接口拉取原帖内容，包括正文、图片（自动按多图 mosaic 拼接）、视频信息。随后调用中文翻译服务对正文进行本地化处理。

整个过程通常在数秒内完成。

### 步骤 4：接收存档卡片

Bot 完成全部处理后，会在同一条消息下方回复一张自适应卡片：

- 纯文字帖：仅展示翻译后的中文正文；
- 含图帖：自动以多图 mosaic 形式排版展示；
- 含视频帖：在卡片中嵌入视频预览。

卡片末尾会附上 `web.archive.org` 永久快照链接，以及 Telegraph 完整存档页面的入口，便于长期回溯。

### 步骤 5：连续处理多条帖子

Bot 支持连续接收多条链接。每条链接独立处理、独立回复，互不干扰。

发送第二条链接：

> 用户：https://x.com/Smartpigai/status/2093191865193677286

Bot 同样返回一张多图 mosaic 卡片，正文已翻译为中文：

![多图 mosaic 帖的存档卡片](assets/07-x-link-r2.png)

### 小贴士

1. **一次只发一条链接**：将多条链接分开发送，可获得更清晰的独立存档卡片，也方便针对单条帖子进行二次操作。
2. **关注 web.archive.org 链接**：卡片末尾的快照链接是永久存档的兜底入口，即使原帖被删除或 Telegraph 页面异常，仍可通过快照访问。
3. **视频帖请稍等片刻**：若帖子含视频，Bot 需要额外抓取媒体资源，响应时间会比纯文字帖略长。
