## X/Twitter 链接 → 帖子存档

本功能用于把 X/Twitter 上的单条帖子一键转存为可长期阅读的 Telegraph 页面，并对正文做中文翻译、保留原始媒体，并附带互联网档案馆（Wayback Machine）的备份链接。Bot 会自动识别帖子类型——单图、多图拼贴、视频还是纯文字——生成与之匹配的卡片布局。

### 步骤 1：粘贴 X 帖子链接

在任意与 Bot 对话的聊天窗口里，直接粘贴一条 X/Twitter 状态链接。无需添加额外指令、命令前缀或说明文字，Bot 会通过链接域名自动识别来源。例如你可以发送：

`https://x.com/Smartpigai/status/2093191865193677285`

链接必须指向单条帖子（包含 `/status/` 段），其他页面（如用户主页、列表、搜索结果）不在本功能覆盖范围内。

### 步骤 2：等待 Bot 拉取并翻译

Bot 收到链接后，会调用 FxEmbed v2 接口拉取该帖的完整数据，包括作者昵称、正文、发布时间、媒体附件以及互动计数。如果帖子含有多张图片，Bot 会先将它们拼合为一张 mosaic 拼贴图，确保存档时图片信息不被截断。紧接着 Bot 对原始正文运行中文翻译，并将译文与原文一起整理为 Telegraph 页面所需的富文本结构。

### 步骤 3：查看生成的存档卡片

处理完成后，Bot 会返回一条消息，包含翻译后的中文摘要、原始话题标签，以及一个 Telegraph 永久链接，供你点击查看完整存档内容。卡片底部还会附带 Wayback Machine 备份链接，以便原帖被删除时仍可追溯。

对于带有多张截图的帖子，Bot 会自动生成拼贴视图的存档卡片，呈现效果如下：

对于带视频或单图的帖子，Bot 则会在 Telegraph 页面中以视频播放器或单张大图的形式呈现，效果如下：

### 步骤 4：访问或转发存档

点击消息中的 Telegraph 链接即可在浏览器中打开完整存档页面。由于 Telegraph 页面托管在外部服务，你可以放心将链接转发给任何人，对方无需登录或关注任何账号即可阅读。如果原帖后续被原作者删除，只要 Wayback Machine 抓取成功，消息底部的备份链接仍可还原原始内容。

### 小贴士

- 单次只粘贴一条链接；批量转存请分多条消息发送，避免 Bot 仅处理首条而忽略其余。
- 若 Bot 长时间未回复，可能是 FxEmbed 接口限流，稍等片刻后重新发送链接即可，无需重复粘贴多次。
- 对于受地区限制或已删除的帖子，Wayback Machine 备份可能同样不可用，此时建议尽早打开 Telegraph 链接并自行另存。
