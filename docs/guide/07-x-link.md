## X/Twitter 链接 → 帖子存档

把 X（Twitter）帖子链接发给 Bot，即可自动完成抓取、翻译、归档，并生成一张自适应卡片。本节按真实对话演示完整流程。

### 步骤 1：复制并发送帖子链接

在 X 客户端打开目标帖子，点击「分享 → 复制链接」，将完整的 `https://x.com/<user>/status/<id>` 链接粘贴到与 Bot 的聊天窗口中并发送。

- **用户操作**：粘贴单条 X 帖子链接。
- **Bot 处理**：识别 X 域名后，调用 FxEmbed v2 拉取该帖的文本、作者、图片与视频等元数据。
- **Bot 回复**：返回中文翻译正文、话题标签，并附带一个 `web.archive.org` 长期快照链接（用于在原帖被删/转私时仍可访问），形如：

  > 小而美命令行工具 刚刚发布了一个用于摘要整理的新命令行工具！ #archive #开发工具 #命令行 📁 [快照链接](https://web.archive.org/...)

  ![单条文字帖存档结果](assets/07-x-link-r1.png)

### 步骤 2：等待 Bot 生成 Telegraph 页与卡片

Bot 在返回消息后，会将原帖内容写入一个 Telegraph 页面，生成永久可读的归档网页，并以此为底生成一张 Telegram 消息卡片。卡片会根据原帖内容自适应：

- **纯文字帖**：只渲染翻译后的文本与作者信息。
- **含图帖**：在正文中嵌入原图或拼接为九宫格 mosaic。
- **含视频帖**：以文件形式附在卡片下方。

### 步骤 3：发送第二条链接，验证多图自适应

继续粘贴另一条 X 帖子链接并发送，例如本次演示中的 `https://x.com/Smartpigai/status/2093191865193677286`。

- **用户操作**：粘贴第二条 X 帖子链接。
- **Bot 处理**：再次通过 FxEmbed v2 拉帖，识别到该帖包含多张图片，按多图自适应规则生成 mosaic 版卡片。
- **Bot 回复**：返回中文翻译正文与同一格式的 archive 快照链接，卡片中以一图多视图的形式展示四张原图。

  ![多图帖子自适应卡片](assets/07-x-link-r2.png)

### 步骤 4：点击快照链接核验归档

点击 Bot 回复中的 `web.archive.org` 链接，浏览器将打开对应快照，确认原帖即使下架后仍可回看。Telegraph 页面则提供无水印的纯文本阅读体验，方便后续二次引用或导出。

---

### 小贴士

1. **保持链接完整**：务必复制 `https://x.com/.../status/...` 形式的完整链接，避免带多余的 `?s=` 查询参数，否则可能命中错误的拉取目标。
2. **善用快照链接**：archive 链接是原帖的「保险」，建议在引用他人观点或保存重要推文时一并收藏。
3. **多图与视频自动识别**：Bot 会根据媒体数量自动选择文字、单图、九宫格或视频附件形态，无需在消息中额外追加指令。
