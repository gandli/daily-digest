## X / Twitter 链接 → 帖子存档

本功能面向 X(原 Twitter)平台:当你在群聊里贴上一条推文链接,Bot 会自动拉取帖子正文、媒体(单图、多图、视频)以及推主信息,完成中文翻译后,生成一张 Telegraph 长页面与一张可在 Telegram 内联显示的卡片。

### 步骤 1:粘贴 X 帖链接

在 Telegram 群聊中,直接粘贴一条 X 帖的完整链接,例如:

`https://x.com/Smartpigai/status/2093191865193677285`

无需添加额外说明文字,Bot 会自动识别 X / Twitter 域名。

### 步骤 2:等待 Bot 拉取与翻译

Bot 后台会向 FxEmbed v2 接口发起请求,完整拉取该条推文的正文、图片(若为多图则自动拼接为 mosaic 拼图)或视频缩略、发布时间与作者信息,并把正文翻译为中文。整过程通常在数秒内完成,你只需等待。

### 步骤 3:查看卡片与存档链接

Bot 回复一条带有 `#archive` 等话题标签的中文消息,并附上 `https://web.archive...` 形式的 Telegraph 永久存档链接。点击链接即可在浏览器中打开经过排版的完整页面。

![第 1 轮:单图推文存档卡片](assets/07-x-link-r1.png)

如截图所示,卡片正文中已包含中文译文、原始话题标签与 Telegraph 存档入口,链接前缀为 `https://web.archive`,可直接复制保存。

### 步骤 4:同一作者后续链接的连续归档

再次粘贴同一作者的另一条链接,例如:

`https://x.com/Smartpigai/status/2093191865193677286`

Bot 会以同样的流程处理:若原帖包含多张图片,FxEmbed 会先把它们拼成一整张 mosaic 大图,再由 Telegraph 渲染为一条独立的长页面。

![第 2 轮:多图 mosaic 推文存档卡片](assets/07-x-link-r2.png)

如截图所示,卡片使用相同的版式呈现,但内嵌的是由四张子图拼接而成的整图,适应了"一条推文多张视图"的内容形态,无需用户手动拆分或下载。

### 步骤 5:视频帖与纯文字帖的自适应

对于视频帖,Bot 会拉取视频首帧缩略图并附上原视频外链;对于纯文字帖,卡片只渲染翻译后的正文与话题标签。无论哪种类型,存档页面与卡片样式均会自动适配,无需额外指令。

### 小贴士

- 链接必须是 `x.com/...` 或 `twitter.com/...` 的完整形态,Bot 才能识别;短链(如 `t.co/...`)建议先在浏览器中展开再粘贴。
- 多图推文会先被合并为 mosaic 单图,以便 Telegraph 单页承载;如需逐张原图,可打开存档页面查看内嵌图源。
- 若 Bot 长时间无响应,通常是 FxEmbed 接口瞬时不可用,稍等片刻重发链接即可,无需修改链接本身。
