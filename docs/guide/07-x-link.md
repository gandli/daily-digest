## X/Twitter 链接 → 帖子存档

将 X（推特）帖子链接发送给 Bot,即可自动完成下载、多图拼接、中文翻译,并生成一张可在 Telegram 内直接预览的 Telegraph 卡片页。无论是纯文字、单图、多图,还是含视频的推文,Bot 都会按内容自适应输出。

### 步骤 1:粘贴 X 帖链接

在 Bot 对话窗口中,粘贴任意一条 X / Twitter 帖子的完整链接。例如:

```
https://x.com/Smartpigai/status/2093191865193677285
```

Bot 接收到链接后,会在内部触发 FxEmbed v2 抓取流程,将原帖文本与所有媒体资源一并拉取。若推文包含多张图片,Bot 会先合成 mosaic 拼图,确保在 Telegram 中完整呈现。

![单帖链接触发的首次回复](assets/07-x-link-r1.png)

### 步骤 2:查看抓取结果

Bot 在短时间内回复一条消息,包含以下要素:

- 原帖正文(若为非中文,会附带中文翻译);
- 若原帖含多图,Bot 会先上传一张合成的 mosaic 拼图,再补一张单图缩略图,例如 `pic-1.png`、`pic-2.png`;
- 视频帖会附带 `<a href="...">video</a>` 形式的内联播放链接;
- 末尾追加 `📁 <a href="https://web.archive.org/...">Wayback</a>`,作为网页存档的二次备份,防止原帖被删除或链接失效。

如截图所示,首轮回复中 Bot 输出了原帖正文、翻译结果、hashtag,以及对应的 Wayback 存档链接。

### 步骤 3:继续发送第二条链接

无需发送任何指令,直接粘贴下一条 X 帖链接,例如:

```
https://x.com/Smartpigai/status/2093191865193677286
```

Bot 立即按相同流程处理:抓取、翻译、生成多图 mosaic、产出 Telegraph 页,并在 Telegram 消息中内联展示。

![多图帖链接触发的卡片回复](assets/07-x-link-r2.png)

可观察到第二条推文为四图组合,Bot 自动按"1×4 横向 mosaic + 4 张分图"的格式输出,文字与第一轮保持一致的翻译体例和 hashtag 风格。

### 步骤 4:阅读 Telegraph 卡片

每条回复中的 `📁` 链接指向由 Bot 自动生成的 Telegraph 页面。点击后可在浏览器中查看:

- 与 Telegram 卡片完全一致的图文排版;
- 长图、宽图都不会被裁切;
- 视频以 Telegraph 可识别的方式嵌入,部分视频会提供"外部播放"跳转。

卡片样式会根据原帖内容自动适配:纯文字仅显示段落、单图帖显示居中图、多图帖显示 mosaic 与缩略图、视频帖显示封面与播放入口。

### 小贴士

1. 单条消息内可连续粘贴多条 X 链接,Bot 会按顺序逐条处理,不会漏单。
2. 私密账号、已被删除或区域限制的推文,Bot 会在回复中提示"无法抓取",并保留原始链接供你手动查看。
3. 若原帖文字非中文,翻译为目标中文;若原帖已是中文,则仅做格式整理,不会重复翻译。
