### 步骤 1：粘贴 X / Twitter 帖子链接

在任意与 Bot 对话的聊天窗口里，直接粘贴一条 X 帖子链接。例如粘贴 `https://x.com/Smartpigai/status/2093191865193677285`，无需添加任何额外说明文字或命令前缀，Bot 会自动识别链接并触发存档流程。

### 步骤 2：等待 Bot 拉取原文

Bot 接收到链接后，会调用 FxEmbed v2 接口拉取目标帖子的完整内容，包括作者、发布时间、正文以及所有媒体附件。媒体类型不限——单图、多图、视频、GIF，FxEmbed 都会一并带回。当帖子包含多张图片时，Bot 会将其合并为一张 mosaic（马赛克拼图）后展示。

### 步骤 3：接收中文翻译结果

拉取完成后，Bot 会将原帖正文翻译为中文并附带原文链接，同时保留原文中的话题标签（例如 `#archive #开发工具 #命令行`），方便读者快速定位主题。回复消息会内联展示关键摘要文字，让用户在 Telegraph 长页加载前就能先睹为快。

![第一轮存档：单文本类推文处理](assets/07-x-link-r1.png)

### 步骤 4：点击 Telegraph 完整存档

翻译消息之后，Bot 会给出一条包含 Web Archive 与 Telegraph 链接的卡片消息。点击 Telegraph 链接即可在浏览器中查看完整存档页：作者信息、原始媒体、中文译文、时间戳与原文 URL 全部整齐陈列。即使原帖被删除，Telegraph 页与 Web Archive 快照也会长久保留。

### 步骤 5：发送第二条链接继续处理

新一条链接粘进窗口即可开始下一轮存档。例如发送 `https://x.com/Smartpigai/status/2093191865193677286`，Bot 会沿用相同流程：拉取 → 多图 mosaic 合并 → 中文翻译 → Telegraph 卡片。本次链接包含四张仪表盘截图，Bot 会自动将其拼为一张 mosaic 在卡片中呈现，无需任何额外指令。

![第二轮存档：多图 mosaic 自动拼接](assets/07-x-link-r2.png)

### 步骤 6：根据卡片形态识别内容类型

观察 Bot 返回的卡片即可判断原帖的媒体类型：

- **纯文字帖**：卡片只展示中文译文与标签，不含图片预览。
- **多图帖**：卡片顶部出现 mosaic 拼图，点击 Telegraph 可看大图列表。
- **视频帖**：卡片包含视频缩略图与播放入口，原画质存档在 Telegraph 页内。

## 小贴士

- 一次性可以发送多条链接，Bot 会按顺序依次处理并分别为每条生成独立的 Telegraph 存档页。
- 如果拉取失败，多半是原帖已被原作者删除或设为私密；可尝试换一个镜像链接，或在对话中说明帖子作者与发布时间，由 Bot 协助判断。
- 翻译为机器翻译（中日英自动识别 → 中文），若帖子含专业术语，Telegraph 页底部会保留原文片段以供对照。
