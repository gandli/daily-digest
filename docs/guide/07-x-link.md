## X/Twitter 链接 → 帖子存档

本功能用于把 X(Twitter)上的任意一条公开帖子快速转为可永久访问的中文存档页。流程为：粘贴链接 → Bot 通过 FxEmbed v2 抓取帖子原文与媒体（含多图自动拼接为马赛克）→ 调用中文翻译模块生成译文 → 发布到 Telegraph 并附带 Telegram 消息卡片，卡片会根据帖子内容自动适配为图片、视频或纯文字三种样式。

### 步骤 1：粘贴 X 帖子链接

在任意与 Bot 的私聊或群聊中，发送一条 X 帖子的完整 URL，例如：

`https://x.com/Smartpigai/status/2093191865193677285`

发送后无需额外指令，Bot 会自动识别链接格式并启动抓取流程。识别阶段通常在 1–2 秒内完成。

### 步骤 2：等待 Bot 抓取并翻译

Bot 会调用 FxEmbed v2 拉取该帖子的完整内容，包括作者信息、发布时间、正文文字以及附带的图片或视频。当帖子包含多张图片时，FxEmbed 会将它们自动拼接为一张竖向 mosaic（马赛克大图），避免 Telegram 单条消息最多 4 张图的限制。

接着 Bot 会对原文执行中文化处理，保留 hashtag、@ 提及、数字、URL 等不可变元素，仅翻译自然语言部分。

### 步骤 3：查看生成的存档卡片

处理完成后，Bot 会回复一条 Telegram 消息卡片，并在卡片正文末尾附上 Telegraph 永久链接（以 `https://web.archive…` 形式呈现）。卡片样式由帖子内容自适应决定：

- 含图片 → 显示 FxEmbed 提供的图或 mosaic 预览；
- 含视频 → 显示视频封面与播放入口；
- 纯文字 → 退化为简洁文字卡片。

### 步骤 4：处理多图帖子

若原帖包含两张以上图片，流程与步骤 1–3 完全一致，区别在于抓取阶段会触发 mosaic 拼接，并在 Telegraph 页中保留原图列表以便展开查看。

### 步骤 5：点击卡片查看原文与译文

点击 Bot 回复中的 Telegraph 链接，即可在浏览器中打开完整存档页，页内同时呈现英文原文、中文译文、媒体缩略图与作者信息，可直接分享给他人或加入书签。

---

### 小贴士

- 单条消息一次只粘贴一个 X 链接，批量发送时 Bot 会按顺序串行处理，避免 Telegraph 发布接口限流。
- 若原帖已被作者删除、设为私密或所在区域不可访问，Bot 会返回明确的抓取失败提示，此时可在原帖仍在线时重试，或改用其他存档服务备份。
- Telegraph 页面支持站内全文检索关键词 `#archive`、`#开发工具`、`#命令行` 等中文标签，便于事后按主题回查。
