## X/Twitter 链接 → 帖子存档

只需把 X（原 Twitter）帖子链接丢给 Bot，剩下的抓取、翻译、归档、排版全自动完成，多图、视频、纯文字帖子均能自适应呈现。

### 步骤 1：发送 X 帖子链接

在 Bot 对话窗口中粘贴完整的 X 帖子 URL 并发送，例如：

`https://x.com/Smartpigai/status/2093191865193677285`

Bot 收到后会立即开始后台处理：调用 FxEmbed v2 接口拉取原帖内容，包括文字、发布时间、媒体附件（图片、视频）等。

### 步骤 2：等待 Bot 拉取并翻译

Bot 完成后会返回一条带翻译的中文摘要消息。若帖子包含多张图片，会自动拼成一张 mosaic（马赛克）合成图；若为视频则保留视频预览；纯文字帖子则仅显示文字部分。

回复形如：

`小而美命令行工具 刚刚发布了一个用于摘要整理的新命令行工具！ #archive #开发工具 #命令行 📁 <a href="https://web.archive.org/...`

消息末尾的 📁 按钮即为 Telegraph 存档页入口。

![Bot 返回的中文翻译摘要与存档链接](assets/07-x-link-r1.png)

### 步骤 3：点击 📁 按钮查看 Telegraph 完整存档

在 Bot 消息中找到末尾的 📁 链接按钮并点击，浏览器会跳转到 Telegraph 页面。该页面包含原帖原文、完整中文翻译、所有图片（多图已拼为 mosaic）、视频（如有）以及发布时间、作者等元信息，排版整洁，适合长期保存与分享。

### 步骤 4（可选）：发送另一条帖子继续测试

如需连续归档多条帖子，重复步骤 1 即可。例如粘贴：

`https://x.com/Smartpigai/status/2093191865193677286`

Bot 会按相同流程处理，并返回该帖的中文摘要 + 📁 Telegraph 链接。同一用户连续发送不同帖子时，处理流程互不干扰，各自生成独立的存档页。

![Bot 对第二条链接的回复示例](assets/07-x-link-r2.png)

### 小贴士

- **链接必须完整**：只粘贴 `x.com/用户名/status/ID` 部分即可，无需带 `https://` 前缀，Bot 也能识别。
- **多图帖子自动拼合**：当原帖包含 2 张及以上图片时，FxEmbed v2 会返回一张 mosaic 合成图，存档页中也是拼合后的效果，不会逐张堆叠。
- **存档永久可访问**：Telegraph 页由 Telegraph 服务承载，链接长期有效，适合作为外部参考资料引用。
