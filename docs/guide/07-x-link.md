### 步骤 1：复制 X / Twitter 帖子链接

在 X (Twitter) App 或网页版打开你想要归档的帖子，点击帖子右下角的「分享」按钮，选择「复制链接」。链接形如 `https://x.com/<用户名>/status/<数字 ID>`，请确保复制的是单条帖子的永久链接，而不是搜索结果或用户主页。

### 步骤 2：粘贴链接发送给 Bot

回到 Telegram，将刚才复制的链接粘贴到与 Bot 的对话框中，直接按下发送即可。无需添加任何额外说明文字，Bot 会自动识别这是 X 链接。

### 步骤 3：查看 Bot 返回的归档卡片

Bot 收到链接后，会依次完成以下处理：调用 FxEmbed v2 抓取帖子原文与媒体（含多图合并为 mosaic 拼接图）、对正文进行中文翻译、生成 Telegraph 长期存档页，最后将结果组装成一张自适应卡片返回给你。

- 如果原帖是**纯文字**，卡片会展示翻译后的中文摘要、原文链接标签、相关话题标签（以 # 开头，例如 #archive #开发工具 #命令行）以及一个指向 Telegraph 长期存档页的「📁」链接。
- 如果原帖是**图文**（含多张图片），FxEmbed 会把多张图片拼接为一张 mosaic 大图作为卡片封面。
- 如果原帖是**视频**，卡片会展示视频缩略图与时长信息。

### 步骤 4（可选）：继续归档更多帖子

每条 X 链接都是一次独立事务，Bot 不会把多条链接合并处理。直接在对话中发送下一条链接即可，重复步骤 2、3 的流程。下方截图演示了用户连续发送第二条链接时 Bot 的响应：

### 小贴士

- **确保链接完整**：发送前检查链接是否以 `/status/<数字>` 结尾，列表页、搜索页、个人主页链接不会被识别为单条帖子。
- **善用 Telegraph 存档**：卡片中以 📁 开头的那条链接指向 Telegraph 长期页面，里面的图视频与翻译都会保留，适合在 Telegram 频道二次转发或日后查阅。
- **标签自动生成**：Bot 会根据原帖内容自动加上 # 标签（如 #archive #开发工具），方便你后续通过 Bot 的标签检索功能找到该归档。
