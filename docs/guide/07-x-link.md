### X/Twitter 链接 → 帖子存档

本功能支持将 X(原 Twitter)上的公开帖子快速转存为可长期阅读的图文档案。无论帖子包含单图、多图、纯文字还是视频,Bot 都会自动拉取、翻译并生成 Telegraph 页面与 Telegram 卡片。

### 步骤 1: 复制 X 帖子链接

在 X 客户端或网页版打开目标帖子,点击帖子的「分享」按钮,选择「复制链接」。例如:

- 普通文本帖:`https://x.com/<用户>/status/<帖子ID>`
- 多图或视频帖:链接格式相同,Bot 会自动识别媒体内容

### 步骤 2: 发送链接给 Bot

在 Telegram 对话窗口中,直接将刚刚复制的 X 链接粘贴并发送,无需添加任何额外说明文字。Bot 会在收到链接的瞬间开始处理。

### 步骤 3: 等待 Bot 抓取与处理

Bot 后台会依次执行以下动作,通常在数秒内完成:

1. 调用 FxEmbed v2 接口抓取帖子正文与媒体资源
2. 识别帖子中的图片(单张或 mosaic 多图)与视频
3. 将外文内容翻译为中文
4. 生成 Telegraph 页面并发布

### 步骤 4: 接收存档结果

处理完成后,Bot 会返回一条结构化的 Telegram 消息,通常包含:

- 帖子的中文翻译正文
- 话题标签(根据帖子内容自动推断,如 `#archive` `#开发工具` `#命令行` 等)
- 媒体预览卡片(图片以卡片形式展示,多图以 mosaic 方式排布)
- 一个 📁 图标开头的链接,指向 Telegraph 永久存档页
- 一个指向 archive.org 的链接,提供第三方独立备份

当你发送一条包含四张截图的多图帖链接时,Bot 会自动以 mosaic 卡片形式呈现:

### 步骤 5: 查看或分享

点击 📁 后面的 Telegraph 链接,即可在浏览器中阅读完整译文与原图。Telegram 卡片本身也可直接转发给其他用户,实现快速分享。

### 小贴士

- 一次只发送一条 X 链接效果最佳;若需批量处理,请逐条发送,Bot 会按顺序排队处理。
- 若帖子为视频内容,Bot 会抓取视频预览与直链,但 Telegraph 页面内可能仅展示封面图与说明文字,具体以 Bot 返回内容为准。
- Telegraph 页面一旦生成即为永久链接,即使原 X 帖被删除,你仍可继续访问存档内容。
