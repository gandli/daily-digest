### 步骤 1: 粘贴 X 帖链接

在 Bot 对话窗口中,将 X(Twitter)帖子的完整链接粘贴并发送。链接形如 `https://x.com/<用户名>/status/<帖子ID>`,无需附带任何额外说明文字,Bot 会自动识别链接类型。

### 步骤 2: 等待 Bot 拉取原帖内容

Bot 收到链接后会调用 FxEmbed v2 接口拉取原帖数据。如果帖子包含多张图片,Bot 会自动按 mosaic(九宫格拼图)方式拼接处理;若为单图、视频或纯文字,Bot 也会自适应选取合适的呈现方式。此过程通常在数秒内完成,无需手动干预。

### 步骤 3: 查看中文翻译与卡片输出

Bot 完成处理后会输出一条完整的反馈消息,包含三部分信息:帖子的中文翻译内容、保留的原始标签(例如 `#archive`、`#开发工具`、`#命令行`),以及指向 Telegraph 存档页面的 `<a href="...">` 锚文本链接(完整 URL 显示在锚文本中,可直接点击访问)。卡片样式会根据原帖类型自适应:多图为九宫格拼图、视频附带播放入口、纯文字则仅显示译文与标签。

### 步骤 4: 重复使用以存档多篇帖子

同一会话内可继续粘贴其他 X 帖子链接,Bot 会按顺序逐条处理并输出独立的存档卡片。例如粘贴 `https://x.com/Smartpigai/status/2093191865193677286` 后,Bot 同样会返回对应的翻译、标签与 Telegraph 链接,每篇帖子的存档互不干扰。

### 小贴士

- **链接需为公开帖**:若目标 X 帖子所属账号受保护或已被删除,FxEmbed v2 拉取会失败,Bot 会返回错误提示,此时可尝试更换为其他存档源链接。
- **多图与视频自适应**:无需在链接后追加任何指令,Bot 会自动识别单图、多图、视频、纯文字四种形态并选择对应卡片样式。
- **存档永久可访问**:生成的 Telegraph 页面与 Wayback Machine 快照链接均独立于 X 平台,即使原帖被删除,存档内容仍可正常查看与分享。
