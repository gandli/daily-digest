# X/Twitter 链接 → 帖子存档

本章介绍如何把 X（Twitter）上的帖子链接转成可长期阅读的存档页。整个流程由 Bot 自动完成：抓取原文、翻译、生成 Telegraph 页面，并以一张自适应卡片回送到聊天窗口。

### 步骤 1：粘贴 X 帖链接

在任意与 Bot 对话的窗口中，粘贴一条 X 帖子的完整链接，例如：

```
https://x.com/Smartpigai/status/2093191865193677285
```

发送后无需附带任何指令，Bot 会自动识别链接并启动处理流水线。

![发送单条 X 链接后，Bot 返回带摘要与存档链接的卡片](assets/07-x-link-r1.png)

### 步骤 2：等待 Bot 拉取与翻译

Bot 会调用 FxEmbed v2 接口拉取帖子内容，包括文本、图片马赛克（mosaic）以及视频信息。拉取成功后会进行中文翻译，并在回复中以一段中文摘要概括帖子要点，例如：

> 小而美命令行工具 刚刚发布了一个用于摘要整理的新命令行工具！ #archive #开发工具 #命令行

这条摘要就是 Telegraph 页面顶部展示的核心内容。

### 步骤 3：生成 Telegraph 存档页

翻译完成后，Bot 自动把整理好的内容写入 Telegraph，生成一个独立、可分享的网页链接，并以超链接形式附带在消息中，例如：

```
📁 https://web.archive.org/...
```

点开链接即可看到标题、正文翻译、配图或视频嵌入，且支持长期访问，便于归档检索。

### 步骤 4：查看卡片形式的回送结果

Bot 最终返回一张自适应卡片：当帖子包含图集时，Bot 会拼接多张截图形成 mosaic；当帖子包含视频时，会嵌入播放控件；纯文字帖则只显示文本摘要。无论哪种形态，回复末尾都会带上 Telegraph 链接，方便一键打开完整存档。

![再次粘贴链接时，Bot 依然给出中文摘要并附上 Telegraph 链接](assets/07-x-link-r2.png)

### 步骤 5：批量或重复粘贴

在同一会话中连续粘贴多条链接，Bot 会按顺序依次处理，每条链接都会得到独立的摘要与 Telegraph 页面，互不覆盖，便于一次性归档多条帖子。

## 小贴士

1. **粘贴完整链接**：务必使用以 `https://x.com/` 开头的完整状态链接，不要只粘贴短链或截图，否则 Bot 无法识别。
2. **耐心等待**：包含多图或视频的帖子处理时间略长，请勿重复发送同一链接，避免生成重复的 Telegraph 页面。
3. **善用 Telegraph 链接**：归档后的网页可自由转发或加入书签，是长期保存原帖译文的最稳妥方式，建议优先收藏 Telegraph 链接而非聊天截图。
