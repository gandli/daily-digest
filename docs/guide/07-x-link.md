### X/Twitter 链接 → 帖子存档

把 X(Twitter) 上的精彩帖子永久存档到 Telegraph，避免原帖被删后内容丢失。Bot 会自动抓取帖子、翻译成中文，并生成一张可在 Telegram 内直接预览的卡片。

### 步骤 1：复制 X 帖子链接

在浏览器或 X 客户端打开目标帖子，点击「分享」按钮复制完整链接。链接格式形如 `https://x.com/<用户名>/status/<帖子ID>`，确保包含 `status/` 后面的数字 ID，否则 Bot 无法识别。

### 步骤 2：发送给 Bot

将链接直接粘贴到与 Bot 的私聊对话框中并发送，无需附加任何说明文字。

![用户在私聊中粘贴 X 链接](assets/07-x-link-r1.png)

Bot 接收到链接后会立即开始处理，依次完成：调用 FxEmbed v2 接口拉取原帖正文与媒体（支持单图、多图 mosaic、视频、纯文字四种类型自适应）、翻译为简体中文、生成 Telegraph 镜像页面、合成 Telegram 卡片消息。

### 步骤 3：查看 Bot 返回的存档卡片

稍等数秒，Bot 会回复一条带摘要与链接的卡片消息：

- 标题为帖子中文摘要，例如「小而美命令行工具」
- 正文前部为中文翻译内容，并附带 `#archive` 等话题标签
- 末尾的 `📁` 链接指向 Telegraph 镜像页，便于在 Telegram 内直接打开阅读

![Bot 生成的存档卡片含摘要与 Telegraph 链接](assets/07-x-link-r1.png)

如果原帖包含多张图片，FxEmbed 会自动拼接为 mosaic 九宫格大图，翻译与卡片生成流程完全相同。

![多图帖子同样会被处理为存档卡片](assets/07-x-link-r2.png)

### 步骤 4：访问完整存档

点击卡片末尾 `📁` 后的 Telegraph 链接，即可在浏览器或 Telegram 内置浏览器中查看完整存档页面。页面包含原帖全部文字、翻译版本以及所有图片/视频媒体，即便 X 原帖被原作者删除，存档依然可访问。

### 小贴士

- 一次只发送一条链接可获得最佳响应速度，如需批量存档请逐条发送并等待上一条返回卡片后再发下一条。
- 若 Bot 长时间无回复，请检查链接是否完整包含 `status/` 段，或尝试重新复制一次链接再发送。
- 视频帖子的 Telegraph 页面会以外链形式保留视频源链接，建议同时收藏 Telegram 卡片消息以便快速回查。
