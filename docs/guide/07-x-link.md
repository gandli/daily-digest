## X/Twitter 链接 → 帖子存档

本节演示如何把一条 X / Twitter 帖子的链接交给 Bot，让 Bot 自动抓取原文、生成中文翻译、生成多图拼贴（mosaic）并发布到 Telegraph，同时把 Telegraph 链接回填到存档卡片里。

### 步骤 1: 复制 X 帖子链接

在浏览器或 App 中打开目标 X 帖子，点击右上角分享按钮，选择「复制链接」。目前 Bot 接受标准的 `https://x.com/<user>/status/<id>` 形式链接，无需附带任何追踪参数。

### 步骤 2: 发送给 Bot

回到 Telegram 对话窗口，把刚才复制的链接直接粘贴并发送。Bot 收到后会先做格式校验，确认链接合法后才会进入抓取流程；非 X 域名或非 `status/` 路径会被礼貌拒绝。

### 步骤 3: 等待 FxEmbed v2 抓取与翻译

Bot 调用 FxEmbed v2 接口拉取帖子正文与媒体。多图帖会被自动拼合为单张 mosaic，无需逐张排队；视频帖会保留首帧预览与直链。原文随后进入翻译管线，输出中文版本并保留原 hashtags。

![步骤 3 示例：单帖抓取与翻译](assets/07-x-link-r1.png)

### 步骤 4: 收到存档卡片

Bot 返回一张 Telegram 消息卡片：标题为翻译后的中文摘要，下方依次列出正文、hashtags 和 `#archive` 标签。卡片最后一行是 `📁` 图标加 `<a href="https://web.archive.…">` 形式的持久化链接，点开即可在 Wayback Machine 查看该帖子快照。FxEmbed 拉取失败的页面也会落入同一存档卡片，便于事后回溯。

### 步骤 5: 查看 Telegraph 长读版

点击卡片中的 `📁 Telegraph` 链接（或消息里的对应按钮），浏览器会跳转到 Telegraph 页面。该页自适应排版：纯文字帖只渲染段落；图文帖把 mosaic 嵌在正文顶部；视频帖则在封面下方提供原始播放链接。

### 步骤 6: 重复处理多条帖子

把下一条链接继续粘贴到同一对话窗口即可，Bot 会按顺序排队处理，每条独立返回一张存档卡片，不会与上一条混淆。

![步骤 6 示例：连续处理多帖](assets/07-x-link-r2.png)

## 小贴士

- **链接里别带 `?s=`、`?t=`** 这类分享参数，FxEmbed 偶尔会因冗余 query string 返回非预期字段；直接粘贴干净的 `status/<id>` 链接最稳。
- **想强制刷新**：同一条链接再次发送时，Bot 会重新抓取并生成新 Telegraph 页，旧页面仍可访问但不会再次推送。
- **媒体较长的视频** mosaic 阶段只取首帧预览，想看完整内容请直接点 Telegraph 页里的原始播放链接。
