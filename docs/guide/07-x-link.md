### 步骤 1: 复制并粘贴 X / Twitter 帖子链接

在 Telegram 对话中,将目标推文的完整 URL 复制下来,直接发送给 Bot。支持单条推文链接,粘贴后无需附带任何说明文字,Bot 会自动识别 X / Twitter 域名并进入处理流程。

### 步骤 2: 等待 Bot 拉取原始帖子

Bot 收到链接后会调用 FxEmbed v2 接口抓取推文原文,包含作者信息、正文以及附带的图片或视频素材。对于多图帖子,系统会将多张图片拼合为一张 mosaic 长图以便统一展示;纯文字帖则跳过图片处理步骤。整个过程通常在数秒内完成,期间 Bot 会显示处理状态。

![第一轮:用户粘贴单条推文链接,Bot 返回抓取并翻译后的摘要卡片](assets/07-x-link-r1.png)

### 步骤 3: 查看中文翻译与 Telegraph 存档链接

抓取完成后,Bot 会将推文原文翻译为中文,并在消息末尾附带一条以 📁 开头的 Telegraph 永久存档链接。该链接指向一个独立的可读页面,保留了推文的原文、译文以及媒体资源,即使原帖被删除或原作者注销账号,内容依然可访问。

### 步骤 4: 继续粘贴下一条链接(多轮批量处理)

Bot 支持连续处理多篇推文,无需发送额外指令。直接粘贴下一个 X / Twitter 链接,Bot 即会重复步骤 2 与步骤 3 的流程,逐条生成对应的中文摘要与 Telegraph 存档。每条结果独立呈现,互不干扰,适合按主题或时间线批量归档推文。

![第二轮:用户粘贴第二条推文链接,Bot 返回多图 mosaic 拼合后的卡片](assets/07-x-link-r2.png)

### 步骤 5: 区分卡片样式

Bot 会根据推文原始内容自适应选择卡片呈现方式:

- **含图片**: 显示主图或多图拼合的 mosaic 长图;
- **含视频**: 优先展示视频封面并附 Telegraph 链接;
- **纯文字**: 仅展示作者头像、译文正文与话题标签。

无论哪种类型,消息末尾始终保留 Telegraph 永久存档链接。

## 小贴士

1. **支持多图与视频**: 即使推文附带 4 张或更多图片,Bot 也会将其拼接为单张长图后输出,避免 Telegram 单条消息媒体数量超限的问题。
2. **存档链接长期有效**: Telegraph 页面不依赖原推文状态,建议将 📁 链接单独收藏,作为推文内容的长期备份。
3. **批量粘贴提升效率**: 可一次性发送多条链接(每条一行),Bot 会按顺序依次处理并分别返回结果。
