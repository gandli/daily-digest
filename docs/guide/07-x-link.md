### 步骤 1: 发送 X / Twitter 帖子链接

在 Telegram 对话中,直接将待存档的 X 帖子链接发送给 Bot。Bot 会自动识别链接格式,无需额外指令或前缀命令。

例如发送:

```
https://x.com/Smartpigai/status/2093191865193677285
```

### 步骤 2: 等待 Bot 拉取与翻译

Bot 收到链接后会调用 FxEmbed v2 接口拉取原帖内容,包括文字、多图 mosaic 以及视频信息;随后调用翻译引擎将原帖文字转为中文,并生成匹配的标签(如 #archive、#开发工具 等)。这一过程通常在数秒内完成。

![Bot 返回的中文存档卡片(单条帖子)](assets/07-x-link-r1.png)

### 步骤 3: 查看返回的存档卡片

Bot 会回复一张中文卡片,包含以下字段:

- 帖子中文标题与正文摘要;
- 自动提炼的话题标签;
- 一个 📁 归档链接(`web.archive.org` 形式的快照),点击即可查看原始页面的镜像存档,即使原帖被删除也可访问。

卡片样式会根据原帖内容自适应:

- 纯文字帖:显示加粗标题 + 标签 + 归档链接;
- 多图帖:首图以封面形式展示在卡片顶部;
- 视频帖:以视频预览形式嵌入卡片。

### 步骤 4: 继续发送其他帖子链接

当 Bot 返回上一张卡片后,你可以继续粘贴下一个链接,Bot 会独立处理每一条,不会与上一条混淆。例如再次发送:

```
https://x.com/Smartpigai/status/2093191865193677286
```

Bot 同样返回一张自适应卡片:含多图 mosaic 时展示四条视图的拼贴,文字、标签与归档链接一并呈现。

![Bot 返回的中文存档卡片(多图帖子)](assets/07-x-link-r2.png)

### 步骤 5: 点击归档链接查看快照

每张卡片底部的归档链接指向 Telegraph / archive 快照页面,点击后可在 Telegram 内置浏览器或外部浏览器中打开,看到包含中文翻译、配图与原始链接的完整存档页面。建议将重要存档的链接收藏,便于日后检索。

## 小贴士

- **多图与视频帖无需特殊处理**:Bot 会自动识别并以最合适的卡片样式呈现,一条命令即可完成抓取、翻译、归档全流程。
- **链接格式兼容**:支持 `x.com` 与 `twitter.com` 两种域名,也兼容带或不带 `?s=` 等查询参数的链接;若 Bot 长时间无响应,通常是 FxEmbed 接口暂不可用,可稍后重试。
- **归档是幂等的**:对同一条链接重复发送,Bot 会生成新的快照而非覆盖旧的,适合多次抓取失败后的重试场景。
