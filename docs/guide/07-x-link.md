## X/Twitter 链接 → 帖子存档

本节介绍如何把 X（Twitter）上的单条帖子链接交给 Bot，让它完成抓取、翻译并生成可长期访问的 Telegraph 存档页。整个过程全自动，常见情况下你只需粘贴一条链接。

### 步骤 1：复制 X 帖链接

在 X（Twitter）App 或网页版打开你想存档的那条帖子，点击分享按钮，复制帖子链接。链接形如 `https://x.com/<用户名>/status/<数字 ID>`。

### 步骤 2：粘贴链接发给 Bot

把复制的链接直接发送到与 Bot 的对话窗口，无需附加任何文字或指令。Bot 会识别链接归属并启动处理流水线。

### 步骤 3：等待 Bot 抓取与翻译

Bot 通过 FxEmbed v2 接口拉取原始帖子，包括文字、正文配图（多图时会自动拼成 mosaic 九宫格）以及视频。拉到内容后，Bot 会用中文重新表达原文，并在末尾附上 `#archive` 等话题标签，便于后续检索。Bot 不会要求你确认或补充信息。

![Bot 拉取并翻译单条文本型帖子](assets/07-x-link-r1.png)

### 步骤 4：查看 Telegraph 存档卡片

处理完成后，Bot 会发送一张结构化消息：上方是中文译文，下方 `📁` 后跟随一条 Telegraph 链接，点击即可在浏览器中打开完整存档页。如果原帖包含配图或视频，Telegraph 页会按"图片、视频、纯文字"自适应排版，呈现效果与原帖一致。

### 步骤 5：多图帖子的特殊呈现

当原帖包含多张图片（例如截图合集、产品多视图）时，Bot 会先把多张图拼成一张 mosaic 大图，再随译文一起推送到 Telegraph 页。这种处理能避免在 Telegram 中出现多张图片刷屏，也保证 Telegraph 页加载时一目了然。

![Bot 处理含多图的截图合集帖子](assets/07-x-link-r2.png)

### 小贴士

- 批量处理时，可以把多个 X 链接按顺序逐条发送；Bot 会串行处理并在每条完成后单独回复，回复顺序通常与发送顺序一致。
- 如果一条帖子很久没收到回复，请确认链接可公开访问（未删除、未受保护）。私密或已删除的帖子无法被抓取，Bot 通常也不会给出错误提示。
- 想要更"纯净"的译文，可以在链接后加一个 `raw` 之类的提示前缀（具体支持的指令以 Bot 内 `/help` 为准），让 Bot 跳过话题标签直接输出译文。
