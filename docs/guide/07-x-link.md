### 步骤 1：粘贴 X / Twitter 帖子链接

在与 Bot 的私聊或群组中，直接发送一条 X 帖链接作为消息内容即可，无需附加任何命令或前缀。例如，发送：

`https://x.com/Smartpigai/status/2093191865193677285`

Bot 会立刻识别该链接为可处理的 X 帖子，并进入抓取与处理流水线。

![用户发送 X 帖子链接](assets/07-x-link-r1.png)

### 步骤 2：等待 Bot 拉取并整理帖子

Bot 会通过 FxEmbed v2 抓取该帖子的原始内容，包括正文、图片、视频和元数据。如果帖子包含多张图片，FxEmbed 会按顺序生成 mosaic 拼图，确保所有媒体都能完整呈现。抓取过程中无需用户介入。

### 步骤 3：接收翻译与存档卡片

处理完成后，Bot 会以一条 Telegram 消息的形式回传结果，包含以下信息：

- **中文翻译**：将帖子原文译为中文，保留话题标签（如 `#archive`、`#开发工具`、`#命令行`）和关键语义。
- **Web 存档链接**：附上 `https://web.archive.org/...` 形式的长期存档地址，方便日后回溯。
- **媒体附件**：帖子中的图片、视频，或纯文字内容，会以 Telegram 卡片形式自适应展示。

回复示例：

> 小而美命令行工具 刚刚发布了一个用于摘要整理的新命令行工具！ #archive #开发工具 #命令行 📁 [存档链接]

### 步骤 4：处理多图帖子

若帖子包含多张图片（如截图合集、新功能演示四宫格等），Bot 同样能正确处理。第二轮对话中，用户发送了一条包含四张仪表盘截图的帖子链接：

`https://x.com/Smartpigai/status/2093191865193677286`

Bot 会拉取全部图片并生成 mosaic，再进行翻译和存档，最终以单条卡片消息回传，用户无需逐张查看或手动拼接。

![多图帖子存档效果](assets/07-x-link-r2.png)

### 步骤 5：查看 Telegraph 详情页

卡片消息中通常会附带一个 Telegraph 链接，点击即可在浏览器中打开经过排版的完整存档页面。Telegraph 页保留了原文与译文的对照布局，适合需要精读或分享的场景。

## 小贴士

- **链接格式兼容**：Bot 同时接受 `x.com` 和 `twitter.com` 域名的链接，无需手动替换。
- **批量发送**：可以在同一条消息中粘贴多条链接，Bot 会逐条排队处理，每条帖子都会生成独立的存档卡片。
- **存档可追溯**：所有帖子都会同步存入 Web Archive，即使原帖被删除或账号被注销，仍可通过存档链接访问内容。
