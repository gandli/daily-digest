### 步骤 1：发送 X / Twitter 帖子链接

在 Telegram 对话窗口中，将目标帖子的完整链接发送给 Bot。链接可以是 `https://x.com/...` 或 `https://twitter.com/...` 形式，Bot 都可识别。

### 步骤 2：Bot 调用 FxEmbed v2 抓取帖子

Bot 收到链接后，会自动调用 FxEmbed v2 接口拉取原始帖子内容，包括文字、正文配图（如有）、视频附件（如有）以及作者信息。整个过程通常在数秒内完成，无需用户额外操作。

### 步骤 3：Bot 完成中文翻译

抓取成功后，Bot 会对帖子的英文文本进行中文翻译。翻译后的正文与原始话题标签（hashtag）一并保留在卡片顶部，确保关键上下文不丢失。

### 步骤 4：Bot 生成 Telegraph 存档页与 Telegram 卡片

Bot 会在 Telegraph 上创建一个永久存档页面，并将内容以 Telegram 卡片形式回传给用户。卡片采用自适应布局：

- 单图或多图帖 → 自动拼接为 mosaic 九宫格预览；
- 含视频帖 → 显示视频缩略图与播放入口；
- 纯文字帖 → 仅展示翻译文本与标签，不附加多余元素。

卡片底部附带 📁 图标按钮，点击即可跳转到 Telegraph 完整存档页，方便后续阅读与分享。

### 小贴士

1. **支持长链接与短链接**：无论帖子 URL 是否携带 `?s=`、`?t=` 等跟踪参数，Bot 都能正确解析。建议直接复制 X 应用分享菜单中的链接发送。
2. **批量发送更高效**：如需存档同一作者的多条帖子，可连续粘贴发送，Bot 会逐条排队处理并依次回传卡片。
3. **存档永久有效**：Telegraph 页由 Bot 自动托管，不会因原帖被删除而失效；如需二次分享，直接转发 Bot 返回的卡片即可。
