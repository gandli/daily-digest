### 步骤 1：粘贴 X/Twitter 帖子链接

将目标帖子的完整 X 链接发送给 Bot，例如 `https://x.com/<用户名>/status/<帖子 ID>`。Bot 收到后会立即向 FxEmbed v2 发起请求，开始抓取原帖文本、媒体附件（图片/视频）及元数据。

### 步骤 2：等待 Bot 返回存档卡片

抓取完成后，Bot 会输出一条存档卡片，内容由四部分组成：

- **翻译后的中文正文**：原帖英文/其他语种内容被翻译成中文；
- **话题标签**：自动从原帖中提炼的 `#archive #开发工具 #命令行` 等关键词；
- **📁 图标**：紧随其后的 Telegraph 存档页跳转入口（`<a href="https://web...">` 形式）；
- **自适应卡片**：若原帖含多张图片，Bot 会按多图 mosaic 方式排版；含视频则嵌入视频卡片；纯文字则呈现简洁文本卡片。

### 步骤 3：查看多图 mosaic 排版

当原帖包含多张图片时，Bot 会将它们拼接为 mosaic 视图统一展示，存档卡片与单图场景结构一致，仍以翻译正文 + 标签 + 📁 Telegraph 入口的形式呈现。下面的截图展示了同一系列下的多图帖存档结果：

### 步骤 4：点击 📁 进入 Telegraph 存档页

卡片中紧跟标签的 `<a href="https://web...">` 即为 Telegraph 永久存档链接，点击即可在新页面查看完整排版版本。Telegraph 页保留了原始媒体布局、中文译文与话题标签，适合作为长期引用与外链分享。

### 小贴士

1. **链接必须完整**：仅粘贴 `https://x.com/.../status/<数字ID>` 形式的完整 URL，FxEmbed v2 才能正确解析；短链或缺省的 `x.com` 域名可能抓取失败。
2. **多媒体自适应无需额外指令**：Bot 会根据原帖媒体类型自动选择卡片样式（多图 mosaic / 视频嵌入 / 纯文字），用户只需粘贴链接即可。
3. **善用 Telegraph 存档**：📁 入口指向的 Telegraph 页可作为永久外链使用，避免原帖被删除或 X 平台访问受限时无法查看内容。
