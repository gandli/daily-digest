### 步骤 1: 发送 X / Twitter 帖子链接

在任意与 Bot 对话的聊天中,直接粘贴一条 X(或 Twitter)帖子的完整链接,例如:

```
https://x.com/Smartpigai/status/2093191865193677285
```

Bot 会立即开始处理,无需额外命令或触发词。发送后,只需等待数秒,Bot 即可完成抓取与归档。

![发送 X 帖子链接,Bot 返回中文摘要与 Telegraph 存档链接](assets/07-x-link-r1.png)

如上图所示,Bot 会输出一段流畅的中文摘要(例如:"小而美命令行工具 刚刚发布了一个用于摘要整理的新命令行工具!"),并在末尾附带 `#archive` `#开发工具` `#命令行` 等话题标签,以及一条 Telegraph 永久存档链接,便于后续回看。

### 步骤 2: 发送含多图的 X 帖子链接

若帖子本身是多图拼接(mosaic,即一条推文中包含四张子图),同样只需粘贴链接,例如:

```
https://x.com/Smartpigai/status/2093191865193677286
```

Bot 会自动识别多图结构,调用 FxEmbed v2 拉取原图,并在 Telegraph 页内以正确的拼接布局呈现,而不是拆成多张独立图片。

![多图 mosaic 帖子,Bot 自动整合并生成 Telegraph 存档](assets/07-x-link-r2.png)

可以看到,即使是"一条帖子里的四个视图"这类内容,Bot 也能用一句精炼的中文概括(例如:"新仪表盘的截图 —— 一条帖子里的四个视图。"),并附上对应的标签与存档链接,卡片布局会根据图文比例自适应。

### 小贴士

- 支持的链接形式包括 `https://x.com/...`、`https://twitter.com/...` 以及带或不带 `?s=20` 等查询参数的短链,均可被正确识别。
- 视频帖与纯文字帖同样适用本流程:视频会以 Telegraph 视频卡片呈现,纯文字帖则直接渲染为长文卡片,无需切换任何模式。
- 若同一链接重复发送,Bot 会基于历史记录返回已生成的存档,而不会重复抓取,可放心用于二次分发。
