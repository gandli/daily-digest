## X/Twitter 链接 → 帖子存档

把任意一条 X/Twitter 帖子的链接发送给 Bot，即可自动完成抓取、翻译与归档。本流程会把帖子正文与图片整理为一张 Telegraph 页面，并通过 Telegram 卡片消息呈现，对图帖、视频帖与纯文字帖均能自适应。

### 步骤 1：复制并发送 X 帖子链接

在 X 应用或网页版中找到要归档的帖子，复制其完整链接（形如 `https://x.com/<用户名>/status/<id>`），粘贴到与 Bot 的对话中并发送。Bot 会自动识别链接类型，无需额外命令。

### 步骤 2：等待 Bot 抓取并翻译

Bot 后台会调用 FxEmbed v2 接口拉取帖子原文，包括文本、作者信息以及附带的图片或视频。拉取成功后，会对原文进行中文翻译，并在消息正文中附上 Internet Archive 永久备份链接。处理通常在数秒内完成，过程中 Telegram 消息会显示"正在处理"状态。

对于单图或多图的帖子，FxEmbed 会自动拼接为一张 mosaic（马赛克拼图），避免 Telegram 单条消息多图的发送限制。

### 步骤 3：查看 Telegraph 归档卡片

处理完成后，Bot 会回送一条包含 Telegraph 链接的卡片消息。卡片会根据帖子类型自适应：

- **多图帖**：拼图 mosaic + Telegraph 完整页面
- **视频帖**：视频预览 + Telegraph 完整页面
- **纯文字帖**：仅显示文本与 Telegraph 完整页面

用户点击卡片中的 📁 链接即可在浏览器中查看完整的 Telegraph 归档页面，包含原图、原文与翻译对照。

### 步骤 4：继续发送更多链接

Bot 对每条链接独立处理，发送新链接即可触发新一轮存档流程，多次发送的消息之间不会互相干扰。

### 小贴士

- **链接需为完整格式**：仅粘贴 `https://x.com/用户名/status/数字ID` 形式的链接才能被正确识别，短链（如 `t.co`）需先展开为完整链接。
- **多图帖自动 mosaic**：一条帖子包含多张图片时，Bot 会自动拼接为单张拼图发送，无需用户额外操作。
- **归档永久可访问**：所有 Telegraph 页面均生成在公开域，配以 Internet Archive 备份链接，长期可访问且不易丢失。
