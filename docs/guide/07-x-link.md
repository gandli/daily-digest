### 步骤 1：粘贴 X / Twitter 帖子链接

在 Bot 对话窗口中，将要存档的 X 帖子链接完整复制后发送给 Bot。链接格式应为 `https://x.com/<用户名>/status/<帖子ID>`，无需附带额外说明文字。

### 步骤 2：等待 Bot 抓取并翻译

Bot 收到链接后会调用 FxEmbed v2 接口拉取帖子内容，包括文字、图片或视频信息。处理流程依次为：

1. 通过 FxEmbed v2 抓取原帖元数据
2. 若是含有多张图片的帖子，自动拼接为 mosaic 拼图
3. 将英文正文翻译为中文
4. 生成 Telegraph 存档页面

这一过程通常需要几秒到十几秒，取决于帖子的媒体复杂度。

### 步骤 3：接收存档卡片

Bot 最终会回复一条消息，包含中文译文、归档标签，以及指向 Telegraph 存档页和 Web Archive 永久备份的链接。卡片样式会根据帖子内容自适应：含图时展示图片 mosaic，含视频时附带视频预览，纯文字则只显示排版清爽的文字版本。

可以看到，当原帖包含多张图片时，Bot 会自动将它们组合成一张 mosaic 大图一并归档，避免 Telegraph 页中图片过多导致浏览体验割裂。

### 步骤 4：访问存档或二次处理

点击 Bot 消息中的 Telegraph 链接即可在浏览器查看完整存档页面，内容包含译文、原始媒体以及发布者信息。若需长期保存，建议同时收藏 Web Archive 备份链接；该链接由 Bot 自动生成，可作为永久副本。

---

### 小贴士

- 粘贴链接前请确认帖子未被作者删除或设为私密，否则 FxEmbed v2 将无法抓取内容，Bot 会提示拉取失败。
- 对于含视频的帖子，Bot 会优先保留视频预览；若 Telegraph 页加载较慢，可直接使用 Web Archive 备份查看。
- 批量存档时，可连续发送多条链接，Bot 会按接收顺序逐一处理，无需等待前一条完全返回。
