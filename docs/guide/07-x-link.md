## X/Twitter 链接 → 帖子存档

把 X/Twitter 上的帖子链接直接发给 Bot，即可自动拉取原文、配图或视频，并生成中文化、可永久访问的 Telegraph 存档页面。

### 步骤 1：复制 X/Twitter 帖链接

在 X（或 Twitter）客户端中找到想要存档的帖子，点击「分享」按钮，复制其完整链接。链接形如 `https://x.com/<用户名>/status/<帖子ID>`，务必包含 `status/` 后面的数字 ID，这是 Bot 定位帖子的唯一凭证。

### 步骤 2：发送给 Bot

把链接作为一条独立消息发送给 Bot，无需附加任何说明文字。Bot 检测到合法 X 链接后即开始处理。

### 步骤 3：等待 Bot 拉取并整理内容

Bot 内部会依次执行以下动作：

1. 调用 FxEmbed v2 接口拉取帖子正文与媒体附件；
2. 若帖子包含多张图片，自动拼接为一张 mosaic 拼图；
3. 将英文（或其它外文）原文翻译为中文；
4. 渲染 Telegraph 页面，整合图片/视频/纯文字三种排版；
5. 同时生成 Web Archive 永久快照链接。

整个过程通常在数秒内完成。

### 步骤 4：接收存档卡片

Bot 最终回复一张包含中文译文、媒体预览和快捷链接的存档卡片。第一行展示中文摘要与话题标签，末尾附上 `📁` 图标开头的 Telegraph 原文链接，以及 Web Archive 镜像链接。

![单图帖存档效果](assets/07-x-link-r1.png)

### 步骤 5：多图帖自动拼图

若原帖包含多张图片，Bot 会自动把它们合并为一张 mosaic 长图，保证在 Telegram 卡片中一次性呈现完整画面，无需用户点击展开。

![多图帖 mosaic 存档效果](assets/07-x-link-r2.png)

### 步骤 6：查看与转发

点击卡片中的 Telegraph 链接即可在浏览器内阅读完整存档页面，包括原图、原始作者信息和发布时间。卡片本身也支持直接转发给群组或好友，对方点开后能看到同样的中文摘要和跳转入口。

---

### 小贴士

- **批量发送**：Bot 一次只处理一条链接，如需存档多篇帖子，请逐条发送，避免消息粘连导致链接识别失败。
- **私密账号**：若原帖作者设置了隐私保护或帖子已被删除，Bot 会返回抓取失败的提示，请换用公开镜像或截图方式存档。
- **优先用 Telegraph**：卡片末的 `📁` Telegraph 链接是可读性最佳的版本，建议收藏时使用此链接；Web Archive 链接则适合作为永久备份。
