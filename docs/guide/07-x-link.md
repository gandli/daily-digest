# X / Twitter 链接 → 帖子存档

把 X(Twitter)上的任意公开帖子链接直接发送给 Bot，Bot 会自动拉取原文、整理媒体资源、翻译为中文并生成可永久访问的 Telegraph 存档页面，整套流程一次完成。

### 步骤 1：复制 X 帖子链接

在 X(网页或 App)中打开想要存档的帖子，点击「分享 → 复制链接」。确认链接形如 `https://x.com/<用户名>/status/<数字 ID>`。Bot 同时支持 `twitter.com` 旧域名，无需手动替换。

### 步骤 2：发送链接给 Bot

将链接粘贴到与 Bot 的私聊或所在群组中直接发送，无需附带任何命令或额外文字。

### 步骤 3：等待 Bot 拉取并翻译

Bot 会调用 FxEmbed v2 接口抓取帖子内容，包括文本、图片(自动拼合为 mosaic 拼图)、视频或投票等富媒体，并对原文进行中文翻译。处理时长通常在数秒内，复杂多图帖子可能略久。

### 步骤 4：接收存档卡片

Bot 回复一张 Telegram 消息卡片，包含：

- **翻译后的中文正文**(顶部);
- **媒体预览**——单图直接显示，多图以 mosaic 拼图呈现，视频则附带播放入口，纯文字帖仅显示标题与正文;
- **归档入口**——指向 Telegraph 永久页的链接，可浏览器打开查看完整排版;
- **Wayback 备份**——链接旁附 `web.archive.org` 快照，确保原帖即使被删除也可访问。

![单帖存档效果：原文、中文翻译与归档链接](assets/07-x-link-r1.png)

### 步骤 5：连续处理多条链接

Bot 支持逐条处理，用户可在同一会话中连续发送不同帖子的链接，Bot 按发送顺序依次返回独立存档卡片，互不干扰。

![多图拼图与第二张存档卡片](assets/07-x-link-r2.png)

## 小贴士

- 想要归档的帖子若包含多张图片，Bot 会自动生成 mosaic 拼图一次性展示，无需逐张请求。
- 若原帖被作者删除，存档卡片仍可通过 `web.archive.org` 链接与 Telegraph 镜像访问，请妥善保存这两个地址。
- 暂不支持私密账号或受社区限制的帖子，如遇抓取失败请确认链接对应的帖子为公开状态。
