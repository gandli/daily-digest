## X/Twitter 链接 → 帖子存档

将任意 X(Twitter)推文链接发送给 Bot,即可一键拉取原文、多图拼接、翻译为中文,并生成 Telegraph 存档页面与适配内容的卡片。

### 步骤 1:复制 X 帖子链接

在浏览器或 X 客户端中找到需要存档的帖子,点击「分享」→「复制链接」。链接形如 `https://x.com/<用户名>/status/<推文 ID>`。

### 步骤 2:粘贴链接并发送

回到 Telegram,直接将链接发送给 Bot,无需附带任何文字或指令。Bot 会自动识别链接归属。

![第一步:粘贴单帖链接](assets/07-x-link-r1.png)

### 步骤 3:查看首条帖子存档

Bot 调用 FxEmbed v2 拉取推文内容,若推文包含多张图片,会按顺序拼合为一张 mosaic 图。处理完成后,Bot 返回一张卡片,包含:

- 中文翻译后的正文(原文为中文时则保留原文);
- 自适应布局:纯文字仅展示文字,有图则展示 mosaic 图,有视频则内嵌播放;
- 底部「📁」按钮,点击即可跳转至 Telegraph 存档页面查看完整原始版本。

### 步骤 4:继续粘贴第二条链接

对于多张需要存档的帖子,重复步骤 2 即可。Bot 每次都独立处理新链接,互不干扰。

![第二步:继续发送下一条链接](assets/07-x-link-r2.png)

### 步骤 5:查看后续帖子存档

Bot 再次返回卡片,以相同的形式展示新帖子的中文内容与附件。多图依旧自动拼接为 mosaic,视频依旧内嵌播放。

### 步骤 6:打开 Telegraph 页面

每张卡片底部的「📁」按钮均指向对应的 Telegraph 页面。在该页面可看到:

- 原始链接与 Wayback Machine 备份链接;
- 原文与翻译对照(若原文非中文);
- 所有图片、视频等媒体的完整列表;
- 原文作者信息与发布时间。

---

**小贴士**

1. **支持批量处理**:无需等待前一条返回即可发送下一条,Bot 会按收到顺序依次处理,各自生成独立存档。
2. **链接去重**:若短时间内重复粘贴同一条链接,Bot 会复用已生成的存档,避免重复抓取。
3. **视频与多图**:Bot 会自动判断内容类型——纯文字只渲染文字、含图则生成 mosaic、含视频则直接内嵌播放,无需手动指定。
