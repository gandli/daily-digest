### 步骤 1: 复制 X / Twitter 帖子链接

在 X (原 Twitter) 中打开想要存档的帖子，点击帖子右上角的「分享」按钮，选择「复制链接」。链接形如 `https://x.com/<用户名>/status/<帖子ID>`。无需复制整段引用文本，单独一条状态链接即可。

### 步骤 2: 粘贴链接并发送

回到与 Bot 的私聊窗口，将刚才复制的链接粘贴到输入框并发送。一次只粘贴一条链接，Bot 会按顺序处理每一条。

### 步骤 3: 等待 Bot 抓取与翻译

Bot 接收到链接后，会依次完成以下几件事：

- 调用 FxEmbed v2 接口拉取帖子的原始内容；
- 如果帖子包含多张图片，自动按网格排版生成 mosaic 拼图；
- 将英文 (或其他外文) 原文翻译为中文；
- 生成 Telegraph 长期可访问页面；
- 根据帖子内容自适应选择输出形式：含图则输出图片卡片，含视频则优先视频卡片，纯文字则只输出 Telegraph 链接。

整个过程通常需要数秒到十几秒，取决于原帖媒体数量与网络状况。

### 步骤 4: 查看返回的存档卡片

Bot 回复的消息包含两部分：翻译后的中文正文，以及末尾的 Telegraph 永久存档链接 `https://web.archive.<...>`。点击链接即可在浏览器中查看排版完整的存档页。

### 步骤 5: 继续发送下一条 (可选)

需要批量存档时，直接发送下一条 X 链接即可，Bot 会逐条独立处理，互不干扰。

## 小贴士

- **链接要完整**：务必使用 `x.com` 或 `twitter.com` 的 status 链接，不要只粘贴 `t.co` 短链或用户主页链接，否则 Bot 无法识别具体帖子。
- **媒体自适应**：发送前无需判断帖子类型，Bot 会自动识别图片、视频或纯文字并选择最合适的卡片样式。
- **存档长期有效**：返回的 Telegraph 链接不受 X 删帖影响，是真正的「存档」，建议收藏到自己的笔记或稍后读列表中。
