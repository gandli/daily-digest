### 步骤 1：复制 X / Twitter 帖子链接

在 X 或 Twitter 中打开想要归档的帖子，点击帖子的「分享」按钮，选择「复制链接」。链接的形态一般为 `https://x.com/<用户名>/status/<数字 ID>`，例如 `https://x.com/Smartpigai/status/2093191865193677285`。

### 步骤 2：把链接发送给 Bot

回到与 Bot 的对话窗口，将刚才复制的链接直接粘贴并发送。Bot 会识别这是一个 X / Twitter 帖子链接，并自动开始处理，不需要额外的命令或前缀。

### 步骤 3：等待 Bot 抓取与翻译

Bot 会通过 FxEmbed v2 接口拉取该帖子的完整内容，包括作者信息、正文、发布时间，以及帖子附带的图片、视频或 mosaic（多图拼接）等媒体资源。拉取完成后，Bot 会将英文或其他外文内容翻译为中文，并自动生成一份可读的中文存档草稿。

### 步骤 4：查看 Bot 返回的存档卡片

处理完成后，Bot 会即时回复一条消息，内容包含：

- 翻译后的中文帖子正文；
- 作者、话题标签（Hashtag）等元信息；
- 一张 Telegraph 长期存档页面的链接，便于随时回访；
- 一份压缩后的 ZIP 附件（包含原始图片、视频或 mosaic 资源），可下载保存到本地。

例如，针对一条介绍新命令行工具的帖子，Bot 会返回形如「小而美命令行工具 刚刚发布了一个用于摘要整理的新命令行工具！#archive #开发工具 #命令行」这样的中文摘要，并附上 Telegraph 页面与 ZIP 包链接。

![Bot 返回第一条 X 帖子存档卡片](assets/07-x-link-r1.png)

### 步骤 5：继续发送其他链接

Bot 不会因为你发送了第一条就「锁定」会话状态，每一条新链接都会触发一次独立的拉取、翻译与归档流程。例如，下一次发送 `https://x.com/Smartpigai/status/2093191865193677286` 时，Bot 会再次拉取该帖（包括一条帖子里多张图片组成的 mosaic），并生成新的中文存档。

![Bot 返回第二条 X 帖子存档卡片](assets/07-x-link-r2.png)

### 步骤 6：善用三种卡片形态

Bot 返回的卡片会根据帖子原始内容自适应：

- **纯文字帖**：只显示翻译后的正文与标签；
- **带图帖**：正文中嵌入原始图片，并在 ZIP 附件中保留原图；
- **带视频帖**：提供视频缩略图与原文件下载链接；
- **多图 mosaic**：自动拼接为一张完整长图，并随附原图。

## 小贴士

- **链接要完整**：务必复制完整的 `https://x.com/.../status/<id>` 形式链接；短链或缺省 `/status/` 段时，Bot 可能无法识别。
- **同作者多条帖子可批量发送**：无需等待上一条处理完，逐条粘贴即可，Bot 会按到达顺序依次归档。
- **Telegraph 链接是长期入口**：ZIP 附件可能因会话清理而失效，但 Telegraph 页面会持续可访问，建议把 Telegraph 链接保存为书签作为长期引用。
