### 步骤 1: 复制 X / Twitter 帖子链接

在 X(原 Twitter)客户端或网页端打开想要存档的帖子,点击「分享」按钮,选择「复制链接」,得到形如 `https://x.com/<用户名>/status/<帖子 ID>` 的完整 URL。

### 步骤 2: 将链接发送给 Bot

打开与 Bot 的对话,把刚才复制的链接粘贴进去并发送。Bot 会识别 X / Twitter 链接域名,自动调用 FxEmbed v2 接口抓取该帖子的完整内容,包括作者信息、正文、图片以及视频。

![Bot 拉取并翻译首条 X 帖子](assets/07-x-link-r1.png)

### 步骤 3: 查看 Bot 返回的归档结果

稍等片刻后,Bot 会回复一条包含 **中文翻译** 与 **Telegraph 永久存档链接** 的消息。你会看到:

- 中文译后的帖子正文(保留 #archive、#开发工具 等话题标签);
- 一个 🏷️ 标签块,列出所有 hashtag;
- 一段 `📁 <a href="...">...</a>` 形式的 [web.archive.org](https://web.archive.org) 快照链接(点击即可跳转到网页存档版本,防止原帖被删);
- 一张**自适应卡片**:若帖子含多张图片,Bot 会拼接成 mosaic 九宫格一次性展示;若含视频,则渲染为带播放控件的卡片;若为纯文字帖,则只输出译文与存档链接,不附加卡片。

### 步骤 4: 验证多图 mosaic 卡片(可选)

如果原帖是多图帖(例如一张仪表盘截图分四条发出),Bot 会按原帖顺序把图片拼成一张 mosaic 卡片直接发送到 Telegram,无需用户点击外链。译文与卡片同时呈现,适合快速浏览。

![Bot 拉取并翻译第二条多图 X 帖子](assets/07-x-link-r2.png)

### 步骤 5: 继续发送其他链接

对其它想要存档的帖子重复步骤 2 — 4。每条链接独立处理,互不干扰。Bot 会为每条 X 链接生成各自的 Telegraph 永久页与 archive.org 快照。

---

### 小贴士

1. **一定要发送完整 `https://x.com/.../status/...` 链接**,短链(如 `t.co/xxx`)或仅粘贴用户名 + 数字 ID 的写法不会被识别。
2. **多图与视频帖的自适应卡片**直接展示在 Telegram 内,无需跳转;若卡片加载失败,可点开消息中的 [web.archive.org](https://web.archive.org) 链接查看完整快照。
3. 若 Bot 长时间无响应或回复「拉取失败」,通常是 X 接口限流或帖子已被原作者删除,稍等几分钟重试一次即可。
