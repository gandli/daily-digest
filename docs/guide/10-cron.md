### 步骤 1: 等待定时触发

每天 08:30（北京时间）系统会自动触发一次推送任务，您无需手动操作。任务会依次执行：新鲜抓取 → 翻译 → 存档 → 推送，同时附带 `refreshLookupDescriptions` 和 `backfillDescriptions` 维护任务，确保描述库持续更新。

### 步骤 2: 接收抓取结果

Bot 会按编号向您推送当天抓取到的热门仓库，每条消息包含仓库名、星标数、作者、简介、话题标签以及存档链接。推送格式如下：

- `1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending #c #editor 🗂 <a href...>`
- `2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 #trending 🗂 <a href...>`

### 步骤 3: 查看失败提示（如有）

若部分数据源抓取失败，Bot 会在所有正常推送结束后追加一条告警，例如：

- `⚠️ Product Hunt 拉取失败, 请稍后再试。`

看到此类提示不必担心其他频道的推送失败，仅代表对应渠道暂时不可用，您可稍后重试或等待下一次定时任务。

![每日 08:30 自动推送消息示例](assets/10-cron-r1.png)

### 小贴士

1. **无需守候**：定时任务完全后台运行，您随时打开 Bot 都能看到当天的完整推送历史，不会错过任何消息。
2. **失败可补救**：若某条数据源频繁拉取失败，可在下次推送前联系管理员检查对应接口，存档功能不受影响。
3. **维护任务静默运行**：`refreshLookupDescriptions` 与 `backfillDescriptions` 在后台持续优化描述库，您无需干预，长期使用会发现翻译质量与描述准确度逐步提升。
