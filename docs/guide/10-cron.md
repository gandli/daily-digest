### 每日自动推送（cron）

本章介绍 Bot 提供的每日定时推送能力。每天北京时间 08:30，Bot 会自动触发后台任务，依次完成新鲜抓取、翻译、存档与推送，并同步执行 `refreshLookupDescriptions` 与 `backfillDescriptions` 两条维护任务，确保仓库描述与翻译词表持续更新。

### 步骤 1：确认当前时区为北京时间

由于定时任务的触发时间固定为「北京时间 08:30」，使用前请确认你的设备或客户端时区设置与北京时间一致。若你在海外或使用 UTC 时区，实际收到推送的时间会换算为本地时间。

### 步骤 2：等待定时触发，无需手动操作

每日 08:30（北京时间）一到，Bot 会自动在后台运行以下流程：

1. 从 Trending 列表抓取当日新鲜仓库；
2. 对仓库描述进行翻译处理；
3. 将结果写入存档库；
4. 通过聊天窗口向用户推送卡片；
5. 顺带执行 `refreshLookupDescriptions` 与 `backfillDescriptions` 维护任务，刷新翻译词表与历史描述。

整个过程无需你发送任何指令，Bot 会按计划执行。

### 步骤 3：查看自动推送内容

定时任务执行完毕后，Bot 会在聊天窗口中依次输出当日上榜的仓库卡片，格式形如：

> 1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器，代码精炼，适合学习 C 语言。 #trending #c #editor 🗂 <a href=…>

每条消息包含序号、仓库名、星标数、作者、中文简介、话题标签与跳转链接。Bot 会按分数从高到低逐条推送，逐条发完当日所有上榜项目。

### 步骤 4：阅读与跳转

点击消息末尾的 `<a href="…">` 链接即可在浏览器中打开对应 GitHub 仓库页面。若某条仓库你不感兴趣，可直接忽略；想深入了解的话，再点开链接阅读源码或 Star 收藏。

### 步骤 5：查看历史推送

由于推送结果会同时写入存档，你可以在后续任意时刻通过查询命令翻阅历史仓库，无需担心错过早晨的推送。

### 小贴士

- 建议将 Bot 会话开启消息提醒，这样每天 08:30 一旦推送就能立即看到，避免被其他消息淹没。
- 如果长时间未收到推送，可先检查网络与时区设置，再确认 Bot 是否仍处于启用状态。
- `refreshLookupDescriptions` 与 `backfillDescriptions` 会在每次推送时自动运行，无需你手动触发；翻译质量会随词表更新逐步变好。
