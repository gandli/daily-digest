# 每日自动推送(cron)

本章介绍如何启用并观察每天 08:30(北京时间)由 cron 定时触发的自动推送流程。该任务会自动完成:抓取 GitHub Trending → 中文翻译 → 仓库信息存档 → 推送消息, 并在后台运行 `refreshLookupDescriptions` 与 `backfillDescriptions` 维护任务以保证翻译与描述库的完整性。

### 步骤 1: 等待定时触发

用户无需任何操作。系统会在每天 08:30(北京时间)自动唤醒 cron 任务。任务启动后会按顺序执行:新鲜抓取 → 翻译 → 存档 → 推送, 同时并行启动两条描述维护任务。

### 步骤 2: 查看每日推送消息

cron 完成后, Bot 会将当日 Trending 仓库以编号消息形式推送到对话中。每条消息包含排名、仓库名、Star 数、作者、简介与标签, 完整覆盖当日榜单。

![每日 08:30 自动推送示例, 包含 antirez/kilo 与 sharkdp/bat 等仓库](assets/10-cron-r1.png)

### 步骤 3: 阅读并互动

用户可直接阅读每条消息获取仓库信息, 也可以点击消息中的链接跳转到对应 GitHub 仓库页面。无需回复指令, 推送为只读通知。

## 小贴士

- 推送按 "1/2、2/2" 等分片发送, 数字代表当日第几条与当日总条数, 收到 "N/N" 即表示今日推送完整结束。
- 首次启用后, 维护任务会先填补历史翻译缺口, 之后每日推送耗时将明显缩短。
- 若错过 08:30 的推送, 可使用「立即推送」指令手动补发当日内容(详见对应章节)。
