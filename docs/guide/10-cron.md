# 每日自动推送（cron）

本章节介绍如何让 Bot 在每天早上 08:30（北京时间）自动为你推送当天的精选仓库与维护任务报告，无需手动触发。

### 步骤 1: 等待定时触发

每天 08:30（北京时间），Bot 会按照预定计划（scheduled cron）自动开始一次推送会话。无需发送任何指令，只需确保 Bot 处于运行状态。

### 步骤 2: 查看自动抓取与翻译结果

触发后，Bot 会先完成「新鲜抓取 → 翻译 → 存档」三步流水线，然后依次把当天的热门仓库推送到当前会话。推送内容会包含仓库名称、Star 数、作者、简介、话题标签以及归档链接，例如：

- `1/2 antirez/kilo ⭐ 3.2k 👤 antirez 仓库简介… #trending #c #editor 🗂 <a href="…">`
- `2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 仓库简介… #trending 🗂 <a href="…">`

### 步骤 3: 接收维护任务报告

紧随仓库推送之后，Bot 会在同一轮会话中执行 `refreshLookupDescriptions` 与 `backfillDescriptions` 维护任务，用于刷新与补全仓库描述字段。这部分为后台维护操作，不产生新的用户可见消息，但你可以在日志中观察到任务已运行。

### 步骤 4: 完成当日推送

当你看到形如 `1/2 … 2/2 …` 的两条仓库消息全部出现时，说明本次自动推送已完成。下一轮推送将在次日 08:30 自动进行，形成稳定的每日节奏。

## 小贴士

- **保持 Bot 在线**：cron 触发依赖 Bot 进程持续运行，若 Bot 离线则当日推送会顺延到下次启动。
- **关注标签与归档链接**：推送中以 `#` 开头的标签便于快速识别主题分类，🗂 后面的链接可用于查看完整归档。
- **维护任务无打扰**：`refreshLookupDescriptions` 与 `backfillDescriptions` 是静默执行的后台任务，不会打断你的对话节奏，只在日志中留痕。
