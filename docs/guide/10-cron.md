### 步骤 1：等待定时触发

用户无需任何手动操作。每天 08:30（北京时间），Bot 会自动通过 scheduled 任务启动新一轮推送。该任务会依次完成：抓取当日新鲜仓库、对仓库描述进行翻译、入库存档、向订阅用户推送卡片，最后还会执行 refreshLookupDescriptions 与 backfillDescriptions 等维护性任务，确保数据持续完整。

### 步骤 2：接收首批推送

定时任务触发后，Bot 会以编号形式逐条推送当日精选仓库。例如：

> `1/2 antirez/kilo ⭐ 3.2k 👤 antirez 这个仓库实现了经典的文本编辑器，代码精炼，适合学习 C 语言。 #trending #c #editor 🗂 <a href="…">`

每条消息按「序号/总数 仓库名 ⭐ 星标数 👤 作者 翻译后的描述 #标签」的格式呈现，方便快速浏览。

### 步骤 3：接收后续推送

Bot 会以同样的格式继续推送剩余仓库，例如：

> `2/2 sharkdp/bat ⭐ 50.0k 👤 sharkdp 这个仓库实现了经典的文本编辑器，代码精炼，适合学习 C 语言。 #trending 🗂 <a href="…">`

直到当日批次全部推送完毕，序号结束于「n/n」。

### 步骤 4：日常查阅

由于推送属于自动化行为，用户在 08:30 之后随时向上滚动与 Bot 的聊天记录即可查看当天的完整列表；历史推送也会保留在对话中，便于回看。

## 小贴士

- **时区确认**：cron 时间基准为北京时间（UTC+8）。若你身处其他时区，请自行换算实际接收时间，避免错过。
- **静默时段建议**：建议保持 Bot 会话置顶或开启消息通知，确保推送到达时能及时看到。
- **维护任务无需干预**：refreshLookupDescriptions 与 backfillDescriptions 由 Bot 自动在后台执行，用于刷新与回填描述字段，无需用户手动触发。
