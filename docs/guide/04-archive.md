### 步骤 1：发送 /archive 命令

在 Telegram 对话框中输入 `/archive` 并发送。Bot 会立即返回最近的历史存档列表。首次响应中,消息正文会展示当前页的项目,顶部显示翻页标题,例如「📂 历史存档 (第 1/2 页, 共 14 条)」。每条存档项以「仓库名 · 日期」开头,随后是摘要文字与对应的 GitHub 链接(以 `<a href="...` 形式出现在消息中)。

消息下方附带 inline keyboard 翻页按钮:`◀️` 与 `▶️`,分别用于向前或向后翻页。当处于第 1 页时,`◀️` 处于不可用状态;处于末页时,`▶️` 不可用。

![历史存档第 1 页列表与翻页按钮](assets/04-archive-r1.png)

### 步骤 2：翻到第 2 页

如果列表条目较多、需要浏览后续存档,可点击 inline keyboard 中的 `▶️` 按钮。Telegram 会向 Bot 回传一个 callback 数据,形如 `arch:pg:1`(表示请求第 2 页,页码从 0 开始计数)。Bot 收到回调后,会原地编辑原消息,展示下一页内容,标题更新为「📂 历史存档 (第 2/2 页, 共 14 条)」,并列出该页的存档条目。翻页过程中不会弹出新消息,原消息的内容与按钮整体替换。

![历史存档第 2 页列表](assets/04-archive-r2.png)

### 步骤 3：查看条目详情或返回

列表中的每条存档摘要尾部都附带了对应 GitHub 仓库的链接(在 Telegram 中会渲染为可点击的链接文本)。如需跳转到具体仓库页面,直接点击摘要中的链接即可在浏览器中打开。

如果想回到第 1 页查看之前的存档,在第 2 页状态下点击 `◀️` 即可,Bot 会再次原地编辑消息并切换回上一页;若想退出浏览,无需任何操作,这条存档消息会一直保留在对话历史中,随时可以向上滚动重新查看。

### 小贴士

- 翻页通过 inline keyboard 按钮触发,操作只会修改原消息,不会产生新消息气泡,保持对话界面整洁。
- 标题中的「共 N 条」反映了 Bot 当前可用的存档总数,若该数字发生变化,说明有新的存档被加入或旧存档被清理。
- 当列表仅有 1 页时,`◀️` 与 `▶️` 两个按钮都会显示为不可用状态,此时无需翻页操作。
