# /archive — 历史存档浏览（分页交互）

使用 `/archive` 命令可以快速浏览 Bot 已收录的全部历史存档。列表按收录时间倒序展示，每页固定显示若干条，并支持通过内联键盘进行翻页与单条详情跳转。

### 步骤 1：发起浏览命令

在 Telegram 对话中直接输入并发送：

```
/archive
```

Bot 会立刻返回最近一页的存档列表。消息正文包含页码标识（如 `第 1/2 页, 共 14 条`），每条记录按顺序展示仓库全称、收录时间、摘要文字以及可点击的外部链接。消息下方附带一行 inline keyboard，提供 `◀️` 与 `▶️` 翻页按钮，以及每条存档对应的条目跳转按钮（按钮回调数据形如 `arch:pg:N`）。

执行后可见效果：

![执行 /archive 后返回的首页列表](assets/04-archive-r1.png)

### 步骤 2：翻到下一页

点击消息下方的 `▶️` 按钮（其回调数据为 `arch:pg:1`），即可加载下一页记录。Bot 会将原文替换为下一页内容，例如 `第 2/2 页, 共 14 条`，并重新生成对应的条目跳转按钮。摘要中带有 `🏷 #demo` 这类标签时，会直接显示在条目内，方便快速识别主题。

翻页后的页面如下：

![翻到第 2 页后的存档列表](assets/04-archive-r2.png)

### 步骤 3：进入单条详情

在任意一页中，点击对应存档条目下方的按钮（例如 `bat`），Bot 会跳转到该条存档的详情视图，展示完整描述、原始链接与相关标签。如果想返回列表继续浏览，使用 Telegram 的「返回」操作或再次发送 `/archive` 即可重新进入首页。

## 小贴士

- **页码定位**：留意消息开头的 `第 X/Y 页` 字样，可快速判断当前位于列表的哪个位置，避免重复翻页。
- **按钮时效**：inline keyboard 的翻页与跳转按钮仅在原消息生效；若列表消息被滚动到屏幕外，可发送 `/archive` 重新召唤一次以拿到最新可用的按钮。
- **跨页查找**：每页条目数量有限，建议结合摘要或标签先粗筛，再点击进入详情查看完整内容，能显著节省翻页次数。
