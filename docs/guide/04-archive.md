## /archive — 历史存档浏览（分页交互）

使用 `/archive` 命令可调阅 Bot 之前抓取并摘要过的所有仓库存档。Bot 会以分页形式呈现列表,每页附带翻页按钮,点击任意条目即可跳转至详情。

### 步骤 1: 发送命令

在对话中输入 `/archive` 并发送。Bot 收到后会检索所有历史存档,按最新时间倒序排列,默认展示第 1 页(每页 7 条),并以页码指示器告知总页数与总条数。例如共有 14 条存档时,会显示「第 1/2 页,共 14 条」。

每条列表项依次包含:仓库名、存档时间、一句话中文摘要,以及对应的 GitHub 链接。链接以 HTML `<a href="…">` 形式给出,部分客户端可点击直接打开。

![第 1 页存档列表,显示 sharkdp/bat 等条目](assets/04-archive-r1.png)

### 步骤 2: 翻页查看下一页

第 1 页底部会附带一个 inline keyboard 按钮,标签为 `arch:pg:1`(其中数字表示「下一页」的页码)。点击该按钮即可请求翻页。

Bot 收到翻页请求后,会渲染第 2 页内容,并更新页码指示器为「第 2/2 页,共 14 条」。当翻到末页后,通常不再提供「下一页」按钮,避免越界。

![第 2 页存档列表,显示 demo/repo-02 等条目](assets/04-archive-r2.png)

### 步骤 3: 浏览并进入详情

在任意一页中,逐条阅读仓库名、时间与摘要即可定位目标。当看到感兴趣的条目时,直接点击其下方的 GitHub 链接(HTML 锚文本),即可跳转到对应仓库的存档详情。

需要继续浏览其他存档时,重复步骤 2 的翻页操作即可。

### 小贴士

- 若存档数量较多,可结合 `/search <关键词>` 先过滤,再对命中结果使用 `/archive` 复核完整时间线。
- 翻页按钮的 `arch:pg:N` 标识仅在该消息存活期内有效;若 Bot 消息被刷出当前窗口,需重新发送 `/archive` 以生成新键盘。
- 摘要中的 🏷 标签(如 `#demo`)对应 Bot 抓取时提取的主题分类,可作为快速筛选的视觉线索。
