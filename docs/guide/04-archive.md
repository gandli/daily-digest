## /archive — 历史存档浏览（分页交互）

`/archive` 命令用于浏览 Bot 保存的全部历史存档。返回结果以列表形式展示，并通过 inline keyboard 提供翻页与详情跳转。

### 步骤 1：发送命令

在 Bot 对话窗口中输入：

```
/archive
```

Bot 立即返回一页存档列表，标题中包含当前页码与总条目数，例如：

> 📂 历史存档 (第 1/2 页, 共 14 条)
>
> **sharkdp/bat** · 2026-09-01
> 📝 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。

列表下方附带 inline keyboard 翻页按钮（◀️ ▶️）与每条存档的快捷跳转按钮。首次进入时默认展示第 1 页。

![第 1 页存档列表](assets/04-archive-r1.png)

### 步骤 2：翻到下一页

当列表条目超出单页容量时，点击消息底部的 **▶️** 按钮（或对应的 `arch:pg:N` 回调按钮）请求下一页数据。

Bot 收到翻页请求后会更新消息内容，标题变为：

> 📂 历史存档 (第 2/2 页, 共 14 条)

并展示该页对应的存档条目，例如：

> **demo/repo-02** · 2026-09-01T08:30:00
> 📝 demo/repo-02 的中文摘要示例。
> 🏷 #demo

按钮区同步刷新为新的 ◀️ ▶️ 组合，方便继续向前或向后翻页。

![第 2 页存档列表](assets/04-archive-r2.png)

### 步骤 3：进入单条存档详情

在任意一页的列表中，点击目标存档对应的 inline 按钮（通常显示仓库名或 `arch:open:<id>`），Bot 将跳转至该条存档的完整详情视图，展示原文链接、完整摘要、标签等扩展信息。

### 小贴士

- **页码提示含义**：标题中“第 X/Y 页”表示当前是第 X 页，共 Y 页；“共 N 条”为所有页面的存档总数，便于估算翻页次数。
- **快速回首页**：连续点击 ◀️ 按钮直到页码变为 1/2；如 Bot 配置了 `arch:pg:0` 快捷按钮，也可一键返回首页。
- **消息时效**：翻页操作通过编辑原消息实现，请避免在短时间内频繁点击，以免触发 Telegram 的编辑频率限制。
