## /archive — 历史存档浏览（分页交互）

使用 `/archive` 命令可以快速浏览 Bot 保存过的所有历史存档。Bot 会按存档时间倒序展示，每页固定显示若干条目，并通过 inline keyboard 提供翻页与跳转交互，方便你在历史记录中来回穿梭。

### 步骤 1：发起存档列表请求

在任意与 Bot 的私聊或群组中，发送 `/archive` 命令。Bot 会立即处理请求，并返回第一页的存档列表，每条记录包含仓库名、存档时间、描述摘要以及对应的 GitHub 链接。

例如，第一次调用时 Bot 会回复类似如下的内容：

> 📂 历史存档 (第 1/2 页, 共 14 条)
> sharkdp/bat · 2026-08-30
> 📝 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。
> https://...

消息末尾的 `(第 1/2 页, 共 14 条)` 表示当前位于第 1 页，共 2 页，总计 14 条存档。

![第一页存档列表展示效果](assets/04-archive-r1.png)

### 步骤 2：阅读当前页内容

在 Bot 回复的消息下方，可以直接看到当前页内的所有存档条目。每条记录通常包含以下几个字段：

- **仓库名称**：格式为 `owner/repo`，例如 `sharkdp/bat`；
- **存档时间**：标准的 ISO 时间戳，如 `2026-08-30T083000`；
- **描述摘要**：以 📝 开头的简要说明，简要介绍仓库内容或亮点；
- **标签**：以 🏷 开头的关键词，便于按主题筛选，例如 `#demo`；
- **跳转链接**：一条指向 GitHub 仓库或具体存档页面的 URL，点击即可在浏览器中打开。

如果当前页只有一条或少数几条记录，可继续向下阅读 Bot 输出的全部文本，每条记录以换行分隔。

### 步骤 3：翻页查看更多存档

当 Bot 提示 `(第 1/2 页)` 时，说明还有下一页内容。Bot 会同时在消息下方附带一个 inline keyboard，其中包含两个按钮：

- ◀️ **上一页**：在当前页 > 1 时可点击；
- ▶️ **下一页**：在当前页 < 总页数时可点击。

点击 ▶️ 按钮（例如按钮文字显示为 `arch:pg:1`，代表跳转到第 1 页索引对应的下一页），Bot 会立即返回下一页的内容。

例如第二次点击翻页按钮后，Bot 会返回：

> 📂 历史存档 (第 2/2 页, 共 14 条)
> demo/repo-02 · 2026-08-30T083000
> 📝 demo/repo-02 的中文摘要示例。
> 🏷 #demo
> https://...

此时标题变为 `(第 2/2 页)`，表示已经是最后一页。

![第二页存档列表展示效果](assets/04-archive-r2.png)

### 步骤 4：点击条目链接跳转到 GitHub

每条存档描述下方都附带一个可点击的 URL 链接，通常指向该仓库的 GitHub 页面或对应的 commit / archive 地址。在 Telegram 中点击该链接，会调用系统默认浏览器打开对应页面，方便你直接查看源码、README 或历史快照。

如果是群组场景，该链接同样可点击，所有成员都能直接跳转，无需 Bot 额外转发。

### 小贴士

- 翻页按钮上的 `arch:pg:N` 是 Bot 自定义的回调标识，N 为页码索引，含义是“跳到第 N 页对应的下一页”，你可以放心多次点击直到看到 `(第 N/N 页)`。
- 当总条数为 0 或单页可全部展示时，Bot 不会附带翻页按钮，直接显示全部存档。
- 若某条存档的描述或链接显示不全，多半是 Telegram 消息长度限制所致，可以翻到对应页后通过点击 URL 在浏览器中查看完整内容。
