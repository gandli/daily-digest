## /archive — 历史存档浏览（分页交互）

`/archive` 命令用于打开历史存档列表,Bot 会将最近的存档条目按页呈现,并通过 inline keyboard 提供分页与跳转功能。每次最多展示一页条目,可通过 ◀️ / ▶️ 按钮在页码之间切换;点击具体条目后会跳转到对应的存档详情(通常是一条包含链接的存档消息)。

### 步骤 1:发送命令打开历史存档列表

在聊天窗口中输入 `/archive` 并发送。Bot 接收到命令后会立即检索最近的存档记录,并以一条带 inline keyboard 的消息作为回复:

> 📂 历史存档 (第 1/2 页, 共 14 条) sharkdp/bat · 2026-08-30 📝 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 …

消息首行展示当前页码与总条目数,便于用户判断列表规模;其后依次列出当前页内的存档条目,每条包含仓库名、归档日期、摘要以及跳转链接。

![第 1 页历史存档列表](assets/04-archive-r1.png)

### 步骤 2:点击 ◀️ 或 ▶️ 按钮翻页

当列表跨越多页时,inline keyboard 会显示翻页按钮。点击 `arch:pg:1`(即 ▶️,前往第 2 页)后,Bot 会就地编辑原消息,将内容替换为下一页的条目:

> 📂 历史存档 (第 2/2 页, 共 14 条) demo/repo-02 · 2026-08-30T083000 📝 demo/repo-02 的中文摘要示例。 🏷 #demo …

用户可以继续点击 ◀️ 回到上一页,或在到达边界页时看到按钮自动禁用。整个翻页过程不会产生新消息,保持对话整洁。

![第 2 页历史存档列表](assets/04-archive-r2.png)

### 步骤 3:点击条目跳转到详情

在任意一页中,每条存档都附带一个跳转链接(对话记录中以 `<a href="…">` 形式呈现)。点击该链接即可跳转到该存档的原始消息,查看完整内容或继续操作(如分享、收藏)。

---

**小贴士**

- 翻页按钮以 `arch:pg:N` 形式标记页码,即使键盘渲染异常,只要回调数据正常即可工作;若按钮长时间不变化,可尝试重新发送 `/archive` 刷新列表。
- 首行的 `共 N 条` 直接反映存档总量,据此可估算需要翻几页;若总量较大,可考虑结合 Bot 的搜索或筛选功能定位具体条目。
- 列表就地更新机制意味着旧页内容会被新页替换,如需保留某一页内容,请提前截图或点击条目跳转到详情后再返回。
