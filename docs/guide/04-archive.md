### 步骤 1：发送 /archive 命令

在 Telegram 对话框中输入 `/archive` 并发送，Bot 会立即拉取最近存档的首页内容，并以 inline keyboard 的形式呈现分页控件。

Bot 的回复格式如下：

```
📂 历史存档 (第 1/2 页, 共 14 条)

1. sharkdp/bat · 2026-09-01
   📝 这个仓库实现了经典的文本编辑器，代码精炼，适合学习 C 语言。
   🔗 https://…
   🏷 #cli #tool

[ ◀️ ]  [ ▶️ arch:pg:1 ]
```

信息区会展示当前页码 `1/2` 与总条目数 `共 14 条`，每个存档条目包含仓库名、收录日期、中文摘要、链接和标签。键盘下方会显示翻页按钮 `◀️` 与 `▶️`，后者带有回调数据 `arch:pg:1`，表示「前往下一页」。

![首次调用 /archive，展示首页条目与翻页按钮](assets/04-archive-r1.png)

### 步骤 2：点击 ▶️ 翻到第二页

直接在 Telegram 消息上点击 `▶️` 按钮（无需再次输入命令），Bot 会识别回调 `arch:pg:1` 并返回第 2 页内容，页码更新为 `2/2`。

Bot 的回复格式如下：

```
📂 历史存档 (第 2/2 页, 共 14 条)

2. demo/repo-02 · 2026-09-01T08:30:00
   📝 demo/repo-02 的中文摘要示例。
   🔗 https://…
   🏷 #demo

[ ◀️ arch:pg:0 ]  [ ▶️ ]
```

此时左侧 `◀️` 按钮的回调数据变为 `arch:pg:0`，右侧 `▶️` 因已到末页而不再可点。

![点击 ▶️ 后切换到第 2 页，按钮状态互换](assets/04-archive-r2.png)

### 步骤 3：点击条目链接查看详情

列表中每条存档下方的 `🔗 https://…` 链接即为该仓库的原始地址。点击链接会跳转到浏览器或 Telegram 内置预览，方便查看完整 README、源码或外部存档页面。点击链接不会触发 Bot 命令，可放心操作。

### 小贴士

- 如果 `▶️` 按钮呈灰色不可点，说明已经到达最后一页，此时改用 `◀️` 返回上一页即可。
- Bot 在每页只展示有限条目，分页是为了让你能快速浏览；若想查找特定仓库，可结合筛选命令配合 `/archive` 使用。
- 翻页按钮的回调数据遵循 `arch:pg:N` 规律（N 从 0 开始），但请勿手动构造或转发按钮——始终通过 Bot 自身渲染的键盘交互，才能保证状态一致。
