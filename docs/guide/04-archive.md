# /archive — 历史存档浏览（分页交互）

通过 `/archive` 命令可以浏览 Bot 记录的所有历史存档，Bot 会以分页形式展示存档列表，并提供 inline keyboard 进行翻页和条目跳转。

### 步骤 1: 发送 /archive 命令

在聊天窗口中输入 `/archive` 并发送，Bot 会立即返回最近存档列表的第一页内容，包含当页条目摘要与翻页按钮。

![archive 第一页列表](assets/04-archive-r1.png)

如对话记录所示，Bot 的回复类似：

> 📂 历史存档 (第 1/2 页, 共 14 条)
> sharkdp/bat · 2026-08-30
> 📝 这个仓库实现了经典的文本编辑器，代码精炼，适合学习 C 语言。
> <a href="https://…">…

消息标题中明确标注了当前页码（`第 1/2 页`）与总条目数（`共 14 条`），每条存档下方附有该仓库的简介与对应链接。

### 步骤 2: 点击翻页按钮浏览下一页

消息下方附有 inline keyboard，包含 ◀️ 与 ▶️ 等翻页按钮。点击 **▶️**（对应按钮数据 `arch:pg:1`）即可加载下一页。

![archive 翻页到第二页](assets/04-archive-r2.png)

Bot 会返回新一页内容：

> 📂 历史存档 (第 2/2 页, 共 14 条)
> demo/repo-02 · 2026-08-30T08:30:00
> 📝 demo/repo-02 的中文摘要示例。
> 🏷 #demo
> <a href="h…

翻页时 `第 X/Y 页` 中的 X 会同步更新，方便确认浏览进度。

### 步骤 3: 查看条目详情或返回上一页

在列表中，每条存档标题下方的摘要链接可直接点击跳转至对应 GitHub 仓库。若需返回上一页，点击 **◀️** 按钮即可；若已翻到最后一页，按钮状态会相应变化（如 ▶️ 变为不可用）。

### 小贴士

- 翻页按钮的数据格式为 `arch:pg:N`（N 为页码索引，从 0 开始），若列表较长可通过连续点击快速定位到目标条目所在页。
- 每条存档的发布时间支持 `YYYY-MM-DD` 与 `YYYY-MM-DDTHHMMSS` 两种格式，时间精度更高的条目通常代表完整提交记录。
- 若 `/archive` 返回的列表为空，说明 Bot 尚未记录任何存档，需先通过 `/add` 或 `/watch` 等命令添加仓库后再来浏览。
