### 步骤 1：发送 `/archive` 命令

在 Telegram 对话框中输入 `/archive` 并发送。Bot 收到指令后会查询数据库中的历史存档记录，并以分页形式返回第一页内容。返回的消息包含：当前页码（"第 1/2 页"）、总条目数（"共 14 条"）、每条存档的仓库名称、收录时间、摘要文本，以及跳转链接。消息底部附带 inline keyboard，包含翻页按钮（◀️ 1/2 ▶️），中间数字显示当前页码。

![首次调用 /archive，返回第一页存档列表与翻页按钮](assets/04-archive-r1.png)

### 步骤 2：点击翻页按钮浏览下一页

查看第一页内容后，如果想看更多存档，可以直接点击消息下方的 `▶️` 按钮。点击后，Bot 会即时渲染第二页内容，无需重新输入命令。返回的消息格式与第一页一致，包含页码标识（"第 2/2 页"）、条目详情以及翻页按钮（此时显示为 `◀️ 2/2`，因为已经到最后一页，所以 `▶️` 按钮会变为不可用状态或自动隐藏）。

![点击翻页按钮后，Bot 返回第二页存档内容](assets/04-archive-r2.png)

### 步骤 3：点击具体存档条目跳转

在每一页的列表中，每条存档都附带了对应的链接（例如指向 GitHub 仓库或归档详情的 URL）。点击该链接即可在浏览器中打开，查看完整的仓库信息或原始内容。inline keyboard 的 `arch:pg:1` 按钮用于翻页控制，而条目本身的链接则用于内容跳转，两者互不干扰。

### 小贴士

- 翻页操作通过 inline keyboard 按钮完成，所有交互都在同一条消息内进行，不会产生新消息刷屏，便于回溯历史。
- 当前实现每页固定显示 7 条记录，共 14 条存档会分为 2 页显示；如果未来存档数量增加，页码会自动扩展。
- 当处于最后一页时，`▶️` 按钮不再显示或不可点击，无需担心误操作；如需快速回到第一页，可重新发送 `/archive` 命令。
