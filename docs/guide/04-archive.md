## /archive — 历史存档浏览（分页交互）

`/archive` 命令用于浏览你此前收藏过的所有仓库存档。Bot 会以列表形式分页展示，每页 5 条；通过 inline keyboard 上的翻页按钮，你可以快速在页码之间切换。点击列表中的任意条目，Bot 会跳转到该存档的详情视图（即 `/view` 的等价页面）。

### 步骤 1: 发送 `/archive` 命令

在聊天窗口中输入 `/archive` 并发送，Bot 即会拉取你的存档数据库并返回第一页内容。

- **Bot 回复**：📂 历史存档 (第 1/2 页, 共 14 条) sharkdp/bat · 2026-08-30 📝 这个仓库实现了经典的文本编辑器, 代码精炼, 适合学习 C 语言。 <a href="https://... — 消息下方附带一个 inline keyboard，包含 ◀️ 与 ▶️ 翻页按钮，以及若干条形如 `arch:item:<id>` 的条目按钮。

![第一页存档列表](assets/04-archive-r1.png)

### 步骤 2: 翻到下一页

当你浏览完第一页、希望查看后续存档时，点击 inline keyboard 中的 ▶️ 按钮（或等效的 `arch:pg:1` 回调按钮），Bot 会读取下一页数据并替换原消息。

- **Bot 回复**：📂 历史存档 (第 2/2 页, 共 14 条) demo/repo-02 · 2026-08-30T08:30:00 📝 demo/repo-02 的中文摘要示例。 🏷 #demo <a href="h… — 消息内容与按钮整体刷新，翻页按钮变为 ◀️（以及在已是末页时 ▶️ 变灰或隐藏）。

![第二页存档列表](assets/04-archive-r2.png)

### 步骤 3: 切换回上一页或结束浏览

若想返回第一页，点击 ◀️ 即可；想浏览某条存档的完整信息，则直接点击该条目对应的按钮 `arch:item:<id>`，Bot 会以 `/view` 等价形式呈现仓库的完整摘要、标签与链接。

### 小贴士

- 当总条目数为 0 时，Bot 会返回空状态提示，不会渲染翻页按钮；此时可使用 `/add` 先收藏若干仓库再回来浏览。
- 翻页按钮通过 `arch:pg:<n>` 标识当前页码，连续点击同一方向按钮可快速到达首末页。
- inline keyboard 的按钮是一次性的：若消息刷新较慢，请等待 Bot 的“编辑消息”提示出现后再继续点击，避免重复触发。
