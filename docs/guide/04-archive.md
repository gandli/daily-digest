## /archive — 历史存档浏览（分页交互）

通过 `/archive` 命令可调取 Bot 历史上为你保存的所有仓库存档,系统以分页形式呈现,每页展示若干条存档摘要,并在消息下方附带 inline keyboard 用于翻页与跳转。

### 步骤 1: 发起存档浏览

在任意与 Bot 的私聊或群组对话中,输入命令:

```
/archive
```

Bot 会立即拉取你的存档列表,并回复一条带 inline keyboard 的消息。消息正文包含以下要素:

- 页码标识,如 `第 1/2 页, 共 14 条`,告知当前页数与总条目数;
- 若干条存档摘要,每条包含:仓库名(如 `sharkdp/bat`)、收录日期、摘要文本(以 📝 引导)、话题标签(以 🏷 引导,如有)以及对应 GitHub 链接。

消息下方会出现一组可点击按钮,通常包括:

- `◀️` `▶️`:上一页 / 下一页翻页按钮;
- 每条存档对应的跳转按钮(如 `arch:open:<id>`),点击后 Bot 会发送该条存档的完整详情。

初次执行后效果如下:

![发送 /archive 后 Bot 返回第一页存档列表](assets/04-archive-r1.png)

### 步骤 2: 翻页查看后续存档

若首页未能展示全部存档,可点击消息底部的 `▶️` 按钮(后端回调为 `arch:pg:1`,表示前往页码 1,采用 0-based 索引),Bot 会立刻刷新消息内容,渲染下一页存档摘要,并更新页码标识(如变为 `第 2/2 页`)。

翻页后,顶部按钮自动切换为 `◀️`,方便你随时回到上一页:

![点击翻页按钮后 Bot 返回第二页存档列表](assets/04-archive-r2.png)

### 步骤 3: 查看单条存档(可选)

如想了解某一条存档的完整内容,可在消息中直接点击该条目对应的 inline 按钮(如 `arch:open:<id>`),Bot 会回复该条存档的完整详情,通常包括完整的摘要、标签、原始链接以及保存时间。

## 小贴士

- **页码与总条数会随存档增长自动变化**,首次使用时若只看到 `第 1/N 页`,可大胆点击 `▶️` 浏览其余分页,无需担心遗漏。
- **inline button 的回调标识仅供 Bot 内部识别**(如 `arch:pg:1`、`arch:open:<id>`),正常点击即可,不要手动复制或转发,否则无法触发正确响应。
- **若列表为空或仅有 1 页**,Bot 将不会渲染 `◀️` `▶️` 按钮,此时无需翻页操作,直接点击条目按钮即可查看详情。
