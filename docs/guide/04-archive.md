## /archive — 历史存档浏览（分页交互）

`/archive` 命令用于浏览 Bot 中已保存的历史存档。Bot 会以分页形式呈现列表，每页包含若干条存档摘要，每条摘要附带对应的 GitHub 链接；列表底部提供内联键盘翻页按钮，方便用户快速在页与页之间切换。

### 步骤 1：发送 /archive 命令

在 Telegram 对话中输入 `/archive` 并发送。Bot 接收到命令后，会立即返回最近存档的第 1 页内容，消息包含页码标识、当前页条目数以及每条存档的仓库名、日期、摘要和 GitHub 链接。例如第 1 页会显示诸如 "📂 历史存档 (第 1/2 页, 共 14 条)" 的标题，列出第一条存档 "sharkdp/bat · 2026-08-30" 及其简介与链接。

![第 1 页：Bot 返回首屏存档列表](assets/04-archive-r1.png)

### 步骤 2：点击 ▶️ 按钮翻到下一页

在 Bot 返回的消息底部，找到内联键盘中的 `▶️` 按钮并点击，Bot 会将列表切换到下一页内容，更新页码标识（例如变为 "第 2/2 页"），并展示该页对应的存档条目，例如 "demo/repo-02 · 2026-08-30T083000" 及其摘要、标签和链接。已到达最后一页时，▶️ 按钮通常会变为不可用状态。

![第 2 页：点击 ▶️ 后 Bot 返回第二屏存档](assets/04-archive-r2.png)

### 步骤 3：点击 ◀️ 按钮返回上一页

若需要回看上一页内容，点击消息底部的 `◀️` 按钮，Bot 会再次将列表切换回对应页码（例如从第 2 页返回第 1 页），消息内容与首次访问该页时保持一致。位于第 1 页时，◀️ 按钮通常为不可用状态。

### 步骤 4：点击条目中的链接查看详情

每条存档摘要中都包含一个指向 GitHub 仓库的链接（以 `<a href="..."` 形式呈现）。点击该链接，浏览器或 Telegram 内置预览将打开对应的仓库页面，便于进一步阅读代码、查看 Star 数或克隆项目。

### 小贴士

- **翻页节奏**：当总条目数较多时（如超过 10 条），Bot 会自动分多页显示，使用 ▶️ / ◀️ 按钮逐页浏览比重新发送 `/archive` 更高效。
- **链接点击**：摘要中的 GitHub 链接为完整的可点击锚点，无需手动复制地址，直接点击即可跳转。
- **末页识别**：当页码显示为 "第 N/N 页"（即页码等于总页数）时，▶️ 按钮会变为失效状态，此时若想回到首页可连续点击 ◀️ 按钮逐页返回。
