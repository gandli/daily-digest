# /archive — 历史存档浏览（分页交互）

通过 `/archive` 命令可以查看历史存档列表,Bot 会以分页形式返回最近保存的仓库摘要,并在每条消息底部附带 inline keyboard 翻页按钮,点选条目即可跳转到对应存档的完整内容。

### 步骤 1:发送 /archive 命令

在聊天窗口中输入 `/archive` 并发送,Bot 会立即返回最近存档的第一页,消息正文包含当前页码、总页数以及当页的存档条目(每条含仓库名、收录时间和一段中文摘要),并附上外链。消息底部会出现翻页按钮 `◀️` 和 `▶️`,点击 `▶️` 即可进入下一页。

![第 1 页存档列表](assets/04-archive-r1.png)

### 步骤 2:点击 `▶️` 翻到下一页

消息底部 inline keyboard 中的按钮以 `arch:pg:1` 形式标识页码(数字代表目标页)。在第 1 页状态下点击 `▶️`,Bot 会返回第 2 页内容,页码更新为 `2/2`,展示后续存档条目(含 demo/repo-02 等仓库的摘要、收录时间与 `#demo` 等标签)。

![第 2 页存档列表](assets/04-archive-r2.png)

### 步骤 3:查看单条存档详情

在列表消息中点选任意一条存档的摘要文本或对应链接,Bot 会跳转到该存档的完整详情页,展示仓库完整描述、原始链接及更多上下文信息。

### 步骤 4:继续翻页或返回

若需再次切换页面,继续点击消息底部的 `◀️` / `▶️` 按钮;若已回到首页或末页,对应方向的按钮会变为不可点击状态。`/archive` 会始终保持每页固定条数,本次共 14 条分为 2 页显示。

## 小贴士

- 当存档超过单页容量时,翻页按钮才会显示;若总数较少,只会看到列表而没有 `◀️` / `▶️`。
- `arch:pg:N` 中的 N 是目标页码(从 0 开始),首尾页对应方向的按钮会自动禁用,无需担心越界。
- 想快速回到第一页,可直接重新发送 `/archive` 命令,Bot 会重置到首页并返回最新数据。
