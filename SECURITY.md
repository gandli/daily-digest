# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Contact [@gandli](https://github.com/gandli) directly via GitHub Issues with a clear description of the issue. Do not include exploit code in the initial report.

## Scope

- Telegram bot token leakage
- GitHub token / API key exposure
- SSRF / credential injection in archive/lookup paths
- XSS via user-supplied content rendered in Telegram messages

## Response

I aim to acknowledge reports within 48 hours and fix confirmed vulnerabilities within 7 days.
